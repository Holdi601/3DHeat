# Référence

Listes de noms exacts, de réglages et d'outils, pour y chercher des informations. Vous n'avez pas besoin de les lire pour utiliser la visionneuse.

Ces listes sont générées à partir du code de la visionneuse par `node tools/docs-refs.mjs` (vous n'avez pas besoin de le lancer), si bien qu'elles correspondent toujours à la version avec laquelle elles ont été faites :

- [Types d'événements et classes](ref-event-types.md) — les sortes d'événements et les classes de véhicules dans lesquelles chaque jeu de données est rangé, et les mots des données qui correspondent à chacune
- [Noms de colonnes](ref-columns.md) — les noms de colonnes que le chargeur reconnaît pour la position, le temps, la personne, l'équipe, la session et la direction du regard
- [Liste des langues](ref-languages.md) — les langues de la visionneuse
- [Touches du navigateur](ref-browser-keys.md) — les raccourcis du navigateur que la visionneuse garde pour elle
- [Réglages enregistrés](ref-settings-storage.md) — ce que le navigateur retient d'une visite à l'autre
- [Tables de valeurs](ref-value-tables.md) — les tables de prix de la pondération des valeurs
- [Outils en ligne de commande](ref-tools.md) — les outils de `tools/` : pour vos données, et pour les développeurs et la documentation

Aussi de la référence, et le [Glossaire](glossary.md) pour les mots utilisés sur ce site. Écrits à la main : [Formats de données](data-formats.md), [Référence clavier et souris](keyboard-reference.md), [Un fichier par match (.3dheat)](container.md).
