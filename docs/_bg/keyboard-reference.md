# Справка за клавиатурата и мишката

Всяко клавиш и действие с мишката на едно място, за да намерите това, което ви трябва. Първо щракнете върху изгледа, за да получи клавиатурата. Клавишите се игнорират, докато текстово поле или падащ списък има фокус. Кратката версия е изписана и в долния ляв ъгъл на изгледа.

Бърз справочник:

| Искам да ... | Натиснете |
|---|---|
| летя | `W A S D`, влачете, за да гледате |
| видя всичко | `F` |
| пусна или паузирам | `K` |
| пусна назад | `J` (натиснете отново за пауза), напред `L` |
| видя какво означават цветовете | `?` или `F1` |
| отменя в раздела Тактика | `Ctrl+Z` |

## Камера {#camera}

От [`camera.ts`](https://github.com/Holdi601/3DHeat/blob/main/src/render/camera.ts).

| Вход | Действие |
|---|---|
| `W` / `↑` | Напред по посоката на гледане |
| `S` / `↓` | Назад |
| `A` / `←` | Странично наляво |
| `D` / `→` | Странично надясно |
| `Space` / `E` | Нагоре |
| `Q` / ляв `Ctrl` | Надолу |
| `Shift` (кой да е) | Задържане: 6× скорост |
| ляв `Alt` | Задържане: 15% скорост |
| Ляво или дясно влачене върху изгледа | Оглеждане (показалецът е заключен, докато бутонът е натиснат) |
| Колелце (перспектива) | Скорост на полета ×1,5 на щрак (най-много 4 щрака на събитие от колелцето) |
| Колелце (успоредна) | Мащабиране |
| Десен бутон | Над изгледа не се отваря контекстно меню |

## Общи {#global}

От [`App.tsx`](https://github.com/Holdi601/3DHeat/blob/main/src/App.tsx).

| Клавиш | Действие |
|---|---|
| `K` | Пуска / паузира [времевата линия](timeline.md) |
| `F` | Показва всички данни в кадър |
| `C` | Копира позицията на камерата, yaw и pitch ([отчитане на камерата](camera.md#camera-readout)) |
| `G` | Отива към написана точка: отваря полето под отчитането на камерата |
| `Esc` | Затваря картата на избора; после спира да гледа втората единица; после спира да следва единица |
| `T` | Включва или изключва тактическия изглед ([Разбор на мач](match-replay.md#display-style)) |
| `?` / `F1` | Режим на помощ: какво означават цветовете ([Настройки, единици и клавиши](settings.md#help-mode)) |
| `1` | [Топлина](heat.md) |
| `2` | [Разлика](difference.md) |
| `3` | [Топлина по отбори](team-heat.md) |
| `4` | [Линии](line-heat.md) |
| `]` | Външната граница на отсичането по разстояние се отдалечава ×1,12 (`Shift`: ×1,35) |
| `[` | Външната граница на отсичането по разстояние се приближава ÷1,12 (`Shift`: ÷1,35) |
| `\` | Външната граница се изключва / връща на мястото, където е била ([Дълбочина и отрязване](depth-and-culling.md#keyboard)) |

Режимът **Наслагване на фигури** няма числов клавиш; изберете го от лентата с режими или отворете раздела Мач. Числовите клавиши минават през същата проверка като лентата с режими: клавиш за режим, който лентата показва като недостъпен за заредените данни, не прави нищо.

## Разбор на мач {#match-replay}

В режима Наслагване на фигури, който използва разделът Мач ([Разбор на мач](match-replay.md)). Работят, независимо дали единица се следва, или не, освен където е отбелязано:

| Клавиш | Действие |
|---|---|
| `B` | Добавя отметка: момента и камерата |
| `M` | 2D карта: ъгъл, цял изглед, изключено |
| `V` / `Shift+V` | Следващ / предишен изглед от камерата на следваната единица |
| `H` | Индикатори на екрана (head-up) в кабината и при захвата |
| `Page Down` / `Page Up` | Следващо / предишно събитие от видовете, които показва списъкът със събития |
| `J` | Пуска назад; отново - пауза |
| `L` | Пуска напред; отново - пауза |
| `.` / `,` | Една секунда напред / назад, на пауза (`Shift`: десет секунди) |
| `Esc` | Първо спира да гледа целта, после спира да следва |
| `Ctrl`+щракване или `Alt`+щракване върху единица (в изгледа или в списъка с единици) | Гледа я от следваната единица (изгледът с две единици); щракнете отново, за да я махнете |
| `Shift`+щракване върху две единици | Измерва между тях: азимут, разстояние, разлика във височината |

`V` изисква следвана единица. Тук `M` е 2D картата, а в раздела Тактика „преместване“.

## Следване на единица {#following-a-unit}

Докато камерата следва единица, колелцето и клавишите за полет се движат около единицата, вместо да летят свободно ([Камера](camera.md#while-following-a-unit)):

| Вход | Действие |
|---|---|
| Колелце, `W` / `S` | По-близо / по-далеч (по-високо / по-ниско в сателитния изглед). Не в кабината и при захвата. |
| `A` / `D`, `Q` / `E` | Орбитира около единицата (изгледи отзад и орбита) |
| Влачене | Оглежда се около единицата; в кабината - оглежда се вътре |
| `V` / `Shift+V` | Следващ / предишен изглед от камерата |
| `H` | Индикатори на екрана (кабина и захват) |
| `Esc` | Спира да гледа втората единица, после спира да следва |

## Тактическа дъска {#tactics-board}

В раздела Тактика ([Тактическа дъска](tactics-board.md)). `F`, `C`, `G` и `T` работят както по-горе; числовите клавиши не правят нищо.

| Клавиш | Действие |
|---|---|
| `Ctrl+Z` | Отмяна |
| `Ctrl+Y` или `Ctrl+Shift+Z` | Възстановяване |
| `Enter` | Завършва стрелката, която се чертае (същото правят двойно щракване или десен бутон) |
| `Esc` | Отказва влачене; иначе пуска стрелката или движението в ход; иначе премахва селекцията |
| `Delete` или `Backspace` | Изтрива избраното |
| `W` / `E` / `R` | Инструмент Преместване / Завъртане / Мащабиране за избраното (схема **W / E / R**) |
| `G` / `R` / `S` | Инструмент Преместване / Завъртане / Мащабиране за избраното (схема **G / R / S**) |
| `R` | Без избрано: завърта следващата фигура за поставяне с 15°. `Shift+R` я връща. |
| `M` | При избрана фигура: я премества към следващото щракване |
| `K` | Пуска или паузира плана |
| Shift+щракване | Добавя към селекцията или я маха от нея |
| Shift+влачене | Чертае правоъгълник около това, което да се избере |
| `Ctrl` докато влачите манипулатор | Прилепва към мрежата или към стъпката на ъгъла |

Клавишите на инструментите работят само когато нещо е избрано; когато нищо не е избрано, `W A S D` управляват камерата както обикновено.

## Избор с щракване {#click-to-pick}

Когато **Щракването показва какво има там** е включено и линийката е изключена ([Избор с щракване](camera.md#click-to-pick)):

| Вход | Действие |
|---|---|
| Ляво щракване (без влачене над 4 px) | Показва точката с данни или, ако няма такава, мястото на нивото под показалеца |

## Мярка {#measure}

Когато **Линийката е активна** ([Мярка](measure.md)):

| Вход | Действие |
|---|---|
| Ляво щракване (без влачене над 4 px) | Поставя точка |
| Десен бутон | Премахва последната точка |

## Други места {#elsewhere}

| Къде | Вход | Действие |
|---|---|---|
| Дръжката на всеки плъзгач (до числото) | Влачене нагоре / надолу | Променя стойността плавно, по-бързо колкото по-далеч влачите; дръжте `Shift` за фина настройка. Пуснете, за да спрете. |
| Показването на скоростта върху изгледа | Влачене нагоре / надолу | Променя скоростта на полета по същия начин. |
| Полетата за положение | `Enter` | Прилага написаното положение или ориентация. |
| Редактор на крива | Двойно щракване / Alt-щракване / десен бутон | Добавя точка / премахва точка ([Форма на спрайта](sprite-shape.md#the-curve-editor)). |

## Раздел Състезателен анализ {#race-analysis-tab}

В раздела Състезателен анализ `K` пуска и паузира повторението на състезанието, `Home` го връща в началото, а числовите клавиши не правят нищо. Виж [Състезателен анализ](race-analysis.md).

## Клавишите, които визуализаторът запазва от браузъра {#keys-the-viewer-keeps-from-the-browser}

Някои клавишни комбинации на браузъра биха затворили или презаредили страницата и биха загубили заредената сесия; визуализаторът ги запазва за себе си. Списъкът се генерира от кода: [Клавиши в браузъра](ref-browser-keys.md).
