# Reference

Lists of exact names, settings and tools, to look things up in. You do not need to read them to use the viewer.

These lists are generated from the viewer's code by `node tools/docs-refs.mjs` (you do not need to run it), so they always match the version they were made with:

- [Event types and classes](ref-event-types.md) - the event kinds and vehicle classes every dataset is sorted into, and which words in the data map to them
- [Column names](ref-columns.md) - the column names the loader recognises for position, time, person, team, session and look direction
- [Language list](ref-languages.md) - the viewer's languages
- [Browser keys](ref-browser-keys.md) - browser shortcuts the viewer keeps for itself
- [Stored settings](ref-settings-storage.md) - what the browser remembers between visits
- [Value tables](ref-value-tables.md) - the price tables of value weighting
- [Command-line tools](ref-tools.md) - the tools in `tools/`: for your data, and for developers and the docs

Also reference, and the [Glossary](glossary.md) for the words used on this site. Written by hand: [Data formats](data-formats.md), [Keyboard and mouse reference](keyboard-reference.md), [One file a match (.3dheat)](container.md).
