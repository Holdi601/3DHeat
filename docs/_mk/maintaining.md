# Одржување на документацијата

Оваа страница е за оној што ги одржува прегледувачот и овој сајт. Ги наведува чекорите за да страниците, сликите и преводите остануваат точни по промена.

Сајтот се проверува повторно при **секое издание** и кога нешто се менува многу: кратенки на тастатурата, патот низ корисничкиот интерфејс, поставки, формати на датотеки. Контролната листа:

1. **Регенерирајте ги референтните страници**: `node tools/docs-refs.mjs` (и `--lang <lang>` за секој јазик). `node tools/docs-refs.mjs --check` паѓа кога страница е застарена.
2. **Регенерирајте ги снимките од екранот** од [демо податоците](demo-data.md). Користете компјутер или контејнер чиј регион е en-US, за бројките да се читаат како `0.35` и не како `0,35` (полињата за броеви го следат регионот на прелистувачот додека не се смени). Направете ги демо податоците со `node tools/demo-data.mjs`, стартувајте развоен сервер на порта 5321 **без** локален пакет фигури, `HEAT3D_FIGURE_PACK=none npx vite --port 5321 --strictPort --host 127.0.0.1`, па извршете `node tools/docs-shots.mjs --lang <lang>`. Погледнете ја секоја слика: само демо имиња (*Demo Valley*, *Blue 1*, *Red 3* ...), без вистински мапи, играчи или записи.
3. **Наведете што се променило** од последната ознака на издание: `git log --oneline <last tag>..HEAD`, и делот **Docs** од `CHANGELOG.md`, кој секоја функција ја поврзува со својата страница. Секоја нова функција треба страница или дел, со слика каде се гледа на екранот.
4. **Независен преглед** на англиските страници од некој што не ги напишал, за три читатели: почетник, осумгодишно дете, експерт. Се комплетни и во вистински редослед чекорите, дали зборовите се оние на корисничкиот интерфејс, дали сликите се тековни, дали ознаките на дијаграмите се точни?
5. **Поправете го она што го најде прегледот.**
6. **Повторно преведете ги променетите страници** според нивниот хеш на изворот, па извршете преглед по јазик. Видете `tools/docs-translate.md`.
7. **Проверете за доверливи термини** во променетите датотеки, и проверете дека ниедна слика не покажува ништо освен демо податоци.
8. **Објавете** само кога издавањето е одобрено.

Истата проверка ги опфаќа и страниците со документација на поврзаните репозиториуми (видете ја страницата [Почетна](index.md#related-repositories)).

## Алатките под exporters/ {#the-tools-under-exporters}

Алатките околу прегледувачот се посебни јавни проекти, секој со своја MIT лиценца, издавања, вики и проверка за ажурирање, закачени во овој репозиториум како git submodules:

| Папка | Репозиториум |
|---|---|
| `exporters/gamefiles/` | [3DHeat-GameFiles](https://github.com/Holdi601/3DHeat-GameFiles) - патеки и нива од архивите на самите игри |
| `exporters/gamecapture/` | [3DHeat-GameCapture](https://github.com/Holdi601/3DHeat-GameCapture) - снимачи на телеметрија од кругови; нива од снимки на игра |
| `exporters/unreal/` | [3DHeat-UnrealExporter](https://github.com/Holdi601/3DHeat-UnrealExporter) - додаток за Unreal Editor |
| `exporters/cs2/` | [3DHeat-CS2](https://github.com/Holdi601/3DHeat-CS2) - демоа и мапи од CS2 |
| `exporters/watcher/` | [3DHeat-Watcher](https://github.com/Holdi601/3DHeat-Watcher) - ја снима играта во позадина |

**Закачено** значи дека овој репозиториум го бележи точно еден точен commit на секоја алатка. Работната копија на прегледувачот ги добива тие commit-и:

```bash
git clone --recursive https://github.com/Holdi601/3DHeat
# or, after a plain clone:
git submodule update --init
```

И двата начини на ажурирање погоре извршуваат `git submodule update --init` по повлекувањето, па алатките ги следат commit-ите што најновата верзија на прегледувачот ги закачува - а не најновите commit-и на самите алатки. Новото издание на алатка стигнува до прегледувачот кога ќе се помести закачувањето овде: промените на алатката се commit-ираат и се испраќаат најпрво во нејзината папка (нејзиниот сопствен репозиториум), а потоа новото закачување се commit-ира овде. Секоја алатка исто така проверува за свои понови издании; тоа е документирано во нејзиниот сопствен репозиториум.
