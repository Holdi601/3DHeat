# Референца за тастатура и глушец

Секое копче и секое дејство со глушец на едно место, за да го најдете она што ви треба. Прво кликнете на приказот, за да ја добие тастатурата. Копчињата се игнорираат додека текстуалното поле или паѓачката листа има фокус. Кратката верзија е испечатена и долу лево во приказот.

Брзо барање:

| Сакам да ... | Притиснете |
|---|---|
| летам | `W A S D`, влечете за да гледате |
| видам сè | `F` |
| пуштам или паузирам | `K` |
| пуштам наназад | `J` (притиснете повторно за пауза), напред `L` |
| видам што значат боите | `?` или `F1` |
| поништам во табот Тактика | `Ctrl+Z` |

## Камера {#camera}

Од [`camera.ts`](https://github.com/Holdi601/3DHeat/blob/main/src/render/camera.ts).

| Влез | Дејство |
|---|---|
| `W` / `↑` | Напред по насоката на гледање |
| `S` / `↓` | Назад |
| `A` / `←` | Странично лево |
| `D` / `→` | Странично десно |
| `Space` / `E` | Нагоре |
| `Q` / лев `Ctrl` | Надолу |
| `Shift` (кој и да е) | Држете: 6× побрзо |
| лев `Alt` | Држете: 15% од брзината |
| Лево или десно влечење на приказот | Гледање (покажувачот е заклучен додека копчето е притиснато) |
| Тркало (перспектива) | Брзината на летање ×1,5 по вжлеб (најмногу 4 вжлеба по еден настан на тркалото) |
| Тркало (паралелна проекција) | Зум |
| Десен клик | Над приказот не се отвора контекстуално мени |

## Глобално {#global}

Од [`App.tsx`](https://github.com/Holdi601/3DHeat/blob/main/src/App.tsx).

| Копче | Дејство |
|---|---|
| `K` | Пушта или паузира [временската линија](timeline.md) |
| `F` | Ги врамува податоците |
| `C` | Ја копира позицијата на камерата, јавот и нагибот ([очитување на камерата](camera.md#camera-readout)) |
| `G` | Оди на впишана точка: го отвора полето под очитувањето на камерата |
| `Esc` | Ја затвора картичката за избор; потоа престанува да гледа во втората единица; потоа престанува да следи единица |
| `T` | Вклучува или исклучува тактички приказ ([Повторување на натпревар](match-replay.md#display-style)) |
| `?` / `F1` | Режим на помош: што значат боите ([Поставки, единици и тастери](settings.md#help-mode)) |
| `1` | [Топлина](heat.md) |
| `2` | [Разлика](difference.md) |
| `3` | [Топлина по тимови](team-heat.md) |
| `4` | [Линии](line-heat.md) |
| `]` | Далечната граница на отсекувањето надвор ×1,12 (`Shift`: ×1,35) |
| `[` | Далечната граница на отсекувањето навнатре ÷1,12 (`Shift`: ÷1,35) |
| `\` | Далечната граница исклучена / повторно вклучена таму каде била ([Длабочина и отстранување](depth-and-culling.md#keyboard)) |

Режимот **Преклопување фигури** нема број на копче; изберете го во лентата со режими или отворете го табот Натпревар. Копчињата со броеви минуваат низ истата проверка како лентата со режими: копче за режим што лентата го прикажува како недостапен за вчитаните податоци не прави ништо.

## Повторување на натпревар {#match-replay}

Во режимот Преклопување фигури, кој го користи табот Натпревар ([Повторување на натпревар](match-replay.md)). Работат без оглед дали е следена единица, освен каде што е наведено:

| Копче | Дејство |
|---|---|
| `B` | Додава обележувач: моментот и камерата |
| `M` | 2D карта: агол, цел приказ, исклучено |
| `V` / `Shift+V` | Следен / претходен поглед на камерата на следената единица |
| `H` | Приказ на главата во кабината и во падлок-прегледите |
| `Page Down` / `Page Up` | Следен / претходен настан од видовите што ги покажува листата на настани |
| `J` | Пушта наназад; повторно, за пауза |
| `L` | Пушта напред; повторно, за пауза |
| `.` / `,` | Една секунда напред / назад, во пауза (`Shift`: десет секунди) |
| `Esc` | Прво престанува да гледа во целта, потоа престанува да следи |
| `Ctrl`+клик или `Alt`+клик на единица (во приказот или во листата на единици) | Гледа во неа од следената единица (приказ од две единици); кликнете повторно за да ја отстраните |
| `Shift`+клик на две единици | Мери меѓу нив: азимут, растојание, разлика во висината |

`V` бара следена единица. `M` овде е 2D картата, а во табот Тактика значи „премести“.

## Следење на единица {#following-a-unit}

Додека камерата следи единица, тркалото и копчињата за летање се движат околу единицата наместо слободно ([Камера](camera.md#while-following-a-unit)):

| Влез | Дејство |
|---|---|
| Тркало, `W` / `S` | Поблиску / подалеку (повисоко / пониско во сателитскиот приказ). Не во приказите од кабината и падлокот. |
| `A` / `D`, `Q` / `E` | Орбитира околу единицата (приказите од задниот дел и орбитата) |
| Влечење | Гледа околу единицата; во кабината гледа внатре |
| `V` / `Shift+V` | Следен / претходен поглед на камерата |
| `H` | Приказ на главата (приказите од кабината и падлокот) |
| `Esc` | Престанува да гледа во втората единица, потоа престанува да следи |

## Табла за тактики {#tactics-board}

Во табот Тактика ([Табла за тактики](tactics-board.md)). `F`, `C`, `G` и `T` работат како погоре; копчињата со броеви не прават ништо.

| Копче | Дејство |
|---|---|
| `Ctrl+Z` | Поништи |
| `Ctrl+Y` или `Ctrl+Shift+Z` | Повтори |
| `Enter` | Ја завршува стрелката што се црта (двоен клик или десен клик прават исто) |
| `Esc` | Откажува влечење; инаку ја фрла стрелката или поместувањето во тек; инаку ја поништува селекцијата |
| `Delete` или `Backspace` | Ја брише селекцијата |
| `W` / `E` / `R` | Поместување / Вртење / Скалирање за селекцијата (шема **W / E / R**) |
| `G` / `R` / `S` | Поместување / Вртење / Скалирање за селекцијата (шема **G / R / S**) |
| `R` | Кога ништо не е избрано: ја врти следната фигура за поставување за 15°. `Shift+R` ја враќа назад. |
| `M` | Со избрана фигура: ја поместува до следниот клик |
| `K` | Пушта или паузира планот |
| Shift+клик | Додава или отстранува од селекцијата |
| Shift+влечење | Црта правоаголник околу она што треба да се избере |
| `Ctrl` при влечење на рачка | Се залепува на мрежата или на чекор од агол |

Копчињата за гизмо работат само додека нешто е избрано; кога ништо не е избрано, `W A S D` ја летаат камерата како обично.

## Клик за избор {#click-to-pick}

Со **Кликот покажува што има таму** вклучено и **Линијарот** исклучен ([Клик за избор](camera.md#click-to-pick)):

| Влез | Дејство |
|---|---|
| Лев клик (без влечење повеќе од 4 px) | Ја покажува податочната точка или местото на нивото под покажувачот |

## Мерење {#measure}

Со **Линијарот е активен** ([Мерење](measure.md)):

| Влез | Дејство |
|---|---|
| Лев клик (без влечење повеќе од 4 px) | Поставува точка |
| Десен клик | Ја отстранува последната точка |

## Друго {#elsewhere}

| Каде | Влез | Дејство |
|---|---|---|
| Рачката на кој било лизгач (до бројот) | Влечете горе / долу | Ја менува вредноста континуирано, побрзо колку подалеку влечете; држете `Shift` за фино прилагодување. Пуштете за да престанете. |
| Прикажувањето на брзината над приказот | Влечете горе / долу | Ја менува брзината на летање на ист начин. |
| Полиња за поза | `Enter` | Ја применува впишаната позиција или насока. |
| Уредник на крива | Двоен клик / Alt-клик / десен клик | Додава точка / отстранува точка ([Облик на спрајт](sprite-shape.md#the-curve-editor)). |

## Табот Анализа на трки {#race-analysis-tab}

Во табот Анализа на трки `K` ја пушта и паузира трката, `Home` ја враќа на почеток, а копчињата со броеви не прават ништо. Видете [Анализа на трки](race-analysis.md).

## Копчиња што прелистувачот не ги дозволува {#keys-the-viewer-keeps-from-the-browser}

Некои кратенки на прелистувачот би ја затвориле или вчитале страницата и би ја загубиле вчитаната сесија, па приказникот ги задржува за себе. Списокот е создаден од кодот: [Тастатурни кратенки во прелистувачот](ref-browser-keys.md).
