# Gamepad и HOTAS

Камерата можете да ја летате со контролер во стилот на Xbox наместо со тастатура. Користете го кога сакате да се потпрете назад и да гледате околу себе во голема сцена. Неговиот влез се **додава** на тастатурниот, па можете да ги користите двете истовремено.

## Поврзете контролер {#connect-a-controller}

1. Приклучете го контролерот (или спарете го).
2. Кликнете на прегледот и притиснете кое било копче на контролерот. Прелистувачите го прикажуваат контролерот дури по неговиот прв влез.
3. Отворете **Камера и сцена → Gamepad**. Листата на уреди го покажува со `●`.
4. Турнете го левиот стик за летање, десниот за гледање. Ако камерата се поместува кога стиковите се во центар, зголемете ја **Мртвата зона**.

Секој уред што прелистувачот го пресликува во стандардниот распоред на гејмпад работи. Стик за летање или гас (HOTAS) по основно се игнорира; видете подолу.

## Пресликување {#mapping}

| Контрола | Ефект |
|---|---|
| Лев стик | Движење: напред/назад и страничен помак |
| Десен стик | Гледање: yaw и pitch, со *Брзина на гледање* степени во секунда при полно отклонување |
| `RT` / `LT` (аналогно) | Горе / долу; кај паралелната проекција, приближување / оддалечување |
| `RB` (задржано) | 6× побрзо |
| `LB` (задржано) | 15% брзина |
| `A` (задржано) | 3× спринт (се комбинира со RB/LB) |
| `Y` (притисок) | Постави ги податоците во кадар |

Броевите на копчињата следат стандардниот распоред: A 0, Y 3, LB 4, RB 5, LT 6, RT 7; стиковите се на оските 0-1 (лев) и 2-3 (десен).

## Поставките на Gamepad {#the-gamepad-settings}

Во **Камера и сцена → Gamepad**. **Поставки** / **Скриј** ги отвора контролите за дотерување.

| Контрола | Стандардно | Опсег (колчо) | Значење |
|---|---|---|---|
| **Вклучено** | вклучено | | |
| Состојба на уредот | | | Секој поврзан уред, `●` кога се следи, `○` кога не, со *- не е XInput pad, се игнорира* или *- не е XInput pad, се користи и така* за нестандардни уреди. Ако нема ниеден: *Не е откриен gamepad. Прелистувачите го откриваат контролерот дури откако ќе испрати прв влез - притиснете копче на него.* |
| **Користи уред** | *Само XInput pads (препорачано)* | | Се прикажува кога е приклучен нестандарден уред. Изберете уред по име за да го следите. |
| **Брзина на гледање** | 150°/s | 20-540 (5000) | Брзина на вртење при полно отклонување на десниот стик. |
| **Мртва зона** | 12% | 0-50% (95%) | Радијална: косо турање никогаш не преминува во една оска сама. Зголемете ја ако камерата се поместува кога стиковите се во центар. |
| **Крива на стикот** | x² | линеарна (1) до x⁴ (16) | Експонент на одѕивот по мртвата зона: поцелосна контрола блиску до центарот, а полна брзина на работ. |
| **Инвертирај Y на стикот** | исклучено | | |
| **Замени ги стиковите** | исклучено | | Движење на десниот стик, гледање на левиот. |

Обликувањето на стикот: при отклонување *m* (должината на векторот на стикот) и мртва зона *d*, излезот = ((m - d) / (1 - d)) ^ крива по насоката на стикот, а 0 во мртвата зона.

## Зошто по основно само стандардни гејмпадови {#why-only-standard-pads-by-default}

Gamepad API ги пријавува **сите** HID уреди со оски - стикови за летање, гасови, педали, волани - а тие не се враќаат во центар. Оската за свиткување или рачката на гасот стои на полно отклонување кога никој не ја допира. Прочитано како стик, тоа е трајен полн влез што ниедна мртва зона не може да го потисне, а камерата се врти сама од моментот кога страницата ќе се вчита (и секој режим на топлина изгледа расипан, бидејќи подвижна камера ја рестартира акумулацијата при секој кадар).

Затоа уред се следи само кога прелистувачот пријави `mapping: "standard"`, што значи „XInput-слично подлога со оските таму каде што ги очекувате“. Другите уреди се наведени и означени како игнорирани, а **Користи уред** експлицитно го вклучува еден - на пример за летање со HOTAS. Откако еден подлога ќе се следи, камерата останува со неа, па два контролери не се борат за камерата во зависност од редоследот на набројување.

**HOTAS:** се читаат само оските 0-3 (два стика) и стандардните копчиња. Гас или педали на други оски не прават ништо, а стик или гас чии оски не се во центар може да бараат поголема **Мртва зона**.

Прелистувачите го скриваат контролерот додека не испрати прв влез, па приклучен подлога што не е допрена за страницата сè уште не постои.
