# 关卡外观

这些控件会改变三维关卡的外观，使热度从中突显出来，同时你仍能读懂这个地方。这里没有任何东西会改变数据。

## 快速开始 {#quick-start}

1. 载入一个三维关卡（[三维关卡](model-levels.md)）。
2. 在**背景/关卡**中，降低**亮度**，直到热度成为屏幕上最亮的东西。
3. 打开**地面起伏**，提高**坡度着色**或**等高线强度**，直到你能分辨山丘和平地。
4. 打开**结构**。降低**面不透明度**可以看到建筑内部，或打开**结构纹理**让它们显示为实体。
5. 如果地面上画有图案，请试着把**地面纹理**关闭再打开。

![展开了地面起伏和结构两个区域，关卡以起伏线索显示](../assets/img/en/level-appearance-sections.webp)

载入[三维关卡](model-levels.md)后，背景/关卡面板会显示这些控件。默认值与新导入的关卡所获得的默认值相同（[`modelLevelFrom`](https://github.com/Holdi601/3DHeat/blob/main/src/ui/panels/LevelPanel.tsx)、[`level.ts`](https://github.com/Holdi601/3DHeat/blob/main/src/render/level.ts)）。改动它们只会重绘场景；热度累积会被保留。

## 整个关卡 {#the-whole-level}

| 控件 | 默认值 | 范围 | 含义 |
|---|---|---|---|
| **不透明度** | 100% | 0-100% | 低于 100% 时，关卡会被半透明混合，且不写入深度，因此不再[遮挡](depth-and-culling.md)热度。 |
| **亮度** | 0.9 | 0-2（拖动 64） | |

关卡以去饱和的方式绘制——灰色的地面，着色的外壳——使热度成为屏幕上唯一饱和的东西。与[地图图像](map-images.md)不同，三维关卡没有去饱和滑块。

## 地面起伏 {#ground-relief}

从远处看，山丘和平地都是同样的灰色，因此查看器添加了三种提示。每一种解决不同的问题：

| 控件 | 默认值 | 含义 |
|---|---|---|
| **等高线间距** | 根据地面的高度范围 | 等高线之间的高度，对数刻度，范围从关卡高度范围的 1/4000 到 1/2；滑轨底部为*关闭*。默认值为地面高度范围的 1/40，并取整为 1/2/5 的步进——10 m 的线适合山坡，却对采石场的底部毫无用处。每第 5 条线会画得更粗。等高线在屏幕空间中绘制，因此在任何缩放级别下都保持一个像素宽，而且它们是唯一能在坡度太缓、根本无法着色时仍然有效的线索。 |
| **等高线强度** | 35% | 0-100% |
| **坡度着色** | 55% | 按陡峭程度变暗，因此无论从哪个摄像机角度看，河岸和悬崖都能辨认——这不同于光照，光照在你正对它时会变得平坦。 |
| **高程色带** | 50% | 在地面高度范围内，低处更暗、高处更亮：这是大尺度的形状。 |

该区域的标题会显示等高线状态：*每 N m*（即等高线间距），或在间距关闭时显示*无等高线*。

## 地面表面 {#ground-surface}

| 控件 | 默认值 | 显示条件 | 含义 |
|---|---|---|---|
| **水面** | 开 | 关卡含有水体 | 湖泊、河流和海洋，以淡蓝灰色平面绘制：根据定义，水平的表面不适用任何地形线索。 |
| **水面不透明度** | 60% | 水面开启时 | 海岸线以及浅水下的地面会透过半透明的水显示出来。 |
| **地面三角形** | 30%（有纹理的关卡为 0） | 始终 | 地形自身的边线叠加在着色表面上，在距摄像机关卡宽度的 6% 到 25% 之间逐渐淡出。它显示地面采样的粗糙程度，并为坡度提供判断距离的依据。首次使用时才生成，在大型关卡上需要一点时间。 |
| **地面仅显示线框** | 关 | 始终 | 用地形的边线替换地形表面。完全是示意性的——它同时也放弃了着色、等高线和遮挡，因此通常更好的选择是*地面三角形*。 |
| **地面纹理** | 开 | 关卡含有纹理 | 以文件所带的纹理（沥青、路边、草地）绘制地面。网格光照会在上面轻柔地叠加，因为纹理本身已经带有精细的起伏。在热度下要让它安静下来，就用**亮度**；去饱和属于地图图像。 |
| **采集颜色** | 关 | 关卡含有顶点颜色 | 用扫描采集到的颜色而非灰色为地面着色——否则重建的道路与路边看起来没有区别。引擎导出的数据不含颜色；没有颜色时，面板会显示*此关卡不含颜色。* |

## 结构 {#structures}

**结构**标题会显示结构的三角形数量；下方的提示说明它们如何绘制（*以各自的纹理绘制为实体*或*以透明外壳绘制，以便看到其中的热度*），以及有多少部分是结构。

| 控件 | 默认值 | 含义 |
|---|---|---|
| **结构纹理** | 结构带有纹理时为开 | 以各自的纹理将结构绘制为实体。开启时会把面不透明度设为 100% 并关闭边线；关闭时则回到 25% 的有色半透明外壳。带纹理的结构会从摄像机所见的一侧受光，因为标牌是两个背对背的面，哪一面赢得深度测试取决于舍入。 |
| **线框边** | 开；结构三角形超过 300,000 个或带纹理时为关 | 结构去重后的边线，每条边一条线。 |
| **边不透明度** | 50% | |
| **外壳面** | 开 | 一层淡淡的表面，带有明亮的菲涅耳边缘，使建筑呈现为体积，而不是笼子或雾团。 |
| **面不透明度** | 25%（结构三角形超过 300,000 个时为 35%，有纹理时为 100%） | 轨道上为 0-60%，拖动手柄可达 100%。请保持低值：实体结构会遮住其中的数据。 |
| **锐利边缘** | 开（有纹理时为关） | 按每个三角形自身的法线为其着色，法线由片段着色器根据屏幕空间导数计算。导出的关卡经过焊接并带有平均法线，这会把每个盒子的角都变圆，成为“融化的箔纸”；为修正它而拆分每个顶点，会使顶点缓冲区成倍增大。对于曲面比棱角更重要的关卡，请关闭它。 |
| **结构色调** | 青色 | 颜色选择器，以及预设**青色**、**琥珀色**、**紫色**、**白色**。 |
| **显示部件分类 (N)** | | 每个部件、它的类别以及原因；见[三维关卡](model-levels.md#ground-structures-and-water)。 |
