# 队伍列表

**队伍** 面板可以让你隐藏一支队伍，或把它放在对比的一侧。用它来只查看 Blue，或者询问"Blue 去了哪里而 Red 没去？"。

*分组* 是队伍或阵营，例如 Blue 和 Red（[分组](sessions-persons-groups.md#group)）。当数据集有分组列时会显示此面板；分组数量显示在其标题上。在队伍热度模式下，侧边栏还有一个名为 **队伍查看器** 的部分，带有它自己的设置；本页介绍的是 **队伍** 列表。

## 隐藏一支队伍 {#hide-a-team}

1. 在侧边栏中打开 **队伍**。
2. 取消勾选要隐藏的队伍的复选框（*可见*）。画面会立即更新。
3. 按 **全部显示** 让每支队伍重新出现。

![队伍列表：Blue 5p、Red 5p，以及全部显示](../assets/img/en/teams-list.webp)

## 每一行 {#each-row}

| 部分 | 含义 |
|---|---|
| 复选框（*可见*） | 显示或隐藏该分组。 |
| 色块 | 分组的颜色：队伍热度模式下为其[队伍热度](team-heat.md)颜色，其他模式下为其基础颜色。 |
| 名称 | 分组标签（悬停可看到完整标签）。 |
| **+** / **-**（差值模式） | 将分组放在[差值](difference.md)的正侧或负侧；再次点击已激活的按钮，即可让它不在任何一侧。 |
| `Np`（其他模式） | 首行位于该分组中的人员数量。 |

![差值模式：Blue 在 + 侧，Red 在 - 侧](../assets/img/en/teams-list-difference.webp)

## 按钮 {#buttons}

| 按钮 | 效果 |
|---|---|
| **全部显示** | 使每个分组重新可见。 |
| **平均分配**（差值模式） | 分组的前一半（向上取整）放在 +，其余放在 -；每次加载开始时使用相同的分配。 |

## 隐藏分组会怎样 {#what-hiding-a-group-does}

- 在 **热度**、**队伍热度** 和 **线条** 中，该分组的行不产生任何贡献。
- 在 **差值** 中，被隐藏的分组无论位于哪一侧都不产生贡献，即使按另一列拆分时也是如此（见[差值](difference.md#for-developers)）。
- 在 **图形叠加** 中，首行位于该分组中的人员不会被绘制。
- 在 **队伍热度** 中，其他分组保持其颜色：色相是根据分组总数分配的，而不是根据可见的分组，因此两张画面保持可比较。

改变可见性会重新开始累积。每次加载新数据集时，每个分组都会重新可见。

面板的提示随模式而变化：在差值模式中解释 + 和 -；在队伍热度模式中，说明色块就是每个分组绘制时使用的颜色。
