# 键盘与鼠标参考

所有按键和鼠标操作都放在这里，方便你找到需要的那一个。先点击视图，让它获得键盘焦点。当文本框或下拉框有焦点时，按键会被忽略。简短版本也印在视图的左下角。

快速查找：

| 我想…… | 按 |
|---|---|
| 飞行 | `W A S D`，拖动以环顾 |
| 看到全部 | `F` |
| 播放或暂停 | `K` |
| 倒放 | `J`（再按一次暂停），正放 `L` |
| 查看颜色的含义 | `?` 或 `F1` |
| 在战术面板中撤销 | `Ctrl+Z` |

## 摄像机 {#camera}

来自 [`camera.ts`](https://github.com/Holdi601/3DHeat/blob/main/src/render/camera.ts)。

| 输入 | 效果 |
|---|---|
| `W` / `↑` | 沿视线方向前进 |
| `S` / `↓` | 后退 |
| `A` / `←` | 向左平移 |
| `D` / `→` | 向右平移 |
| `Space` / `E` | 上升 |
| `Q` / 左 `Ctrl` | 下降 |
| `Shift`（任一） | 按住：6 倍速 |
| 左 `Alt` | 按住：15% 速度 |
| 在视图上左键或右键拖动 | 环顾（按住按钮时指针被锁定） |
| 滚轮（透视） | 每格飞行速度 ×1.5（每次滚轮事件最多 4 格） |
| 滚轮（平行） | 缩放 |
| 右键 | 在视图上不打开右键菜单 |

## 全局 {#global}

来自 [`App.tsx`](https://github.com/Holdi601/3DHeat/blob/main/src/App.tsx)。

| 按键 | 效果 |
|---|---|
| `K` | 播放 / 暂停[时间线](timeline.md) |
| `F` | 框选数据 |
| `C` | 复制摄像机的位置、偏航和俯仰（[摄像机读数](camera.md#camera-readout)） |
| `G` | 前往输入的点：打开摄像机读数下方的方框 |
| `Esc` | 关闭拾取卡片；然后停止观看第二个单位；然后停止跟随单位 |
| `T` | 开启或关闭战术显示外观（[比赛回放](match-replay.md#display-style)） |
| `?` / `F1` | 帮助模式：颜色的含义（[设置、单位与按键](settings.md#help-mode)） |
| `1` | [热度](heat.md) |
| `2` | [差值](difference.md) |
| `3` | [队伍热度](team-heat.md) |
| `4` | [线条热度](line-heat.md) |
| `]` | 远端剔除边界向外 ×1.12（`Shift`：×1.35） |
| `[` | 远端剔除边界向内 ÷1.12（`Shift`：÷1.35） |
| `\` | 远端剔除边界关闭 / 恢复到原位置（[深度与剔除](depth-and-culling.md#keyboard)） |

**模型叠加**模式没有数字键；请在模式栏中选择它，或打开 Match 标签页。数字键与模式栏使用相同的检查：如果模式栏显示某个模式对已载入的数据不可用，按下对应的数字键不会有任何反应。

## 比赛回放 {#match-replay}

在模型叠加模式中生效，Match 标签页使用此模式（[比赛回放](match-replay.md)）。除非另有说明，无论是否跟随单位，它们都可以使用：

| 按键 | 效果 |
|---|---|
| `B` | 添加书签：当前时刻和摄像机 |
| `M` | 2D 地图：角落、全屏视图、关闭 |
| `V` / `Shift+V` | 被跟随单位的下一个 / 上一个摄像机视角 |
| `H` | 驾驶舱和锁定视角中的平视显示 |
| `Page Down` / `Page Up` | 事件列表所显示种类的下一个 / 上一个事件 |
| `J` | 倒放；再按一次暂停 |
| `L` | 正放；再按一次暂停 |
| `.` / `,` | 暂停时前进 / 后退一秒（`Shift`：十秒） |
| `Esc` | 先停止观看目标，然后停止跟随 |
| 在单位上 `Ctrl`+点击或 `Alt`+点击（在视图中或单位列表中） | 从被跟随的单位视角观看它（双单位视角）；再点一次即可取消 |
| `Shift`+点击两个单位 | 测量它们之间的距离：方位、距离、高度差 |

`V` 需要一个被跟随的单位。在这里 `M` 是 2D 地图，而在战术面板中它是“移动”。

## 跟随单位 {#following-a-unit}

当摄像机跟随某个单位时，滚轮和飞行键会围绕该单位转动，而不是自由飞行（[摄像机](camera.md#while-following-a-unit)）：

| 输入 | 效果 |
|---|---|
| 滚轮、`W` / `S` | 更近 / 更远（在卫星视图中为更高 / 更低）。在驾驶舱和锁定视角中无效。 |
| `A` / `D`、`Q` / `E` | 围绕单位环绕（追尾和环绕视角） |
| 拖动 | 绕单位环顾；在驾驶舱中则在内部环顾 |
| `V` / `Shift+V` | 下一个 / 上一个摄像机视角 |
| `H` | 平视显示（驾驶舱和锁定视角） |
| `Esc` | 停止观看第二个单位，然后停止跟随 |

## 战术面板 {#tactics-board}

在战术标签页中（[战术面板](tactics-board.md)）。`F`、`C`、`G` 和 `T` 的作用与上面相同；数字键无效。

| 按键 | 效果 |
|---|---|
| `Ctrl+Z` | 撤销 |
| `Ctrl+Y` 或 `Ctrl+Shift+Z` | 重做 |
| `Enter` | 结束正在绘制的箭头（双击或右键也可以） |
| `Esc` | 取消拖动；否则放下正在进行的箭头或移动；否则取消选择 |
| `Delete` 或 `Backspace` | 删除选中内容 |
| `W` / `E` / `R` | 选中内容的移动 / 旋转 / 缩放操纵器（按键方案 **W / E / R**） |
| `G` / `R` / `S` | 选中内容的移动 / 旋转 / 缩放操纵器（按键方案 **G / R / S**） |
| `R` | 未选中任何内容时：把下一个要放置的图标转动 15°。`Shift+R` 将其转回。 |
| `M` | 选中图标时：在下一次点击处移动它 |
| `K` | 播放或暂停计划 |
| Shift+点击 | 加入或移出选择 |
| Shift+拖动 | 绘制一个框来选择范围内的内容 |
| 拖动手柄时按 `Ctrl` | 吸附到网格或角度步进 |

操纵器按键只在选中了某物时有效；未选中任何内容时，`W A S D` 照常控制摄像机飞行。

## 点击拾取 {#click-to-pick}

开启**点击显示该处内容**并关闭标尺时（[点击拾取](camera.md#click-to-pick)）：

| 输入 | 效果 |
|---|---|
| 左键点击（拖动不超过 4 px） | 显示指针下的数据点，若没有则显示关卡上该处的位置 |

## 测量 {#measure}

开启**标尺已启用**时（[测量](measure.md)）：

| 输入 | 效果 |
|---|---|
| 左键点击（拖动不超过 4 px） | 放下一个点 |
| 右键点击 | 删除最后一个点 |

## 其他位置 {#elsewhere}

| 位置 | 输入 | 效果 |
|---|---|---|
| 任何滑块的手柄（数字旁边的把手） | 上 / 下拖动 | 连续改变数值，拖得越远变化越快；按住 `Shift` 进行精细调节。松开即停止。 |
| 视图上方的速度显示 | 上 / 下拖动 | 以同样的方式改变飞行速度。 |
| 位姿方框 | `Enter` | 应用输入的位置或朝向。 |
| 曲线编辑器 | 双击 / Alt 点击 / 右键点击 | 添加点 / 删除点（[精灵形状](sprite-shape.md#the-curve-editor)）。 |

## 赛车分析标签页 {#race-analysis-tab}

在赛车分析标签页中，`K` 播放和暂停赛车回放，`Home` 将其倒回开头，数字键无效。见[赛车分析](race-analysis.md)。

## 查看器保留的浏览器按键 {#keys-the-viewer-keeps-from-the-browser}

有些浏览器快捷键会关闭或刷新页面，从而丢失已载入的会话；查看器会自行保留这些按键。该列表由代码生成：[浏览器按键](ref-browser-keys.md)。
