# 对局分析（Counter-Strike 2）

**对局**标签页会以模型的形式回放录像；对于 Counter-Strike 2 对局，它还会显示记分板：每个回合谁赢了、如何赢的、谁拿到了击杀。用它可以逐回合复盘一场对局，然后跳转到热力图中的同一时刻。

对局标签页可以以模型形式回放任何录像：War Thunder 或 Tacview 录像，或 CS2 录像，它们都列在**回放中的对局**下（[对局回放](match-replay.md)）。CS2 的 `.match.json` 文件会添加本页所述的记分板。

## 复盘 CS2 对局 {#review-a-cs2-match}

1. 将录像转换为 `.parquet` 和 `.match.json` 文件（[见下文](#where-the-data-comes-from)）。
2. 在**热力图**标签页中，于**数据源**下加载 `.parquet` 文件。
3. 打开**对局**标签页，点击**加载对局文件…**，或将 `.match.json` 文件拖放到视图上。
4. 在**对局摘要**中点击一场对局，然后点击回合条上的某个单元格，以打开该回合。
5. 点击**显示回合**即可在热力图中查看该回合，或点击**回放回合**以模型形式观看。

![对局标签页：打开了一个回合的回合条、击杀信息和记分板](../assets/img/en/match-analysis-round.webp)

KAST、ADR、eco、强起、补枪等词语见[术语表](glossary.md#counter-strike-words)。

## 数据来源 {#where-the-data-comes-from}

[3DHeat CS2](https://github.com/Holdi601/3DHeat-CS2) 的录像转换器会把录像转换为每场对局两个文件，按地图分文件夹存放：

```bash
python -m heat3d_cs2 demos <demo files or folders> -o out
```

| 文件 | 加载于 | 包含内容 |
|---|---|---|
| `<match>.parquet` | **热力图**标签页（数据源面板，与任何 Parquet 相同：一个文件、多个文件，或整个文件夹） | 每位玩家每秒八次的位置，以及每个事件发生的地点：击杀、死亡、受伤、射击、投掷、烟雾弹、闪光弹、手雷、燃烧弹、诱饵弹、致盲、下包、拆包、爆炸；包括 `match`、`round`、`roundId`、`event`、`player`、`side`、`team`、视线方向、`weapon`、`place`、`opening`、`traded` … |
| `<match>.match.json` | **对局**标签页 | 队伍、比分、每个回合（胜者、方式、经济、下包、按顺序的每次击杀、残局、幸存者），以及每位玩家的记分板行 |

Parquet 文件的页脚包含读取说明（键 `heat3d`），因此无需任何设置即可打开：玩家作为人员，阵营作为分组，每个回合（`roundId`，"<match> #NN"）作为一个会话，视线方向已开启，世界也以正确的方向显示（CS2 的世界为右手坐标系、Z 轴向上；若按默认的 Z 轴向上映射读取，画面会被镜像）。见[列映射](column-mapping.md)和[加载文件](loading-files.md)。`python -m heat3d_cs2 map <map>` 会以相同的坐标系导出地图几何体，在**关卡**中加载。

数字背后的约定来自转换器（在其 README 中说明，并记录在每份摘要中）：当被击杀者在 **5 秒**内被受害者的队友击杀时，该死亡即为**被补**；**KAST** 是指有击杀、助攻（包括闪光助攻）、存活或被补死亡的回合所占的比例；**伤害**是实际损失的生命值，仅计敌方；**残局**是指在敌方仍然存活时，己方最后一名存活的玩家，并在己方获胜时计为胜利；**购买**按阵营计算，依据冻结时间结束时的平均装备价值——每个常规半场的第一回合为手枪局（加时赛中没有），然后低于 1,500 美元为 eco，低于 4,000 美元为强起，其余为全亮。

## 标签页 {#the-tab}

对局标签页的侧边栏顶部是热力图的模式切换和会话选择器，下面是对局的各个部分，再往下是热力图的**筛选**、**关卡**和**相机**面板——视图显示的是热力图标签页中所加载的任何 Parquet 的热力图。

### 对局摘要 {#match-summaries}

| 控件 | 作用 |
|---|---|
| **加载对局文件…** | 选择 `.json` 文件（可一次选择多个）：即 `.match.json` 摘要 |
| 拖放到视图上 | 对局标签页打开时，拖放到视图上的 JSON 文件会以同样方式加载（其他文件被忽略） |
| **清除** | 移除所有对局 |
| **所有对局**（有两场或以上时） | "N 场对局 · M 个回合"：所有对局的统计数据 |
| 某个对局行 | "TeamA 13 对 TeamB 9"，地图 · N 个回合：打开该对局 |

文件只有在为 JSON 且包含 `"format": "heat3d-cs2-match"`，以及数组 `rounds`、`players` 和 `teams` 时才会被接受。错误会列在按钮下方："<file>: not JSON"（不是 JSON）、"<file>: not a CS2 match summary (heat3d-cs2-match)"（不是 CS2 对局摘要）、"<file>: rounds, players or teams missing"（缺少 rounds、players 或 teams）。再次加载同一对局（相同的 `match` 名称）会替换之前的对局。对局先按地图排序，再按名称排序。只加载一场对局时会直接打开它；否则保持选择状态（默认为所有对局）。

未加载任何内容时，该部分会给出说明：用 `python -m heat3d_cs2 demos` 转换，在此加载 `.match.json` 文件，并在热力图标签页中加载 `.parquet` 文件。

### 对局（打开一场对局） {#match-one-match-open}

**标题栏：**两支队伍及其比分、地图、半场——"半场 7-5、6-6"：第 1–12 回合和第 13–24 回合（竞技和竞争模式均为 MR12；若摘要中说明了半场长度，则使用其自身的长度，因此 MR15 为第 1–15 回合和第 16–30 回合）——然后，当比赛进入加时赛时，单独显示加时赛的比分："加时 4-2"，即两个半场之后的回合。平局的回合对任何一支队伍都不计分。当摘要列出了不完整的回合时，还会显示"演示中有 N 个回合被截断"。

**回合条：**每个回合一个单元格，颜色取决于获胜的阵营，单元格中有其编号以及表示结束方式的标记。平局回合（无胜者）是中性的灰色单元格，标记为 `=`，绝不使用任何阵营的颜色；其提示文字为"第 30 回合：平局——双方都未赢得该回合"。

| 标记 | 结束方式 |
|---|---|
| B | 炸弹爆炸 |
| D | 炸弹被拆除 |
| K | 全部被淘汰 |
| T | 时间耗尽 |
| S | 投降 |
| = | 平局 |
| ? | 其他 |

分隔线标出第二个半场的开始（第 13 回合，或摘要中半场长度之后的那一回合）以及每个三回合加时赛半场的开始（第 25、28、31 回合……）。将鼠标悬停在某个单元格上会显示："第 7 回合：TeamA（T）——炸弹爆炸，在 A 下包"（若摘要没有包点信息，则为"……，下包，包点未知"），以及双方的购买和装备价值。点击即可打开该回合；再次点击则关闭（"点击某个回合，查看其击杀、经济和回放。"）。

**该回合：**

- "第 7 回合：<队伍> 获胜 - <方式>"（若为平局，则为"第 30 回合：平局——双方都未赢得该回合"），以及该回合持续的时长（从冻结结束到决出胜负，分:秒格式）；
- 经济：每个阵营的队伍、购买（手枪、eco、强起、全亮）和装备价值（"$4,350"）；
- 下包：包点、玩家，以及回合开始后的时间（取自任一版本的摘要）；当包点未知时显示"由 <player> 于 1:05 下包，包点未知"；
- **击杀信息**，按顺序列出：回合开始后的时间、攻击者（以其阵营的颜色显示；无攻击者时为"world"）、武器，以及标记——**HS** 爆头、**WB** 穿墙、**SM** 穿烟；该回合的**首杀**标为**首杀**，**补枪**（5 秒内为队友复仇）、**被补**（击杀者在 5 秒内被击杀）、**队友**为误杀（自杀不计）。回合已决出胜负之后的击杀会变暗显示；
- 残局："<player> (T) 单独对抗 3 人：赢得残局" / "输掉残局"；
- 每个阵营在结束时的幸存者（"无"）；
- **显示回合**：热力图中该回合的全部内容；
- **回放回合**：从回合开始处以方框形式回放该回合（见下文）。

该对局或打开的回合，可使用**在热力图中显示**按钮（见[下文](#show-in-the-heatmap)）。

### 记分板 {#scoreboard}

每支队伍一张表，每位玩家一行：

| 列 | 含义 |
|---|---|
| K、D | 击杀、死亡 |
| A | 助攻，包括闪光助攻 |
| ± | 击杀减死亡（大于 0 为绿色，小于 0 为红色） |
| ADR | 每回合伤害，即实际损失的生命值 |
| KAST | 有击杀、助攻、存活或被补死亡的回合所占的百分比 |
| HS | 爆头击杀的百分比 |
| 首杀 | 赢得的首杀对决 - 输掉的首杀对决 |
| 残局 | 赢得的残局/参与的残局 |

将鼠标悬停在某位玩家上：会显示补枪击杀、被补次数、闪光助攻、致盲的敌人数、道具伤害，以及多杀回合（"2×3k"）。**点击某位玩家**，即可在热力图中查看其击杀和死亡（仅限本场对局）。

### 跨对局（所有对局） {#across-matches-all-matches}

基于所有已加载的对局：

- "N 场对局 · M 个回合 · <地图>"，若有平局则还会显示"N 个回合为平局，双方都未赢得"；
- **赢得回合**，按阵营：总体、**手枪**局（摘要中的手枪局）、以及 **eco**、**强起**和**全亮**购买（每项为百分比，并附上进行的回合数；鼠标悬停可看到"赢得数 / 进行数"）。平局回合双方都进行了，但双方都没有赢；
- **炸弹**：每个包点的下包次数，以及 T 方在这些回合中继续获胜的频率（"在 A 下包 12 次（T 方赢得 67%）"）、摘要本身不知道包点的下包（"在未知包点下包 2 次（T 方赢得 50%）"），或"从未下包"；回合的结束方式，按最常见的排列；
- "拿到首杀的阵营赢得了其中 N% 的回合。"（自杀不算首杀；平局回合不转化首杀）；
- **首杀对决的位置**：首杀最多的十个地点（按受害者所在位置；将游戏中的地点名称转换为可读形式，"TopofMid" → "Top of Mid"），对决次数，以及 T 方赢得的比例；
- **玩家**：按击杀减死亡排列的前十五名，合并其所有对局（以 Steam ID 匹配）：对局数、K-D、按回合数加权的 ADR 和 KAST、按击杀数加权的 HS%、首杀对决。**点击某位玩家**，即可在热力图中查看其在所有对局中的击杀和死亡。

所有已加载对局的"在热力图中显示"按钮位于其下方。

## 在热力图中显示 {#show-in-the-heatmap}

每个链接都会设置热力图自身的**筛选**，因此显示的内容会保留在筛选面板中，并可以继续编辑；**全部显示**则会将其清除。它们作用于热力图标签页中加载的热力图表；对局标签页本身从不加载该表。

| 按钮 | 显示的事件 |
|---|---|
| **位置** | `position`：玩家所在的位置，每秒八次 |
| **击杀** | `kill`：击杀者所站的位置 |
| **死亡** | `death`：受害者倒下的位置 |
| **首杀** | `kill` 和 `death`，其中 `opening` = 1：每个回合的第一次击杀，双方所在的位置（仅当表中有 `opening` 列时提供） |
| **烟雾弹** | `smoke`：烟雾弹落下的位置 |
| **闪光弹** | `flash`：闪光弹炸开的位置 |
| **燃烧弹** | `molotov`：燃烧弹和燃烧瓶燃烧的位置 |
| **手雷** | `he`：手雷爆炸的位置 |
| **下包** | `plant`：炸弹被下包的位置 |
| **射击** | `shot`：开火的位置 |

按钮所在的位置决定其作用范围：所有已加载的对局、本场对局，或本回合（"在热力图中显示 - 第 7 回合"）。

无法应用的内容会在按钮下方说明，而不会被静默地筛选为空：如"未保留对局列 - 未应用对局筛选"、"对局：X 不在已加载的数据中"、回合和事件同理、"玩家 X 不在已加载的数据中"、"阵营 X 不在已加载的数据中"、"未加载热力图数据：请在热力图标签页中加载对局的 .parquet 文件"。未加载数据时，这些链接还会显示"请在热力图标签页中加载对局的 .parquet 文件，以便在地图上查看。"

**回放回合**还会将热力图切换为**盒式回放**，将时间线切换为*播放*模式并将其窗口设为*生命周期*，定位到该回合会话的开始处并开始播放。若该回合不是已加载数据中的一个会话，则显示："此回合不是已加载数据中的会话：没有可回放的内容"。

### 摘要版本 {#summary-versions}

该标签页会并排读取版本 1 和版本 2 的摘要（文件中的 `"version"`），并以相同方式处理它们：

| | 版本 2 | 版本 1 |
|---|---|---|
| 下包时间 | 回合开始后的秒数，与击杀相同 | 对局秒数；标签页会减去回合的开始时间 |
| 下包包点 | `A` 或 `B`；若演示中未说明则为空 | `A`、`B`，或实体编号——按未知包点处理 |
| 半场长度 | `halfLength`，取自双方首次交换阵营之处；为 null 时为 12 | 12（MR12） |
| 手枪局 | `pistolRounds`（第 1 回合以及半场后的第一回合） | 购买为 `pistol` 的回合 |
| 平局回合 | `winner` 和 `winnerTeam` 为空 | - |
| 自杀 | 击杀上的 `suicide`，绝不为队友误杀 | 由攻击者与受害者为同一玩家判定 |

击杀的 `noscope` 和 `attackerBlind`（版本 2）不会显示在对局标签页中；该标签页也不会显示热力图表中的任何地点，因此手雷行中为空的 `place` 在这里不产生任何影响。

焦点如何转换为筛选（`focusFilters`）：

- **对局** → 对 `match` 列的类别筛选；
- **回合** → 对数值型 `round` 列的范围筛选 `round` = N（对分类列则为类别筛选），并且在会话选择器中选中该回合的会话（`<match> #NN`）；
- **事件** → 对 `event` 列的类别筛选；
- **玩家** → 对该玩家的人员筛选；
- **阵营** → 分组筛选。
