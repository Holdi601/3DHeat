# 参考

这些是精确的名称、设置和工具的列表，用于查找。使用查看器不必阅读它们。

这些列表由 `node tools/docs-refs.mjs` 从查看器的代码中生成（你不需要运行它），因此它们始终与生成它们的版本一致：

- [事件类型与类别](ref-event-types.md)：每个数据集都会被归入的事件种类和载具类别，以及数据中哪些词语对应它们
- [列名](ref-columns.md)：加载器为位置、时间、人员、队伍、会话和视线方向所识别的列名
- [语言列表](ref-languages.md)：查看器支持的语言
- [浏览器按键](ref-browser-keys.md)：查看器为自身保留的浏览器快捷键
- [已保存的设置](ref-settings-storage.md)：浏览器在两次访问之间记住的内容
- [数值表](ref-value-tables.md)：数值加权的价格表
- [命令行工具](ref-tools.md)：`tools/` 中的工具：用于你的数据，以及用于开发者和文档

同样属于参考资料的，还有[术语表](glossary.md)，它解释本站使用的词语。手写的内容包括：[数据格式参考](data-formats.md)、[键盘与鼠标参考](keyboard-reference.md)、[每场比赛一个文件 (.3dheat)](container.md)。
