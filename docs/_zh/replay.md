# 回放

回放会以三维方式重放一场比赛，每个单位都以它本来的载具或人员形象绘制。用它来观看发生了什么、比较多场比赛，或看清谁击中了谁。

- [比赛回放](match-replay.md)：播放一场比赛，带有图形、曳光和命中效果，以及 Tacview 风格的摄像机。
- [同时查看多场比赛](many-matches.md)：把数百场比赛叠放在一起。
- [图形](figures.md)：用于单位的形状，以及它们的来源。
- [命中分析](hit-analysis.md)：某辆载具或某名士兵在哪里被击中，以及被谁击中。
