# 摄像机与控制

你可以像鸟一样在场景中飞行：**W A S D** 移动，拖动鼠标环顾四周。本页告诉你如何飞行、如何跳到俯视或侧视，以及如何准确读取相机的位置。

## 4 步开始飞行 {#fly-in-4-steps}

1. 在视图上单击一次，使其获得键盘焦点。
2. 按住 **W** 向前飞，**S** 向后，**A** 和 **D** 左右平移，**空格** 向上，**Q** 向下。
3. 按住鼠标左键或右键并拖动，即可环顾四周。
4. 按 **F** 重新聚焦所有数据。

相机是一台自由飞行相机，支持透视和平行投影、预设视角、可输入的位姿以及景深。它的设置位于侧边栏底部的**相机与场景**面板中（在赛道分析和对局标签页中也会显示）。实现代码见 [`camera.ts`](https://github.com/Holdi601/3DHeat/blob/main/src/render/camera.ts)。

## 飞行 {#flying}

| 输入 | 效果 |
|---|---|
| `W` `A` `S` `D` 或方向键 | 向前（沿视线方向，包括其俯仰）、向左、向后、向右 |
| `Space` 或 `E` | 向上（世界的上方） |
| `Q` 或左 `Ctrl` | 向下 |
| 按住 `Shift` | 速度提高 6 倍 |
| 按住左 `Alt` | 速度降至 15% |
| 按住鼠标左键或右键拖动 | 环顾四周。拖动时光标被锁定。 |
| 鼠标滚轮 | 透视：每格飞行速度 ×1.5；平行：缩放 |
| `F` | 聚焦数据 |
| 单击（不拖动） | 显示光标下的内容（[检查视图](#inspecting-the-view)） |
| `C` | 复制相机的位置、偏航和俯仰 |
| `G` | 跳转到输入的点 |
| `Esc` | 关闭拾取卡片（并停止跟随单位） |

### 跟随单位时 {#while-following-a-unit}

当相机在回放中跟随某个单位时（[对局回放](match-replay.md)），飞行键的作用会不同：

| 输入 | 效果 |
|---|---|
| 滚轮，`W` / `S` | 靠近单位 / 远离单位（在卫星视角中为更高 / 更低） |
| `A` / `D`，`Q` / `E` | 围绕单位环绕（追尾和环绕视角） |
| 拖动 | 围绕单位环顾（驾驶舱：在内部环顾） |
| `V` / `Shift+V` | 下一个 / 上一个相机视角 |
| `Esc` | 先停止注视第二个单位，然后停止跟随 |

移动键可与[手柄](gamepad.md)叠加使用；其他所有按键见[键盘参考](keyboard-reference.md)。当文本框或下拉列表获得焦点时，按键会被忽略。俯仰被限制在刚好不到垂直向上和向下的位置。

## 相机与场景面板 {#camera--scene-panel}

![相机与场景面板：投影、预设视角、视场角按钮、飞行速度和位姿](../assets/img/en/camera-panel.webp)

### 投影 {#projection}

**投影**：*透视*（默认）或*平行*。

*平行*（正交）去除了透视缩短，因此两个密度相同的热点，无论在画面的哪个位置，看起来都是同样大小——这正是地图热力图用于比较的前提——它也是使等轴测视图成为等轴测的原因。在平行模式下，鼠标滚轮用于缩放（没有会改变比例的前进运动），并且[速度显示](#fly-speed)会被隐藏。

**切换时保持主体大小不变。** 平行投影没有视场角，因此其视锥高度与相机距离无关；直接切换要么剧烈缩放，要么什么都看不见。切换到平行时，视锥高度会设为透视相机在聚焦距离处所覆盖的范围（2 × 距离 × tan(视场角 / 2)，聚焦距离即上一次聚焦时的距离）。切换回来时，会恢复你离开时的透视位姿，并保持相同的视觉比例，而不是平行视图漂移到的位置。

### 预设视角 {#preset-views}

| 分组 | 按钮 | 朝向 |
|---|---|---|
| **等轴测** | **NE**、**NW**、**SE**、**SW** | 平行，俯仰 -35.264°（= atan(1/√2)，即三个轴投影长度相同的角度），偏航 -45°、45°、-135°、135°。四个角，因为单独一个角总会让一半地图被较近的东西挡住。 |
| **立面** | **Top**、**Bottom**、**Front**、**Back**、**Left**、**Right** | 平行。Top 垂直向下看（俯仰 -89.9°），Bottom 垂直向上看，Front 沿 -Z（偏航 0°），Back 沿 +Z（180°），Left 沿 -X（-90°），Right 沿 +X（90°）。 |
| | **回到透视** | 返回你离开时的透视位姿。在透视模式下不可用。 |
| | **四分之三视图** | 透视，偏航 -35°，俯仰 -28°。 |

每个预设都会切换投影本身——在透视下，"俯视图"仍会汇聚到一个消失点，相等的面积就不再看起来相等——并从该方向聚焦数据。

### 视场角 {#field-of-view}

**视场角**——垂直方向的角度。默认 65°，滑轨范围为 10–140°（使用手柄时为 179°），并有按钮 **平 20°**、**长 35°**、**标准 50°**、**宽 65°**、**超宽 90°**。较窄的视场会使透视变平，看起来更接近平行投影；较宽的视场会夸大深度，使距离难以判断。在平行模式下它仍然有效，它决定切换回透视时所求解的比例，以及**聚焦**所用的距离。

### 飞行速度 {#fly-speed}

**飞行速度**——全速时每秒的世界单位（米）。默认 120；每次加载时，取数据的水平范围 / 12。对数刻度，0.02–20,000（使用手柄时为 200,000；手柄按比例而非按数量改变它）。鼠标滚轮每格乘以或除以 1.5，范围为 0.02–200,000。

同样的数值显示在视图右下角（仅透视模式）：以 m/s 或 km/s 表示的速度，以及在该速度下穿过数据（若加载了三维关卡，则为关卡）所需的时间。上下拖动即可改变速度。

### 近裁剪面与远裁剪面 {#near-and-far}

**近裁剪面**（默认 0.5）和**远裁剪面**（默认 40,000）是裁剪距离。二者在每次加载时都会根据数据重新计算（近 = max(0.05, 范围 / 20,000)，远 = 范围 × 12），并且只会被更大的三维关卡放宽，绝不会收窄（[关卡](levels.md#what-a-level-does-for-the-heat)）。二者的比值决定遮挡所依赖的深度精度，因此极小的近裁剪面配上极大的远裁剪面会削弱[遮挡](depth-and-culling.md)。从场景外或其地面上方很高处观看时，实际使用的近裁剪面会向外移动到该距离的 2%，这样从远处俯视的地图仍保有足够的深度精度，使水面和岸线不会闪烁；面板中的方框仍显示所设定的数值。

| **景深** | 关 | 见下文。 |

| **聚焦数据集（F）** | | 将数据（在赛道分析标签页中：各圈）适配到视图，并保持当前方向。相机放置在距中心 r / tan(视场角 / 2) 处，r 为数据边界对角线的一半。 |
| **网格**、**坐标轴** | 开、开 | 地面网格，间距为 1/2/5 × 10ⁿ，约为数据跨度的 1/40（延伸至数据的 1.5 倍，介于 8 到 120 个网格步长之间），以及彩色坐标轴。 |

### 位姿 {#pose}

五个数值框——**X**、**Y**、**Z**，以及 **偏航 °**、**俯仰 °**——在它们都没有焦点时，会跟随相机变化。输入数值后按 `Enter`（或离开该框），相机即移动到那里。**复制**会把 `pos X Y Z · yaw A · pitch B` 放到剪贴板上（选择该约定时，末尾还会加上 `(game yaw)`）。飞行用于探索；坐标用于重现视图。它们与[相机读数](#camera-readout)是同样的数字：数据自身的坐标（包括轴被反转时），以及所选[约定](#yaw-conventions)下的偏航。

### 反转世界轴 {#invert-world-axis}

**反转世界轴 X / Y / Z** 会把该轴反向后绘制世界。保持左手坐标系的游戏，在这个右手坐标系的查看器中会被镜像——右转弯被画成左转弯——而反转 X 或 Z 即可将其还原。**只改变绘制**：数据、分析以及工具显示的每个坐标（位姿、标尺、切片）都仍然是游戏自身的。视图会原地翻转，你仍然看着同一个地方。此设置会保存在浏览器中（`localStorage` 键 `heat3d.mirror`）；对比加载时的[翻转](axes-units-and-time.md#flips)，后者会改变数据。

## 检查视图 {#inspecting-the-view}

相机位于何处、光标下是什么、以及跳转到某个点——这些都在相机与场景面板的**检查**部分，以及视图左上角的两个浮层中。代码见 [`pose.ts`](https://github.com/Holdi601/3DHeat/blob/main/src/render/pose.ts)、[`pick.ts`](https://github.com/Holdi601/3DHeat/blob/main/src/render/pick.ts) 和 [`inspector.ts`](https://github.com/Holdi601/3DHeat/blob/main/src/render/inspector.ts)。

| 控件 | 默认 | 含义 |
|---|---|---|
| **在视图上显示相机位置** | 开 | 下面的相机读数。也可用其 **×** 关闭。 |
| **单击显示该处内容** | 开 | 单击拾取，见下文。 |
| **偏航约定** | 查看器 | 读数、位姿框和跳转框所显示和读取的偏航。 |

这三项会保存在浏览器中（`localStorage` 键 `heat3d.inspect`）。

### 相机读数 {#camera-readout}

位于视图左上角：相机的 **x**、**y**、**z**、**偏航** 和 **俯仰**，实时更新，并带有一个标签说明偏航约定。它显示的数字与[位姿](#pose)框相同，飞行时不会增加任何开销（它在帧时钟上写入页面，无需重新渲染面板）。

- **复制**（或在文本框之外按 `C`）会把 `x X y Y z Z yaw A pitch B (viewer yaw)` 放到剪贴板上，小数点始终为 `.`，与界面语言无关——跳转框以及任何脚本都能读回这一行。
- **跳转**（或按 `G`）会在其下方打开一个框：粘贴一个点并按 `Enter` 即可查看该点，粘贴一个完整复制的位姿则可站到该视角。`Esc` 关闭该框。

### 坐标：数据自身的坐标系 {#coordinates-the-datas-own-frame}

检查工具所显示或接受的每个坐标，都位于**已加载数据自身的坐标系**中：加载时的[轴映射](axes-units-and-time.md)（向上轴、翻转、缩放）已被撤销。从视图中读取的位置，就是源表中保存的数字；把表格中的数字输入跳转框，会落在该位置。当映射不做任何改变时（即 Y 轴向上、未缩放的加载——这正是采集工具和关卡导出器所写入的内容），它就是世界坐标本身；否则读数会带有**数据坐标系**标签。没有数据集时，坐标即为世界坐标。偏航和俯仰始终以查看器的世界为准，Y 轴向上。

### 偏航约定 {#yaw-conventions}

| 约定 | 偏航 0° 时朝向 | 增大时转向 | 使用者 |
|---|---|---|---|
| **查看器** | -Z | -X | 自由飞行相机、[预设视角](#preset-views) |
| **游戏 / 采集工具** | +X | -Z | 采集工具的 `yaw` 列和位姿；在以查看器坐标系导出的关卡中，即游戏自身的偏航 |

两种约定中的俯仰相同：从水平面向上为正。二者只相差四分之一圈，别无其他区别：

> 查看器偏航 = 游戏偏航 - 90°

在游戏约定下，方向 `d` 为 `(cos p · cos y, sin p, -cos p · sin y)`；在查看器约定下为 `(-sin y · cos p, sin p, -cos y · cos p)`。选择**游戏 / 采集工具**，即可直接输入采集表格中的偏航，或将读数与之比较。

### 跳转到点 {#going-to-a-point}

**跳转到点**，位于检查部分（以及读数中的**跳转**框）：

- 文本框接受 `x, y, z` 或 `x y z`（或 `x; y; z`），小数点可以是点或逗号——`-321.6, 137.8, -59.9` 与 `-321,6 137,8 -59,9` 是同一个点。输入五个数字则额外加上偏航和俯仰；从读数或位姿框复制的完整位姿会被整体读取，包括标签和约定；
- **偏航 °** 和 **俯仰 °**（可选）按所选约定转动相机；
- **看向**保持当前朝向（若原本水平看，则会倾斜至少 20° 向下看），并沿该朝向后退到当前距离，距离保持在场景宽度的 0.3% 到 3% 之间——在两公里的关卡上为 6 到 60 米。聚焦距离、平行视图的高度和飞行速度随之调整，使视图一到达即可使用；
- **站在这里**把相机放在该点上，朝向所给的偏航和俯仰，或保持原样。

粘贴的位姿若带有自己的偏航和俯仰，则总是会站到该视角。

### 单击拾取 {#click-to-pick}

在视图上单击——按下并松开，拖动不超过 4 像素；拖动仍然用于环顾——会在左上角显示一张卡片，列出光标下的内容。打开[标尺](measure.md)时，单击会改由标尺处理。

**已绘制的数据点优先。** 距单击位置 8 像素以内、实际绘制出来的最近采样点：处于时间窗口和生命周期内的行，通过[筛选](filters.md)的、显示的分组和差异拆分中的行，位于距离剔除范围内，并且在切片之内（切片会裁剪热力图）。在盒式回放中，则为光标下的任何一个方框（其上任意位置）。卡片以数据源自身的列名列出该行携带的每一列——时间（墙上时钟时间，或文件自身的秒数，格式为 `m:ss.ss`）、人员、分组、会话、每个保留的列、位置和视线方向——以及距相机的距离。内存中只保留加载时保留的列：未被选为[筛选列](column-mapping.md)的列不会显示。

**否则为关卡表面**：单击射线与关卡真实三角形相交的点（而非标尺的参考平面），并显示其所属的**部件**（导出器的名称，如 `structure:props`、`ground:terrain …`）、其**类型**（地面、结构、水面、地图图像）、坐标和距离。被切片或距离剔除所隐藏的几何体会被穿透。若关卡有[导航网格](model-levels.md#navigation-meshes)，一行文字会将其命名，并说明该点是否位于其上（✓）。部件名称前缀为 `≈` 的，是根据部件的包围盒推测的，因为该部分关卡在加载时被简化过。

卡片会一直保留，直到被关闭（**×**、`Esc`），另一次单击回答了其他内容，或单击空白处。场景中该点会绘制一个青色十字，屏幕上则在其外围画一个圆环。其按钮有：**复制**（所有数值，以及 `x, y, z` 形式的坐标）、**看向**，以及**站在这里**（对于数据点，若该行带有视线方向，则按该行的视线方向朝向；对于表面，则站在其上方 1.7 米处）。

关卡会在第一次需要拾取的单击时建立拾取索引：在其占地范围上建立一个列网格，在帧与帧之间分批构建，每次仅几毫秒，因此视图永不停顿（对于数百万个三角形的关卡约需一秒的工作量），并一直保留到关卡更换为止。在此之前，卡片会显示*正在为拾取准备关卡*及百分比，并在准备就绪后回应该次单击。在超过四百万个已绘制行中搜索数据点的操作，也以同样的方式分散到各帧中进行。

## 景深 {#depth-of-field}

相机与场景中的一个可折叠部分，启用时标题为*景深 - 开*。默认关闭：它是一种呈现效果，默认视图应显示数据本身，而不是对数据的解读。

| 控件 | 默认 | 范围（拨动） | 含义 |
|---|---|---|---|
| **启用** | 关 | | |
| **对焦于聚焦的对象** | 开 | | 在上一次聚焦所用的距离处对焦（*已对焦于 N 米。*）。 |
| **对焦距离** | 1000 | 1–200,000，对数刻度（10,000,000） | 对焦为手动时显示。 |
| **光圈** | ±35% | ±2% 到 ±200%，对数刻度（±3200%） | 保持清晰的深度范围，以对焦距离的比例表示——相对值而非光圈数，因为场景从一个房间到八公里的地图都有。 |
| **最大模糊** | 12 px | 1–48（256） | 最大模糊半径；开销随之增加。 |

它模糊的是**关卡、网格和方框**——*不模糊热力图*。像素上的热力是许多深度上精灵的总和，因此它没有单一的深度可以失焦；若用其后方的几何体来模糊它，在它悬浮于前方的任何地方都会是错误的。清晰的数据配上柔化的背景，也是两者中更有用的组合。模糊在合成阶段采用 24 次抽样的黄金角聚集，并加权，使清晰的前景不会被其后模糊的背景向外拖散。改变它会重新绘制，而不会重新开始热力累积。

## 画布分辨率 {#canvas-resolution}

画布按显示器的像素比渲染，上限为 2。热力缓冲区可以比这更低的分辨率渲染（[热力分辨率](performance-and-stats.md)）。
