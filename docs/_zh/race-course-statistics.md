# 赛道统计

载入同一条赛道的许多圈，查看器会统计失误：哪个弯道最耗时间、有多少圈在那里出了问题、原因是什么。用它来找出值得练习的弯道。

试一试：**演示圈** 提供三圈，足以让本节显示出来。

![带失误地图的赛道统计：按每个弯道有多少圈损失了时间着色的赛道，以及弯道列表](../assets/img/en/race-course-mistake-map.webp)

载入一条赛道的整个文件夹——几十圈、几辆车、几个性能等级——每一圈都会被评判，然后统计。本页涵盖按等级的比较、什么算失误、**赛道统计** 一节、失误地图、热力图导出、多条赛道的情况，以及圈数很多时的性能限制。

## 与同级中最快的圈比较 {#against-the-best-of-its-own-class}

每一圈都会逐弯与 **其所在性能等级中最快的完整圈** 比较（参考圈，且参考圈属于该等级）；参考圈本身则与其等级中在每个弯道最快的车手比较，若它是唯一在其等级中的圈，则与所有圈比较。车辆按游戏的性能等级分组（在《Forza》中为 D 到 X；C 和 S2 是其中两个）。一辆 C 级车的刹车点与一辆 S2 车的刹车点相比，说明不了驾驶的好坏。时间地图、圈列表中的差距，以及 *逐弯分析* 表都遵循同样的比较方式（参见 [每一圈与谁比较](race-corner-analysis.md#who-each-lap-is-compared-with)）。

这些统计建立在对每一圈的分析之上，而不是与之并行。

## 什么算失误 {#what-counts-as-a-mistake}

一次 **失误** 是一圈在一个弯道（分段）中的一次错误。一圈在某个弯道中的失误包括：

1. **分析找出的驾驶原因**——在那里造成其损失的一项发现，且该发现是一项损失，归因于驾驶员（而非车辆或环境），与对比圈相比损失 **0.05 秒** 或更多。它的代价就是该弯道的损失。
2. **该圈在那里犯下、而另一圈没有犯的每一项车辆操控错误**（非共同的），损失 **0.03 秒** 或更多——抱死、轮胎打滑、车尾甩出、推头、打转。它的代价就是该事件本身的代价。
3. **每一次碰撞与撞击**，无论是否共同发生，也无论代价多少。

一个弯道中可以有多项；每种类型在 **每圈每弯道只计一次**。获得的时间、车辆的份额，以及在前一弯道已经决定的较晚到达，都不算失误。

### 从发现到失误 {#from-findings-to-mistakes}

| 发现 | 失误 |
|---|---|
| 入弯太快、出弯慢，原因是比对方晚了好几米才刹车 | 刹车太晚 |
| 刹车太早 | 刹车太早 |
| 刹车很轻 | 刹车太轻 |
| 抱死是原因 | 车轮抱死 |
| 滑行 | 滑行 |
| 有余力却未用，入弯慢，刹车位置比对方只是松油门的地方更早 | 弯中太慢 |
| 走线太紧 | 走线太紧 |
| 被推向外侧 | 被推向外侧 |
| 转向车身不足 / 过度 | 转向错误 |
| 出弯后踩油门太晚、全油门太晚、犹豫 | 油门踩得太晚 |
| 出弯太慢 | 出弯太慢 |
| 轮胎打滑 | 轮胎打滑 |
| 车尾甩出，弯中横向滑动 | 车尾甩出 |
| 跑出弯道外侧 | 跑出弯道外侧 |
| 速度被磨掉 | 速度被磨掉 |
| 松油门（入弯时或在直道上） | 松油门 |
| 接近停车、打转、撞击或碰撞是原因 | 当该弯道的事件表明时记为打转 / 撞上东西 / 碰撞（先看碰撞，其次打转，再次撞击）；否则记为接近停车 |
| 飞得太远（距离更长） | 飞得太远 |

两种模式按其中所包含的原因计入，依据同一张表。*入弯时给出的比出弯时收回的还多* 的失误与其条目的原因相同：刹车太早即 *刹车太早*，抱死即 *车轮抱死*，滑行即 *滑行*，未用的抓地力即 *弯中太慢*。*入弯太快，出弯慢* 在该圈比对方刹车更晚时即 *刹车太晚*；否则即其出弯原因的失误——*油门踩得太晚*、*轮胎打滑*、*车尾甩出*、*跑出弯道外侧*、*出弯太慢*。原因属于车辆、或是较晚到达的模式，不计入。

不计入：较晚到达、起步、每一项 *车辆* 发现（拉力、抓地、刹车、动力），以及每一个获得时间或获得的弯道。

### 类别及其顺序 {#the-kinds-in-their-order}

刹车：*刹车太晚*、*刹车太早*、*刹车太轻*、*车轮抱死*。入弯：*滑行*、*弯中太慢*、*走线太紧*、*被推向外侧*、*转向错误*。出弯：*油门踩得太晚*、*出弯太慢*、*轮胎打滑*、*车尾甩出*、*跑出弯道外侧*、*速度被磨掉*。直道：*松油门*。事故：*打转*、*撞上东西*、*碰撞*、*接近停车*、*飞得太远*。

## 赛道统计一节 {#the-course-statistics-section}

从 **3** 圈起显示，位于 **圈数** 与 **可改进之处** 之间。

- **摘要**："9 辆车的 40 圈，3 个等级：每圈与其所在等级中最快的圈逐弯比较。"（车辆按车号计数，或按名称计数。）
- **等级标签**（有多个等级时）：**全部** 以及每个等级一个标签，每个标签附带其圈数，按游戏的顺序排列（D、C、B、A、S1、S2、R、X，然后是其他）。点击某个等级即只看该等级的圈；**Shift+点击** 可以添加或移除一个等级。下方的所有内容——列表、地图、热力图导出——都跟随所选的等级。
- **最常见的失误**：每种失误类型，按圈数从多到少排列（然后按次数、再按代价），最多显示 8 种（**全部 N 种** 显示其余的，**收起** 则再次隐藏）。每一行包括：名称、"M 圈中的 N 圈"、该比例的条形，以及 "K 次 · 约 X 秒 · 最多出现在 T3 (5)、T7 (4)、T1 (2)"——它出现的次数（按圈逐弯计）、它总共造成的代价，以及该失误出现圈数最多的三个弯道。**点击某一行** 会在失误地图上显示它（并打开地图）；再次点击则显示所有失误。
- **逐弯分析**（或选中一项时为 *逐弯分析 - <失误>*）：按分段显示，"N 圈中有 M 圈损失了时间 · X 秒"——完整驶过该弯道的圈数、在那里相对于其等级最佳损失了 **0.05 秒** 或更多的圈数，以及它们在其中损失的全部时间。展开后会列出其三个最常见的失误及其圈数。**点击某个弯道** 可以打开它，用摄像机将其框住，并切换到失误地图：对每一种失误（或只对选中的那一种）会显示一行，例如 "在此处，40 圈中有 12 圈刹车太早。涉及 9 辆不同的车，每次约 0.21 秒。"，并列出造成该失误的圈，**最糟的排在最前**，每圈附有其代价——最多 8 圈，其余以 "+N 个更多" 表示。**点击某一圈** 可以聚焦它，并回放那里的失误（对齐到其前 40 米处）。
- **在热力图中显示**：见下文。运行时显示 "正在构建热力图…"；没有失误时此项不可用。

## 失误地图 {#the-mistake-map}

**视图 → 失误地图** 沿参考路径绘制：在每一米处，有多少圈（所选等级中的）在那里犯了错误——所有种类，或统计中选中的那一种。每一圈在每一米只计一次；每个失误的范围（其原因或事件所在之处）两侧各加宽 6 米，使短的失误也能显示。哪里的圈越多，线条就越宽、越亮：宽度为 `3 + 10 · (此处的圈数 / 任何地方的最多圈数)` 米，颜色从暗棕色到亮橙色；没有失误的地方则是一条 2 米宽的灰色带。图例：*圈数少 ↔ 圈数多*。

打开 **标签** 后，每个弯道的顶点会显示其最常见的失误："T3 · 12/40 刹车太早"（犯此错误的圈数 / 驶过该弯道的圈数），选中一种类型时为 "T3 · 12/40"，没有选中时若无失误则为 "T3 · 干净"。把鼠标悬停在标签上会列出该弯道的损失及其五个最常见的失误；点击标签则打开或关闭统计中的该弯道。

## 在热力图中显示 {#show-in-the-heatmap}

**在热力图中显示** 会把同样的内容交给热力图标签，作为一个名为 "*<赛道>* 上的失误"（或 "赛道上的失误"）的数据集，因此热力图的全部工具——热度模式、筛选、时间线、切片——都可以用于分析圈在哪里出错。

它是一个在内存中构建的 CSV（`mistakeTable`），每个失误的每个网格点（每 2 米）一行，位于 **该圈自己的位置** 上：

| 列 | 内容 |
|---|---|
| `x`、`y`、`z` | 该圈在该米处的位置（游戏坐标） |
| `elapsed` | 该圈在该处的时间，单位秒 |
| `lap` | 该圈的标签 |
| `car` | 车辆名称（或 "car 1234"） |
| `mistake` | 失误名称，使用当前语言 |
| `car_class` | 等级，无则为 `-` |
| `corner` | 弯道标签，`T3` |
| `cost` | 该失误的代价，单位秒 |

它通过热力图自身的加载器载入，并带有映射提示：Y 轴向上，不翻转坐标轴，缩放为 1；时间 `elapsed` 单位为秒；**人员** = `car`，**分组** = `mistake`，**会话** = `lap`；没有视线方向；`car_class`、`corner` 和 `cost` 保留为筛选列。随后标签页切换到 **热力图** 并对数据取景。只导出在统计中所选的等级。

## 多条赛道的圈 {#courses-from-several-tracks}

圈是 **每次分析一条赛道**。包含多条赛道圈的文件夹（整个圈库）会为每条赛道提供单独的载入选项（附其圈数，多者在前）；未完成的运行（FH Companion 的 `unfinished/`）的圈随其赛道一起，标记为 *部分*。作为文件选中的、属于多条命名赛道的圈，也以同样的方式提供；未命名赛道的圈则归入所选的那条。载入与已载入赛道不同的命名赛道会替换已载入的圈。详情：[加载圈次](race-loading-laps.md#folders-and-courses)。

## 圈数很多时的性能 {#performance-with-many-laps}

几十圈可在一两秒内分析完毕（始终全部分析）。绘制的内容则有限制，以便视图保持帧率：

| 限制 | 数值 | 效果 |
|---|---|---|
| 默认绘制的圈数 | 8（`SHOW_ALL_UP_TO`） | 载入超过 8 圈后，新加入的圈会被隐藏，除非它是参考圈、被聚焦的圈或其等级中的最佳圈。**全部显示** 会绘制每一圈；**只显示正在查看的** 则恢复原状。聚焦某一圈会取消其隐藏，并显示其等级的最佳圈 |
| 普通车辆与细线 | 可见圈超过 10 个（`PLAIN_PAST`） | 除焦点、被追踪的车辆和参考圈以外的圈：每 6 米一个线点（而非每 1.5 米），车辆以普通方式绘制 |
| 绘制图表的圈 | 8（`CHART_LAPS`） | 焦点、其等级最佳和参考圈优先；"另有 +N 圈已绘制，未入图表" |
| HUD 卡片 | 6 | 前六个可见的圈 |
| 统计 | 从 3 圈起 | 低于此数时隐藏该一节 |
| 列出的发现 | 驾驶 12 项、车辆 / 环境 8 项、增益 10 项 | 按每个聚焦的圈 |
| 显示的车辆对 | 3 | 超过 3 对时，改为一对，并附选择器 |

失误的发生次数在每次分析时计算一次并缓存；失误地图的密度按每个等级选择与每种失误缓存。
