# Tacview 对齐

Tacview 是一款常用的飞行录像观看程序。如果你用过它，本页会告诉你它的每项工具在 3DHeat 中位于何处。

本页列出了 Tacview 1.9 的每一项功能（依据其手册、界面字符串表和 ACMI 2.2 文件格式），以及 3DHeat 的[对局回放](match-replay.md)与之相比的进展。目标是：Tacview 能为回放及其数据做的事，3DHeat 也能做。

**状态：**
- **已完成**：3DHeat 中已有。
- **新增**：为对齐某项 Tacview 功能而构建。
- **尚未实现**：适用，但尚未构建。
- **不适用**：这里不适用，并说明原因。

功能位置：**对局**标签页、**模型回放**（或热力图标签页中的**模型叠加**），以及侧边栏的各部分：**回放**、**单位**、**事件**、**书签**、**战术显示**、**统计**、**时间平移与裁剪**、**地图与位置**、**音频和视频**和**标签**。参见[对局回放](match-replay.md)。

## 开发者参考：ACMI 2.2 属性 {#for-developers-acmi-22-properties}

由 `data/acmi.ts` 读取；数值属性成为数值列，文本属性成为类别列。所有属性都会在单位卡片的**原始**下显示。以下属性各有用途：

| 属性 | 用途 |
|---|---|
| T（全部四种形式）、Name、Type、Pilot、Group、Country、Coalition、Color、CallSign | 位置、姿态、模型、单位名称、团队 |
| IAS、CAS、TAS、Mach、AOA、AOS、AGL、HDG、HDM、OnGround | 字段、图表、HUD、起飞和降落检测 |
| VerticalGForce、LongitudinalGForce、LateralGForce | G 字段 |
| Throttle(2)、Afterburner、EngineRPM(2)、NR、AirBrakes、Flaps、LandingGear、Tailhook | 字段 |
| FuelWeight..9、FuelVolume..9、FuelFlowWeight..8 | 燃油字段，按油箱求和 |
| RadarMode、RadarAzimuth、RadarElevation、RadarRoll、RadarRange、RadarHorizontalBeamwidth、RadarVerticalBeamwidth、RadarRangeGateAzimuth/Elevation/Min/Max/HorizontalBeamwidth/VerticalBeamwidth | 雷达锥和距离门 |
| LockedTarget..9、LockedTargetMode、LockedTargetAzimuth/Elevation/Range、FocusedTarget | 锁定线 |
| EngagementMode(2)、EngagementRange(2)、VerticalEngagementRange(2) | 交战圆顶 |
| QNH、AltimeterSetting、WindSpeed、WindDirection、HeartRate | 字段 |
| Health | 字段 |
| 事件：Destroyed、TakenOff、Landed、Bookmark、Message、Comment、LeftArea、Timeout | 事件列表、统计（死亡、起飞、降落）、书签；Message 和 Comment 作为字幕 |
| PilotHeadYaw、PilotHeadPitch | 飞行员视线 |
| 类型标签 Bullseye（Navaid+Static+Bullseye） | Bullseye 字段和地图环 |
| 其他所有属性（PilotHeadRoll、操控、表面、ILS 偏差、SpO2、ENL、Label、Debug、Importance、Slot、Visible、Disabled、Radius、尺寸……） | 按原样显示在**原始**下 |

雷达和锁定角度相对于单位自身的轴线计算：方位角向右，俯仰角向上，滚转向右翼下沉。ACMI 规范说明它们相对于飞机，但没有说明哪个方向为正；此处的理解遵循其变换（偏航顺时针，俯仰向上，滚转向右）。
