# 累积

当查看器无法在一帧中绘制所有点时，它会先绘制其中一部分，再绘制另一部分，并在你保持静止时把这些画面叠加起来。画面会逐渐变清晰，就像照片显影一样。移动摄像机会从头开始。统计叠加中的**覆盖率**一行显示它进行到了哪一步。

![统计叠加：画面显影时覆盖率显示为百分比，完成后显示为*精确*](../assets/img/en/performance-stats-overlay.webp)

## 开发者信息 {#for-developers}

当一帧无法绘制所有行时，它会绘制一个样本并按权重放大；此时画面是一个无偏但有噪声的估计。**累积**会把连续的帧合并起来，使估计在画面保持不变时收敛到精确的答案。每一帧都会从五种模式中选择一种（[`engine.ts`](https://github.com/Holdi601/3DHeat/blob/main/src/render/engine.ts)）；最近使用的模式保存在 `engine.live.accumMode` 中。

| 模式 | 何时 | 累加缓冲区发生什么 |
|---|---|---|
| **reset（重置）** | 摄像机移动、改变了场的某些内容、关闭了渐进细化、一个增长中的时间窗口开始（回放的第一帧、跳转之后），或回放中的线热度发生了移动 | 替换为本帧的估计。 |
| **extend（扩展）** | 一个**累积**窗口自上一帧以来只增长了 | 本帧只绘制刚刚变得可见的行，以全权重绘制并相加。没有任何衰减。 |
| **ema（指数移动平均）** | 滑动窗口（**窗口**、**生命周期**）发生了移动 | `acc = acc × (1 - 0.34) + frame × 0.34`——约三帧的指数移动平均。 |
| **mean（均值）** | 没有任何变化，且估计尚未完成 | 在第 *n* 帧时 `acc = acc × (1 - 1/n) + frame × 1/n`：一个滚动均值。 |
| **skip（跳过，空闲）** | 已收敛且没有任何变化 | 不绘制任何内容；该帧只重新合成。 |

### 各模式的原因 {#why-each}

- **滚动均值，而不是求和。** 把缓冲区乘以 1 - 1/n 并加上新帧的 1/n，在代数上等同于最后求和再除以 *n*，但缓冲区始终只保存一个场的量。求和会达到场的 *n* 倍，而在 16 位目标上它会饱和于 65,504；如果除数不断增长，静止的视图就会随着停留时间变长而逐渐变暗——而摄像机移动时每帧都会重置，看起来完全正确。烟雾测试断言：合并 16 帧所得的结果与单帧相比为 1.00 倍。
- **累积回放使用扩展。** 已经累积的行仍然可见，因此一帧只需要刚刚到达的那一小段时间的数据——它正好能放进一帧，因此被精确地加入。如果改为重新估计，每一帧都会点亮一个不同的随机子集并使其淡出，看起来就像一阵阵闪烁而后消失，而暂停的帧还会不断填充。测试断言：回放期间总量单调上升，暂停 2.5 s 期间保持在 0.02% 以内。
- **滑动窗口使用移动平均。** 这些窗口确实每一帧都在变化。固定的混合权重能跟上移动的窗口（自回放开始以来所有帧的平均值会落后于播放头），而且比从头开始要平稳得多。
- **回放线热度使用重置。** 线热度的头部每一帧都在移动；移动平均会把每一个头部涂抹成一道条纹，因此每一帧都被完整绘制，尾部的淡出就是画面本身的效果。
- **部分帧经过临时目标。** 以部分全权重合并的帧，会从零开始被喷绘到一个单独的目标中，然后再混合进累加器，而不是直接以 1/n 权重喷绘。直接喷绘时，每个精灵会以它所加入的总量的 1/n 大小相加，而半精度浮点目标会把它舍入掉——在最密集的地方最为严重（[半精度累积](half-float-accumulation.md)）。

### 收敛 {#convergence}

每一帧的计划都知道有多少候选行，以及提交了多少行，因此覆盖每一行所需的帧数为 ⌈候选数 / 提交数⌉。一旦合并了这么多帧，视图就**收敛**了：统计叠加的*覆盖率*一行会从百分比变为*精确*，之后的帧则空闲。开启**每帧绘制所有行**（默认）时，单帧通常就能覆盖全部内容，因此收敛是即时的；渐进机制只在时间窗口包含的行多于一个绘制计划所能承载的数量（约 6700 万）时才需要。

### 什么会使其重新开始 {#what-restarts-it}

设置分为三组，取决于它们改变后累加缓冲区仍然代表什么：

| 组 | 改变的内容 | 效果 |
|---|---|---|
| **几何** —— 哪些行参与计算，以及各自的权重 | 视图模式；线路；精灵半径、中心和边缘强度、衰减、平滑衰减、曲线、像素限制、压平；距离剔除的近、远和平面界限；遮挡和隐藏地形后方；切片；画布尺寸；热度分辨率；组的可见性和符号；差值分割；全部 / 播放；历史；列筛选和实体选择；半精度增益 | 重置。 |
| **窗口** —— 时间范围 | 播放头移动；生命周期后备和淡出 | 扩展（累积）或移动平均（滑动）。 |
| **合成** —— 只影响着色 | 饱和度、密度响应、最低热度、颜色带；切开关卡；网格和坐标轴；模型叠加的设置和会话；景深 | 重新绘制，不改动热度。 |

摄像机移动总是会重置。因此拖动饱和度或颜色带是免费的；而拖动精灵半径则会在每一步都重新开始收敛。
