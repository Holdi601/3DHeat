# 实体

**实体** 让你选择一名玩家（或几名），只查看该玩家去过的地方。用它来跟踪你自己的移动，或某一名对手。

当数据集有人员列时会显示此面板。其标题显示人员数量；有选中项时则显示 `已选 / 总数`（*人员* 指一名玩家或 AI，见[术语表](glossary.md)）。

## 选择一名玩家 {#pick-a-player}

1. 在侧边栏中打开 **实体**。
2. 在搜索框中输入名字的一部分。
3. 勾选该玩家。标题会显示，例如 `2 / 10`，其他一切都会消失。
4. **清除** 会让所有人重新显示。

![选中十名玩家中的两名的实体面板](../assets/img/en/entities-selected.webp)

在热度模式（点、线、差值、队伍热度）中，以及在[图形回放](box-replay.md)的轨迹、图形和尾迹中，选择都只显示被选中的人员。留空则显示所有人；选中所有人与不选任何人的效果相同。

## 面板 {#the-panel}

| 部分 | 含义 |
|---|---|
| 搜索框 | *搜索 N 个实体……*——按名称中不区分大小写的子串过滤列表。显示 `N 个匹配`，或 `N 个匹配，显示前 200 个`；搜索无结果时显示 *没有与"……"匹配的项*。 |
| 列表 | 最多 200 名人员（前 200 个匹配项），每人有一个复选框、该人员颜色的色块，以及名称（名称为空时显示 *（未命名）*）。 |
| 播放中提示 | 时间正在播放时，列表只包含*播放头处正在进行中*的人员；搜索则会查找全部。 |
| **AI (n)** | 一个可折叠的分组，包含由 AI 控制的单位，与玩家分开。 |
| **添加所列项** | 把当前列出的所有人加入选择。 |
| **仅选所列项** | 使选择恰好是列出的这些人。 |
| **清除** | 清空选择。 |

## 限制 {#limits}

在热度中，选择是一个过滤器，占用四个[过滤器槽位](filters.md#rules)之一。当其他过滤器已经占满四个槽位时，面板会显示 *未应用于热度：所有过滤器槽位均已占用。图形回放仍只显示这些实体。请在过滤器下清除一个过滤器以释放槽位。* 清除一个过滤器即可释放一个槽位。

每次加载新数据集时，选择都会被清除。当你在对局标签页中聚焦某一名玩家时，它会设置相同的选择。

## 开发者须知 {#for-developers}

选择以*人员*过滤器的形式保存（[过滤器](filters.md#for-developers)）。着色器的掩码保存 65,536 个人员 id；超过这一数量的人员在有选择时不会在热度中绘制。
