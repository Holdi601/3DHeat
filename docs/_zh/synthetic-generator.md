# 合成数据生成器

没有自己的数据？按一个按钮，3DHeat 会为你虚构一场模拟战斗，规模大小随你选择。

1. 在热力图侧边栏中打开 **数据集** 面板（位于 **数据源** 的下方）。
2. 滚动到 **合成数据生成器**。
3. 设置 **行数（百万）**。先试 1：默认的 800 万对于第一次尝试来说负担很重。
4. 按 **生成**。

![100 万行、8 支队伍，以队伍热度绘制](../assets/img/en/synthetic-generator-team-heat.webp)

**数据集** 面板可以生成数据集，而不必加载。它有两个用途：在没有自己数据的情况下试用查看器，以及在把大型真实数据加载到电脑*之前*，检查给定的行数、精灵半径和预算能否保持可用的帧率。它的移动模式模仿大逃杀式的对局——队伍一开始彼此分开，然后被挤压在一起——因为均匀的噪声在任何预算下看起来都没问题，却恰恰隐藏了值得发现的假象。

## 控件 {#controls}

| 控件 | 默认值 | 含义 |
|---|---|---|
| **行数（百万）** | 8 | 要生成的行数。对每个玩家向下取整为整数个时间刻。 |
| **队伍** | 8 | 分组数量（至少为 1）。 |
| **每队人数** | 12 | 每个分组的玩家数（至少为 1）。 |
| **地图半宽（m）** | 4000 | X 和 Z 方向上可玩区域宽度的一半。 |
| 估算行 | | "≈ X GB 内存，量化后 GPU 上 Y GB。"（每行约 26 字节内存和 8 字节 GPU 内存）。 |
| **生成** | | 在导入工作线程中生成，并显示进度，并替换任何已加载的数据集。 |

生成在后台工作线程中进行，因此数千万行也不会使页面冻结。

## 它生成什么 {#what-it-generates}

来自 [`src/data/synth.ts`](https://github.com/Holdi601/3DHeat/blob/main/src/data/synth.ts)：

- **列：** 位置、时间、人员（`P000`、`P001`，……）、分组（`Team 1`、`Team 2`，……）、偏航和俯仰，以及生命周期。没有会话列，也没有过滤器列。
- **时间：** 每个玩家每 0.25 秒一个样本，从 0 开始（相对时间，没有挂钟时间）。
- **移动：** 每支队伍从一个环形区域中自己的扇区开始，位于半宽的 55%–95% 处。一个以中间附近为中心的安全圆（随机偏移最多为半宽的四分之一）分六个阶段缩小到半宽的 8%，中间有停顿；每个玩家都朝圆内一个游移的点转向，带有阻尼和噪声。高度在 0 到 220 米之间起伏。
- **视线方向：** 偏航沿行进方向，俯仰由垂直速度决定。
- **可重复：** 随机种子固定（1337），因此相同的设置总是产生相同的数据。

所有热度模式、盒子回放和线路热度（整条轨迹，因为没有事件列）都可用于它。生命周期历史也可用。
