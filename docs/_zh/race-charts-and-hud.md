# 图表与 HUD

图表把你的圈按米逐一对齐，因此你可以看出一个车手在哪里刹车更晚，或在哪里更早松油门。视图左上角的卡片显示每辆车和每位车手此刻正在做什么。

![视图下方的图表：两圈的油门、刹车、转向等行，顶部的时间与原因条，以及带卡片的光标](../assets/img/en/race-charts-rows.webp)

## 图表 {#the-charts}

所有圈都在同一条距离轴上——沿参考线的米数（见[统一的距离轴](race-corner-analysis.md#one-distance-axis)）——因此同一个 x 值在每一圈中都是赛道上的同一个位置。一圈会单独绘制（并可回放）；同一赛道的第二圈则会与之对比绘制。没有载入任何圈（或分析失败）时，区域会显示："载入一圈后会出现图表；再载入同一赛道的另一圈即可比较两者。"

### 图表上有什么 {#what-is-on-them}

- **图例**：每个已绘制圈的颜色和标签，参考圈标注为"（参考）"；当可见的圈多于已绘制的圈时显示"另有 +N 圈已绘制，未入图表"；**曲线图 (N) ▾**；缩放时显示 **整圈**；以及一行提示。
- **两条条带**位于顶部，针对焦点圈：
  - *时间*：[时间地图](race-replay-and-scene.md#time-map-where)以条带显示，红色为落后，绿色为领先；
  - *原因*：它的每项损失都是一根条，位于其原因所在处，使用原因的颜色；悬停在条上可查看其标题和代价。
- **弯道色带**：从每个弯道的入口到出口的阴影带（依参考圈而定），以及它在轴下方顶点处的名称（`T1` 等）。
- **所选发现**：一条以其原因颜色标示其范围的色带。
- **各行**（曲线），每个所选通道一行，左侧显示其名称以及范围的上下限，范围跨越零时有一条零线。每一圈是其颜色的一条线：焦点圈为 2 像素宽且不透明，参考圈不透明，其余圈为 1.5 像素、75% 透明度。差距行不包括参考圈（它与自身的差距为零）。
- **光标**：参考车所在位置（或指针所在位置）的一条竖线，以及除差距行外每一行上每辆车的一个点——光标处所有车都在同一米位置；否则每辆车则在回放时钟时显示其各自的距离。

最多绘制 **8** 圈：焦点圈、其等级最佳圈和参考圈优先，其余按载入顺序。

### 各行及其高度 {#rows-and-their-heights}

各行按权重共享图表的高度，最低为 16 像素：

| 行 | 权重 |
|---|---|
| 差距（相对参考圈，秒，带符号） | 1.7 |
| 速度（km/h） | 1.7 |
| 一个踏板（油门、刹车、离合） | 1 |
| 转向 | 1.1 |
| 挡位 | 0.8 |
| 一个指示灯（手刹、ABS……） | 0.55 |
| 其他 | 1 |

表中为某个通道设定了固定显示范围（踏板为 0-100%）的，使用该范围；其他则依所见圈的可见部分进行调整。行名称对于所占空间而言过长（另一种语言中的长单词）时，若行足够高，则顶部数值下移一行；否则以省略号截断；完整名称则显示在工具提示中。

### 默认曲线 {#the-default-graphs}

在选择曲线之前：先是**差距**，然后是所有圈都具有的、表中标记为 `graph` 的每个通道——油门、刹车、离合、手刹、转向、挡位、速度——只是踏板或指示灯通道除非某圈的数值超过 0.02，否则不计入（从未踩下的离合不算曲线）。顺序与表中相同。

### 曲线选择器 {#the-graph-picker}

**曲线图 (N) ▾** 会在按钮上方打开一个面板：

- 一个过滤框（匹配通道的名称或编号）；
- **默认**（恢复默认集合；其工具提示会显示数量）和 **关闭**；
- *与参考圈的差距*，然后是已绘制圈所带的每个通道，按类别分组（运动、操作输入、引擎、辅助、轮胎、刹车、悬挂、车轮、其他、计时、位置），每项一个复选框；按车轮分的通道为一行，每个车轮一个标签（FL、FR、RL、RR）。

无论勾选的先后，勾选的通道都保持表中的顺序。这一选择会保留到点击 **默认** 或重新加载为止。表中没有的通道会列在 *其他* 下，名称取自其自身的编号（"brakeLinePress" → "Brake line press"）。

### 悬停、滚轮、缩放、点击 {#hover-wheel-zoom-click}

| 操作 | 作用 |
|---|---|
| 悬停 | 每辆车、它的卡片和它的操作输入都移动到该米位置；一根标记柱在赛道上标出该处；一个表格列出该处每个已绘制圈在每一行上的数值（差距对参考圈显示为"ref"）；在卡片上方显示"在 N 米 - 图表的光标"。移出绘图区后，控制权交回回放 |
| 滚轮 | 沿圈以每格 1/200 的可见跨度步进回放，并暂停回放（Shift：5 倍）；缩放时，视图跟随光标 |
| Ctrl+滚轮（Cmd+滚轮） | 以指针为中心缩放距离轴，每格向外 1.25 倍 / 向内 0.8 倍，最窄为 40 米；缩放到整圈即结束缩放 |
| 横向滚轮 | 缩放时平移（每 100 单位滚动量平移跨度的 10%） |
| 双击，**整圈** | 缩小视图 |
| 点击 | 将回放跳到参考圈到达该米位置的地方 |
| Shift+点击 | 在该处让各车对齐（见[对齐](race-replay-and-scene.md#lining-up)） |

语言更改时，图表会以当前语言重绘。

图例中的提示行简要说明了同样的内容："悬停：每辆车在该处 · 滚轮：沿圈步进 · Ctrl+滚轮：缩放 · 点击：跳转 · Shift+点击：对齐"。

## 车辆卡片（HUD） {#the-car-cards-hud}

位于视图左上角，每个可见的圈一张卡片——最多 **6** 张，即按载入顺序排列的前六个可见圈——显示回放（或图表光标）所在时刻的数据。

**标题：** 圈的颜色和标签；实时差距——该圈到达当前距离所用的时间减去参考圈到达同一距离所用的时间，"+0.48 秒"——或"参考"；**⋯** 用于显示或隐藏其他每个数值（与 *卡片上的所有数值* 相同）。被追逐车辆的卡片会高亮显示。

**俯视的车辆：** 圈颜色的车身轮廓，前端有一个箭头，四个轮胎（前轮随转向最多转 28°），每个轮胎按其温度着色，与 3D 车辆平面绘制的图标相同：滑移环、悬挂条、刹车辉光、磨损带、负荷条。

**读数：** 速度（km/h）、该圈自己的时间、它沿参考线的距离。

**操作输入：**

- 一个按转向输入转动的方向盘（满打方向画作 180°），其下方显示百分比；
- 每个踏板一根条，按踏板盒的样子从左到右排列——离合、刹车、油门——每根条都有其百分比和简称，并使用其颜色（仅显示该圈带有的踏板）；
- 挡位（R 为倒挡，N 为空挡）；
- 每个该圈带有的开关通道一个小指示灯——手刹、ABS、TC、DRS、进站限速、腾空——开启时以其颜色点亮（超过其范围的一半时）；
- 每个等级通道一个读数：刹车分配、ABS 和 TC 设置、增压、燃油。

**操作输入轨迹：** 每个踏板（一条车道，各自使用其颜色）以及转向（独立的车道，居中）的最后 **6 秒**，截至此刻——即驾驶员在此之前做了什么。最多 160 个点。

**所有数值**（⋯ 或 *卡片上的所有数值*）：此刻该圈带有的每个其他标量，然后是每个按车轮分的通道，以四个数值显示（FL FR RL RR），名称取自通道表或通道自己的名称，按类别排序。

### 通道表 {#the-channel-table}

[`src/race/schema.ts`](https://github.com/Holdi601/3DHeat/blob/main/src/race/schema.ts) 中的 `CHANNELS` 是描述通道的唯一地方：它的单位、是每个样本一个值还是每个车轮一个值（存为 `name.FL` 等）、它的分组、显示范围、它在车辆上如何绘制（`glyph`）、它在卡片上如何出现（`input`：`pedal`、`steering`、`gear`、`lamp`、`level`）、它是否为默认曲线、它是跳变而非渐变的（挡位、标志），以及它如何显示（缩放、单位、位数）。标签和简称是每种语言中的消息（`race.channel.<name>.label` / `.short`）。

带有绘制方式或默认曲线的通道：

| 通道 | 单位 | 绘制方式 | 默认曲线 |
|---|---|---|---|
| `throttle`、`brake`、`clutch` | 0..1 | 踏板（绿色、红色等），以 % 显示 | 是 |
| `handbrake` | 0..1 | 指示灯 | 是 |
| `steer` | -1..1，右为正 | 方向盘 | 是 |
| `gear` | - | 挡位 | 是 |
| `speed` | m/s，显示为 km/h | - | 是 |
| `absActive`、`tcActive`、`drs`、`pitLimiter`、`airborne` | 0..1 | 指示灯 | - |
| `brakeBias`、`absLevel`、`tcLevel`、`boost`、`fuel` | - | 等级读数 | - |
| `tireTemp`（按车轮） | °C，显示 40-130 | 轮胎颜色 | - |
| `tireTempInner/Middle/Outer` | °C | - | - |
| `slipRatio`、`slipAngle`（按车轮） | 按游戏的缩放，显示 ±1.5 | 滑移环 | - |
| `combinedSlip`、`slipIndex`（按车轮） | 显示 0-1.5、0-1 | 滑移环 | - |
| `suspension`（按车轮） | 0..1 | 悬挂条 | - |
| `brakeTemp`（按车轮） | °C，显示 100-900 | 刹车辉光 | - |
| `tireWear`（按车轮） | 0..1 | 磨损带 | - |
| `wheelLoad`（按车轮） | N，显示 0-12 000 | 负荷条 | - |

表中其他的通道（绘制为曲线并列出，但不在车辆上绘制）：`latAcc`、`longAcc`、`vertAcc`、`yaw`、`pitch`、`roll`、`yawRate`、`latVel`、`longVel`、`vertVel`、`bodySlip`（漂移角）、`loose`、`lateral`（与参考线的偏移）、`rpm`、`power`、`torque`、`waterTemp`、`oilTemp`、`tirePressure`、`camber`、`padLife`、`discLife`、`suspensionM`、`wheelSpeed`、`wheelSurfaceSpeed`，以及 `time`、`distance`、`x`、`y`、`z`。

**表中没有的通道** 仍会被读取、绘制为曲线（归在 *其他* 下）并列在卡片上，其标签取自其自身的名称。**要为它赋予正式的名称、单位和绘制方式**，在表中添加一项（并在每种语言的 `src/i18n/locales/<语言>/race-channels.json` 中添加其标签消息）。新的一种车轮绘制方式，只需在 `WHEEL_GLYPHS`（glyph.ts）中添加一项及其平面对应的 `CARD_GLYPHS`（RaceHud.tsx）；两者都按类型定义，因此在两者都存在之前构建会失败。`src/race/extensible.test.ts` 检查：未知通道能到达曲线，表中的每个图形都能绘制，指示灯能够点亮。
