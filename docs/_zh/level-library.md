# 关卡库

关卡库会把你的关卡保存在这个浏览器中，这样你就不必再次加载和简化它们。**清除浏览器中该网站的数据会删除关卡库，而且没有导出功能。** 请保留你的原始文件。

处理一个关卡——解析、分类、焊接、抽稀、打包纹理——很慢，而且每次结果都相同。背景 / 关卡面板底部的 **库** 会把处理过的关卡保存在这个浏览器中，因此抽稀后的网格永远不需要重建两次（[`levelLibrary.ts`](https://github.com/Holdi601/3DHeat/blob/main/src/data/levelLibrary.ts)）。

## 保存并重新加载关卡 {#save-and-reload-a-level}

1. 加载地图图像或三维模型，并检查它看起来是否正确。
2. 按 **保存到库**。面板会显示 *已保存。下次将立即加载。*
3. 下次，打开 **库** 列表，然后在该关卡上按 ▸。
4. 对于不再需要的条目，按 ✕ 将其删除。

## 使用方法 {#using-it}

| 控件 | 效果 |
|---|---|
| **保存到库** | 存储当前关卡。地图图像以 PNG 格式存储，并带有其两个锚点；模型则存储其处理后的缓冲区。面板会显示 *已保存。下次将立即加载。* |
| 库列表 | 每个已存储的关卡占一行：名称（悬停可看到其存储大小）、模型的三角形数量或图像的宽度（像素）。 |
| ▸（*加载*） | 将该条目加载为当前关卡。 |
| ✕（*删除*） | 删除该条目。 |
| 用量行 | `已使用 X，共 Y。`——浏览器为该网站估算的存储空间。 |

如果没有存储任何内容，列表会显示 *空。加载地图或模型，然后点击"保存到库"。*

## 存储了什么 {#what-is-stored}

| 类型 | 已存储 | 未存储 |
|---|---|---|
| 地图图像 | 图像（PNG）、其尺寸、其锚点 | 高程、翻转、不透明度、亮度、去饱和——恢复为默认值（高程 = 当前数据集的最低 Y，翻转开启） |
| 三维关卡 | 顶点、顶点颜色、纹理坐标、它们的图块和纹理图集、地面 / 结构 / 水体三角形、结构边缘、三角形数量 | 部件名称和分类原因，以及每个外观设置——恢复为全新导入时的默认值 |

从库中加载的模型没有部件列表，其边界和地面高度范围会根据其顶点重新计算。

## 存放位置 {#where-it-lives}

存放在浏览器的 IndexedDB 中，数据库为 `3dheat`，对象存储为 `levels`，对应本页面的来源（浏览器地址栏中的地址）。它只存在于该浏览器配置文件中：另一个浏览器、另一个配置文件，或另一个地址（例如 `localhost` 而不是 `127.0.0.1`）会看到一个不同的、空的库。清除浏览器中该网站的数据会删除它。旧版本保存的、没有结构、颜色或水体的条目仍然可以加载。
