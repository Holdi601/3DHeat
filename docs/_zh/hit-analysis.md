# 命中分析

**载具**标签页显示某辆坦克、舰船或士兵在哪里被命中，以及是谁命中的。用它来查看坦克的哪一侧会被射中，或哪个敌人造成了伤害。

## 试一试 {#try-it}

1. 载入一场有命中记录的对局（见下表，了解哪些游戏会提供命中数据）。
2. 打开顶部的**载具**标签页。
3. 在**载具**下选择一个单位，例如某种坦克。括号中的数字是它承受的命中次数。
4. 查看图形：每个标记都是一次命中，位于它被击中的位置。
5. 打开**谁命中的**，查看射手、武器或射手载具，以及命中次数、伤害、击杀数和距离。

![载具标签页：带有命中标记的演示坦克，并展开了谁命中的](../assets/img/en/hit-analysis-tank.webp)

如果没有载入任何内容，或数据中没有载具的命中记录，该标签页会说明缺少什么，以及应使用哪个转换器。

```
        shooter ----> o  hit mark on the figure
        shooter ----> o
  [ tank figure ]
```

当数据给出了一个点或一个身体部位时，图形会显示这些命中。细分（谁命中的、用什么、造成多大伤害、从多远处射击）适用于所有来源。

## 每个来源提供什么 {#what-each-source-gives}

| 来源 | 单位上的点 | 射手 | 武器 | 伤害 / 结果 |
|---|---|---|---|---|
| 战争雷霆 | 有，位于单位的坐标系中，并带有射击的方向 | 有 | 射手的载具 | 致命、严重、模块被毁、致命一击 |
| CS2 | 身体部位（hitgroup） | 有 | 有 | 伤害、护甲、剩余生命值 |
| 坦克世界 | 有（部件方框、入口和出口） | 有 | - | 伤害或无（跳弹、未穿透） |
| 战舰世界 | 有，位于舰船的坐标系中 | 有 | 命中类型 | - |
| Squad | 载具：有——撞击点根据载具自身的位置和朝向放置在载具的坐标系中 | 无（数据中没有指明） | 伤害类型 | 该时刻载具生命值的下降，以及是否被摧毁 |
| Squad 士兵 | 无：命中结果（骨骼和撞击点）由转换器原样保存；写入时带有 `hitBone` 的 `impact` 行会被立即读取 | | | 仅有伤口和死亡 |
| Arma（OCAP，即 Arma 3 记录器） | 无：OCAP 记录的是谁命中或击杀了谁、用什么、从多远处，而不是位置 | 有 | 有 | 命中或击杀、距离 |
| Tacview ACMI | 有，前提是某个武器对象在距单位 30 m 之内结束（不包括发射器）：它在单位坐标系中的最后位置（朝向、俯仰、横滚），以它飞来的方向计 | 武器的 `Parent` | 武器的名称，或 Timeout 的 AmmoType | Timeout 的 Outcome，`Health` 的下降，`Destroyed`；没有武器时，则为没有位置的击杀或伤害 |
| IL-2 遥测（Watcher） | 有：`hit` / `damage` 事件以玩家自己飞机的坐标系携带该点（视为 x 向前、y 向上、z 向右） | 无 | 无 | 伤害力 |

| 战地 6（GameCapture） | 无：捕获读取的是击杀信息栏（击杀、死亡、爆头标记），而不是命中 | | | |
| DCS / 其他 Watcher 实时来源 | 除其 Tacview 录像所含内容外，没有命中事件 | | | |

如果单位的任何命中都没有点，图形就不会显示标记，而**谁命中的**细分会自动展开：按射手、武器或射手的载具分组，每组都有其命中次数、伤害和击杀数，以及中位数和最远距离。

## 限制在某个区域内 {#restrict-to-an-area}

**区域**区会把分析限制在地图上某个地点发生的命中。

1. 按**画矩形**或**画多边形**，在三维地面或战术地图上绘制。
2. 选择**受害者在内**（当被命中的单位位于该区域内时计为一次命中）或**射手在内**（当开火的一方位于该区域内时）。
3. 按**用作筛选**。标签会显示“{n} / {total} 次命中位于该区域内”。
4. **重置区域**会移除所有区域。

每个区域都是一个[体积](volumes.md)，因此同样的形状也会筛选热力图和回放。区域可以包含或排除（排除型区域会把其中的命中剔除，并显示为“{n} / {total} 次命中位于该区域之外”）。每个区域都显示为一个标签，并附有该单位有多少次命中位于其中；标签上的 × 会将其移除。计数、图形、细分和筛选列表都会随之变化。

命中的位置：产生该命中的行保存的是一方的位置（受伤或被击中者为受害者，开火者为射手）；另一方则取该单位自身在时间上最接近的样本（5 s 之内）。当区域在进行筛选时，如果该方的位置未知，这次命中会被剔除，面板会说明有多少次（“因无已知位置而剔除”）。

## 开发者信息 {#for-developers}

任何转换器都可以添加命中：受害者的行（`hit`、`impact`、`hurt`、`wounded`），附带 `hitBone`（骨骼骨节、Arma 的选区、Reforger 的命中区——映射为头部、胸部、腹部、手臂和腿部），或 `hitLocalX/Y/Z`（米，x 向前、y 向上、z 向右），并以 `other` 指明射手，以及 `damage`。
