# 筛选与工具

这些面板让你选择查看*哪些*数据，并测量所看到的内容。当画面过于杂乱时使用它们：只显示一支队伍、一名玩家、一个地点，或建筑物的一层。

每个面板都会缩小数据范围，它们协同工作：只有通过**全部**筛选的行才会被绘制（逻辑与）。

```
all rows -> Filters -> Teams -> Entities -> Slice -> picture
              AND       AND       AND        AND
```

示例：在筛选中取消勾选*坦克*，在队伍中隐藏红队，并在实体中选择一名玩家。你只会看到该玩家的非坦克移动。

| 面板 | 作用 | 热度模式 | 模型叠加 |
|---|---|---|---|
| [筛选](filters.md) | 对加载时保留的任意列进行范围和类别筛选。 | 是 | 否（仅列筛选） |
| [差值拆分](difference.md#the-difference-split-panel) | 在差值模式中，哪些行相加、哪些行相减。 | 仅差值 | 否 |
| [队伍](teams-list.md) | 显示或隐藏每支队伍；将队伍放到 + 或 - 一方。 | 是 | 是 |
| [实体](entities.md) | 选择单个玩家。 | 是 | 是 |
| [切片](slice.md) | 从关卡和热度中切出一层，以观察建筑物内部。 | 是，以及关卡 | 否 |
| [测量](measure.md) | 一把尺子，以及光标下的热度值。 | 是 | 是 |
| [体积与比较](volumes.md) | 绘制三维形状并询问其中发生了什么。也可以筛选。 | 是 | 是 |
| [细分](breakdown.md) | 在某个地点中，哪种载具、玩家或武器表现最好。 | 不适用 | 不适用 |

命中分析在**载具**标签页中有自己的区域筛选：参见[命中分析](hit-analysis.md)。

热度图、行、人员和分组等术语在[术语表](glossary.md)中有说明。

## 面板的位置 {#where-the-panels-are}

热力图标签页的侧边栏，从上到下：

1. 模式栏和会话选择器
2. 数据源、列映射、数据集
3. 路线（线条模式）
4. 热度面板，或队伍查看器
5. 差值拆分
6. 队伍
7. 实体
8. 筛选
9. 背景 / 关卡
10. 切片
11. 测量
12. 摄像机路径与渲染
13. 性能
14. 摄像机与场景

对局标签页显示模式栏、会话选择器、其自身的面板、筛选、背景 / 关卡和摄像机与场景。
