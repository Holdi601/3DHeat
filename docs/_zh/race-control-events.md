# 车辆操控事件

查看器会看每一圈是怎么开的，并标出车辆在哪里打滑、打转、撞上东西或浪费了抓地力。这很有用，因为损失时间的失误是最容易修正的。

![车辆操控部分：每一圈有多少次车轮抱死、打转或推头，以及展开了一项的故障列表](../assets/img/en/race-control-table.webp)

## 通俗解释 {#in-plain-words}

- **抱死**：刹车太猛，车轮停止转动并开始滑动。车会停得更差，也无法转向。
- **车轮空转**：油门踩得太猛，驱动轮转得比车前进得还快。你会失去动力。
- **转向过度**：车尾大幅甩出。如果整个车转了一圈，那就是**打转**。
- **转向不足**：车头大幅滑出（"推头"）；方向盘打得再多也没有用。
- **碰撞**和**撞毁**：车子碰到了什么东西（碰撞是轻微的刮擦或顶碰，撞毁是严重的）。
- **ABS**、**TC**：车辆自带的辅助系统，用来对抗抱死和车轮空转。它们不是失误。

## 车辆操控部分（你会看到什么） {#the-car-control-section-what-you-see}

对于所选的那一圈，无论这些圈数据里有什么——即使没有轮胎滑移和漂移角，它仍会显示找到的内容，而不是什么都不显示（见下文）。

**表格**：每种至少在其中一圈出现的类型各占一行——锁死车轮、车轮空转、尾部甩出（转向过度和打转）、推头、撞毁、碰撞、ABS 工作、牵引力控制工作、手刹、腾空——每个单元格显示"次数 · 秒数"，分别对应所选的那一圈和与之比较的那一圈；如果有漂移角，还会显示*最大漂移角*（地面上的最大值）。

**列表**：其中未与对方共有的故障，至少损失 0.02 秒的，按代价从高到低排列，最多 12 项，每项都有标题和代价（以及其类型的标签）。点击一项即可阅读其提示、在故障前 40 米对齐两辆车并重放。**还有两圈在那里的表现**会列出每一项故障，包括共有的（标签为"两者都这样做"，代价为"—"，即低于 0.01 秒）。如果没有任何项目，则显示："X 在轮胎上做的事没有让它多损失时间，而 Y 也没有做这些事。"

**其下方的提示**说明检测所依据的数据——"根据每个车轮的滑移和滑移角，以及车辆的漂移角。"（或者是滑移和滑移角、滑移和漂移角、仅滑移，或"仅根据车辆的漂移角——这些圈数据不含轮胎滑移。"）——还说明了限值所依据的路面（柏油、松散、混合：超过 80% 的样本为松散则为松散，低于 20% 则为柏油）、事件是与哪一圈对比得出的，以及代价是如何计算的。

在**没有轮胎滑移也没有漂移角**的情况下（即没有其遥测数据的 FH Companion 圈文件），表格和列表仍然照常显示，提示会说明仅凭这些圈数据还能找到什么："这些圈数据不含轮胎滑移，也不含漂移角，因此无法判断锁死和车轮空转。仍可找到：推头（根据方向盘与路径的对比）；碰撞和撞毁（根据速度和加速度）。"——如果圈数据中有偏航率，还会提到从偏航率得出的滑动；只有存在方向盘数据时才会判断推头。关于滑移和漂移角限值的那句话会被省略，并有第二条提示："对于 Forza Horizon，也请选择每个 FH Companion 圈旁边的 `.tele.gz` 文件：它是完整的遥测数据，每个车轮的滑移每秒采样 64 次。"

这一圈的**总**操控代价（用于摘要）会把重叠的故障——例如一次抱死以及它引发的滑动，相隔 40 米以内——只计算一次，取该组中代价最高的那一项。

## 各种类型 {#the-kinds}

| 类型 | 表格行 | 是否为故障？ | 计入的最短时长 |
|---|---|---|---|
| `lock` | 锁死车轮 | 是 | 0.1 秒 |
| `wheelspin` | 车轮空转 | 是 | 0.15 秒 |
| `oversteer` | 尾部甩出 | 是 | 0.2 秒 |
| `spin` | （与尾部甩出一起计数） | 是 | 0.1 秒 |
| `understeer` | 推头 | 是 | 0.25 秒 |
| `crash` | 撞毁 | 是 | - |
| `hit` | 碰撞 | 是 | - |
| `abs` | ABS 工作 | 否 | 0.2 秒 |
| `tc` | 牵引力控制工作 | 否 | 0.2 秒 |
| `handbrake` | 手刹 | 否 | 0.1 秒 |
| `airborne` | 腾空 | 否 | 0.15 秒 |

较短的片段属于噪声（路肩、颠簸、单个采样）。通过检测的网格点（每 2 米一个）若连续片段之间的间隔不超过 2 个点，则会被合并。只有**故障**才可能是失误并带有代价；其他类型是车和驾驶员所做的动作。

## 每项检测都需要的内容 {#what-every-test-needs}

### 派生通道 {#derived-channels}

在任何判断之前，每一圈都会得到其游戏没有发送的数据，并使用统一的名称（游戏自己的值始终优先）：

| 通道 | 来源 |
|---|---|
| `bodySlip`（漂移角） | 车身坐标系下的速度，`atan2(latVel, abs(longVel))`，在游戏发送它的地方使用（速度低于 3 m/s 时为 0）；否则使用航向（游戏的偏航角，在速度超过 10 m/s 的样本上按符号和偏移量拟合到行驶方向，仅当圆形方差低于 0.05 时采用）与行驶方向（间隔至少 2 m 的位置）之差，适用于速度超过 3 m/s 时 |
| `yawRate` | `yaw` 随时间的变化，适用于有航向但没有速率的情况 |
| `airborne` | 每个车轮的地面接触都断开（≤ 0.5）；否则每个车轮的载荷都低于其中位数的 5%；否则每个悬架行程都在或低于 0.02（完全伸展）。单个偶发样本不算飞行 |
| `slipRatio.<W>` | 当速度超过 3 m/s 时，`(车轮表面速度 - 车速) / 车速`，适用于游戏发送车轮表面速度的情况；或者由车轮转速 × 在该圈上测得的滚动半径得出——在直线滑行时 `speed / rotation` 的中位数（速度 > 10 m/s，油门 < 0.3，刹车 < 0.05，abs(纵向加速度) < 3 m/s²，不在空中；若样本少于 20 个，则取所有高于 10 m/s 的样本），在 0.1 到 1 m 之间才采用。标记为 `physical` |
| `loose` | Forza 的路面隆隆声在至少 2 个车轮上（> 0.001）持续至少 0.33 秒（路肩更短），间隔不足 1 秒的会被跨接 |

### 着地且稳定 {#on-the-ground-and-settled}

在空中或**着地后 0.3 秒**内，不会判断任何内容——悬架触底，加速度会突然升高，这不是抓地力、刹车或驱动。样本还必须处于**行驶中**：速度超过 5 m/s。

### 地面 {#the-ground}

每个样本的地面，若该圈的 `loose` 通道这样标示（Forza 的路面隆隆声、Trackmania 的车轮材质），则为**松散**；否则取该圈的路面（见[项目与路面](race-loading-laps.md#discipline-and-surface)）：柏油，或其他任何情况下的松散路面。弯道、漂移习惯和阈值对柏油和松散路面分别保存。

### 滑移，以轮胎标称峰值的倍数表示 {#slip-as-a-multiple-of-the-tyres-nominal-peak}

各游戏对滑移的缩放方式不同；`meta.slip` 说明了方式，每个滑移都会除以一个比例，使约 1 为轮胎的标称峰值：

| `meta.slip` | 含义 | 除以 |
|---|---|---|
| `peak` | 由游戏归一化：超过 1 即失去抓地力（Forza Data Out） | 1 |
| `scaled` | 物理滑移除以柏油峰值（Kunos 记录器） | 该路面的标称峰值除以柏油的标称峰值 |
| `index` | 0..1 的滑动度量（Trackmania 的 SlipCoef） | 0.5 |
| `physical`（或未知） | 滑移率以小数表示，滑移角以弧度表示 | 该路面的标称峰值 |

在没有更好的数据时使用的标称峰值：

| 路面 | 滑移率 | 滑移角 |
|---|---|---|
| 柏油 | 0.12 | 8° |
| 混合 | 0.18 | 12° |
| 松散（砾石） | 0.25 | 15° |
| 雪地 | 0.25 | 15° |
| 冰面 | 0.10 | 6° |

### 抓地力何时到达极限：每辆车的轮胎曲线 {#where-grip-ends-each-cars-tyre-curves}

轮胎在何时不再提供更多的抓地力，是**按车辆测量**的，取自它的每一圈有载荷的数据（`measureTyres`），柏油和松散路面分别计算：

| 曲线 | 样本（速度 > 10 m/s，稳定，加速度低于 45 m/s²） | 滑移（x） | 力（y） |
|---|---|---|---|
| 刹车 | 刹车 > 0.3，手刹 ≤ 0.2，直线行驶（横向低于最大值的 30%） | abs(四个车轮滑移率的平均值) | 减速度 |
| 牵引 | 油门 > 0.8，刹车 ≤ 0.05，直线，该速度下车辆的满油门拉力 > 0.5 m/s² | 驱动轮中最大的滑移率 | 加速度占该拉力的比例 |
| 前轴 | 横向超过最大值的 30%，该速度下车辆的抓地力 > 1 m/s² | 较大的前轮滑移角 | 横向加速度占该抓地力的比例 |
| 后轴 | 同上 | 较大的后轮滑移角 | 同上 |

"最大值"是该圈在该路面上 abs(横向加速度) 的第 99 百分位（若该路面的样本少于 50 个，则取所有路面的数据）。传动系统决定驱动轮（前驱为前轮，后驱为后轮，四驱为全部；未知则为全部）。

当样本达到至少 **150 个**时，滑移被切分为 6 到 14 个等数量的区间（每 40 个样本一个），每个区间的力取其上四分位数（即驾驶员要求时轮胎所给出的力），并与相邻区间平滑。**最佳点**是力最大的区间；**极限**是力首次从该点下降 **8%** 之后的那个区间。若数据中曲线从未下降，则没有极限（无穷大）——在该游戏中超过"峰值"并不会付出代价，而仅凭滑移也不会在那里标出任何问题（Forza Horizon 的转弯和牵引曲线就是这样）。若某个路面的样本太少，则使用另一个路面的数据；若总样本太少，则使用**标称**极限：标称峰值的 1.5 倍。

每辆车还会得到：

- 它的**漂移习惯**：在其以最大值的 60% 或更高速度转弯时，漂移角的上四分位数（需要 100 个样本）；
- 它的**每曲率转向量**（`steerGain`），按每 5 m/s 的速度区间划分：在较坚定地转弯但仍远低于抓地极限时（最大值的 30%–60%，曲率比 400 m 半径更紧，转向大于 0.02；每个区间需 25 个样本），abs(转向) / 路径曲率 的中位数。路径的曲率在游戏发送偏航率的地方取偏航率除以速度，否则取位置 ±5 米处的数据。

## 逐类检测 {#detection-kind-by-kind}

| 类型 | 检测（基于行驶中且稳定的样本） | `peak` 和 `limit` |
|---|---|---|
| **lock** | 刹车 > 0.05，手刹不超过 0.2，且任一车轮的滑移率低于负的刹车极限 | 最负的滑移（以标称峰值的倍数表示）；极限取负值 |
| **wheelspin** | 油门 > 0.2（或没有油门通道），且某个驱动轮的滑移率高于牵引极限 | 最大的驱动轮滑移；极限 |
| **oversteer**（漂移角） | 漂移角高于该路面的下限与该处车辆漂移习惯的 1.5 倍两者中的较大者 | 最大漂移角，弧度 |
| **oversteer**（滑移角，无漂移角） | 较大的后轮滑移角高于后轴极限，且比较大的前轮滑移角高出 0.25 以上 | 后轮滑移角（以峰值的倍数表示） |
| **oversteer**（无漂移角，但有偏航率和横向加速度） | "姿态速度"——abs(偏航率) 减去 abs(横向加速度) / 速度，速度高于 8 m/s——超过 0.2 rad/s，且转向与弯道方向相反 | rad/s；极限 0.2 |
| **spin** | 漂移角峰值超过 **60°** 的一段转向过度 | 同 oversteer |
| **understeer**（滑移角） | 未在滑动，较大的前轮滑移角高于前轴极限，且比后轮高出 0.3 以上 | 前轮滑移角；极限 |
| **understeer**（无滑移角） | 速度超过 12 m/s，未在滑动，未反向打舵，横向加速度高于该圈最大值（第 99 百分位）的一半，路径比 300 m 半径更紧，且转向超过车辆自身每曲率转向量所认为路径所需转向的 **1.6 倍** | 所需转向的倍数；极限 1.6 |
| **abs**、**tc** | `absActive` / `tcActive` 高于 0.5 | - |
| **handbrake** | `handbrake` 高于 0.2 | - |
| **airborne** | `airborne` 高于 0.5 | - |
| **hit**、**crash** | 见[碰撞与撞毁](#hits-and-crashes) | 撞击所造成的速度 |

各路面的漂移角下限：柏油 **7°**，混合 **10°**，松散与雪地 **15°**，冰面 **10°**。这些值遵循文献：轮胎滑移角在柏油路面上于 3–10° 达到峰值，普通道路车辆的车身侧滑角稳定极限在干燥沥青上约为 12°，而拉力赛和漂移驾驶则在 30–50°（[赛车分析，来源](race-analytics.md#sources)）。一辆车若本来就漂移得更多——例如街机式轮胎模型，或砾石专用车——则会从它自己的圈数据得出它自己的、更高的阈值（其习惯的 1.5 倍）。

**车辆如何转向**（用于"与弯道方向相反"）：该圈自身路径在 ±6 米范围内的航向变化（至少 2 个网格点）；半径比 600 m 更紧的算作转弯；左转或右转取决于世界是否镜像。若 abs(转向) > 0.05 且其符号与弯道方向相反，则转向为**反向**——即以反向打方向盘来**收住**滑动。

**事件开始时的踏板状态**（`pedal`）：刹车高于 0.1 时为*刹车*；油门高于 0.3 时为*油门*；在之前 8 个网格点（16 米）内油门曾高于 0.5 则为*松油门*；其他情况为*滑行*（或没有油门通道时）。

## 与另一圈对比 {#laid-against-the-other-lap}

每个事件都会与所选那一圈在该段所对比的那一圈进行对比（同级中最快的那一圈；对于那一圈本身，则取其同级中在该段最快的那一位）：

1. **另一圈在同样的距离内走了多远**，范围为 ±8 米：另一圈在同一段内同族的事件（打转计为转向过度，撞毁计为碰撞），以相同的单位测量，不使用阈值，并使用另一辆车的轮胎曲线。
2. **共有**：若另一圈走了 **80%** 或更远，那就是这个弯道的正常驾驶方式，而不是失误。非故障类型始终视为"共有"。
3. **代价**，对于未共有的故障：从事件前 5 米到事件后 **40 米**，本圈相对于另一圈所损失的时间（对于碰撞或撞毁，则直到车辆恢复速度为止——以其自身拉力恢复速度所需的距离计，即 40 至 400 米；若没有测得拉力，则按 5 m/s²）。从不为负。
4. **让给车辆极限的速度**：对于锁死，车辆在该速度下能做到的减速度减去其实际所做的减速度，在事件期间求和；对于车轮空转，则为其满油门拉力减去其实际所做的拉力；对于撞击，则为撞击所造成的速度。超过 0.5 m/s（1.8 km/h）时才会说明。

未共有且代价至少为 **0.02 秒**的故障会被列出（[赛道统计](race-course-statistics.md)只计入代价为 **0.03 秒**或以上的故障，因此在多圈中累计的失误是明确的失误），并且可以成为某个弯道时间损失的原因（见[逐弯分析](race-corner-analysis.md#car-control-faults-and-impacts)）。

## 碰撞与撞毁 {#hits-and-crashes}

`impacts.ts` 直接从该圈的**原始样本**中读取碰撞，即在重新采样之前——碰撞在百分之一秒之内就结束了。轮胎无法产生碰撞的力，因此碰撞是以该圈自身车辆来衡量的：

- **它的抓地力 `G`**：该圈上水平加速度 `√(lat² + long²)` 的第 99 百分位，取在地面上且速度超过 5 m/s 时。若没有加速度通道（或低于 3 m/s²），则取 15 m/s²——即普通公路车的抓地力。
- **阈值**：`max(1.8 G, G + 18, 30)` m/s²。
- **受撞样本**：水平加速度高于阈值*并且*较前一样本跳升超过 `G` 的一半；**或者**车速在 0.1 秒内下降的幅度超过阈值在 0.1 秒内所能达到的值再加 1.5 m/s。仅在着地且稳定时，且车速超过 5 m/s 时。
- 在 **0.4 秒**内的受撞样本算作同一次撞击。
- **前与后**：撞击前 0.15 秒内的最高速度；直到最后一个受撞样本之后 0.3 秒内的最低速度。
- **不算撞击**：速度下降但没有相应的力——在 0.1 秒内的水平加速度峰值低于 `G` 与 25 m/s² 两者中的较大者——这是游戏在倒带或重置车辆。
- **撞毁**：当它损失的速度达到 **30 km/h** 或更多，或使车速降至原来的一半以下时；**碰撞**则为其他情况——即一次磕碰、沿墙擦刮。
- **方向**：纵向加速度大于横向且为负：*正面*；为正：*从后方*；横向较大：*沿车身侧面*。若没有加速度数据，则视为正面。

车辆能做什么，是在去掉所有撞击后测得的，取撞击前 0.1 秒至撞击后 1 秒的数据（`struckMask`）。

## 文字 {#the-texts}

每个事件都会用文字说明，同时点明两圈，包括发生的位置（沿参考线的米数）、开始时的速度、相对于另一圈超出极限多少，以及一条提示。提示取决于类型和测得的数据：

| 事件 | 提示 |
|---|---|
| 锁死，仅前轮 | 前轮锁死时无法转向：在区域顶端少踩一点刹车，并在入弯时把它释放掉 |
| 锁死，仅后轮 | 后轮锁死会让车辆转起来：直线上多刹车，入弯时减少转向；如果经常发生，就把刹车分配前移 |
| 锁死，松散路面 | 锁死的车轮会犁进去：轻踩，刚好停在锁死之前 |
| 锁死，其他 | 对于抓地力来说踏板踩得太猛：更循序渐进地踩 |
| 车轮空转 | 方向回正时逐渐给油；在受牵引力限制时短换挡（在松散路面：挂高一档可减轻扭矩） |
| 打转 / 转向过度 | 按踏板情况：刹车中（入弯时刹车踩得太重，或降挡过早）、松油门（收油门引起的转向过度：保持稳定油门）、踩油门（方向还未回正时油门太猛）、两者皆非（入弯太快）；反打方向时的"反向收住"；在松散路面或拉力赛中，"某种角度是最快的过弯方式——另一圈的角度就够了" |
| 转向不足 | 前轮一旦失去抓地，多打方向盘也没用：进弯时减速，稍微保持刹车以压住前轮，再回正；在松散路面，用松油门或左脚轻踩刹车来转向 |
| 碰撞 / 撞毁 | 沿车身侧面：留出一米的余量比擦刮更省时；从后方：另一辆车，或向后滑动；正面撞毁：更早刹车；车头的一次磕碰：擦到了什么。若与他人共有，则显示"X 在那里也碰撞了。" |

在 Trackmania 中，滑动还会说明：低于约 **400 km/h**（在松散路面：泥土、草地、塑料为 **300**）时，滑动提供的驱动力少于抓地前进；高于该速度时，以正确角度进行的速滑会获得收益，而本次则因角度不对而损失了时间。

## 每个数据来源允许做什么 {#what-each-source-allows}

| 圈数据包含 | 锁死 / 车轮空转 | 转向过度 / 打转 | 转向不足 |
|---|---|---|---|
| 每个车轮的滑移率和滑移角、车辆速度（Forza Data Out，AC 系列游戏） | 由滑移得出 | 由漂移角得出，或由后轮滑移角 | 由滑移角得出 |
| 车轮转速、世界速度（拉力赛游戏，BeamNG） | 由派生的滑移得出 | 由派生的漂移角得出 | 由每曲率转向量得出 |
| 偏航和偏航率，无滑移（iRacing） | - | 由漂移角得出（拟合的偏航与行驶方向的对比）；仅在无法信任偏航时，才由姿态速度加反向打舵得出 | 由每曲率转向量得出 |
| 仅航向 | - | 由航向与行驶方向的对比得出 | 由每曲率转向量得出 |
| 仅 FH Companion 圈文件（无偏航，无滑移） | - | - | 由每曲率转向量得出（它有转向和加速度数据） |

碰撞和撞毁只需要速度（有加速度数据则更好），因此每个数据来源都能检测。**车辆操控**部分会显示每个数据来源允许做什么：仅凭 FH Companion 圈文件时，会显示由转向得出的推头和碰撞，并提示加载 `.tele.gz` 以获得其余内容。
