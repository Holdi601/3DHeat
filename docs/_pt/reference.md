# Referência

Listas de nomes exatos, definições e ferramentas, para consultar. Não precisa de as ler para usar o visualizador.

Estas listas são geradas a partir do código do visualizador por `node tools/docs-refs.mjs` (não precisa de o executar), por isso correspondem sempre à versão com que foram feitas:

- [Tipos de evento e classes](ref-event-types.md) - os tipos de evento e as classes de veículos em que cada conjunto de dados é organizado, e que palavras dos dados correspondem a elas
- [Nomes de colunas](ref-columns.md) - os nomes de colunas que o carregador reconhece para posição, tempo, pessoa, equipa, sessão e direção do olhar
- [Lista de línguas](ref-languages.md) - as línguas do visualizador
- [Teclas do navegador](ref-browser-keys.md) - os atalhos do navegador que o visualizador reserva para si
- [Definições guardadas](ref-settings-storage.md) - o que o navegador se lembra entre visitas
- [Tabelas de valores](ref-value-tables.md) - as tabelas de preços da ponderação de valor
- [Ferramentas de linha de comandos](ref-tools.md) - as ferramentas em `tools/`: para os seus dados, e para programadores e a documentação

Também de referência, e o [Glossário](glossary.md) para as palavras usadas neste site. Escritas à mão: [Formatos de dados](data-formats.md), [Referência de teclado e rato](keyboard-reference.md), [Um ficheiro por partida (.3dheat)](container.md).
