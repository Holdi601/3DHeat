# Referencia

Listas de nombres exactos, ajustes y herramientas para consultar. No necesitas leerlas para usar el visor.

Estas listas se generan a partir del código del visor con `node tools/docs-refs.mjs` (no necesitas ejecutarlo), así que
siempre coinciden con la versión con la que se hicieron:

- [Tipos de evento y clases](ref-event-types.md) - los tipos de evento y las clases de vehículo en las que se ordena cada conjunto de datos, y qué palabras de los datos corresponden a ellos
- [Nombres de columna](ref-columns.md) - los nombres de columna que reconoce el cargador para la posición, el tiempo, la persona, el equipo, la sesión y la dirección de la mirada
- [Lista de idiomas](ref-languages.md) - los idiomas del visor
- [Teclas del navegador](ref-browser-keys.md) - los atajos del navegador que el visor se reserva
- [Ajustes guardados](ref-settings-storage.md) - lo que recuerda el navegador entre visitas
- [Tablas de valores](ref-value-tables.md) - las tablas de precios de la ponderación de valor
- [Herramientas de línea de comandos](ref-tools.md) - las herramientas de `tools/`: para tus datos, y para desarrolladores y la documentación

También de referencia, y el [Glosario](glossary.md) para las palabras que usa este sitio. Escritas a mano: [Formatos de datos](data-formats.md), [Referencia de teclado y ratón](keyboard-reference.md), [Un archivo por partida (.3dheat)](container.md).
