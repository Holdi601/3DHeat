# レベルのライブラリ

ライブラリは、レベルをこのブラウザに保存しておくので、読み込みと簡略化を何度もやり直す必要がありません。**ブラウザでサイトのデータを消去すると、ライブラリも消えます。書き出し機能はありません。** 元のファイルは保管しておいてください。

レベルの処理（解析、分類、溶接、間引き、テクスチャの梱包）は遅く、結果はいつも同じです。背景 / レベルのパネルの下にある **ライブラリ** は、処理済みのレベルをこのブラウザに保存します。そのため、間引いたメッシュを 2 回作り直すことはありません（[`levelLibrary.ts`](https://github.com/Holdi601/3DHeat/blob/main/src/data/levelLibrary.ts)）。

## レベルを保存して読み直す {#save-and-reload-a-level}

1. 地図画像か 3D モデルを読み込み、正しく見えるか確認します。
2. **ライブラリに保存** を押します。パネルには *保存しました。次回は即座に読み込まれます。* と表示されます。
3. 次回は、**ライブラリ** の一覧を開き、レベルの ▸ を押します。
4. 不要になった項目を削除するには、✕ を押します。

## 使い方 {#using-it}

| 項目 | 効果 |
|---|---|
| **ライブラリに保存** | 現在のレベルを保存します。地図画像は、2 つのアンカーと一緒に PNG として保存されます。モデルは、処理済みのバッファーとして保存されます。パネルには *保存しました。次回は即座に読み込まれます。* と表示されます。 |
| ライブラリの一覧 | 保存されたレベルごとに 1 行。名前（マウスを載せると、保存されたサイズが出ます）。モデルの場合は三角形の数、画像の場合はピクセルの幅。 |
| ▸（*読み込む*） | 項目を現在のレベルとして読み込みます。 |
| ✕（*削除*） | 項目を削除します。 |
| 使用量の行 | `Using X of Y.`。このサイトのブラウザの保存領域の見積もりです。 |

何も保存されていない場合、一覧には *空です。地図かモデルを読み込んでから、「ライブラリに保存」を押してください。* と表示されます。

## 保存されるもの {#what-is-stored}

| 種類 | 保存されるもの | 保存されないもの |
|---|---|---|
| 地図画像 | 画像（PNG）、そのサイズ、アンカー | 標高、反転、不透明度、明るさ、彩度の低下。既定値に戻ります（標高 = 現在のデータセットの最も低い Y、反転はオン） |
| 3D のレベル | 頂点、頂点の色、テクスチャの座標、それらのタイルとテクスチャのアトラス、地面・構造物・水の三角形、構造物の辺、三角形の数 | 部品の名前と分類の理由、そして見た目のすべての設定。新しく取り込んだときの既定値に戻ります |

ライブラリから読み込んだモデルには、部品の一覧はありません。その境界と地面の高さの帯は、頂点から計算し直されます。

## 保存場所 {#where-it-lives}

ブラウザの IndexedDB の中にあります。データベース `3dheat`、オブジェクトストア `levels`。このページのオリジン（ブラウザのアドレスバーにあるアドレス）に対応します。このブラウザのプロファイルだけに存在します。別のブラウザ、別のプロファイル、別のアドレス（たとえば `127.0.0.1` の代わりの `localhost`）では、別の空のライブラリが見えます。ブラウザでサイトのデータを消去すると、ライブラリも消えます。構造物、色、水のない古いバージョンで保存された項目は、今も読み込めます。
