# ゲームパッドと HOTAS

キーボードの代わりに、Xbox 型のコントローラーでカメラを飛ばせます。大きなシーンで体を後ろに預けて周りを見たいときに使ってください。その入力は、キーボードの入力に**加わります**。そのため、両方を同時に使えます。

## コントローラーをつなぐ {#connect-a-controller}

1. コントローラーをつなぎます（またはペアリングします）。
2. ビューをクリックし、コントローラーのボタンを 1 つ押します。ブラウザは、コントローラーが最初の入力を送るまで表示しません。
3. **カメラとシーン → ゲームパッド** を開きます。デバイスの一覧に `●` 付きで表示されます。
4. 左のスティックで飛び、右のスティックで見回します。スティックを中央に置いたままでカメラが流れる場合は、**デッドゾーン** を上げます。

ブラウザが標準のゲームパッドの配置に対応付けるデバイスなら、どれでも使えます。フライトスティックやスロットル（HOTAS）は、既定では無視されます。下を見てください。

## 割り当て {#mapping}

| 操作 | 効果 |
|---|---|
| 左のスティック | 移動: 前後と横移動 |
| 右のスティック | 視点: 方位と仰角。目一杯倒したとき、毎秒 *視点の速度* 度 |
| `RT` / `LT`（アナログ） | 上 / 下。平行投影では、ズームイン / ズームアウト |
| `RB`（押し続ける） | 6 倍の速さ |
| `LB`（押し続ける） | 15% の速さ |
| `A`（押し続ける） | 3 倍のダッシュ（RB / LB と組み合わせられます） |
| `Y`（押す） | データを画面に収める |

ボタンの番号は標準の配置に従います。A が 0、Y が 3、LB が 4、RB が 5、LT が 6、RT が 7。スティックは軸 0-1（左）と 2-3（右）です。

## ゲームパッドの設定 {#the-gamepad-settings}

**カメラとシーン → ゲームパッド** にあります。**設定** / **隠す** で調整項目を開閉します。

| 項目 | 既定値 | 範囲（ジョグ） | 意味 |
|---|---|---|---|
| **有効** | オン | | |
| デバイスの状態 | | | 接続されているすべてのデバイス。追従しているものには `●`、していないものには `○` が付きます。標準でないデバイスには、*- XInput パッドではないため無視* または *- XInput パッドではないが、そのまま使用* と表示されます。デバイスがない場合は、*ゲームパッドが見つかりません。ブラウザは、コントローラーが最初の入力を送るまで表示しません。ボタンを 1 つ押してください。* と表示されます。 |
| **使用するデバイス** | *XInput パッドのみ（推奨）* | | 標準でないデバイスがつながっている場合に表示されます。名前でデバイスを選ぶと、それに追従します。 |
| **視点の速度** | 150°/秒 | 20-540（5000） | スティックを右に目一杯倒したときの回転の速さ。 |
| **デッドゾーン** | 12% | 0-50%（95%） | 円形。斜めに倒したとき、片方の軸だけに入力が漏れることはありません。スティックを中央に置いたままカメラが流れる場合は、上げてください。 |
| **スティックのカーブ** | x² | 線形（1）から x⁴（16） | デッドゾーンの後の応答の指数。中央付近では細かく操作でき、端では最大の速さのままです。 |
| **スティックのYを反転** | オフ | | |
| **スティックを入れ替え** | オフ | | 右のスティックで移動し、左のスティックで視点を動かします。 |

スティックの形の補正は次のとおりです。倒れ具合 *m*（スティックのベクトルの長さ）とデッドゾーン *d* のとき、出力は、スティックの向きに沿って ((m - d) / (1 - d)) ^ カーブ です。デッドゾーンの中では 0 です。

## 既定で標準のパッドだけを使う理由 {#why-only-standard-pads-by-default}

ゲームパッドの API は、軸を持つ**すべての** HID デバイスを報告します。フライトスティック、スロットル、ペダル、ハンドルなどです。これらは中央に戻りません。ねじりの軸やスロットルのレバーは、誰も触っていなくても目一杯の位置にあります。スティックとして読むと、デッドゾーンでは消せない、常に最大速度の入力になります。ページを開いた瞬間からカメラが勝手に回り、どのヒートのモードも壊れて見えます。カメラが動くと、累積がフレームごとにやり直されるためです。

そのため、ブラウザが `mapping: "standard"` と報告したデバイスだけを追従します。これは「XInput 型のパッドで、軸が期待どおりの位置にある」という意味です。ほかのデバイスは一覧に表示されますが、無視と印が付きます。**使用するデバイス** で明示的に選ぶと使えます。たとえば、HOTAS でカメラを操作する場合です。いったんパッドに追従すると、カメラはそのパッドについていきます。そのため、列挙の順番によって 2 つのコントローラーがカメラを取り合うことはありません。

**HOTAS:** 読み取られるのは、軸 0-3（2 本のスティック）と標準のボタンだけです。ほかの軸にあるスロットルやペダルは何もしません。中央に戻らない軸を持つスティックやスロットルは、**デッドゾーン** を大きくする必要があるかもしれません。

ブラウザは、コントローラーが最初の入力を送るまで、そのコントローラーを隠します。そのため、つながっているが触っていないパッドは、ページから見ればまだ存在していません。
