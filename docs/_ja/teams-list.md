# チームの一覧

**チーム** のパネルでは、チームを隠したり、比較の片側に置いたりできます。青だけを見たいとき、または「赤には無くて、青だけが行く場所はどこか?」を調べたいときに使ってください。

*グループ* は、チームまたは陣営です。たとえば青と赤です（[グループ](sessions-persons-groups.md#group)）。このパネルは、データセットにグループの列があるときに表示されます。グループの数はそのヘッダーにあります。ヒートのチームのモードでは、サイドバーにも **チームビューアー** というセクションがあり、独自の設定があります。このページは **チーム** の一覧を扱います。

## チームを隠す {#hide-a-team}

1. サイドバーで **チーム** を開きます。
2. 隠したいチームのチェックボックス（*表示*）のチェックを外します。絵はすぐに更新されます。
3. **すべて表示** を押すと、すべてのチームが戻ります。

![チームの一覧: Blue 5p、Red 5p、そして すべて表示](../assets/img/en/teams-list.webp)

## 各行 {#each-row}

| 部分 | 意味 |
|---|---|
| チェックボックス（*表示*） | グループを表示するか、隠すかを切り替えます。 |
| 見本 | グループの色。ヒートのチームのモードでは[チームヒート](team-heat.md)の色、ほかのモードでは基本の色です。 |
| 名前 | グループのラベル（マウスを載せると、完全なラベルが出ます）。 |
| **+** / **-**（差分のモード） | グループを[差分](difference.md)の正の側か負の側に置きます。有効なボタンをもう一度押すと、どちらの側にも置かれなくなります。 |
| `Np`（ほかのモード） | 最初の行がこのグループにある人物の数。 |

![差分のモード: Blue は + 側、Red は - 側](../assets/img/en/teams-list-difference.webp)

## ボタン {#buttons}

| ボタン | 効果 |
|---|---|
| **すべて表示** | すべてのグループを再び表示します。 |
| **均等に分割**（差分のモード） | グループの前半（切り上げ）を +、残りを -に置きます。読み込むたびに、同じ分割から始まります。 |

## グループを隠すと何が起きるか {#what-hiding-a-group-does}

- **ヒート**、**チームヒート**、**ライン** では、そのグループの行は何も寄与しません。
- **差分** では、隠されたグループは、どちら側にあっても何も寄与しません。別の列による分割があっても同じです（[差分](difference.md#for-developers)を参照）。
- **フィギュアのオーバーレイ** では、最初の行がそのグループにある人物は描かれません。
- **チームヒート** では、ほかのグループは色を保ちます。色相は、表示されているものではなく、グループの総数から割り当てられます。そのため、2 つの絵は比べられるままです。

表示を変えると、累積がやり直されます。新しいデータセットを読み込むたびに、すべてのグループが再び表示されます。

パネルのヒントは、モードによって変わります。差分では + と - の意味を説明します。チームヒートでは、見本が、各グループが描く色であることを説明します。
