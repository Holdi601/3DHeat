# 集団の行動: 群衆、群れ、家畜の群れ、圧力下の判断

試合のプレイヤーは、どこにいる人とも同じように振る舞います。ドアに集まり、最初に行った者についていき、まとまったり散らばったりし、大きな損失の後に後退し、悪い人生の後にリスクを取ります。**行動レンズの指標**は、これらの型を、群衆の科学、集団運動の物理学、行動経済学、軍事心理学の方法で測ります。それぞれ独自の帰無モデルと比べ、結果を[ナレッジベース](knowledge.md)の対応する項目を通して読みます。

## 試してみる {#try-it}

1. 時刻、位置、チームのある試合を1つ以上読み込みます。
2. **インサイト**を開き、実行します。
3. **レンズ指標**を開くと、行動の指標が、ほかの指標と一緒に並んでいます（集団の整合、経路の群れ、レーンと軌跡、混雑、リーダーとフォロワー、結束と落伍者、限界点、損失後のリスク、連続、購入の一致、抑制）。それぞれに数値、検定、説明している文献があります。
4. **まとめ**はこれらを引用します。**AIで書く**は、報告書と一緒にこれらを送ります。

## 指標 {#the-measures}

軌跡は、2秒ごとに1点へ再サンプリングされます（区間の終わりの位置と、その区間の速度）。距離は、データ自身の典型的な間隔（ユニットから最も近いチームメイトまでの距離の中央値）で尺度を合わせます。そのため、同じ指標が歩兵、戦車、航空機に使えます。

| 指標 | 測るもの | 帰無モデルと検定 | ナレッジ |
|---|---|---|---|
| 集団の整合 | 2秒ごとの、各陣営の移動中のユニットの平均進行方向の長さ（偏り）、重心を中心とした回転（渦巻き）、時間に対する偏りと渦巻き、群れの割合（試合の局面別）。2つの整列した陣営の戦闘では、より整列している陣営のキルの割合 | 各ユニット自身の軌跡を試合内で時間的にずらす（経路は保つが、同時性は壊す）。60秒の窓での符号反転検定 | Vicsek 1995、Couzin 2002、Tunstrøm 2013 |
| 経路の群れ | ユニットが、前のチームメイトがしたのと同じ道で（30秒以内に）場所を離れる頻度。同じ入り方について、その場所自身の出口の割合と比べ、さらに敵の以前の通過をまねることと比べる | 出口を場所と入口の中で並べ替える。効果は、チームメイトのまねから敵のまねを引いたもの（Manski の反映問題: まねと、陣営が共有する計画は似て見える） | Banerjee 1992、Bikhchandani ら 1992、Manski 1993 |
| レーンと軌跡 | 逆流がある場所での、2つの方向の横方向の分離。最も混む地面10%での移動の割合、そのジニ係数、試合の最も混む地面の重なり | 方向を訪問全体の間で並べ替える。場所の半分ずらした2つの格子を、それぞれ検定し、Bonferroni 補正 | Helbing ら 1997、2005 |
| 混雑 | 典型的な間隔の2倍以内の隣人の数で分けた速度（ユニット自身の速さに対する相対）と流量。最も密な区分での容量の低下。最も混む地面で。群衆での1時間あたりの死亡数。近くのチームメイトが1分あたりに撃った弾数（社会的手抜き） | 各ユニット自身の速度と密度の相関、ユニットをまたぐ符号反転、ρ が ±0.05 を超える最小効果。正確な率の検定 | Helbing ら 2000、Seyfried ら 2005、Latané ら 1979 |
| リーダーとフォロワー | 一緒に移動するチームメイトについて、一方の進行方向が他方の進行方向を最もよく予測する時間差（最大8秒）。リーダーのグラフ、三者関係の推移性、リーダーの死亡率とキル率 | 片方の軌跡を時間的にずらしたペアで 95% の閾値を得る。5% に対する二項検定 | Nagy ら 2010、Couzin ら 2005 |
| 結束と落伍者 | 最も近いチームメイトから、陣営の典型的な間隔の3倍を超えて離れている時間。そこでの死亡率と、群れと一緒にいるときの死亡率を比べる。陣営の間隔と、戦闘のキルの割合を比べる | 2つのポアソン率の正確な条件付き検定 | Shils と Janowitz 1948、Siebold 2007 |
| 限界点 | 直近1分間の陣営の損失割合による、敵への接近速度（陣営自身の速さに対して）。陣営が撤退する最も低い損失水準 | 片側のクラスターブートストラップで、速さの10分の1の撤退に対して検定（損失は陣営が出会う場所で生じ、出会った陣営は接近を止める）。水準ごとに Bonferroni 補正 | Dupuy 1987、Rowland 2006 |
| 損失後のリスク | 次の人生のうち、キルのない損失の後と、キルのある後とで、敵に向かって陣営より前にいた時間の割合。そのときの陣営自身の割合やほかの帰還ユニットより上。早い死の後の早い死（ティルト） | 各ユニットの人生を並べ替える（最初の人生は保つ）。そのため、有限の系列による偏りが帰無モデルに入る | Kahneman と Tversky 1979、Thaler と Johnson 1990 |
| 連続 | k キルの後にキルが起きる確率 − k 回の死の後にキルが起きる確率（k = 1〜3） | 各プレイヤー自身の系列を1,000回並べ替える。Miller と Sanjurjo が示した偏りを差し引く。k ごとに Bonferroni 補正 | Gilovich ら 1985、Miller と Sanjurjo 2018 |
| 購入の一致 | 陣営のラウンド内での、装備の区分（エコ、フォース、フル。カウンターストライク以外では三分位）の Fleiss のκ | 陣営のプレイヤーとラウンドの組を、その陣営のラウンドの間で並べ替える | Fleiss 1971 |
| 抑制 | 致命的でないダメージの後の4秒間の速さと、前の4秒間の速さの比較。ヒットでの10秒後と前の弾数、および同じユニットの平穏な瞬間での比較 | ユニットをまたぐ符号反転。最小効果は陣営の速さの0.05と、1分に1発 | Rowland 2006 |

レポートのすべての p 値は、Benjamini-Hochberg の偽発見率（`q`）を通ります。データがその指標を支えられないときは、その指標を除外します。購入の一致にはラウンドと装備の値が、抑制にはダメージのイベントが、連続と損失後のリスクにはユニットに計上されたキルと死亡が必要です。

## マスアナリシスでの指標 {#in-the-mass-analysis}

各試合の要約（`<match>.summary.json`、[マスアナリシス](mass-analysis.md)を参照）は、その試合の同じ指標を `behaviour` のセクションに持ちます。そのため、行を読み直さずに数千の試合を比べられます。

## どれだけ有効か {#how-well-it-works}

それぞれの効果を組み込んだシミュレーションの戦闘と、効果のない同じ世界で（`src/insights/behaviour/sim.ts`、`behaviour.test.ts`）、すべての指標は、埋め込まれた効果を見つけ、効果のない世界は偽発見の閾値を下回りました。損失後のリスクは検出力が最も低いです。経路の群れは、まねと共有された計画を区別できません（1つの目標を共有する陣営は、この指標では「群れ」になります）。

## 開発者向け {#for-developers}

- `src/insights/behaviour/acc.ts` - アキュムレーター（再サンプリングされた軌跡、イベント、ラウンド）と `finish`。`motion.ts` と `choice.ts` は指標。`bstats.ts` は順列、ブートストラップ、κ の補助関数。`shows.ts` は、レンズが読むパターンと文（`lens.<measure>`）。
- `feed.ts` は、インサイトのワーカーのチャンクからそれに供給します。`summaryTap.ts` は、表をストリームするときの試合の要約から供給します。
- ナレッジ: `src/insights/knowledge/behaviour.ts`（項目）、`patterns-behaviour.ts`、`refs-behaviour.ts`（参考文献。それぞれ Crossref または Open Library の記録で確認済み）。
- ラベル: `locales/*/lens.json` の `lens.metric.<measure>`。
