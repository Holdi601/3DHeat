# コースの統計

1 つのコースの多くのラップを読み込むと、ビューアがミスを数えます。どのコーナーで最も時間を失うか、そのコーナーでラップが何周失敗したか、そしてその理由です。練習する価値のあるコーナーを見つけるために使ってください。

試してみる: **デモラップ** は 3 つのラップを与えます。このセクションが表示されるのに十分な数です。

![ミスのマップ付きのコース統計: 各コーナーで何周のラップが時間を失ったかで塗られたコース、およびコーナーの一覧](../assets/img/en/race-course-mistake-map.webp)

コースの **フォルダー全体** を読み込みます。数十のラップ、複数の車、複数の性能クラスです。すると、すべてのラップが判定され、数えられます。このページでは、クラス別の比較、何をミスとみなすか、**コース統計** のセクション、ミスのマップ、ヒートマップへの書き出し、複数のコースのトラック、そして多くのラップでの性能の限界を扱います。

## 同じクラスの中で最良と比べる {#against-the-best-of-its-own-class}

各ラップは、コーナーごとに、**自身の性能クラスの中で最速の完走ラップ** (基準であり、基準のクラスにあるもの) と比べられます。そのラップ自身は、各コーナーを最も速く抜けた同じクラスのラップと比べられます。クラスに 1 台だけしかいない場合は、すべてのラップと比べられます。車は、ゲームの性能クラスでグループ分けされます (Forza では D から X まで。C と S2 はその 2 つです)。C クラスの車のブレーキング地点を、S2 の車のものと比べても、運転については何もわかりません。タイムのマップ、ラップの一覧のギャップ、そして *コーナー別* の表は、同じ比較に従います ([各ラップが誰と比べられるか](race-corner-analysis.md#who-each-lap-is-compared-with) を参照)。

統計は、すべてのラップの解析の上に作られます。その隣ではありません。

## 何をミスとみなすか {#what-counts-as-a-mistake}

**発生** は、1 つのコーナー (セグメント) での 1 周のラップのミスです。ラップのそのコーナーでのミスは次のとおりです。

1. その場所での損失について、解析が見つけた **運転の原因**。損失であり、ドライバーのせいとされる発見 (車や状況のせいではない) で、比較対象のラップに対して **0.05 秒** 以上失ったもの。その費用は、そのコーナーの損失です。
2. そのラップがそこで犯し、もう一方のラップが犯さなかった **すべての車両制御のミス** (共有されない)。**0.03 秒** 以上失ったもの。ロック、ホイールスピン、リアの暴れ、押し出し、スピンです。その費用は、そのイベント自身のものです。
3. **すべての接触と衝突**。共有されているかどうか、そしていくら失ったかに関わらず。

1 つのコーナーに複数のものが入ることがあります。種類はそれぞれ、**ラップとコーナーごとに 1 回** 数えられます。ゲイン、車の取り分、そして前のコーナーで決まった遅い到着は、ミスではありません。

### 発見からミスへ {#from-findings-to-mistakes}

| 発見 | ミス |
|---|---|
| 速すぎて入り、遅く出る。もう一方より数メートル以上遅くブレーキをかけたため | ブレーキが遅すぎた |
| 早くブレーキをかけた | ブレーキが早すぎた |
| 穏やかにブレーキをかけた | ブレーキが弱すぎた |
| 原因としてのロック | タイヤをロックさせた |
| 惰性で走った | 惰性走行 |
| グリップに余裕があり、頂点まで遅い。もう一方はリフトしただけなのに、ブレーキをかけた | 中間区間が遅すぎた |
| ライン取りがきつすぎた | ライン取りがきつすぎた |
| 外へ押し出された | 外へ押し出された |
| 車を曲げすぎた / 曲げ足りなかった | 車の向きを誤った |
| パワーオンが遅い、全開が遅い、ためらった | スロットルが遅い |
| コーナーを遅く出た | 出口が遅い |
| ホイールスピン | ホイールスピン |
| リアが流れた、中間区間で横滑り | リアが流れた |
| 外へ膨らんだ | 外へ膨らんだ |
| 速度を殺した | 速度を殺した |
| リフトした (進入中、または直線で) | リフトした |
| ほぼ停止、スピン、接触、または原因としての衝突 | そのラップのそこでのイベントが示すものによる: 衝突が先、次にスピン、次に接触。それ以外はほぼ停止 |
| より長い飛行 | 飛びすぎた |

2 つのパターンは、その中にある原因として、同じ表によって数えられます。*進入で、出口で取り戻せる以上を与えた* は、その項目の原因のミスです。ブレーキが早ければ *ブレーキが早すぎた*、ロックなら *タイヤをロックさせた*、惰性走行なら *惰性走行*、使われなかったグリップなら *中間区間が遅すぎた*。*速すぎて入り、遅く出る* は、ラップがもう一方より遅くブレーキをかけた場合は *ブレーキが遅すぎた* です。それ以外は、その出口の原因のミスです。*スロットルが遅い*、*ホイールスピン*、*リアが流れた*、*外へ膨らんだ*、*出口が遅い* です。原因が車のものであるパターンや、遅い到着は数えられません。

数えられないもの: 遅い到着、スタート、すべての *車* の発見 (引っ張り、グリップ、ブレーキ、駆動)、そしてすべてのゲインやレベルのコーナー。

### 種類とその順番 {#the-kinds-in-their-order}

ブレーキング: *ブレーキが遅すぎた*、*ブレーキが早すぎた*、*ブレーキが弱すぎた*、*タイヤをロックさせた*。進入: *惰性走行*、*中間区間が遅すぎた*、*ライン取りがきつすぎた*、*外へ押し出された*、*車の向きを誤った*。出口: *スロットルが遅い*、*出口が遅い*、*ホイールスピン*、*リアが流れた*、*外へ膨らんだ*、*速度を殺した*。直線: *リフトした*。事故: *スピンした*、*何かに当たった*、*クラッシュした*、*ほぼ停止*、*飛びすぎた*。

## コース統計のセクション {#the-course-statistics-section}

**3** ラップ以上で表示され、**ラップ** と **改善ポイント** の間にあります。

- **まとめ**: 「9 台の車、3 クラスで 40 ラップ: 各コーナーを、同じクラスの最速ラップと比べて判定」。(車は車番で、または名前で数えられます)。
- **クラスのチップ** (複数のクラスがあるとき): **すべて** と、クラスごとに 1 つのチップ。それぞれにラップ数が付き、ゲームの順番 (D、C、B、A、S1、S2、R、X、その後にその他) です。クラスをクリックすると、そのラップだけになります。**Shift+クリック** で 1 つ追加または削除します。下のすべて (一覧、マップ、ヒートマップへの書き出し) は、選ばれたクラスに従います。
- **多いミス**: ミスの種類ごとに、ラップの多いものから (次に回数の多いもの、次に費用の多いもの)、最大 8 まで (**すべての N 種類** で残りを表示し、**折りたたむ** で再び隠します)。各行には、その名前、「N / M ラップ」、その割合のバー、そして「K 回 · 約 X 秒 · 最も多いのは T3 (5)、T7 (4)、T1 (2)」が出ます。これは、そのミスが何回起きたか (ラップごとのコーナー)、合計でいくら失ったか、そしてそれを最も多くのラップが犯した 3 つのコーナーです。**行をクリック** すると、それをミスのマップに表示します (マップもオンにします)。もう一度クリックすると、すべてのミスに戻ります。
- **コーナー別** (または、1 つ選ばれているときは *コーナー別 - <ミス>*): セグメントごとに、「N / M 時間を失った · X 秒」。これは、コーナー全体を走ったラップ、そこで **0.05 秒** 以上、クラスの最良と比べて失ったラップ、そして失った時間のすべてです。折りたたむと、3 つの最も多いミスを、そのラップ数とともに一覧します。**コーナーをクリック** すると、それが開き、カメラで囲み、ミスのマップに切り替わります。各ミス (または選ばれた 1 つだけ) について、「ここで 12 / 40 ラップがブレーキを早くかけた。9 台の異なる車で、それぞれ約 0.21 秒」のような行と、それを犯したラップが **最悪のものから** 並びます。各ラップには費用が付きます。最大 8 まで、残りは「+N 件」。**ラップをクリック** すると、それにフォーカスし、そのミスを再生します (そのミスの 40 m 前にそろえて)。
- **ヒートマップに表示**: 下を参照。実行中は「ヒートマップを作成しています…」と表示されます。ミスがない場合は無効です。

## ミスのマップ {#the-mistake-map}

**表示 → ミスのマップ** は、基準の経路に沿って、1 メートルごとに、そこでミスをした (選ばれたクラスの) ラップが何周あるかを塗ります。すべての種類、または統計で選んだ 1 つ。各ラップは、メートルごとに 1 回数えられます。各発生の範囲 (その原因またはイベントがあった場所) は、両側に 6 m 広げられるので、短いものも見えます。多くのラップがあるほど、より広く、より明るくなります。幅は `3 + 10 · (ここのラップ数 / どこかの最多ラップ数)` メートル、色は暗い茶色から明るいオレンジまで。どのラップもない場所は、灰色の 2 m の帯です。凡例: *少ないラップ ↔ 最も多いラップ*。

**ラベル** がオンのとき、各コーナーの頂点には、最も多いミスが付きます。「T3 · 12/40 ブレーキが早い」(ミスをしたラップ / そのコーナーを走ったラップ)、1 つの種類が選ばれているときは「T3 · 12/40」、なしのときは「T3 · クリーン」。ラベルにカーソルを合わせると、そのコーナーの損失と、最も多い 5 つのミスが一覧されます。クリックすると、統計の中でそのコーナーが開閉します。

## ヒートマップに表示 {#show-in-the-heatmap}

**ヒートマップに表示** は、同じものをヒートマップのタブに「<コース>のミス」(またはコースのミス) という名前のデータセットとして渡します。そのため、ヒートマップのツールの全体、つまりヒートのモード、フィルター、タイムライン、スライスが、ラップがどこでミスをするかに対して働きます。

これは、メモリ内で作られた CSV (`mistakeTable`) です。すべての発生の、すべての格子点 (2 m ごと) につき 1 行で、その **ラップ自身のそこでの位置** にあります。

| 列 | 内容 |
|---|---|
| `x`、`y`、`z` | そのメートルでのラップの位置 (ゲームの座標) |
| `elapsed` | そこでのラップの時刻 (秒) |
| `lap` | ラップのラベル |
| `car` | 車の名前 (または「car 1234」) |
| `mistake` | ミスの名前。現在の言語で |
| `car_class` | クラス。ない場合は `-` |
| `corner` | コーナーのラベル。`T3` |
| `cost` | その発生の費用 (秒) |

ヒートマップ自身の読み込み機能を、マッピングのヒント付きで通して読み込まれます。Y 軸が上、軸の反転なし、倍率 1。時刻 `elapsed` は秒。**人物** = `car`、**グループ** = `mistake`、**セッション** = `lap`。視線の向きなし。`car_class`、`corner`、`cost` はフィルター用の列として残されます。タブはその後 **ヒートマップ** に切り替わり、データをフレームに収めます。書き出されるのは、統計で選ばれたクラスだけです。

## 複数のコースのトラック {#courses-from-several-tracks}

ラップは **一度に 1 つのコース** ごとに解析されます。複数のコースのラップがあるフォルダー (ラップのライブラリ全体) では、各コースを、それぞれ単独で読み込む候補として出します (ラップ数付き、多い順)。完走しなかった走行 (FH Companion の `unfinished/`) のラップは、そのコースに付き、*部分的* と印が付きます。ファイルとして選ばれた、いくつかの名前付きのトラックのラップも、同じように候補になります。トラックの名前がないラップは、選ばれたもののどれかに付きます。読み込まれているものと違う名前付きのトラックのラップを読み込むと、それらは置き換えられます。詳しくは [ラップの読み込み](race-loading-laps.md#folders-and-courses) を参照してください。

## 多くのラップでの性能 {#performance-with-many-laps}

数十のラップは、1 秒か 2 秒で解析されます (常にすべてです)。描かれるものは、ビューがフレームレートを保つよう制限されています。

| 制限 | 値 | 効果 |
|---|---|---|
| 既定で描かれるラップ | 8 (`SHOW_ALL_UP_TO`) | 読み込まれたラップが 8 を超えると、新しく追加されたラップは、基準、フォーカスされたラップ、またはそのクラスの最良でない限り隠されます。**すべて表示** はすべてのラップを描きます。**注目中のみ** で元に戻ります。ラップにフォーカスすると、それと、そのクラスの最良が再び表示されます。 |
| 素の車と細い線 | 10 を超える表示 (`PLAIN_PAST`) | フォーカス、追いかけている車、基準以外のラップは、6 m ごとの線の点 (1.5 m の代わりに)、車は素のまま描かれます。 |
| グラフ化されるラップ | 8 (`CHART_LAPS`) | フォーカス、そのクラスの最良、基準が先。「+N 件を描画、グラフ化せず」。 |
| HUD のカード | 6 | 最初の 6 つの表示されているラップ。 |
| 統計 | 3 ラップから | それ未満ではセクションは隠されます。 |
| 一覧される発見 | ドライバー 12、車/状況 8、ゲイン 10 | フォーカスされたラップごと。 |
| 表示される車のペア | 3 | 3 組を超えると、1 組だけを選べるピッカーになります。 |

ミスの発生は、解析のたびに一度だけ計算され、キャッシュされます。ミスのマップの密度は、クラスの選択とミスの種類ごとにキャッシュされます。
