Tacview は、飛行の記録を見るための、よく使われるプログラムです。Tacview を知っているなら、このページで、そのツールそれぞれが 3DHeat のどこにあるかがわかります。

このページでは、Tacview 1.9 のすべての機能（マニュアル、ユーザーインターフェースの文字列表、ACMI 2.2 のファイル形式）を一覧にし、3DHeat の[試合のリプレイ](match-replay.md)がそれぞれどこまで対応しているかを示します。目標は、Tacview がリプレイとそのデータに対してできることを、3DHeat でもできるようにすることです。

**状態：**
- **done**：3DHeat にすでにあります。
- **new**：Tacview の機能に合わせて作りました。
- **not yet**：当てはまるものの、まだ作っていません。
- **n/a**：ここでは当てはまりません。理由を付けています。

機能の場所：**Match** タブ、**Figure replay**（またはヒートマップタブの **Figure overlay**）、サイドバーの **Replay**、**Units**、**Events**、**Bookmarks**、**Tactical display**、**Statistics**、**Time shift and trim**、**Map and position**、**Audio and video**、**Labels** の各セクションです。[試合のリプレイ](match-replay.md)を参照してください。

## 開発者向け：ACMI 2.2 のプロパティ {#for-developers-acmi-22-properties}

`data/acmi.ts` が読み込みます。数値のプロパティは数値の列に、文字のプロパティはカテゴリの列になります。すべてユニットカードの**生データ**に表示されます。以下は目的があって読み込むものです。

| プロパティ | 用途 |
|---|---|
| T（4つの形式すべて）、Name、Type、Pilot、Group、Country、Coalition、Color、CallSign | 位置、姿勢、フィギュア、ユニット名、チーム |
| IAS、CAS、TAS、Mach、AOA、AOS、AGL、HDG、HDM、OnGround | 項目、グラフ、HUD、離陸と着陸の検出 |
| VerticalGForce、LongitudinalGForce、LateralGForce | G の項目 |
| Throttle(2)、Afterburner、EngineRPM(2)、NR、AirBrakes、Flaps、LandingGear、Tailhook | 項目 |
| FuelWeight..9、FuelVolume..9、FuelFlowWeight..8 | 燃料の項目。タンクごとに合計 |
| RadarMode、RadarAzimuth、RadarElevation、RadarRoll、RadarRange、RadarHorizontalBeamwidth、RadarVerticalBeamwidth、RadarRangeGateAzimuth/Elevation/Min/Max/HorizontalBeamwidth/VerticalBeamwidth | レーダー円錐とレンジゲート |
| LockedTarget..9、LockedTargetMode、LockedTargetAzimuth/Elevation/Range、FocusedTarget | ロック線 |
| EngagementMode(2)、EngagementRange(2)、VerticalEngagementRange(2) | 交戦のドーム |
| QNH、AltimeterSetting、WindSpeed、WindDirection、HeartRate | 項目 |
| Health | 項目 |
| 出来事：Destroyed、TakenOff、Landed、Bookmark、Message、Comment、LeftArea、Timeout | 出来事の一覧、統計（死亡、離陸、着陸）、ブックマーク。Message と Comment は字幕 |
| PilotHeadYaw、PilotHeadPitch | パイロットの視線 |
| Type タグ Bullseye（Navaid+Static+Bullseye） | ブルズアイの項目と地図の輪 |
| それ以外すべて（PilotHeadRoll、操作、表面、ILS のずれ、SpO2、ENL、Label、Debug、Importance、Slot、Visible、Disabled、Radius、大きさなど） | **生データ**に書かれたとおりに表示 |

レーダーとロックの角度は、ユニット自身の軸を基準にします。方位は右、仰角は上、ロールは右翼が下がる向きです。ACMI の仕様では、角度は機体基準だが、どちら向きが正かは書かれていません。この解釈は、その変換（ヨーは時計回り、ピッチは上、ロールは右）に従っています。
