# リファレンス

正確な名前、設定、ツールを調べるための一覧です。ビューアを使うのに読む必要はありません。

これらの一覧は、`node tools/docs-refs.mjs` によってビューアのコードから生成されます (実行する必要はありません)。そのため、作られたときのバージョンと常に一致します。

- [イベントの種類とクラス](ref-event-types.md) - すべてのデータセットが分類されるイベントの種類と車両のクラス、そしてデータのどの語がそれに対応するか
- [列の名前](ref-columns.md) - 位置、時刻、人物、チーム、セッション、視線の向きについて、読み込み機能が認識する列の名前
- [言語の一覧](ref-languages.md) - ビューアの言語
- [ブラウザのキー](ref-browser-keys.md) - ビューアが自分のために取っておくブラウザのショートカット
- [保存される設定](ref-settings-storage.md) - ブラウザが訪問の間に覚えているもの
- [値の表](ref-value-tables.md) - 値の重み付けの価格表
- [コマンドラインツール](ref-tools.md) - `tools/` にあるツール: データのため、そして開発者とドキュメントのため

このサイトで使われている言葉の参考として、[用語集](glossary.md) もあります。手で書かれたものは、[データの形式](data-formats.md)、[キーボードとマウスの参照](keyboard-reference.md)、[試合ごとに1ファイル (.3dheat)](container.md) です。
