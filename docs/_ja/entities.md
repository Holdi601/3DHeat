# エンティティ

**エンティティ** では、1 人（または数人）のプレイヤーを選び、そのプレイヤーが行った場所だけを表示できます。自分の動きや、1 人の相手を追うのに使ってください。

このパネルは、データセットに人物の列があるときに表示されます。ヘッダーには人数が表示されます。選択が有効な間は `選択数 / 全体` と表示されます（*人物* は 1 人のプレイヤーまたは AI です。[用語集](glossary.md)を参照してください）。

## プレイヤーを選ぶ {#pick-a-player}

1. サイドバーで **エンティティ** を開きます。
2. 検索のボックスに、名前の一部を入力します。
3. プレイヤーにチェックを入れます。ヘッダーには、たとえば `2 / 10` と表示され、ほかのものはすべて消えます。
4. **クリア** を押すと、全員が再び表示されます。

![10 人のうち 2 人を選んだエンティティ](../assets/img/en/entities-selected.webp)

選択すると、選ばれた人物だけが表示されます。ヒートのモード（点、ライン、差分、チームヒート）でも、[フィギュアの再生](box-replay.md)の航跡、フィギュア、軌跡でも同じです。全員を表示するには空のままにします。全員を選ぶことは、誰も選ばないことと同じです。

## パネル {#the-panel}

| 部分 | 意味 |
|---|---|
| 検索のボックス | *N 件のエンティティを検索...* - 名前の、大文字と小文字を区別しない部分一致で一覧を絞ります。`N 件一致` または `N 件一致、先頭の 200 件を表示` と表示されます。検索で何も見つからない場合は *"..." に一致するものはありません* と表示されます。 |
| 一覧 | 最大 200 人（一致する先頭の 200 人）。それぞれにチェックボックス、人物の色の見本、名前があります（名前が空のときは *（名前なし）*）。 |
| 再生中のヒント | 時間が再生されているとき、一覧には *再生位置で活動中* の人物が入ります。検索は、すべてを対象にします。 |
| **AI (n)** | プレイヤーとは別に、AI が操作するユニットを入れた折りたためるグループ。 |
| **表示中を追加** | 今一覧に出ているすべての人物を、選択に加えます。 |
| **表示中のみ** | 選択を、一覧に出ている人物だけにします。 |
| **クリア** | 選択を空にします。 |

## 制限 {#limits}

ヒートでは、選択はフィルターとして働き、4 つの[フィルターの枠](filters.md#rules)のうち 1 つを使います。ほかのフィルターがすでに 4 つとも使っている場合、パネルには *ヒートには適用されていません。すべてのフィルターの枠が使われています。フィギュアの再生は、引き続きこれらのエンティティだけを表示します。フィルターの下でフィルターをクリアすると、枠が空きます。* と表示されます。枠を空けるには、フィルターをクリアしてください。

選択は、新しいデータセットを読み込むたびにクリアされます。マッチのタブは、1 人のプレイヤーに焦点を当てると、同じ選択を設定します。

## 開発者向け {#for-developers}

選択は、*persons* フィルターとして保存されます（[フィルター](filters.md#for-developers)を参照）。シェーダーのマスクは 65,536 個のプレイヤー ID を保持します。それを超える人物は、選択が有効な間、ヒートには描かれません。
