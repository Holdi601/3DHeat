# 言語

ビューアーは、あなたの言語で話せます。すべてのボタン、ヒント、メッセージ、そしてレースと試合分析のすべての文は、選んだ言語で表示されます。40の言語に対応しており、ブラウザーの言語が対応している場合は、その言語で始まります。

ヨーロッパの公用語はすべて含まれています（EUの24言語、さらにノルウェー語、アイスランド語、ウクライナ語、ロシア語、ベラルーシ語、セルビア語、ボスニア語、マケドニア語、アルバニア語、トルコ語、ルクセンブルク語、カタロニア語）。加えて、日本語、韓国語、中国語（簡体字と繁体字）もあります。全一覧: [言語一覧](ref-languages.md)。

英語は、ほかのすべての言語の翻訳元であり、訳されていないメッセージの代わりに表示される言語です。

## 言語を変える {#change-the-language}

1. サイドバーの上部にある名前の横のドロップダウンを開きます。最初の項目は **自動 - <言語>**（現在検出されたブラウザーの言語）です。その後に、すべての言語がその言語自身の名前で並んでいます。表示されている言語が読めなくても、自分の言語を見つけられます。
2. 1つ選びます。すぐに切り替わり、このブラウザーに保存されます。選択を忘れるには *自動* を選びます。

プライベートウィンドウや、保存が禁止されている場合は、選択はページを閉じるまで有効です。

切り替えると、次のことが起こります:

- すべてのラベル、ヒント、メッセージが新しい言語で描き直されます;
- レース分析は、その言語で**計算し直されます**（文は測定値から組み立てられ、後から翻訳されるのではありません）。デモのラップの名前が変わり、グラフが描き直されます;
- 数字、一覧、複数形は、新しい言語の決まりに従います。

## 最初に使われる言語 {#which-language-it-starts-in}

1. このブラウザーで**選んだ**言語（あれば）。（`localStorage` に `heat3d.language` として保存されています）。
2. なければ、**ブラウザーの**言語: `navigator.languages` のうち、ビューアーが話せる最初のもの。タグは言語の部分で照合されます（`de-AT` → `de`）。次の別名があります: `nb` と `nn` → ノルウェー語（`no`）; `zh-TW`、`zh-HK`、`zh-MO`、`zh-Hant`、および `Hant` 文字体系を持つすべてのタグ → 繁体字中国語; `zh-Hans`、`zh-CN`、`zh-SG` とそのほかの `zh` → 簡体字中国語; `cnr`（モンテネグロ語）→ セルビア語。
3. それもなければ **英語**。

ページの `<html lang>` は、話している言語に設定されます。

## 数字、一覧、複数形 {#numbers-lists-and-plurals}

ビューアーの文章の数字、一覧、複数形は、その言語の書き方になります（「3.5」または「3,5」、「a、b、c」）。英語より長いラベルは、サイドバーからはみ出す代わりに、言語が許す場所でハイフンを入れて折り返されます。長すぎるグラフの行名は省略記号で切られ、ホバーすると全文が表示されます。

ボックスに入力する数字は、小数点でもカンマでも構いません。

### 数字、一覧、複数形の書き方 {#how-numbers-lists-and-plurals-are-written}

- 小数を含む**数字**（`num`）は、その言語の小数点を使い、**桁区切りは使いません**。距離の3108 mは、どの言語でも1つの数字のままです。
- 件数やサイズなどの**整数**（`int`）は、その言語の桁区切りを使います。
- **一覧**（`list`）は、その言語の方法でつながれます: 「a、b、c」、「a、b または c」、またはその言語の区切り記号で一つずつ（メッセージ `common.listSeparator`: 英語では ", "、日本語と両方の中国語では「、」）。
- **複数形**は、`Intl.PluralRules`（`one`、`two`、`few`、`many`、`other`）を通して、その言語自身の規則に従います。
- `Intl` に渡すロケールは、その言語のタグです。ただし、タグだけでは別の国の規則になってしまう場合は例外です。ポルトガル語は `pt-PT`（ブラジルの複数形では0が one になる）、ノルウェー語は `nb`、簡体字中国語は `zh-CN`、繁体字中国語は `zh-TW` です。

### カタログ {#the-catalogs}

`src/i18n/locales/<言語>/<部分>.json`。ビューアーの部分ごとに1ファイルで、どの言語でも同じ部分があります。

ビューアーの部分ごとに1ファイルあります（現在30個。例: `app.json`、`heat.json`、`match.json`、`race-text.json`、`units.json`）。どの言語も同じ一式を持ちます。フォルダーには、すべてが並んでいます。

各ファイルは、フラットな JSON オブジェクトです。キーは完全な形で書かれ（`"race.ui.laps.load"`）、値がメッセージです。英語はビューアーに同梱されています。ほかの言語は、選ばれたときに取得されます。

**検索:** 現在の言語のメッセージ、なければ英語のメッセージ、なければキーそのもの（開発中はコンソールに「i18n: no message …」と警告が出ます）。整形に失敗したメッセージは英語に戻ります。そのため、壊れた翻訳がビューアーを壊すことはありません。

#### メッセージの書き方 {#the-message-syntax}

ビューアーが使う ICU メッセージ構文の部分:

| 形 | 例 | 意味 |
|---|---|---|
| `{name}` | `{file} has no rows` | 与えられた値をそのまま入れる |
| `{n, plural, …}` | `{laps, plural, one {# lap} other {# laps}}` | 言語の複数形規則で数字に当てはまる分岐、または `=0`、`=1` などの完全一致。`#` は、その言語の書き方の数字 |
| `{w, select, …}` | `{kind, select, crash {Crash} other {Hit}}` | 単語による分岐 |

分岐は入れ子にできます。すべての `plural` と `select` には `other` の分岐が必要です。

完全な ICU と違い、**アポストロフィはただのアポストロフィ**です。車の名前や英語の所有格には多く含まれるため、引用符で囲む必要はありません。リテラルの `{` や `}` は書けません。

翻訳で保つ必要がある値を持つメッセージ: 波括弧の中の名前は、コードが埋めます。`select` の単語は、コードが選ぶ基準です（`crash`、`onto-straight`、`yes`/`none`）。そのため、英語のまま残す必要があります。複数形のカテゴリは異なっていて構いません。言語ごとに独自のものを使います（ポーランド語は `one`、`few`、`many`、`other`。日本語は `other` のみ）。

### 翻訳の作り方とテスト {#how-the-translations-were-made-and-the-tests}

翻訳は、英語から AI モデルで作成され、レース用語の用語集を使いました。レースの文は、値を入れた状態で二度目の読み直しを行いました。母語話者による修正を歓迎します（下記）。

`src/i18n/i18n.test.ts` は次を確認します:

- コードが求めるすべてのメッセージが英語に存在すること。すべての `t('…')` の呼び出しと、表に保持されて後で `t()` に渡されるキー（`app.` や `heat.` などの部分名で始まるキー）を含みます;
- 部品から組み立てられるメッセージが存在すること。すべてのミスの `label`、`short`、`count`、`here`、すべての車両比較の特徴、すべてのチャンネルのラベルを含みます;
- すべてのメッセージが、すべての言語で**解析できる**こと;
- すべての翻訳が、英語メッセージの値と選択肢を**保っている**こと（値の追加や欠落がない。すべての `select` が単語を保つ）;
- すべての言語が、英語のすべてのメッセージを**持っている**こと。翻訳された言語の集合が、上の一覧と正確に一致すること;
- 選んだ言語でメッセージが話され、英語に戻ること。

### 翻訳の修正 {#correcting-a-translation}

母語話者による修正を歓迎します。1行の JSON で直せます。

1. メッセージを探す: 英語のカタログ（`src/i18n/locales/en/`）で、見えている英語の文を検索し、そのキーを控えます（英語に切り替えて読んでください）。
2. 自分の言語の同じ部分を開きます（例: `src/i18n/locales/de/race-ui.json`）。そのキーの値を変えます。すべての `{name}` を残し、`select` の単語を残し、必要な複数形の分岐を書きます:

   ```json
   "race.ui.laps.courseLaps": "{count, plural, one {# Runde} other {# Runden}}",
   ```

3. `npm test`（または `npx vitest run src/i18n`）を実行します。値や選択肢が欠けたか、メッセージが解析できなくなったかを、テストが知らせます。
4. 開発サーバーを起動した状態で、言語を切り替える（またはページを再読み込みする）と、変更が表示されます。

**メッセージを追加する**（コードで）: まず英語の部分に追加し、次にほかのすべての言語に追加します（それぞれに追加するまでテストは失敗します）。

**言語を追加する**: `languages.ts` の `LANGUAGES` に（その BCP 47 タグと、その言語自身の名前、必要なら別名または `Intl` ロケールを）追加し、すべての部分を含むフォルダー `src/i18n/locales/<タグ>/` を作ります。
