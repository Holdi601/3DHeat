# フィルターとツール

これらのパネルで、*どのデータ*を見るか選び、見ているものを計測できます。絵が混みすぎているときに使ってください。1つのチーム、1人のプレイヤー、1つの場所、または建物の1階だけを表示できます。

各パネルはデータを絞り込み、互いに組み合わさって働きます。行は、**すべて**を通るときだけ描かれます（AND）。

```
すべての行 -> フィルター -> チーム -> エンティティ -> スライス -> 絵
                 AND        AND       AND          AND
```

例：フィルターの *Tank* のチェックを外し、チームの赤チームを隠し、エンティティで1人のプレイヤーを選びます。そうすると、そのプレイヤーの戦車以外の動きだけが見えます。

| パネル | 役割 | ヒートモード | フィギュアオーバーレイ |
|---|---|---|---|
| [フィルター](filters.md) | 読み込み時に保持した任意の列での範囲とカテゴリーによる絞り込み。 | はい | いいえ（列のフィルターのみ） |
| [差分の分割](difference.md#the-difference-split-panel) | 差分モードで、どの行を足し、どの行を引くか。 | 差分のみ | いいえ |
| [チーム](teams-list.md) | 各チームを表示するか隠すか。チームを + または - の側に置く。 | はい | はい |
| [エンティティ](entities.md) | 個々のプレイヤーを選ぶ。 | はい | はい |
| [スライス](slice.md) | レベルとヒートから板を切り出し、建物の中を見る。 | はい、およびレベル | いいえ |
| [計測](measure.md) | 物差しと、カーソルの下のヒートの値。 | はい | はい |
| [ボリュームと比較](volumes.md) | 3D の形を描き、その中で何が起きたかを尋ねる。絞り込みもできる。 | はい | はい |
| [内訳](breakdown.md) | ある場所で、どの車両、プレイヤー、武器が最もよいか。 | 該当なし | 該当なし |

被弾分析には、**車両** タブに独自の領域フィルターがあります。[被弾分析](hit-analysis.md)を参照してください。

ヒートマップ、行、人物、グループなどの用語は、[用語集](glossary.md)で説明しています。

## パネルの場所 {#where-the-panels-are}

ヒートマップタブのサイドバーを、上から下へ：

1. モードバーとセッションの選択
2. ソース、列の割り当て、データセット
3. 経路（ラインモード）
4. ヒートのパネル、またはチームビューアー
5. 差分の分割
6. チーム
7. エンティティ
8. フィルター
9. 背景/レベル
10. スライス
11. 計測
12. カメラの経路と描画
13. パフォーマンス
14. カメラとシーン

Match タブには、モードバー、セッションの選択、そのパネル、フィルター、背景/レベル、カメラとシーンが表示されます。
