# レベルの見た目

これらの設定は、3Dレベルの見た目を変えます。そのため、ヒートがレベルから浮き上がり、場所をそのまま読み取れます。ここでは、データは何も変わりません。

## すぐに始める {#quick-start}

1. 3Dレベルを読み込みます（[3Dレベル](model-levels.md)）。
2. **背景/レベル**で、ヒートが画面で最も明るいものになるまで **明るさ** を下げます。
3. **地面の起伏**を開き、丘と平地を見分けられるまで **傾斜の陰影** または **等高線の濃さ** を上げます。
4. **構造物**を開きます。建物の中を見るには **面の不透明度** を下げます。立体的に見るには **構造物のテクスチャ** をオンにします。
5. 地面に絵が描かれている場合は、**地面のテクスチャ** をオフとオンで試します。

![地面の起伏と構造物のセクションを開き、起伏の手がかりを付けたレベルを表示した画面](../assets/img/en/level-appearance-sections.webp)

[3Dレベル](model-levels.md)を読み込むと、背景/レベルのパネルにこれらの設定が表示されます。既定値は、新しく取り込んだレベルが得る値です（[`modelLevelFrom`](https://github.com/Holdi601/3DHeat/blob/main/src/ui/panels/LevelPanel.tsx)、[`level.ts`](https://github.com/Holdi601/3DHeat/blob/main/src/render/level.ts)）。変更しても、シーンを描き直すだけです。ヒートの累積は保たれます。

## レベル全体 {#the-whole-level}

| 設定 | 既定値 | 範囲 | 意味 |
|---|---|---|---|
| **不透明度** | 100% | 0〜100% | 100% 未満では、レベルは混ぜられ、深度を書き込まなくなります。そのため、もはやヒートを[遮蔽](depth-and-culling.md)しません。 |
| **明るさ** | 0.9 | 0〜2（ジョグ 64） | |

レベルは彩度を落として描かれます。灰色の地面、色づいた殻です。そのため、画面で彩度があるのはヒートだけになります。[マップ画像](map-images.md)と違い、3Dレベルには彩度を下げるスライダーがありません。

## 地面の起伏 {#ground-relief}

遠くから見ると、丘と平地は同じ灰色に見えます。そこで、ビューアーは3つのヒントを加えます。それぞれ、異なる失敗に対応しています。

| 設定 | 既定値 | 意味 |
|---|---|---|
| **等高線の間隔** | 地面の高さの範囲から | 等高線の間の高さ。レベルの高さの範囲の 1/4000 から 1/2 まで、対数。トラックの下端は*オフ*です。既定値は、地面の高さの範囲の 1/40 を、1/2/5 の段階に丸めたものです。10 m の線は山の斜面に合いますが、採石場の床では役に立ちません。5 本ごとの線は強く描かれます。等高線は画面上の空間で描かれるため、どのズームでも 1 ピクセルの幅を保ちます。そして、陰影を付けるには浅すぎる地面でも残る、唯一の手がかりです。 |
| **等高線の濃さ** | 35% | 0〜100% |
| **傾斜の陰影** | 55% | 急さによって暗くします。そのため、どのカメラの角度からでも、土手や崖が読めます。光源は、向き合うと平らになってしまいます。 |
| **標高ランプ** | 50% | 地面の高さの範囲にわたって、低い地面は暗く、高い地面は明るくします。大きな規模の形です。 |

セクションの見出しには、等高線の状態が表示されます: *N m ごと*（等高線の間隔）、または間隔がオフのときは *等高線なし*。

## 地面の表面 {#ground-surface}

| 設定 | 既定値 | 表示される条件 | 意味 |
|---|---|---|---|
| **水** | オン | レベルに水がある | 湖、川、海。淡い青灰色で平らに描かれます。定義上、水平な面には、地形の手がかりは当てはまりません。 |
| **水の不透明度** | 60% | 水がオン | 海岸線と浅瀬の下の地面が、半透明の水を通して見えます。 |
| **地面の三角形** | 30%（テクスチャ付きのレベルでは 0） | 常に | 地形自身の辺を、陰影の付いた表面の上に描きます。カメラから、レベル幅の 6%〜25% の間で消えていきます。地面がどれだけ粗くサンプリングされたかを示し、傾斜が距離を判断する手がかりになります。初回の使用時に作られるため、大きなレベルでは少し時間がかかります。 |
| **地面をワイヤーフレームのみで表示** | オフ | 常に | 地形の表面を、その辺に置き換えます。完全に模式的で、陰影、等高線、遮蔽も失われます。そのため、通常は**地面の三角形**の方が良い選択です。 |
| **地面のテクスチャ** | オン | レベルにテクスチャがある | ファイルが持つテクスチャ（アスファルト、路肩、草）で地面を描きます。テクスチャ自身が細かい起伏を持っているため、メッシュの照明は控えめに上から加えられます。ヒートの下で静かにしたい場合は、**明るさ**を使います。彩度を下げるのは、マップ画像の役目です。 |
| **取得した色** | オフ | レベルに頂点色がある | 地面を、灰色の代わりに、スキャンで取得した色で陰影を付けます。そうしないと、再構築された道路は路肩と区別がつきません。エンジンからの書き出しには色がありません。ない場合、パネルは *このレベルには色がありません。* と表示します。 |

## 構造物 {#structures}

**構造物**の見出しには、構造物の三角形の数が表示されます。その下のヒントには、それらがどう描かれているか（*独自のテクスチャで立体的に描く*、または *中のヒートが見えるように透明な殻として描く*）と、いくつの部分が構造物かが書かれています。

| 設定 | 既定値 | 意味 |
|---|---|---|
| **構造物のテクスチャ** | 構造物がテクスチャを持つとき、オン | 構造物を、独自のテクスチャで立体的に描きます。オンにすると、面の不透明度が 100% になり、縁はオフになります。オフにすると、25% の色付きの透けて見える殻に戻ります。テクスチャ付きの構造物は、カメラが見ている側から照らされます。看板は背中合わせの2面であり、どちらが深度テストに勝つかは丸め誤差次第だからです。 |
| **ワイヤーフレームの辺** | オン。構造物の三角形が 300,000 を超えるとき、またはテクスチャ付きのときはオフ | 構造物の辺の重複を除いたもの。1辺につき1本の線です。 |
| **辺の不透明度** | 50% | |
| **殻の面** | オン | 明るい フレネルの縁を持つ、かすかな表面です。そのため、建物は檻や霧の塊ではなく、立体として読めます。 |
| **面の不透明度** | 25%（構造物の三角形が 300,000 を超えると 35%、テクスチャ付きは 100%） | トラック上では 0〜60%、ハンドルでは 100% まで。低く保ってください。中身の見えない構造物は、その中のデータを隠します。 |
| **鋭い辺** | オン（テクスチャ付きではオフ） | 各三角形を、その法線で陰影付けします。法線はフラグメントシェーダーで、画面空間の微分から計算されます。書き出されたレベルは溶接されていて、平均化された法線を持つため、箱の角がすべて「溶けた箔」のように丸くなってしまいます。それを直すために頂点をすべて分けると、頂点バッファが増えてしまいます。曲面が角より大事なレベルでは、オフにしてください。 |
| **構造物の色合い** | シアン | 色選択ツールと、プリセット **シアン**、**アンバー**、**バイオレット**、**白**。 |
| **部分の分類を表示 (N)** | | すべての部分、その分類、理由。[3Dレベル](model-levels.md#ground-structures-and-water)を参照してください。 |

## レベルを切る {#cutting-the-level}

[スライス](slice.md)と、*レベルもカット*がオンのときの[距離カリング](depth-and-culling.md#distance-culling)は、ヒートと同じ平面で、地面、構造物、水を切ります。
