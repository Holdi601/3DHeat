# 被弾分析

**車両**タブは、1台の戦車、艦船、または兵士がどこに被弾したか、そして誰に撃たれたかを示します。戦車のどの側が撃たれているか、またはどの敵がダメージを与えているかを見るのに使います。

## 試してみる {#try-it}

1. 被弾のある試合を読み込みます（どのゲームが被弾を提供するかは下の表を参照してください）。
2. 上部の **車両** タブを開きます。
3. **車両** の下で、ユニットを選びます（例: 戦車の種類）。括弧内の数字は、受けた被弾の数です。
4. 図を読みます。各印は被弾で、命中した場所に置かれています。
5. **誰が被弾させたか** を開くと、射手、兵装、または射手の車両が、被弾、ダメージ、キル、距離とともに表示されます。

![車両タブ: 被弾の印のあるデモの戦車と、開いた「誰が被弾させたか」](../assets/img/en/hit-analysis-tank.webp)

何も読み込まれていない場合、または車両への被弾がデータにない場合、タブは何が足りないか、どのコンバーターを使うかを表示します。

```
        shooter ----> o  hit mark on the figure
        shooter ----> o
  [ tank figure ]
```

図には、データが点または部位を与えている場合の被弾が表示されます。内訳（誰が、何で、どれだけ強く、どれだけ離れた場所から被弾させたか）は、すべてのソースで機能します。

## 各ソースが提供するもの {#what-each-source-gives}

| ソース | ユニット上の点 | 射手 | 兵装 | ダメージ / 結果 |
|---|---|---|---|---|
| War Thunder | あり。ユニットの座標系で、弾の進む方向とともに | あり | 射手の車両 | 致命的、重大、モジュール破壊、とどめの弾 |
| CS2 | 身体の部位（hitgroup） | あり | あり | ダメージ、装甲、残りの体力 |
| World of Tanks | あり（コンポーネントの箱、入口と出口） | あり | - | ダメージまたはなし（跳弾、貫通なし） |
| World of Warships | あり。艦の座標系で | あり | 被弾の種類 | - |
| Squad | 車両: あり。そのユニット自身の位置と向きから、車両の座標系に置かれた着弾 | なし（データが名前を示さない） | ダメージの種類 | その瞬間の車両の体力の低下、破壊 |
| Squad の兵士 | なし。命中の結果（骨と着弾点）は、コンバーターが生のまま保持します。`hitBone` を持つ `impact` の行は、書かれた時点で読まれます | | | 負傷と死亡のみ |
| Arma（OCAP、Arma 3 の記録装置） | なし。OCAP は、誰が誰に、何で、どれだけ離れた場所から被弾またはキルしたかを記録しますが、どこに当たったかは記録しません | あり | あり | 被弾またはキル、距離 |
| Tacview ACMI | ユニットから 30 m 以内で武器のオブジェクトが終わる場合にあり（発射装置ではない）。ユニットの座標系での最後の場所（向き、ピッチ、ロール）。飛んできた方向から | 武器の `Parent` | 武器の名前、または Timeout の AmmoType | Timeout の Outcome、`Health` の低下、`Destroyed`。武器がない場合は、点のないキルまたはダメージ |

| Battlefield 6（GameCapture） | なし: キャプチャーはキルフィード（キル、死亡、ヘッドショットのフラグ）を読み、被弾は読まない | | | |

ユニットのどの被弾にも点がない場合、図には印が表示されず、**誰が被弾させたか** の内訳が自動的に開きます。射手、兵装、または射手の車両ごとに、被弾、ダメージ、キル、中央値と最も遠い距離が表示されます。

## 領域に絞り込む {#restrict-to-an-area}

**領域** のセクションは、マップ上のある場所で起きた被弾に、分析を絞り込みます。

1. **矩形を描く** または **多角形を描く** を押し、3D の地面または戦術マップの上に描きます。
2. **被弾側が内側** （被弾したユニットが領域内にあった場合に被弾を数える）または **射手が内側**（撃った側が領域内にあった場合）を選びます。
3. **フィルターとして使う** を押します。チップには「領域内の {n} / {total} 被弾」と表示されます。
4. **エリアをリセット** で、すべての領域を削除します。

各領域は[ボリューム](volumes.md)なので、同じ形状でヒートマップとリプレイも絞り込めます。領域は含めることも除外することもできます（除外する領域は、その中の被弾を外します。「領域外の {n} / {total} 被弾」と表示されます）。各領域は、ユニットの被弾のうちいくつがその中にあったかを示すチップとして表示されます。チップの × で削除します。件数、図、内訳、フィルターの一覧は、すべてこれに従います。

被弾の場所: その被弾のもとになった行は、片方の当事者（被害を受けた側、または撃たれた側は被害者、撃った側は射手）のものを持ちます。もう一方は、そのユニット自身のサンプルのうち、時間的に最も近いもの（5 秒以内）です。当事者の場所がわからない被弾は、領域がフィルターをかけている間は除外され、パネルはその数を表示します（「除外: 既知の場所なし」）。

## 開発者向け {#for-developers}

どのコンバーターも被弾を追加できます。被害者の行（`hit`、`impact`、`hurt`、`wounded`）に `hitBone` を付けます（スケルトンの骨、Arma の選択、Reforger の被弾ゾーン。頭、胸、腹、腕、脚にマップされます）。または `hitLocalX/Y/Z`（メートル、x を前方、y を上、z を右）を付けます。`other` は射手、`damage` はダメージです。
