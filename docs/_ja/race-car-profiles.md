車は、ブレーキ、旋回、加速をどこまで強くできるかに限りがあります。ビューアーは、あなた自身のラップからその限界を測るので、車にできないことを指示することはありません。これによって、失ったコンマ何秒のうち、どれだけが車のせいで、どれだけがあなたのせいかもわかります。

![車両比較：2台の車を並べ、グリップ、ブレーキング、加速力を表示](../assets/img/en/race-cars-compared.webp)

分析は、車がその性能を示したところでだけ、ブレーキを強く、速度を高く保つ、または早く加速するよう指示します。また、車そのものが説明できる分は、損失から取り除きます。そのため、各車の限界（下の*エンベロープ*）と特徴（*プロファイル*）は、その車の読み込まれたすべてのラップから測ります。このページでは、エンベロープ、プロファイル、**車両比較**の欄、そして各コーナーで車が何を決めるかを扱います。

**1台の車** = 同じ車番号（番号がなければ名前）と、同じ性能指数のラップです。チューニングが違えば、別の車です。

## エンベロープ：各速度で車ができること {#the-envelope-what-the-car-can-do-at-each-speed}

車ごとに、その車のすべての読み込まれたラップを使い、**5 m/s の速度帯**（24帯、最大120 m/s まで）で集計します。空中にある間のサンプル、着地後0.3秒の安定待ち、各接触の0.1秒前から1秒後までのサンプルは除外します。80 m/s² 以上の加速度は無視します（ダウンフォースのある車が保てる値を超えるためです）。

| エンベロープ | サンプル | 各帯の値 | 必要数 |
|---|---|---|---|
| **横方向のグリップ** | 横加速度が**0.5秒間保たれた**もの（中心を取った0.5秒の窓での絶対値の平均）。車がコーナリングしている箇所だけ。すべての値の99パーセンタイルの3分の1以上のもの | 95パーセンタイル | 6サンプル |
| **ブレーキング** | ブレーキ > 0.3。前後加速度は、各サンプルとその前後2点の中央値 | 減速度の95パーセンタイル | 4サンプル |
| **全開の駆動力** | アクセル > 0.95、ブレーキ 0.05 未満。同じく3点の中央値 | 90パーセンタイル | 4サンプル |

横加速度を0.5秒保つ理由：縁石、滑りからの戻り、車を立て直す動きは、どれも一瞬だけ横加速度を跳ね上がらせます。それがよく起きる車は、実際よりグリップがあるように見えてしまいます。3点の中央値を使う理由：5 m 間隔では、1サンプルの間隔がかなり長くなります。1サンプルだけの跳ね上がりは、縁石、段差、壁によるものです。

ある速度でエンベロープを読むときは、帯の中心の間を補間します。帯にデータがなければ、データがある一番近い帯を使います。

**2種類の路面について。** その車のラップの、サンプルの5分の1以上がターマックと未舗装路の両方で走られている場合は、それぞれ別のエンベロープを保持し、各コーナーは、最も遅い地点で車の下にある路面で判定します。

**交差点。** 駆動力が `1/v`（出力制限）で落ちていき、一定に保たれない（牽引制限）ときの速度です。見られた最大の `a·v` の15%以内に入る最初の帯です。

## プロファイル：どんな車か {#the-profile-what-kind-of-car-it-is}

同じラップから作る `profile`（地面にあるサンプル、衝撃を受けていないもの、8 m/s を超えるもの）：

| 指標 | 方法 |
|---|---|
| **保てるグリップ**（m/s²） | 0.5秒保たれた横加速度の95パーセンタイル |
| **加速力**（50 km/h まで、50〜120、120〜200、200 km/h超。m/s²） | 3〜14、14〜33、33〜56、56〜90 m/s の範囲で、エンベロープの全開の駆動力の平均。車が到達した速度で（最速 + 2 m/s まで）、1 m/s 刻みの少なくとも3点から。また、示した最大値とその場所 |
| **ブレーキング**（m/s²） | 比較が示す帯である、60〜160 km/h（16.7〜44.4 m/s）でのエンベロープのブレーキングの平均 |
| **最高速度** | 到達した最も高い速度 |
| **頭打ちになる速度** | 直線で全開のとき、それ以上速くならなくなった場所（下記） |
| **最高速度でも加速し続ける** | 最速の速度でのエンベロープの駆動力。あとどれだけ速くなれたか |
| **リアが流れて立て直した回数（1ラップあたり）** | 立て直しが必要なほど滑った回数（下記） |
| **アクセルで始まった割合** | そのうち、アクセル > 0.5 でブレーキなしに始まったものの割合 |
| **手放す地点** | 滑りが始まる0.15秒前の、保たれた横加速度の中央値。グリップに対する割合 |
| **ドリフト10°超の割合（激しいコーナリング中）** | 最大グリップの60%以上でコーナリングしているサンプルのうち、滑っている割合（ターマックでは10°、未舗装路では20°）。30サンプル必要 |
| **ドリフトの中央値** | 同じサンプルで |
| **バランス** | 激しくコーナリングしていて滑っていないとき、前輪のスリップアングルから後輪のスリップアングルを引いた値（公称ピークの倍数）。少なくとも30サンプルの平均。+ は膨らむ |
| **路面** | 未舗装のサンプルが80%を超えれば未舗装路。20%未満ならターマック。それ以外は混在 |

**頭打ち。** あるサンプルは、その前後1秒（±0.5 秒、少なくとも 0.9 秒分のデータ）が、すべて全開（> 0.95、ブレーキなし）で、地面にあり、**まっすぐ**走られ（|横方向| が 4 m/s² と、グリップの4分の1のうち大きい方より小さい）、加速が **0.35 m/s²** 未満で、25 m/s を超え、そのラップの最速の90%以内にある場合に数えます。坂を全開で登る場合や、長いカーブを全開で抜ける場合も、加速が止まります。車の最高速度よりずっと低い速度でも起きます。すべてのラップで、そのような頭打ちの区間が**少なくとも1秒**あれば、その速度の中央値が頭打ちの速度です。そうでなければ、最高速度はありません。十分な長さの直線がなかった場合は、*最高速度でも加速し続ける*が、どれだけ足りなかったかを示します。ラップが示す以上のことは推測しません。ギア比とリミッターは、抵抗よりずっと前に車の駆動力を終わらせるからです。

**リアを失う。** 運転者が立て直さなければならなかった場合に数えます。最大グリップの60%以上でコーナリングしていて、滑っていて（ターマックでは10°、未舗装路では20°を超えるドリフト）、ステアリング（0.06 を超える）がコーナーに**逆らって**切られている状態です。どの符号のステアリングが、どの符号のコーナリングの力と一致するかは、ラップごとに測ります（滑らずに曲がっているサンプル）。滑りは、車が滑らなくなるまで1回と数えます。わざと少し横に流して走っても、何も失っていません。逆ハンドルが必要になったものは失っています。すべての車で同じ基準で数えるので、2台の車を比べられます。ステアリングとドリフトアングルが必要です。

## 車両比較 {#cars-compared}

サイドバーの欄は、1台のときは**車両**、複数のときは**車両比較**です。

**表**：車ごとに列があり、どれかの車に値がある指標ごとに行があります。グリップ、50 km/h までの加速、50〜120、120〜200、200 km/h 超の加速、ブレーキング、最高速度、頭打ちになる速度（頭打ちにならなかった場合は「まだ加速中」）、最高速度でも加速し続ける、リアが流れて立て直した回数、激しいコーナリング中にドリフト10°を超えた割合。車同士の差が3%を超える場合は、より良い値に印を付けます（グリップ、加速、ブレーキング、速度は高い方が良く、リアの滑りは低い方が良い）。

**1台だけの場合**：ラップが示すその車の文です。保てるグリップ（m/s² と g）、各帯での加速力、長い直線で加速が止まった場所（または頭打ちにならなかったこと、最高速度でまだ加速していたこと）、リアを立て直す必要がどれほど多かったか（1ラップに1回未満なら「ほとんどない」、60%以上がアクセルで始まったなら「ほとんどアクセルでの滑り」）。

**2台の場合**：組ごとに、一方がもう一方に対してどうかを、それぞれ1文で示します（「Xは加速がよいが、Yほど強く曲がれず、止まるのに長くかかり、リアを失いやすい」）。その後に表、そして明確な差を大きい順に並べ、最後に**それぞれの乗り方**です。**3組**を超える場合は、1組だけ表示します。選択中のラップの車と、ドロップダウンから選んだ車です（既定では、そのクラスの最速ラップの車。なければ基準のラップの車。それもなければ最初の別の車）。

差は、ラップが明確に示す場合にだけ述べます。

| 差 | 判定の基準 | 文 |
|---|---|---|
| グリップ | **4%** | 「Xはコーナー全体で N% 多くグリップを保つ……それは、どのコーナーの中盤でも M% 速い速度になるということ」（速度はグリップの比の平方根） |
| 加速力 | **5%**。両車がそろう最初の帯（120〜200、50〜120、200 km/h 超） | 「Xは 120〜200 km/h を N% 強く加速する」。発進も違う場合（8% 以上の差）は「Yは発進がより強い」を付け加える |
| 最高速度 | **4 km/h** | 「Xはより高く頭打ちになる。……で加速が止まった」 |
| 最高速度（片方だけ） | 片方の車だけが頭打ちになり、もう一方はならなかった | 「Yは……で駆動力を使い切った。Xはブレーキを踏んだときもまだ加速していた」 |
| 最高速度（どちらもなし） | どちらも頭打ちにならなかった | それぞれ、最速の速度でまだ加速していた値 |
| ブレーキング | **5%** | 「Xは N% 強く止まる……Yはより早くブレーキを踏む必要がある」 |
| リアを失う | 1ラップあたり少なくとも1回多く、**かつ**半分以上多い | 「Xはリアを失いやすい。逆ハンドルが必要なほど流れた回数が、1ラップあたり N 回で、M 回に対して……」。主にアクセル（60%以上）で、または主にターンインと戻し（30%以下）で、グリップの約 P% から。未舗装路では「その一部は車の向きの付け方によるもので、立て直しは違う」 |
| 横滑り | ドリフトのしきい値を超えて、激しいコーナリングの中で **12 ポイント**以上 | 「Xは限界で、より横を向いて走る」 |
| フロントのバランス | 公称ピークの **0.3** | 「Xはフロントがより膨らむ……頂点の前に減速して、早く向きを変えたい」 |

まとめに使う特徴語：*より多くグリップを保つ* / *同じほどは曲がれない*、*加速がよい* / *駆動力が少ない*、*より高く頭打ちになる* / *より低く頭打ちになる*、*直線の終わりでも加速し続ける* / *駆動力を使い切る*、*より強く止まる* / *止まるのに長くかかる*、*より安定している* / *リアを失いやすい*（2倍の回数に1回を足して超える場合は*かなり滑りやすい……*、未舗装路では*立て直しが多く必要*）、*フロントが膨らむ*。その中に違いがないときは、「このラップでは、Yと区別がつくほどの違いはない」と書きます。

**それぞれの乗り方：**

- 一方はグリップがあり、もう一方は駆動力が強い場合：グリップのある車では、広くて丸い線（「U」）で中盤の速度を保ちます。強い駆動力の車では、まっすぐブレーキを踏み、短くタイトな中盤で向きを変え、出口でまっすぐ戻します（「V」）。
- 両方で劣る場合：その車の最速ラップがもっともきれいなものです。まっすぐブレーキを踏み、いちばん広い半径を取り、保てる限り早く全開にします。
- リアを失いやすい車の場合：ステアリングが戻るのに合わせてアクセルを入れ、ショートシフトします（アクセル中の滑り）。または、ブレーキを静かに緩めて、中盤を一定のアクセルで保ちます（進入での滑り）。

この欄の下のヒントは、それぞれの測り方を繰り返します。

## コーナーで車が決めるもの {#what-the-cars-decide-in-a-corner}

ラップが異なる車で走られている場合、失ったコーナーの所見はすべて、**車：**で終わります。その中で、車が決めている部分と、この車でどう最大限に活かすか（`carNote`）を示します。

- **中盤を通過するとき**：この車のグリップが、もう一方の車の96%未満で、もう一方が最も遅い地点で0.5 m/s を超えて速く、このラップがその車のグリップが説明する分の70%を超えて、大きくは下回らなかった場合。もう一方の車のラインでは、この車のグリップで許される速度は `v_other · √(grip_mine / grip_other)` です。ラップがそれ（1 m/s 以内）を保っていれば、差は車によるもので、ブレーキングの位置を変えても変わりません。少なければ、まだ取り戻せる分がどれだけあるかを示します。そのうえで、どこでタイムを取り戻せるかを示します。直線の上、2つのカーブの間、または駆動力が5%強い車では、頂点の後です（まっすぐブレーキを踏み、ターンインを遅らせ、早めに出口へ向ける）。それ以外は、道路が許す最も広い半径です。
- **ここでリアが離れた場合**（共有されていない滑りやスピン、または進入時に滑りのしきい値を超えたドリフト）で、その車がそれを1ラップに1回以上、かつ半分以上多く失う場合：この車でどうするか。ハンドルが戻るのに合わせて駆動力を入れる（その滑りは、60%以上の時間、駆動力の上で始まっています）。またはブレーキを静かに緩め、アクセルを抜かない。
- **その後の直線**：車の駆動力が 0.03 s 以上を説明する場合、同じ速度からもう一方の車の、より強い駆動力。両車の、120〜200 km/h の駆動力。
- **最高速度**：このラップが、150 m を超える直線で、その車が頭打ちになる速度の98%に達し、もう一方が 1.5 m/s 速かった場合。それがその車の最高速度で、そこに達するまでは、コーナーの出口で 1 km/h 多く出すたびに役立ちます。
- **ブレーキング**：もう一方の車が5%強くブレーキを踏み、このラップが5 m を超えて早くブレーキを踏んでいた場合、早めたブレーキの一部は車によるものです。

車の分は、時間そのものからも取り除かれます（[車の分](race-corner-analysis.md#the-cars-share)を参照）。車が60%以上を説明するコーナーは、車のせいとされます。
