# 合成データジェネレーター

自分のデータがありませんか? ボタンを 1 つ押すと、3DHeat が架空の戦闘を作ります。大きさは好きに選べます。

1. ヒートのサイドバーで **データセット** のパネルを開きます（**ソース** の下にあります）。
2. **合成データジェネレーター** まで下にスクロールします。
3. **行数（百万）** を設定します。最初は 1 を試してください。既定の 800 万は、最初に試すには重すぎます。
4. **生成** を押します。

![100 万行、8 チームを、チームヒートで描いたもの](../assets/img/en/synthetic-generator-team-heat.webp)

**データセット** のパネルは、読み込む代わりにデータセットを生成できます。目的は 2 つです。1 つは、自分のデータなしでビューアーを試すこと。もう 1 つは、大きな実データを読み込む*前に*、指定した行数、スプライトの半径、予算で、そのコンピューターが使えるフレームレートを保てるかを確かめることです。移動は、バトルロイヤルの試合のような形になっています。チームは離れた場所から始まり、次第に寄せ集められます。一様なノイズは、どの予算でも正しく見えてしまい、まさに見つけたいアーティファクトを隠してしまうからです。

## 操作 {#controls}

| 項目 | 既定値 | 意味 |
|---|---|---|
| **行数（百万）** | 8 | 生成する行数。プレイヤーごとのティック数の整数に切り下げられます。 |
| **チーム** | 8 | グループの数（1 以上）。 |
| **チームあたり** | 12 | グループごとのプレイヤー数（1 以上）。 |
| **マップの半幅（m）** | 4000 | X と Z で、プレイできる範囲の幅の半分。 |
| 見積もりの行 | | 「≈ X GB の RAM、量子化の後に GPU で Y GB」。（行あたり約 26 バイトの RAM と 8 バイトの GPU） |
| **生成** | | 取り込みのワーカーで、進行状況を表示しながら生成します。読み込まれていたデータセットは置き換えられます。 |

生成はバックグラウンドのワーカーで行われるので、数千万行でもページが固まることはありません。

## 生成されるもの {#what-it-generates}

[`src/data/synth.ts`](https://github.com/Holdi601/3DHeat/blob/main/src/data/synth.ts) より:

- **列:** 位置、時間、人物（`P000`、`P001`、...）、グループ（`Team 1`、`Team 2`、...）、ヨーとピッチ、寿命。セッションの列とフィルターの列はありません。
- **時間:** プレイヤーごとに 0.25 秒ごとに 1 つのサンプル。0 から始まります（相対時間で、壁時計ではありません）。
- **移動:** 各チームは、半幅の 55-95% にある円環の、自分の区画から始まります。中央付近に置かれた安全な円（半幅の最大 4 分の 1 だけ、ランダムにずれます）は、6 段階で半幅の 8% まで縮みます。各段階には一定の期間があります。すべてのプレイヤーは、その中のさまようような点に向かって進みます。減衰とノイズがかかっています。高さは 0 から 220 m の間で上下します。
- **視線の方向:** 進行方向に沿ったヨー。上昇率からのピッチ。
- **再現可能:** 乱数の種は 1337 に固定されているので、同じ設定なら常に同じデータになります。

すべてのヒートのモード、ボックス再生、ライン・ヒート（イベントの列がないので、経路全体）が、このデータで動きます。寿命の履歴も動きます。
