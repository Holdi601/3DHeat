# キーボードとマウスのリファレンス

すべてのキーとマウス操作を1か所にまとめました。必要なものをすぐ探せます。最初にビューをクリックして、キーボードを有効にしてください。テキストボックスまたはドロップダウンにフォーカスがあるとき、キーは無視されます。短い版は、ビューの左下にも表示されます。

すぐに探す:

| やりたいこと | 押すキー |
|---|---|
| 飛ぶ | `W A S D`、ドラッグで見回す |
| すべてを見る | `F` |
| 再生または一時停止 | `K` |
| 逆再生 | `J`（もう一度押すと一時停止）、順再生は `L` |
| 色の意味を見る | `?` または `F1` |
| 作戦タブで元に戻す | `Ctrl+Z` |

## カメラ {#camera}

[`camera.ts`](https://github.com/Holdi601/3DHeat/blob/main/src/render/camera.ts) より。

| 入力 | 効果 |
|---|---|
| `W` / `↑` | 見ている方向へ前進 |
| `S` / `↓` | 後退 |
| `A` / `←` | 左へ横移動 |
| `D` / `→` | 右へ横移動 |
| `Space` / `E` | 上へ |
| `Q` / 左 `Ctrl` | 下へ |
| `Shift`（どちらでも） | 押している間: 6倍の速さ |
| 左 `Alt` | 押している間: 15%の速さ |
| ビュー上で左または右ドラッグ | 見回す（ボタンを押している間、ポインターは固定） |
| ホイール（透視） | ノッチごとに飛行速度 ×1.5（ホイール1回で最大4ノッチ） |
| ホイール（平行） | ズーム |
| 右クリック | ビュー上では コンテキストメニューを開かない |

## 全体 {#global}

[`App.tsx`](https://github.com/Holdi601/3DHeat/blob/main/src/App.tsx) より。

| キー | 効果 |
|---|---|
| `K` | [タイムライン](timeline.md)の再生／一時停止 |
| `F` | データに合わせて表示する |
| `C` | カメラの位置、ヨー、ピッチをコピーする（[カメラの表示](camera.md#camera-readout)） |
| `G` | 入力した地点へ移動する: カメラの表示の下にあるボックスを開きます |
| `Esc` | 選択カードを閉じる。次に、2つ目のユニットを見るのをやめる。その次に、ユニットの追従をやめる |
| `T` | 戦術表示の見た目をオン／オフ（[試合のリプレイ](match-replay.md#display-style)） |
| `?` / `F1` | ヘルプモード: 色の意味（[設定、単位、キー](settings.md#help-mode)） |
| `1` | [ヒート](heat.md) |
| `2` | [差分](difference.md) |
| `3` | [チームヒート](team-heat.md) |
| `4` | [ライン](line-heat.md) |
| `]` | 遠方カリングの境界を ×1.12 で外へ（`Shift`: ×1.35） |
| `[` | 遠方カリングの境界を ÷1.12 で内へ（`Shift`: ÷1.35） |
| `\` | 遠方カリングの境界をオフ／元の位置でオンに戻す（[深度とカリング](depth-and-culling.md#keyboard)） |

**フィギュアオーバーレイ**モードには数字キーがありません。モードバーで選ぶか、マッチタブを開いてください。数字キーはモードバーと同じチェックを通ります。読み込んだデータでモードバーが使えないと示しているモードのキーは、何もしません。

## 試合のリプレイ {#match-replay}

フィギュアオーバーレイモードで使えます。マッチタブがこのモードを使います（[試合のリプレイ](match-replay.md)）。ユニットを追従していても、していなくても動きます。ただし、注記のあるものは除きます。

| キー | 効果 |
|---|---|
| `B` | ブックマークを追加: 時刻とカメラ |
| `M` | 2Dマップ: 隅、全体表示、オフ |
| `V` / `Shift+V` | 追従中のユニットの次／前のカメラ視点 |
| `H` | コックピットとパドロック視点でヘッドアップディスプレイ |
| `Page Down` / `Page Up` | イベントリストに表示される種類の次／前のイベント |
| `J` | 逆再生。もう一度押すと一時停止 |
| `L` | 順再生。もう一度押すと一時停止 |
| `.` / `,` | 1秒進む／戻る（一時停止中）（`Shift`: 10秒） |
| `Esc` | まず目標を見るのをやめ、次に追従をやめる |
| ユニットを `Ctrl`+クリックまたは `Alt`+クリック（ビュー内またはユニット一覧で） | 追従中のユニットから見る（2ユニット表示）。もう一度クリックすると外れる |
| 2つのユニットを `Shift`+クリック | 2つの間を計測: 方位、距離、高度差 |

`V` には追従中のユニットが必要です。ここでの `M` は2Dマップです。作戦タブの「移動」ではありません。

## ユニットの追従 {#following-a-unit}

カメラがユニットを追従している間、ホイールと飛行キーは自由に飛ばず、ユニットの周りを動きます（[カメラ](camera.md#while-following-a-unit)）。

| 入力 | 効果 |
|---|---|
| ホイール、`W` / `S` | 近づく／遠ざかる（衛星視点では上／下）。コックピットとパドロック視点では無効 |
| `A` / `D`、`Q` / `E` | ユニットの周りを周回（チェイスとオービット視点） |
| ドラッグ | ユニットの周りを見回す。コックピットでは、中で見回す |
| `V` / `Shift+V` | 次／前のカメラ視点 |
| `H` | ヘッドアップディスプレイ（コックピットとパドロック視点） |
| `Esc` | 2つ目のユニットを見るのをやめ、次に追従をやめる |

## 作戦ボード {#tactics-board}

作戦タブ（[作戦ボード](tactics-board.md)）で使えます。`F`、`C`、`G`、`T` は上と同じように動きます。数字キーは何もしません。

| キー | 効果 |
|---|---|
| `Ctrl+Z` | 元に戻す |
| `Ctrl+Y` または `Ctrl+Shift+Z` | やり直す |
| `Enter` | 描いている矢印を終える（ダブルクリックまたは右クリックでも同じ） |
| `Esc` | ドラッグを取り消す。なければ、描いている矢印または移動を取り消す。なければ選択を解除する |
| `Delete` または `Backspace` | 選択を削除する |
| `W` / `E` / `R` | 選択したものの移動／回転／拡大縮小のギズモ（キー配列 **W / E / R**） |
| `G` / `R` / `S` | 選択したものの移動／回転／拡大縮小のギズモ（キー配列 **G / R / S**） |
| `R` | 何も選択していないとき: 次に置くフィギュアを15°回す。`Shift+R` で戻す |
| `M` | フィギュアを選択しているとき: 次にクリックした場所へ移動する |
| `K` | 計画の再生／一時停止 |
| `Shift`+クリック | 選択に追加、または選択から外す |
| `Shift`+ドラッグ | 選ぶものを囲む矩形を描く |
| ハンドルをドラッグ中に `Ctrl` | グリッドまたは角度の刻みに合わせる |

ギズモのキーは、何かを選択しているときだけ働きます。何も選択していないときは、`W A S D` で通常どおりカメラを飛ばします。

## クリックして選ぶ {#click-to-pick}

**クリックでその場所を表示**がオンで、定規がオフのとき（[クリックして選ぶ](camera.md#click-to-pick)）:

| 入力 | 効果 |
|---|---|
| 左クリック（4 px を超えてドラッグしない） | ポインターの下にあるデータ点を表示する。なければ、レベル上のその地点を表示する |

## 計測 {#measure}

**定規を有効化**（[計測](measure.md)）がオンのとき:

| 入力 | 効果 |
|---|---|
| 左クリック（4 px を超えてドラッグしない） | 点を置く |
| 右クリック | 最後の点を削除する |

## そのほか {#elsewhere}

| 場所 | 入力 | 効果 |
|---|---|---|
| どのスライダーのつまみ（数字の横のハンドル） | 上／下にドラッグ | 値を連続して変える。遠くまでドラッグするほど速く変わる。細かく調整するには `Shift` を押したまま。離すと止まる |
| ビューの上の速度表示 | 上／下にドラッグ | 同じ方法で飛行速度を変える |
| 姿勢のボックス | `Enter` | 入力した位置または向きを適用する |
| カーブエディター | ダブルクリック／`Alt`+クリック／右クリック | 点を追加／点を削除（[スプライトの形](sprite-shape.md#the-curve-editor)） |

## レース分析タブ {#race-analysis-tab}

レース分析タブでは、`K` でレースのリプレイを再生・一時停止し、`Home` で巻き戻します。数字キーは何もしません。[レース分析](race-analysis.md)を参照してください。

## ブラウザから取り除かれたキー {#keys-the-viewer-keeps-from-the-browser}

ブラウザのショートカットの中には、ページを閉じたり再読み込みしたりして、読み込んだセッションを失わせるものがあります。ビューアーはそれらを自分のために保持します。一覧はコードから生成されています: [ブラウザのキー](ref-browser-keys.md)。
