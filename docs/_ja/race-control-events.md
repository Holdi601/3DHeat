# 車両操作イベント

このビューアーは、各ラップがどう走られたかを見て、車がスライドした、スピンした、何かに接触した、グリップを無駄にした、という箇所に印を付けます。タイムを失うミスは、いちばん早く直せるものなので、これは役立ちます。

![車両コントロールの欄：各ラップでタイヤがロックした、スピンした、外に膨らんだ回数と、開いた不具合の一覧](../assets/img/en/race-control-table.webp)

## 平易な説明 {#in-plain-words}

- **ロック**：ブレーキを強く踏みすぎて、タイヤが回らなくなり滑る状態です。車は止まりにくくなり、ハンドルも効かなくなります。
- **ホイールスピン**：アクセルを強く踏みすぎて、駆動輪が車の進む速さより速く空回りする状態です。駆動力を失います。
- **オーバーステア**：車の後ろが大きく流れる状態です。そのまま一回転すると、**スピン**になります。
- **アンダーステア**：車の前が大きく流れる状態です（「膨らむ」とも言います）。ハンドルを切り増しても効きません。
- **接触**と**クラッシュ**：車が何かにぶつかった状態です。接触は軽い衝撃やこすりで、クラッシュは強い衝突です。
- **ABS**、**TC**：ロックとホイールスピンを抑える、車の補助装置です。ミスではありません。

## 車両コントロールの欄（画面に見えるもの） {#the-car-control-section-what-you-see}

選択中のラップについて、そのラップが持っているデータで表示します。タイヤのスリップもドリフトアングルもない場合でも、見つけられるものは表示します（下記）。

**表**：どちらかのラップに現れた種類ごとに1行あります。タイヤロック、ホイールスピン、リアが流れる（オーバーステアとスピン）、フロントが膨らむ、クラッシュ、接触、ABS作動、トラクションコントロール作動、ハンドブレーキ、空中です。各セルには「回数 · 秒数」を、選択中のラップと、それと比べているラップの両方について表示します。ドリフトアングルがあるときは、*最大ドリフトアングル*（地面の上で最も大きい値）も表示します。

**一覧**：共有されていない不具合のうち、0.02秒以上のタイムを失ったものを、損失の大きい順に最大12件表示します。各項目には題名と損失時間があり（その種類のチップも付きます）、クリックするとヒントを読めます。また、その40 m手前で両車の位置を揃えて、リプレイできます。**両ラップがそこでしたこと**を選ぶと、共有されている不具合もすべて加わります（チップは「両者とも」、損失は0.01秒未満なら「—」です）。不具合がない場合は「{name}のタイヤの使い方で、{other}はしていないのにタイムを失ったものはありません。」と表示されます。

**表の下のヒント**：検出に何を使ったかを示します。「各タイヤのスリップとスリップアングル、および車のドリフトアングルから判定。」のように書かれます（ほかに「各タイヤのスリップとスリップアングルから判定。」「各タイヤのスリップと、車のドリフトアングルから判定。」「各タイヤのスリップから判定。」「車のドリフトアングルのみから判定 - これらのラップにはタイヤのスリップが含まれていません。」があります）。さらに、限界値を測った路面（ターマック、未舗装路、混在。サンプルの80%以上が未舗装なら未舗装路、20%未満ならターマック）、どのラップと比べて出来事を並べたか、損失時間をどう数えたかも書かれます。

**タイヤのスリップもドリフトアングルもない場合**（タイヤのテレメトリーがないFH Companionのラップファイル）でも、表と一覧は同じように表示されます。ヒントには、ラップのデータから何が見つかったかが書かれます。「これらのラップにはタイヤのスリップもドリフトアングルも含まれていないため、ロックとホイールスピンは判別できません。引き続き検出されるもの：…」という形です。スリップとドリフトの限界値についての文は省かれ、2つ目のヒントとして「Forza Horizonの場合は、各FH Companionラップの隣にある `.tele.gz` ファイルも選択してください。全輪のスリップが毎秒64回記録された、完全なテレメトリーです。」が表示されます。ヨーレートがあるラップでは、スライドもヨーレートから名前が付けられます。ステアリングがあるラップでのみ、膨らみも検出されます。

ラップ全体の**合計**の車両コントロール損失（要約で使われます）は、重なり合う不具合を一度だけ数えます。ロックと、そこから始まるスライド（40 m以内）は、そのまとまりのうち最も大きいものでまとめて数えます。

## 種類 {#the-kinds}

| 種類 | 表の行 | 不具合か | 数えられる最短時間 |
|---|---|---|---|
| `lock` | タイヤロック | はい | 0.1 s |
| `wheelspin` | ホイールスピン | はい | 0.15 s |
| `oversteer` | リアが流れる | はい | 0.2 s |
| `spin` | （リアが流れるに含めて数える） | はい | 0.1 s |
| `understeer` | フロントが膨らむ | はい | 0.25 s |
| `crash` | クラッシュ | はい | - |
| `hit` | 接触 | はい | - |
| `abs` | ABS作動 | いいえ | 0.2 s |
| `tc` | トラクションコントロール作動 | いいえ | 0.2 s |

短い区間は雑音です（縁石、段差、サンプル1点など）。テストに合格したグリッド点（2 mごと）の連続は、最大2点までの途切れをつないで1つにします。**不具合**だけがミスになり、タイムの損失を持ちます。それ以外は、車と運転者がしたことを示すものです。

## すべてのテストに必要なこと {#what-every-test-needs}

### 導出チャンネル {#derived-channels}

判定の前に、各ラップには、ゲームが送ってこないものを正規の名前で加えます（ゲーム自身の値があれば、常にそちらを使います）。

| チャンネル | 元にするもの |
|---|---|
| `bodySlip`（ドリフトアングル） | 車体座標の速度 `atan2(latVel, abs(longVel))`。ゲームが送る場合に使用（3 m/s未満は0）。送らない場合は、ヘッディング（ゲームのヨー。10 m/sを超えるサンプルで、進行方向に符号とずれを合わせたもの。円形分散が0.05未満のときのみ信頼）と進行方向（2 m以上離れた位置）との差。速度は3 m/sを超えるときに使用 |
| `yawRate` | ヘッディングはあるがヨーレートがない場合の、`yaw` の時間変化 |
| `airborne` | すべての輪の接地（≤ 0.5）がオフ。そうでなければ、すべての輪の荷重が中央値の5%未満。そうでなければ、すべてのサスペンションの移動量が0.02以下（完全に伸びきった状態）。1点だけの誤差は空中とみなしません |
| `slipRatio.<W>` | ゲームが輪の表面速度を送る場合は、`(輪の表面速度 - 車の速度) / 車の速度`（車の速度が3 m/sを超えるとき）。送らない場合は、輪の回転数 × ラップで測った転がり半径。転がり半径は、まっすぐ惰性走行している間の `速度 / 回転数` の中央値（速度 > 10 m/s、アクセル < 0.3、ブレーキ < 0.05、abs(前後加速度) < 3 m/s²、空中でない。20点未満のときは10 m/sを超えるすべてのサンプル）で、0.1〜1 mの範囲で採用します。`physical` と印を付けます |
| `loose` | Forzaの路面の振動が、少なくとも2輪で0.33秒以上続く（> 0.001）もの（縁石はそれより短い）。1秒未満の途切れはつなぎます |

### 接地していて安定していること {#on-the-ground-and-settled}

空中にあるとき、そして**着地後0.3秒の間**は、何も判定しません。サスペンションが底をつき、加速度が跳ね上がるためです。これはグリップ、ブレーキング、駆動ではありません。サンプルは**走行中**でもある必要があります。つまり5 m/sを超える速さです。

### 路面 {#the-ground}

各サンプルの路面は、ラップの `loose` チャンネルがそう示す場合（Forzaの路面の振動、Trackmaniaのタイヤ素材）は**未舗装路**です。それ以外は、そのラップの路面（[種目と路面](race-loading-laps.md#discipline-and-surface)を参照）で判定します。つまり、ターマックまたは、それ以外の場合は未舗装路です。カーブ、ドリフトの癖、閾値は、ターマックと未舗装路で別々に管理します。

### スリップを、タイヤの公称ピークの倍数で表す {#slip-as-a-multiple-of-the-tyres-nominal-peak}

ゲームごとにスリップの尺度が違うため、`meta.slip` がその尺度を示し、すべてのスリップは、約1がタイヤの公称ピークになるような尺度で割られます。

| `meta.slip` | 意味 | 割る値 |
|---|---|---|
| `peak` | ゲームが正規化済み。1を超えるとグリップを失う（Forza Data Out） | 1 |
| `scaled` | 物理的なスリップを、ターマックのピークで割ったもの（Kunosの記録） | 路面の公称ピークを、ターマックの公称ピークで割った値 |
| `index` | 0〜1のスライド指標（TrackmaniaのSlipCoef） | 0.5 |
| `physical`（または不明） | スリップ比は割合、スリップアングルはラジアン | 路面の公称ピーク |

わかっていないときに使う公称ピーク：

| 路面 | スリップ比 | スリップアングル |
|---|---|---|
| ターマック | 0.12 | 8° |
| 混在 | 0.18 | 12° |
| 未舗装路（砂利） | 0.25 | 15° |
| 雪 | 0.25 | 15° |
| 氷 | 0.10 | 6° |

### グリップがどこで終わるか：車ごとのタイヤカーブ {#where-grip-ends-each-cars-tyre-curves}

タイヤがそれ以上グリップを生まなくなる点は、**車ごとに**測ります。その車のすべての荷重のかかったラップ（`measureTyres`）から、ターマックと未舗装路で別々に測ります。

| カーブ | サンプル（速度 > 10 m/s、安定、加速度が45 m/s²未満） | スリップ（x） | 力（y） |
|---|---|---|---|
| ブレーキ | ブレーキ > 0.3、ハンドブレーキ ≤ 0.2、まっすぐ走行中（横方向が最大値の30%未満） | abs(4輪のスリップ比の平均) | 減速度 |
| 牽引 | アクセル > 0.8、ブレーキ ≤ 0.05、まっすぐ、その速度での全開の駆動力 > 0.5 m/s² | 最も大きい駆動輪のスリップ比 | その駆動力に対する加速度の割合 |
| 前輪 | 横方向が最大値の30%より大きい。その速度での車のグリップ > 1 m/s² | 前輪の大きい方のスリップアングル | その車のグリップに対する横加速度の割合 |
| 後輪 | 前輪と同じ | 後輪の大きい方のスリップアングル | 同じ |

「最大値」とは、そのラップのその路面における abs(横加速度) の99パーセンタイルです（サンプルが50点未満の場合は、すべての路面を使います）。駆動方式によって駆動輪を決めます（FFは前輪、FRは後輪、AWDは全輪。不明の場合は全輪）。

**150サンプル**以上あると、スリップを6〜14の等数ビンに分けます（40サンプルごとに1ビン）。各ビンの力は上位四分位数（運転者が求めたときにタイヤが出した力）で、隣のビンと平滑化します。**最良点**は力が最大のビンです。**限界**は、力が**8%**落ちた最初のビンです。データの中で一度も落ちないカーブには限界がありません（無限大）。そのゲームでは「ピーク」を超えてもコストがなく、スリップだけでは何も検出されません（Forza Horizonのコーナリングと牽引のカーブはそのようなものです）。ある路面のサンプルが少なすぎる場合は、もう一方の路面のものを使います。全体でも少なすぎる場合は、**公称**の限界を使います。公称ピークの1.5倍です。

各車は、さらに次のものも持ちます。

- **ドリフトの癖**：その車が、最大値の60%以上の力でカーブを曲がるときのドリフトアングルの上位四分位数（100サンプル必要）。
- **カーブあたりのステアリング**（`steerGain`）：5 m/sの速度帯ごとに、abs(舵角) / 走行ラインの曲率の中央値。グリップの余裕が十分ある範囲（最大値の30〜60%、半径400 mより急なカーブ、舵角 > 0.02で、速度帯ごとに25サンプル）で、しっかりと曲がっているときに測ります。走行ラインの曲率は、ゲームがヨーレートを送る場合は、ヨーレート ÷ 速度です。送らない場合は、位置の ±5 m から求めます。

## 種類ごとの検出 {#detection-kind-by-kind}

| 種類 | テスト（走行中で安定したサンプルについて） | `peak` と `limit` |
|---|---|---|
| **ロック** | ブレーキ > 0.05、ハンドブレーキが0.2以下、いずれかの輪のスリップ比がマイナスのブレーキ限界より小さい | 最も負のスリップ（公称ピークの倍数）。限界は負の値で示す |
| **ホイールスピン** | アクセル > 0.2（またはアクセルのチャンネルがない）、かつ駆動輪のスリップ比が牽引限界を超える | 最も大きい駆動輪のスリップ。限界 |
| **オーバーステア**（ドリフトアングル） | ドリフトアングルが、その路面の下限と、そこでの車のドリフトの癖の1.5倍のうち大きい方を超える | 最も大きいドリフトアングル（ラジアン） |
| **オーバーステア**（スリップアングル、ドリフトアングルなし） | 後輪の大きいスリップアングルが後輪の限界を超え、かつ前輪の大きい方より0.25以上大きい | 後輪のスリップアングル（ピークの倍数） |
| **オーバーステア**（ドリフトアングルなし、ヨーレートと横加速度がある） | 「姿勢の速さ」（abs(ヨーレート) − abs(横加速度) / 速度。速度が8 m/sを超えるとき）が0.2 rad/sを超え、ステアリングがカーブと逆向き | rad/s。限界は0.2 |
| **スピン** | ドリフトアングルが**60°**を超えたオーバーステア | オーバーステアと同じ |
| **アンダーステア**（スリップアングル） | 滑っていない。前輪の大きいスリップアングルが前輪の限界を超え、かつ後輪より0.3以上大きい | 前輪のスリップアングル。限界 |
| **アンダーステア**（スリップアングルなし） | 12 m/sを超える速さ。滑っていない。逆ハンドルでない。横加速度がそのラップの最大値（99パーセンタイル）の半分を超える。半径300 mより急な走行ライン。そして、そのカーブに必要な舵角をその車のカーブあたりのステアリングから求めた値の**1.6倍**を超えて切っている | 必要な舵角の倍数。限界は1.6 |
| **ABS**、**TC** | `absActive` / `tcActive` が0.5を超える | - |
| **ハンドブレーキ** | `handbrake` が0.2を超える | - |
| **空中** | `airborne` が0.5を超える | - |
| **接触**、**クラッシュ** | [接触とクラッシュ](#hits-and-crashes)を参照 | 衝突で失った速度 |

ドリフトアングルの下限は路面ごとに決まっています。ターマックは**7°**、混在は**10°**、未舗装路と雪は**15°**、氷は**10°**です。普段からよく滑る車（アーケード型のタイヤモデルや、砂利を得意とする車など）は、そのラップから求めた独自の、より高い閾値（その車の癖の1.5倍）を持ちます。

**車がどちら向きに曲がっているか**（「カーブと逆向き」を判定するため）：その周囲 ±6 m（少なくとも2グリッド点）にわたる、そのラップの走行経路の向きの変化です。600 mより急な半径は、曲がっているとみなします。右か左かは、世界が反転しているかどうかで決まります。ステアリングが**逆向き**なのは、abs(舵角) > 0.05 で、その符号がカーブと反対のときです。つまり、滑りを逆ハンドルで**立て直している**状態です。

**始まりのペダル**（`pedal`）：ブレーキが0.1を超えていれば*ブレーキング*、アクセルが0.3を超えていれば*アクセル*、その前の8グリッド点（16 m）以内にアクセルが0.5を超えていたら*アクセルオフ*、それ以外は*惰性*です（またはアクセルのチャンネルがない場合）。

## もう一方のラップとの比較 {#laid-against-the-other-lap}

すべての出来事は、その区間で選択中のラップと比べているラップと照らし合わせて判定します（比べるラップは、同じクラスの中で最速のもの。そのラップ自身の場合は、同じクラスの中でその区間が最速だった相手）。

1. **もう一方のラップがどれだけ進んだか**：同じ距離（±8 m）で、もう一方のラップ自身の同じ系統の出来事（スピンはオーバーステアとして、クラッシュは接触として数える）を、同じ単位で、閾値を使わず、もう一方の車のタイヤカーブを使って測ります。
2. **共有**：もう一方のラップが**80%**以上進んでいれば、それはそのコーナーの走り方であり、ミスではありません。ミス以外の種類は、常に「共有」です。
3. **損失時間**（共有されていない不具合について）：出来事の5 m前から**出来事の40 m後**までに、このラップがもう一方に対して失った時間。接触やクラッシュの場合は、車が速度を取り戻すまで（その車自身の牽引で速度を回復するのに必要な距離。40〜400 m）。牽引が測れていない場合は5 m/s²を使います。負にはなりません。
4. **速度の損失**（その車の限界に対して）：ロックの場合は、その速度で車が出せると示した減速度から実際の減速度を引いたもの（出来事の間で合計）。ホイールスピンの場合は、全開の駆動力から実際の駆動力を引いたもの。衝突の場合は、衝突で失った速度。0.5 m/s（1.8 km/h）を超えたときに示します。

共有されておらず、損失時間が**0.02 s**以上の不具合は一覧に載ります（[コースの統計](race-course-statistics.md)は**0.03 s**以上の不具合だけを数えます。多くのラップで数えられるミスは、はっきりしたミスだからです）。そして、コーナーの損失の原因になることもあります（[コーナーごとの分析](race-corner-analysis.md#car-control-faults-and-impacts)を参照）。

## 接触とクラッシュ {#hits-and-crashes}

`impacts.ts` は、接触を、再サンプリングされる前のラップの**元のサンプル**から読み取ります。接触は、わずか数百分の1秒で終わるからです。タイヤでは接触の力を作れないため、接触は、そのラップの車自身を基準に測ります。

- **車のグリップ `G`**：ラップ全体で、接地していて5 m/sを超えるときの水平加速度 `√(lat² + long²)` の99パーセンタイル。加速度のチャンネルがない場合（または3 m/s²未満の場合）は、15 m/s²（一般的な道路車のグリップ）を使います。
- **閾値**：`max(1.8 G, G + 18, 30)` m/s²。
- **衝撃のサンプル**：水平加速度が閾値を超え、**かつ**前のサンプルから `G` の半分以上跳ね上がっている。**または**、0.1秒以内に速度が、閾値で0.1秒の間に失う量と1.5 m/sを足した量を超えて落ちている。接地していて安定しており、車が5 m/sを超えて走っているときだけ。
- 0.4秒以内の衝撃のサンプルは、1回の衝突とみなします。
- **前と後**：衝撃の前0.15秒の最高速度。最後の衝撃のサンプルから0.3秒後までの最低速度。
- **衝突ではないもの**：速度が落ちたのに、その後ろに力がないもの。0.1秒以内の水平加速度のピークが、`G` と25 m/s²のうち大きい方より小さい場合は、ゲームが車を巻き戻したりリセットしたりしたものです。
- **クラッシュ**は、**30 km/h**以上の速度を失った場合、または速度が半分以下になった場合です。それ以外は**接触**です。軽い衝撃や、壁に沿ったこすりなどです。
- **向き**：前後加速度が横加速度より大きく、かつ負であれば、*正面から*。正であれば、*後ろから*。横加速度の方が大きければ、*側面で*。加速度がない場合は、正面からとみなします。

車が何をできるかは、衝撃の前0.1秒から後1秒までのすべての衝撃を除いて測ります（`struckMask`）。

## 表示される文章 {#the-texts}

各出来事は、両方のラップの名前を挙げて書かれます。場所（基準に沿った距離 m）、始まった時の速度、もう一方のラップに対して限界をどれだけ超えたか、そしてヒントが付きます。ヒントは種類と、測定された内容から決まります。

| 出来事 | ヒント |
|---|---|
| ロック、フロントだけ | ロックした前輪はステアできません。ゾーンの頭では踏力を弱め、コーナーに入るときに抜きましょう |
| ロック、リアだけ | ロックしたリアは車を回転させてしまいます。まっすぐでブレーキを強め、ターンインでは緩めます。繰り返すなら、バランスを前寄りにします |
| ロック、未舗装路 | ロックした輪は路面を掘りながら進みます。ロック寸前までブレーキを絞りましょう |
| ロック、その他 | グリップに対してペダルを踏みすぎています。もっと段階的に踏みましょう |
| ホイールスピン | ステアリングを戻すのに合わせてアクセルを入れます。牽引が足りないところではショートシフトします（未舗装路では、高いギアでトルクが和らぎます） |
| スピン / オーバーステア | ペダルの状態で判断します。ブレーキング中（トレイルブレーキングが強すぎる、シフトダウンが早すぎる）、アクセルオフ（アクセルを抜くと荷重が前に移る。一定のアクセルを保つ）、アクセル中（まだ切っているのに踏みすぎ）、どちらでもない（ターンインが速すぎる）。逆ハンドルで立て直したときは「カウンターステアで立て直し」と書きます。未舗装路やラリーでは「ある程度の角度が速い走り方。もう一方の走りで十分だった」 |
| アンダーステア | フロントが流れたら、それ以上ハンドルを切っても効きません。遅めの速度で入り、少しブレーキを残してフロントに荷重をかけ、ステアリングを戻しましょう。未舗装路では、アクセルを抜くか左足で軽くブレーキを当てて、車の向きを変えます |
| 接触 / クラッシュ | 側面なら、1メートルの余裕を持つ方がこすりよりも安く済みます。後ろからなら、他の車か後ろ向きの滑り。正面からのクラッシュならブレーキを早めます。フロントの軽い衝撃なら、何かをかすめています。共有されているときは「{them}もそこで接触しています。」 |

Trackmaniaでは、スライドについても書かれます。約**400 km/h**（未舗装の路面（土、草、プラスチック）では**300 km/h**）未満では、スライドはグリップ走行より推進力が少なくなります。それ以上では、適切な角度のスピードスライドで速度が伸びます。今回のスライドは時間を失ったので、角度がずれていたことになります。

## 各ソースが許すこと {#what-each-source-allows}

| ラップが持つもの | ロック / ホイールスピン | オーバーステア / スピン | アンダーステア |
|---|---|---|---|
| 輪ごとのスリップ比とスリップアングル、車の速度（Forza Data Out、ACシリーズ） | スリップから | ドリフトアングルから、またはリアのスリップアングルから | スリップアングルから |
| 輪の速度、ワールド速度（ラリーゲーム、BeamNG） | 導出したスリップから | 導出したドリフトアングルから | カーブあたりのステアリングから |
| ヨーとヨーレート、スリップなし（iRacing） | - | ドリフトアングルから（進行方向に合わせたヨー）。ヨーを信頼できない場合のみ、逆ハンドルを伴う姿勢の速さから | カーブあたりのステアリングから |
| ヘッディングのみ | - | ヘッディングと進行方向の比較から | カーブあたりのステアリングから |
| FH Companionのラップファイルだけ（ヨーもスリップもなし） | - | - | カーブあたりのステアリングから（ステアリングと加速度があるため） |

接触とクラッシュは速度だけあれば判定できます（加速度があればより正確です）。そのため、どのソースにもあります。**車両コントロール**の欄には、各ソースで何が許されるかが表示されます。FH Companionのラップファイルだけの場合は、ステアリングから求めた膨らみと接触が表示され、残りには `.tele.gz` を読み込むようにヒントが出ます。
