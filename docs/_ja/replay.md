# リプレイ

リプレイは、試合を 3D で再生します。それぞれのユニットは、その車両または人物として描かれます。何が起きたかを見たり、多くの試合を比べたり、誰が誰に当てたかを見たりするために使ってください。

- [試合のリプレイ](match-replay.md): 1 つの試合を再生します。フィギュア、トレーサー、命中、Tacview のようなカメラ付きです。
- [多数の試合を一度に](many-matches.md): 何百もの試合を重ねて並べます。
- [フィギュア](figures.md): ユニットに使われる形と、その出どころ。
- [命中の解析](hit-analysis.md): ある車両や兵士がどこに当たったか、そして誰に当たったか。
