# グラフとHUD

グラフは、ラップを 1 メートル単位でそろえるので、あるドライバーがどこでより遅くブレーキをかけたか、どこでより早くリフトしたかが見えます。ビューの左上にあるカードには、各車とドライバーが今何をしているかが表示されます。

![ビューの下のグラフ: 2 つのラップのギャップ、速度、スロットル、ブレーキ、ステアリングの行。上には時間と原因の帯、カーソルとカードがある](../assets/img/en/race-charts-rows.webp)

## グラフ {#the-charts}

すべてのラップが 1 つの距離の軸に乗ります。基準に沿ったメートル数です ([1 つの距離の軸](race-corner-analysis.md#one-distance-axis) を参照)。そのため、同じ x は、すべてのラップにとってコース上の同じ場所です。1 つのラップは単独でグラフ化されます (そして再生されます)。同じコースの 2 つ目のラップは、それと比べてグラフ化されます。ラップが読み込まれていない場合 (または解析が失敗した場合)、領域には「ラップが読み込まれると、グラフが表示されます。同じコースの別のラップを読み込んで、2 つを比べてください」と表示されます。

### 何が載っているか {#what-is-on-them}

- **凡例**: グラフ化された各ラップの色とラベル。基準は「(基準)」と印が付きます。グラフ化されているより多くのラップが表示されているとき「+N 件を描画、グラフ化せず」。**グラフ (N) ▾**。拡大中は **ラップ全体**。1 行のヒント。
- フォーカスされたラップのための、上部の **2 つの帯**:
  - *時間*: [タイムのマップ](race-replay-and-scene.md#time-map-where) を帯として。負けは赤、ゲインは緑。
  - *原因*: その損失それぞれが、原因のある場所の上のバーとして、原因の色で。バーにカーソルを合わせると、その見出しと費用が出ます。
- **コーナーの帯**: 各コーナーの進入から出口までの、影付きの帯 (基準で見つかったとおり)。その名前 (`T1` …) は、頂点の位置で軸の下に出ます。
- **選ばれた発見**: その範囲の上に、その原因の色の帯。
- **行** (グラフ)。選ばれたチャンネルごとに 1 行。左に、その名前と範囲の上端と下端、範囲がゼロをまたぐところにゼロの線。各ラップは、その色の線です。フォーカスされたラップは幅 2 px で不透明、基準は不透明、ほかのものは 1.5 px で 75% の透明度。ギャップの行は基準を除きます (基準は自分自身に対してゼロだからです)。
- **カーソル**: 基準の車がある (またはポインターがある) 場所の縦線と、ギャップ以外のすべての行にある車ごとの点。カーソルの位置では、すべての車が同じメートルにいます。それ以外は、リプレイの時計での各車自身の距離です。

グラフ化されるラップは、最大 **8** です。フォーカスされたラップ、そのクラスの最良、基準が先で、その後は読み込み順の他のラップです。

### 行とその高さ {#rows-and-their-heights}

行は、ウェイトに従ってグラフの高さを分け合い、どれも 16 px 未満にはなりません。

| 行 | ウェイト |
|---|---|
| ギャップ (基準に対して、秒、符号付き) | 1.7 |
| 速度 (km/h) | 1.7 |
| ペダル (スロットル、ブレーキ、クラッチ) | 1 |
| ステアリング | 1.1 |
| ギア | 0.8 |
| ランプ (ハンドブレーキ、ABS など) | 0.55 |
| その他すべて | 1 |

表に固定の表示範囲があるチャンネル (ペダルは 0〜100%) は、それを使います。ほかは、ラップの表示されている区間に合わせられます。空間に対して長すぎる行の名前 (別の言語の長い単語) は、行が十分高いところでは、上の値を 1 行下に動かします。高さが足りないところでは、省略記号で切られます。全体の名前はツールチップになります。

### 既定のグラフ {#the-default-graphs}

グラフが選ばれるまでは、**ギャップ**、その後は、表が `graph` と印を付けていて、そのラップが持っているすべてのチャンネル (スロットル、ブレーキ、クラッチ、ハンドブレーキ、ステアリング、ギア、速度) です。ただし、ペダルやランプのチャンネルは、どのラップかがそれを 0.02 を超えて動かさない限り、除かれます (一度も踏まれないクラッチはグラフになりません)。順番は表のものです。

### グラフのピッカー {#the-graph-picker}

**グラフ (N) ▾** は、ボタンの上にパネルを開きます。

- フィルターの欄 (チャンネルの名前か ID に一致)。
- **既定** (既定のセットに戻します。そのツールチップに数が書かれています) と **閉じる**。
- *基準に対するギャップ*。その後、グラフ化されたラップが持つすべてのチャンネルを、グループごと (動き、操作入力、エンジン、支援、タイヤ、ブレーキ、サスペンション、ホイール、その他、タイミング、位置)、それぞれにチェックボックス付きで。車輪ごとのチャンネルは、1 行で、車輪ごとのチップ (FL、FR、RL、RR) が付きます。

チェックを付けると、チェックした順番にかかわらず、表の順番が保たれます。選択は、**既定** を押すか、再読み込みするまで続きます。表が知らないチャンネルは、*その他* の下に、その ID から名前を付けて出ます (「brakeLinePress」→「Brake line press」)。

### ホバー、ホイール、拡大、クリック {#hover-wheel-zoom-click}

| 操作 | 働き |
|---|---|
| ホバー | すべての車、そのカード、その操作入力が、そのメートルへ動く。支柱がコース上にその場所を示す。表は、そこでグラフ化された各ラップの、すべての行の値を一覧する (基準のギャップは「ref」と表示)。カードの上に「N m - グラフのカーソル」。プロットから外れると、リプレイに戻る |
| ホイール | 1 ノッチごとに、表示されている区間の 1/200 だけラップに沿ってリプレイを進める (Shift: 5 倍)。リプレイは一時停止する。拡大中は、ビューがカーソルに従う |
| Ctrl+ホイール (Cmd+ホイール) | ポインターを中心に距離の軸を拡大・縮小する。1 ノッチごとに 1.25 倍で縮小、0.8 倍で拡大。40 m より狭くはならない。ラップ全体まで縮小すると、拡大は終わる |
| 横のホイール | 拡大中は横に移動する (100 単位のスクロールごとに区間の 10%) |
| ダブルクリック、**ラップ全体** | 縮小する |
| クリック | リプレイを、基準がその距離に達する場所へ跳ばす |
| Shift+クリック | その場所で車をそろえる ([そろえる](race-replay-and-scene.md#lining-up) を参照) |

言語が変わると、グラフは現在の言語で描き直されます。

凡例の中のヒントの行は、それを短く言います: 「ホバー: その場所のすべての車 · ホイール: ラップに沿って進む · Ctrl+ホイール: 拡大 · クリック: 跳ぶ · Shift+クリック: そろえる」。

## 車のカード (HUD) {#the-car-cards-hud}

ビューの左上にあり、表示されているラップごとに 1 枚のカード。最大 **6** 枚で、読み込み順の最初の 6 つの表示されているラップです。リプレイ (またはグラフのカーソル) がその時点にいるときのものです。

**ヘッダー:** ラップの色とラベル。ライブのギャップ。このラップがその現在の距離に達するまでの時間から、基準が同じ距離に達するまでの時間を引いたもの (「+0.48 s」) か、「基準」。**⋯** は、ほかのすべての値を表示または非表示にします (*カードのすべての値* と同じ)。追いかけられている車のカードは強調されます。

**上から見た車:** ラップの色の車体の輪郭に、前方の矢印、4 つのタイヤ (前輪はステアリングとともに最大 28° まで回る)。それぞれ温度で色が付き、3D の車を平らに描いたものと同じ記号が付きます: スリップのリング、サスペンションのバー、ブレーキの光、摩耗の帯、荷重のバー。

**読み出し:** km/h の速度、そのラップ自身の時刻、基準に沿った距離。

**操作入力:**

- ステアリングの入力で回るステアリングホイール (全切りは 180° で描かれる) と、その下のパーセンテージ。
- ペダルボックスと同じく左から右へ、ペダルごとのバー (クラッチ、ブレーキ、スロットル)。それぞれ、その色で、パーセンテージと短い名前が付きます (そのラップが持つペダルだけ)。
- ギア (R は後退、N はニュートラル)。
- ラップが持つオン/オフのチャンネルごとの小さなランプ: ハンドブレーキ、ABS、TC、DRS、ピットリミッター、空中。オンの間はその色で点灯します (範囲の半分より上)。
- レベルのチャンネルごとの読み出し: ブレーキバイアス、ABS と TC の設定、ブースト、燃料。

**入力の軌跡:** すべてのペダルの直近 **6 秒** (1 つのレーン、それぞれその色) と、ステアリング (その独自のレーン、中央揃え)。この瞬間で終わります。ドライバーがそこへ入る途中で何をしたかです。最大 160 点まで。

**すべての値** (⋯ または *カードのすべての値*): そのラップがこの瞬間に持つ、ほかのすべてのスカラー。その後、車輪ごとのチャンネルのすべてを、4 つの値 (FL FR RL RR) として。名前はチャンネルの表から、またはチャンネル自身の名前から付けられ、グループごとに並びます。

### チャンネルの表 {#the-channel-table}

[`src/race/schema.ts`](https://github.com/Holdi601/3DHeat/blob/main/src/race/schema.ts) の `CHANNELS` は、チャンネルを説明する唯一の場所です。その単位、サンプルごとに 1 つの値か車輪ごとに 1 つか (`name.FL` … として保存)、そのグループ、表示範囲、車の上での描かれ方 (`glyph`)、カードでの現れ方 (`input`: `pedal`、`steering`、`gear`、`lamp`、`level`)、既定のグラフかどうか、滑らかに混ざらずステップするか (ギア、フラグ)、そして表示の仕方 (倍率、単位、桁数)。ラベルと短い名前は、各言語のメッセージです (`race.channel.<名前>.label` / `.short`)。

描画または既定のグラフがあるチャンネル:

| チャンネル | 単位 | 描き方 | 既定のグラフ |
|---|---|---|---|
| `throttle`、`brake`、`clutch` | 0..1 | ペダル (緑、赤など)、% で表示 | はい |
| `handbrake` | 0..1 | ランプ | はい |
| `steer` | -1..1、右が正 | ステアリングホイール | はい |
| `gear` | - | ギア | はい |
| `speed` | m/s、km/h で表示 | - | はい |
| `absActive`、`tcActive`、`drs`、`pitLimiter`、`airborne` | 0..1 | ランプ | - |
| `brakeBias`、`absLevel`、`tcLevel`、`boost`、`fuel` | - | レベルの読み出し | - |
| `tireTemp` (車輪ごと) | °C、表示 40〜130 | タイヤの色 | - |
| `tireTempInner/Middle/Outer` | °C | - | - |
| `slipRatio`、`slipAngle` (車輪ごと) | ゲームが拡大縮小したとおり、表示 ±1.5 | スリップのリング | - |
| `combinedSlip`、`slipIndex` (車輪ごと) | 表示 0〜1.5、0〜1 | スリップのリング | - |
| `suspension` (車輪ごと) | 0..1 | サスペンションのバー | - |
| `brakeTemp` (車輪ごと) | °C、表示 100〜900 | ブレーキの光 | - |
| `tireWear` (車輪ごと) | 0..1 | 摩耗の帯 | - |
| `wheelLoad` (車輪ごと) | N、表示 0〜12 000 | 荷重のバー | - |

表にあるほかのもの (グラフ化され一覧されるが、描かれない): `latAcc`、`longAcc`、`vertAcc`、`yaw`、`pitch`、`roll`、`yawRate`、`latVel`、`longVel`、`vertVel`、`bodySlip` (ドリフト角)、`loose`、`lateral` (基準からのずれ)、`rpm`、`power`、`torque`、`waterTemp`、`oilTemp`、`tirePressure`、`camber`、`padLife`、`discLife`、`suspensionM`、`wheelSpeed`、`wheelSurfaceSpeed`、さらに `time`、`distance`、`x`、`y`、`z`。

**表にないチャンネル** も、読まれ、グラフ化され (*その他* の下)、カードに一覧されます。名前は、その ID から付けられます。**適切な名前、単位、描き方を与えるには**、表に 1 つの項目を加えます (そのラベルのメッセージを、各 `src/i18n/locales/<言語>/race-channels.json` にも)。新しい *種類* の車輪の描き方は、`WHEEL_GLYPHS` (glyph.ts) の 1 項目と、その平面版の `CARD_GLYPHS` (RaceHud.tsx) です。どちらも種類で型付けされるので、両方が存在するまでビルドは失敗します。`src/race/extensible.test.ts` は、未知のチャンネルがグラフに届くこと、表のすべてのグリフが描けること、ランプが点灯することを確かめます。
