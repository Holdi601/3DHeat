# Sorting lists

Every list in the viewer can be sorted: filter values, teams, entities and units, matches, the level library, volumes, events, bookmarks, insights findings, race laps and corners, and the breakdown, compare, versus and mass-analysis tables.

- **Lists** have a small **Sort** control above them: pick what to sort by (name, count or rows, a value, time or date, recently used, or *As listed* for the data's own order) and press the arrow to flip the direction.
- **Tables** sort by their column headers: click a header to sort by it, click it again for the other direction. The arrow in the header shows the column and the direction.

Names sort the way you read them: case and accents do not split the list, and numbers inside names count as numbers, so *MP_2* comes before *MP_10*. Rows without a value always go to the end. Ties keep their previous order.

Filter value lists start in name order, ranked tables in the order of their measure. The viewer remembers your choice for each list in this browser; without browser storage each list starts from its default.

Sorting long lists (more than 10,000 entries) happens in the background, so the 3D view does not stutter. Sorting filter values by *Rows* counts the rows once, in small steps.
