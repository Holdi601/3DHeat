# Referanse

Lister over nøyaktige navn, innstillinger og verktøy, å slå opp i. Du trenger ikke lese dem for å bruke seeren.

Disse listene genereres fra seerens kode av `node tools/docs-refs.mjs` (du trenger ikke kjøre den), så de alltid stemmer med versjonen de ble laget for:

- [Hendelsestyper og klasser](ref-event-types.md) – hendelsestypene og kjøretøyklassene hvert datasett sorteres i, og hvilke ord i dataene som hører til dem
- [Kolonnenavn](ref-columns.md) – kolonnenavnene innleseren gjenkjenner for posisjon, tid, person, lag, økt og blikkretning
- [Språkliste](ref-languages.md) – seerens språk
- [Tastatursnarveier i nettleseren](ref-browser-keys.md) – nettleserens snarveier som seeren beholder for seg selv
- [Lagrede innstillinger](ref-settings-storage.md) – det nettleseren husker mellom besøk
- [Verditabeller](ref-value-tables.md) – prisntabellene for verdivekting
- [Kommandolinjeverktøy](ref-tools.md) – verktøyene i `tools/`: for dataene dine, og for utviklere og dokumentasjonen

Også referanse, og [Ordlisten](glossary.md) for ordene som brukes på dette nettstedet. Skrevet for hånd: [Referanse for dataformater](data-formats.md), [Referanse for tastatur og mus](keyboard-reference.md), [Én fil per kamp (.3dheat)](container.md).
