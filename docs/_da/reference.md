# Reference

Lister over præcise navne, indstillinger og værktøjer, til at slå ting op i. Du behøver ikke læse dem for at bruge vieweren.

Disse lister genereres ud fra vieweres kode med `node tools/docs-refs.mjs` (du behøver ikke køre den), så de altid passer til den version, de blev lavet med:

- [Hændelsestyper og klasser](ref-event-types.md) - de hændelsestyper og køretøjsklasser, hvert datasæt sorteres i, og hvilke ord i dataene der svarer til dem
- [Kolonnenavne](ref-columns.md) - de kolonnenavne, indlæseren genkender for position, tid, person, hold, session og blikretning
- [Sprogliste](ref-languages.md) - vieweres sprog
- [Browsertaster](ref-browser-keys.md) - browsergenveje, vieweren beholder for sig selv
- [Gemte indstillinger](ref-settings-storage.md) - hvad browseren husker mellem besøg
- [Værditabeller](ref-value-tables.md) - prislisterne for værdivægtning
- [Kommandolinjeværktøjer](ref-tools.md) - værktøjerne i `tools/`: til dine data, og til udviklere og dokumentationen

Også reference, og [Ordlisten](glossary.md) for de ord, der bruges på siden. Skrevet i hånden: [Dataformater](data-formats.md), [Tastatur- og museoversigt](keyboard-reference.md), [En fil pr. kamp (.3dheat)](container.md).
