# Сутності

**Об’єкти** дозволяє вибрати одного гравця (або кількох), щоб бачити лише те, де був цей гравець. Скористайтеся ним, щоб стежити за власним рухом або за одним суперником.

Панель показується, коли в наборі даних є стовпець осіб. Її заголовок показує кількість осіб або `selected of total`, поки вибір активний. (*Особа* — це один гравець або ШІ, див. [глосарій](glossary.md).)

## Виберіть гравця {#pick-a-player}

1. Відкрийте **Об’єкти** на бічній панелі.
2. Введіть частину імені в поле пошуку.
3. Позначте гравця. Заголовок покаже, наприклад, `2 of 10`, а все інше зникне.
4. **Очистити** знову показує всіх.

![Об’єкти: вибрано двох із десяти гравців](../assets/img/en/entities-selected.webp)

Вибір показує лише вибрані особи в режимах тепла (точки, лінії, різниця, тепло команд), а також у треках, фігурах і слідах [повтору фігурами](box-replay.md). Залиште порожнім, щоб показувати всіх. Вибрати всіх — те саме, що не вибрати нікого.

## Панель {#the-panel}

| Частина | Значення |
|---|---|
| Поле пошуку | *Пошук серед N об’єктів...* Фільтрує список за підрядком імені без урахування регістру. Показує `N matches` або `N matches, showing the first 200`. Якщо пошук нічого не знайшов, показує *Nothing matches "..."*. |
| Список | До 200 осіб (перші 200 збігів), кожна з позначкою, зразком кольору особи та іменем (*(без імені)* для порожнього імені). |
| Підказка про гру | Коли час відтворюється, у списку лишаються ті, що *в грі в позиції відтворення*. Пошук знаходить усіх. |
| **ШІ (n)** | Згорнута група з юнітами, якими керує ШІ, окремо від гравців. |
| **Додати показані** | Додає до вибору всіх, хто зараз у списку. |
| **Лише показані** | Робить вибір рівно тими, що в списку. |
| **Очистити** | Очищає вибір. |

## Обмеження {#limits}

У тепловій карті вибір є фільтром і використовує один із чотирьох [слотів фільтрів](filters.md#rules). Коли інші фільтри вже використовують усі чотири, панель каже: *Не застосовано до теплової карти: усі слоти фільтрів зайняті. Повтор фігурами все одно показує лише ці об’єкти. Очистіть фільтр у розділі Фільтри, щоб звільнити слот.* Очистіть фільтр, щоб звільнити слот.

Вибір очищується з кожним новим набором даних. Вкладка **Матч** встановлює той самий вибір, коли фокусується на одному гравці.

## Для розробників {#for-developers}

Вибір зберігається як фільтр *persons* ([Фільтри](filters.md#for-developers)). Маска шейдера містить 65 536 ідентифікаторів осіб. Особа, що виходить за це, не малюється в тепловій карті, поки вибір активний.
