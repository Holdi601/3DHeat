# Паритет з Tacview

Tacview — популярна програма для перегляду записів польотів. Якщо ви її знаєте, ця сторінка показує, де кожен її інструмент є в 3DHeat.

Вона перелічує кожну функцію Tacview 1.9 (його посібника, таблиці рядків інтерфейсу і формату файлів ACMI 2.2) і те, де [повтор матчу](match-replay.md) 3DHeat стоїть щодо неї. Мета: те, що Tacview може зробити з повтором і його даними, 3DHeat теж може зробити.

**Статус:**
- **готово**: уже є в 3DHeat.
- **нове**: зроблено, щоб відповідати функції Tacview.
- **ще не зроблено**: стосується, але не зроблено.
- **н/д**: сюди не стосується, з причиною.

Де шукати функції: вкладка **Матч**, **Повтор фігурами** (або **Накладання фігур** на вкладці Теплова карта), у бічних розділах **Розбір**, **Одиниці**, **Події**, **Закладки**, **Тактичний показ**, **Статистика**, **Зсув у часі та обрізання**, **Карта й координати**, **Аудіо та відео** і **Підписи**. Див. [Повтор матчу](match-replay.md).

## Для розробників: властивості ACMI 2.2 {#for-developers-acmi-22-properties}

Читаються `data/acmi.ts`; числові властивості стають числовими стовпцями, текстові — категорійними. Усі вони показані у **Сирих** на картці одиниці. Вони читаються з певною метою:

| Властивості | Використання |
|---|---|
| T (усі чотири форми), Name, Type, Pilot, Group, Country, Coalition, Color, CallSign | Положення, положення в просторі, фігура, назва одиниці, команда |
| IAS, CAS, TAS, Mach, AOA, AOS, AGL, HDG, HDM, OnGround | Поля, графіки, HUD, визначення зльоту і посадки |
| VerticalGForce, LongitudinalGForce, LateralGForce | Поля G |
| Throttle(2), Afterburner, EngineRPM(2), NR, AirBrakes, Flaps, LandingGear, Tailhook | Поля |
| FuelWeight..9, FuelVolume..9, FuelFlowWeight..8 | Поля палива, сума по баках |
| RadarMode, RadarAzimuth, RadarElevation, RadarRoll, RadarRange, RadarHorizontalBeamwidth, RadarVerticalBeamwidth, RadarRangeGateAzimuth/Elevation/Min/Max/HorizontalBeamwidth/VerticalBeamwidth | Конуси радара і строб дальності |
| LockedTarget..9, LockedTargetMode, LockedTargetAzimuth/Elevation/Range, FocusedTarget | Лінії захоплення |
| EngagementMode(2), EngagementRange(2), VerticalEngagementRange(2) | Купола ураження |
| QNH, AltimeterSetting, WindSpeed, WindDirection, HeartRate | Поля |
| Health | Поле |
| Події: Destroyed, TakenOff, Landed, Bookmark, Message, Comment, LeftArea, Timeout | Список подій, статистика (загибелі, зльоти, посадки), закладки; Message і Comment як субтитри |
| PilotHeadYaw, PilotHeadPitch | Лінія погляду пілота |
| Тег типу Bullseye (Navaid+Static+Bullseye) | Поле булзая і кільця на карті |
| Усе інше (PilotHeadRoll, керування, поверхні, відхилення ILS, SpO2, ENL, Label, Debug, Importance, Slot, Visible, Disabled, Radius, розміри...) | Показано як записано у **Сирих** |

Кути радара і захоплення беруться відносно власних осей одиниці: азимут — праворуч, кут місця — вгору, крен — праве крило вниз. Специфікація ACMI каже, що вони відносні до літака, але не яким боком позитивні; це прочитання йде за її перетворенням (рискання за годинниковою стрілкою, тангаж вгору, крен праворуч).
