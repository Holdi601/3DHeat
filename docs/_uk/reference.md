# Довідник

Списки точних назв, налаштувань і інструментів, щоб шукати в них. Щоб користуватися переглядачем, їх читати не потрібно.

Ці списки генеруються з коду переглядача командою `node tools/docs-refs.mjs` (запускати її не потрібно). Тому вони завжди збігаються з версією, для якої їх створено:

- [Типи подій і класи](ref-event-types.md) - види подій і класи техніки, за якими сортується кожен набір даних, і які слова в даних з ними відповідають
- [Назви стовпців](ref-columns.md) - назви стовпців, які завантажувач розпізнає для позиції, часу, особи, команди, сесії і напрямку погляду
- [Список мов](ref-languages.md) - мови переглядача
- [Клавіші браузера](ref-browser-keys.md) - комбінації браузера, які переглядач залишає собі
- [Збережені налаштування](ref-settings-storage.md) - що браузер пам'ятає між відвідинами
- [Таблиці значень](ref-value-tables.md) - таблиці цін для зважування цінності
- [Інструменти командного рядка](ref-tools.md) - інструменти в `tools/`: для ваших даних, для розробників і для документації

Також довідка - [Глосарій](glossary.md) зі словами, які використовуються на цьому сайті. Написано вручну: [Формати даних](data-formats.md), [Довідник клавіатури і миші](keyboard-reference.md), [Один файл на матч (.3dheat)](container.md).
