# Маневри: як рухаються групи

**Висновки → Маневри** стежить, як одиниці кожної сторони рухаються *разом як групи*. Вона називає маневри, які вони виконують: фланг, кліщі, прорив, засідку, відхід, оборону від ракет, перетин T. Для кожного показано, наскільки вона впевнена, цифри, на яких це ґрунтується, чи маневр окупився, і його паралелі в доктрині й історії. **Масовий аналіз → Маневри** рахує їх у тисячах матчів: як часто кожен маневр робиться на мапі, в режимі й на кожній стороні, і як часто він окупається.

Усе обчислюється у вашому браузері, у власному воркері (`src/insights/maneuver`). Матч із кількома сотнями одиниць займає 10-500 мс. Двогодинна повітряна війна з тисячами об'єктів займає близько секунди.

## Як користуватися {#using-it}

- Відкрийте **Висновки**, вкладку **Маневри**. Вона рахує, коли її відкривають уперше. Після зміни фільтрів натисніть **Знайти знову**.
- **Певно / Імовірно / Можливо** задає рівень впевненості в списку (за замовчуванням - Імовірно).
- **Хронологія** має смугу для кожної сторони та стовпчик для кожного маневру. **Список** під нею показує те саме, за часом. Клік переносить вас у повтор на початок маневру, переводить камеру туди і малює його в 3D: шлях кожної групи як стрілку (два плечі кліщів - це її дуги), контури груп у ключовий момент (ворог - кольором своєї сторони) і фронт ворога як білу лінію. **Показати всі в 3D** додає інші маневри матчу, блідими лініями. Лінії передаються відеокарті один раз, коли змінюється вибір, а не щокадру. Зі 480 маневрами, намальованими під час відтворення, часи кадрів на справжньому GPU (WebGL2 і WebGPU, p99 18,0-18,5 мс, максимум 19,5-20,8 мс) такі самі, як без них.
- Відкритий маневр показує свій результат (знищення і втрати одиниць, що його виконували, поки він тривав і одразу після, порівняно з обміном сторони за весь матч), свої докази і записи бази знань про нього: доктрину та історичні паралелі (Канни для кліщів, Седан 1940 для прориву, Цусіма для перетину T, операція Bolo для відволікального удару...).
- Невелика таблиця в кінці: для кожного виду й сторони - скільки виконано і скільки окупилося.

## Як знаходять групи {#how-groups-are-found}

Кожну одиницю ставлять на спільну шкалу часу: крок 1 с для піхоти, 2 с в інших випадках, довший для дуже великих файлів. Коли одиниця гине, її тримають на місці, щоб відродження не малювало лінію через мапу. На кожному кроці одиниці однієї сторони й одного виду (літак, техніка, кораблі, піхота) з'єднуються, якщо вони близько: 18 м для піхоти, 170 м для техніки, 3 км для кораблів, 5 км для літаків. Вони також мають рухатися однаково: швидкості відрізняються не більше ніж на половину швидшої, або обидві стоять. Скупчення зберігає ідентифікатор тієї групи, у якій було більшість його членів. Одиниця без класу стає піхотою, технікою або літаком за своєю швидкістю.

**Форму** групи читають відносно її напрямку руху. Колона або лінія визначаються за розкидом уздовж і поперек. Клин - коли середина попереду. Уступ - коли члени відступають убік. Каре - коли вони тримають кути.

Усе оцінюється в масштабі самого матчу. **Дистанція бою** `R` - це 75-й перцентиль відстані між вбивцею та його жертвою (обмежений смислом домену). Часи маневру масштабуються за видом одиниць: піхота займає третину часу, що й техніка на землі.

## Що знаходить {#what-it-finds}

| Маневр | Знаходиться, коли |
|---|---|
| Шикування | група тримає одну форму на 60% своїх кроків руху протягом 30 с |
| Фронтальна атака | група зближується від поза дальністю до зіткнення, на ¾ R або більше, з кута до 35° від напрямку, куди дивиться ворог |
| Флангова атака | те саме з кута 50-130° (тил - далі); певно лише тоді, коли є друга сила, що зв'язує ворога і б'ється з ним там (знищення в обидва боки) |
| Кліщі | дві флангові атаки однієї сторони на одне тіло ворога з протилежних боків (100° і більше одна від одної), протягом 90 с; певно, коли обидва плечі б'ються |
| Оточення | компактна група ворога, навколо якої є щонайменше стільки ж одиниць іншої сторони в межах 1,5 R, з двох або більше груп, без проміжку більше 100°, протягом хвилини, відрізана від своїх; певно, коли кільце стиснулося на ½ R і б'ється в кишені |
| Прорив | група проходить крізь утриманий рубіж (вороги стоять 30 с і зліва, і справа від неї, а центр їхньої сторони - за ними); певно, коли вона проходить на ½ R, лишається там 20 с і б'ється; прорив - на ще один R далі |
| Перебіжки під прикриттям | у малій групі частина рухається, поки інша стоїть, ролі міняються чотири рази або більше, і стояча частина прикриває вогнем |
| Зосередження / розосередження | частка сторони біля її найщільнішої точки росте від 35% до 60% (одиниці наближаються на 1,5 R або більше, а потім зіткнення) - або падає, коли сторона розходиться |
| Відволікальний удар | малий елемент у бою притягує двох або більше ворогів з іншого місця; тоді більша група б'є за чотири дальності там, де ворога менше |
| Відхід / переслідування | група в бою розвертається і відходить на R від місця бою; певно, коли там ворог щойно знищив одного з її членів, а група відійшла на 2 R від цього вбивці (на землі ніколи: див. нижче); вороги, що рухаються в той самий бік і не відстають, переслідують |
| Ешелонована оборона | нерухомі одиниці в двох або більше смугах поперек осі ворога, на R вглиб, ворог наближається, вогонь іде з смуг |
| Оборона на зворотному схилі | три або більше знищень на короткій дистанції від нерухомих одиниць, а жертви прийшли через гребінь |
| Засідка | група в русі зустрічає ворогів, які стояли 45 с; вони стріляють першими, і ті, що рухалися, втрачають двох або половину групи |
| Охорона | одна або дві одиниці рухаються попереду тіла з трьох або більше і першими зустрічають ворога |
| Внутрішні лінії | групи однієї сторони стоять близько одна до одної між групами іншої, її одиниці переходять між ними |
| Темп | сторона відповідає на зіткнення (поворот, зміна швидкості, перший постріл) у 1,5 раза швидше, p за тестом Манна-Уїтні менше 0,05 |
| Crank, notch, drag, pump | ціль пуску ракети розвертає стрілка на 35-70°, 75-105° або більше 140°, або тягне й розвертається назад |
| Повітряні кліщі, стіна, lead-trail, grinder | пара, що розходиться на одного ворога; три в ряд на ворога; елемент на 5-20 км позаду іншого; двоє кружляють на відстані однієї точки |
| Бойове повітряне патрулювання | кружляє навколо станції три хвилини |
| Бій на енергії / на кутах | у близькому бою - курси на 30° одне від одного, кожен по черзі тримає іншого перед собою, або між ними є знищення - використовується висота і набір, або політ на низькій висоті з жорстким розворотом і зниженням швидкості; певно, коли один знищив іншого |
| Ударна група, ППО | повітряна група з різними ролями, частина з яких б'є по землі; знищення ППО - раніше за більшість інших наземних знищень |
| Лінія баталії, перетин T | три кораблі в колоні; колона квадратом поперек голови ворожої колони |

Кожен маневр показує, які **патерни** бази знань він відображає (`patterns-maneuver.ts`: шикування, фронтальна атака, подвійне охоплення, оточення, прорив, вогонь і маневр, відволікальний удар, відхід, переслідування, ешелонована оборона, охорона, розосередження, оборона від ракет, бій на кутах, бойове повітряне патрулювання, ударна група, лінія баталії, перетин T) і записи, які варто прочитати першими. Старіші записи отримують нові патерни через `knowledge/maneuver-tags.ts`. Див. [Лінза знань](knowledge.md).

**Окупився** порівнює обмін одиниць, поки маневр тривав (і ще хвилину після), з обміном їхньої сторони за весь матч. Відхід окупається, коли після розвороту втрачено менше одиниць, ніж до нього. Оборона від ракет - коли літак живе хвилину. Оточення - коли кишеня втрачає половину.

## По багатьох матчах {#over-many-matches}

Зведення кожного матчу (`src/mass/summarize.ts`, див. [Масовий аналіз](mass-analysis.md)) має невеликий розділ `maneuvers`: для кожного виду й сторони - виконано (на Імовірно або вище), окупилося, не окупилося, знищення і втрати. **Масовий аналіз → Маневри** додає їх разом за матчами, які лишає фільтр, - за мапою і режимом або за всіма разом. До частки окупу додається довірчий інтервал Вілсона. Рядок завантажує матчі, у яких він був виконаний. Зведення, записані до появи цього розділу, його не мають. Щоб додати його, запустіть `node tools/3dheat-summarize.mjs <folder> --force`.

## Наскільки це певно {#how-sure-it-is}

Синтетичні матчі із закладеними маневрами (`synth.ts`, запускає `maneuver.test.ts`): усі 28 закладених видів знаходяться на Імовірно або вище. З 50 повідомлених маневрів 31 - саме закладеного виду, а решта 19 теж справді є (шикування рухомої групи, фронтальне наближення колони, що прориває). Жоден не хибний. На 30 нульових матчах - випадкових блуканнях окремо і разом, одиницях, що стоять у випадкових місцях, літаках на прямих курсах, натовпі, що снує навколо, - на Імовірно або вище нічого не повідомлено.

На реальних даних (десятки наземних боїв, кілька довгих місій повітряної війни, десяток матчів шутерів): фронтальні атаки, фланги, прориви й оточення в танкових боях, шикування й близькі бої в повітрі, оборона від ракет, орбіти CAP і пари lead-trail у місіях повітряної війни, фронтальні знищення, колони, а також кілька засідок і перебіжок у шутері. Пороги - це форми доктрини, перенесені на масштаб гри. Читайте окрему знахідку разом з її доказами, а частки з таблиці масового аналізу - разом з їхніми інтервалами.

### Проти нульових моделей тих самих матчів {#against-null-models-of-the-same-matches}

Детектор можна ввести в оману землею і натовпом: у бійці кожна група має ворогів з усіх боків. Тому кожен вид також запускають на **нульових моделях**, побудованих із тих самих матчів (`nulls.ts`). Там сторони вже не зустрічаються так, як було насправді. Це або часова шкала однієї сторони, зсунута на третину - дві третини матчу (*shift*), або її треки, повернуті навколо центру мапи (*rotate*). Також мітки команд перемішують (*teams*, що за побудовою зберігає близько половини справжніх боїв). Бої рахуються лише як знищення, спарені з їхніми смертями: вбивця в межах 2 R, а жертва на місці. Нульова модель це порушує. Знахідки на Імовірно або вище, справжні проти нульових моделей (30 танкових боїв; 12 матчів шутерів):

| Вид | Танкові бої: справжні / shift / rotate | Шутер: справжні / shift / rotate |
|---|---|---|
| Оточення | 0 / 0 / 0 (було 1,3 / 1,2 / 0,8) | 0 / 0 / 0 |
| Прорив | 0,03 / 0,02 / 0,05 (було 1,6 / 1,8 / 1,4) | 0 / 0 / 0 |
| Флангова атака | 0,33 / 0,07 / 0,10 | 1,0 / 0,08 / 0,21 |
| Фронтальна атака | 0,87 / 0,47 / 0,12 | 14,4 / 6,5 / 4,3 |
| Відхід | 0,03 / 0 / 0,02 | 0,08 / 0,08 / 0,5 (тому на землі ніколи не певно) |
| Засідка | - | 0,17 / 0,04 / 0,04 |
| Бій на енергії | 1,2 / 0,1 / 0,85 | - |
| Бій на кутах | 0,6 / 0,07 / 0,3 | - |

Близькі повітряні бої над центром бою переживають розворот навколо цього центру, тому колонка rotate їм менше шкодить, ніж видам на землі. Види всередині однієї сторони - шикування, бойове повітряне патрулювання, grinder, ударна група, ППО, перебіжки, охорона - не залежать від іншої сторони, і їх так не перевіряють. `maneuver.test.ts` перевіряє, що нульові моделі прибирають закладені флангові атаки, кліщі, оточення, прориви, засідки й відходи із синтетичних матчів.

## Обмеження {#limits}

- Групам потрібні позиції в часі. Файл із самими подіями їх не має.
- Напрямок фронту з даних не читається. Фронт ворога там, де його зв'язує друга сила, що б'ється з ним. Інакше - там, куди він рухається. Інакше - звідки прийшов атакувальник.
- Рельєф береться з власних висот одиниць (зворотний схил). Перевірки видимості немає.
- Дуже великі файли читаються з більшими кроками. Короткі повітряні маневри в них усе одно читаються з кроків 2-4 с.
