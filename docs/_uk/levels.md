# Рівні та фонова геометрія

Рівень - це 3D-місце, де відбулася гра: карта, місто, траса. Поставте його за своїми даними, і ви бачите, *де* тепло. Панель **Тло / рівень** (див. [Глосарій](glossary.md) щодо «рівня») дає три види контексту:

- **зображення карти**, прив’язане до місцевості двома якорями - див. [Зображення карт](map-images.md);
- **3D-рівень** - `.glb`, `.gltf`, `.obj`, `.stl` або `.ply` - розбитий на землю, споруди й воду і спрощений під час імпорту - див. [3D-рівні](model-levels.md) і [Вигляд рівня](level-appearance.md).
- **фон світу** - для запису, що вказує своє місце на Землі (файл Tacview ACMI), справжній рельєф, дороги, воду, аеродроми й будівлі, завантажені з відкритих даних - див. [Фон світу](world-backdrop.md).

Коли нічого не завантажено, сцена темна з сіткою і кольоровими осями (**Сітка** і **Осі** в [Камера й сцена](camera.md)), а панель каже *Nothing loaded - the scene shows a grid and axes. Add a map image or a level mesh to give the heat context.*

Рівень спільний для всіх трьох вкладок: траса, завантажена на вкладці Аналіз заїздів, - це той самий рівень, що показує теплова карта.

## Поставте рівень за своїми даними {#put-a-level-behind-your-data}

1. Спочатку завантажте дані ([Завантаження даних](getting-data-in.md)), щоб рівень підігнався під них.
2. Відкрийте **Тло / рівень** на бічній панелі.
3. Натисніть **Зображення карти…** для картинки або **3D-модель…** для 3D-рівня і виберіть файл. Для запису з реального світу використовуйте **Реальний світ як тло** або **Театр воєнних дій**.
4. Дочекайтеся завершення рядка прогресу. Велику модель спершу спрощують (див. **Ціль спрощення** нижче).
5. Натисніть **F** у виді, щоб вписати все в кадр. Користуйтеся **Непрозорість** і **Яскравість**, доки тепло не почне виділятися на тлі рівня.
6. Натисніть **Зберегти в бібліотеку**, якщо будете користуватися рівнем знову ([Бібліотека рівнів](level-library.md)).

## Що рівень робить з теплом {#what-a-level-does-for-the-heat}

- Він **заслоняє**: точки даних за ним тьмяніють відповідно до поверхні, а точки за рельєфом приховані ([Глибина і відсікання](depth-and-culling.md)). Без рівня заслонення немає.
- Його **зрізає** [Зріз](slice.md) і, з *Різати й рівень*, [відсікання за відстанню](depth-and-culling.md#distance-culling) разом із теплом.
- Це єдине, що розмиває [глибина різкості](camera.md#depth-of-field), крім сітки й кубів.
- 3D-рівень **розширює дальню площину камери**, коли він більший за дані: ближня й дальня площини калібруються з набору даних, і експортована карта завширшки кілька кілометрів інакше цілком опинилася б за дальньою площиною, лишивши порожній вид. Дальня площина стає 3 × горизонтальна протяжність рівня, коли це більше, ближня рухається разом із нею (щонайменше дальня / 100,000), щоб зберегти точність глибини, від якої залежить заслонення, а швидкість польоту піднімається щонайменше до протяжність / 12. Її лише розширюють, ніколи не звужують.

## Панель, згори вниз {#the-panel-top-to-bottom}

| Частина | Деталі |
|---|---|
| **Зображення карти…**, **3D-модель…** | Завантажити один; він замінює поточний рівень. |
| **Реальний світ як тло**, **Забути тайли мапи** | Лише для набору даних із географічною прив’язкою: побудувати під ним справжнє місце як рівень або видалити завантажені тайли. [Фон світу](world-backdrop.md) |
| **Ціль спрощення** | Бюджет трикутників для наступного імпорту моделі: *Full - no simplification* (типово), *High - 8M*, *Medium - 3M*, *Low - 800k*, *Silhouette - 100k*. [3D-рівні](model-levels.md#simplification) |
| Прогрес і **Скасувати** | Поки декодується або імпортується. |
| Примітка імпорту | Трикутники до і після, поділ на землю / споруди / воду, використаний рівень деталізації. |
| Назва і розмір | `width×height px · x × z m/px` для зображення, `N triangles (from M)` для моделі. |
| **Непрозорість**, **Яскравість** | Для обох видів. |
| Елементи керування зображенням | **Знебарвити**, **Віддзеркалити північ/південь**, **Розміщення** (два якорі), **Припасувати до меж даних**, **Висота**. [Зображення карт](map-images.md) |
| Елементи керування моделлю | Рельєф землі, вода, трикутники землі, каркас, текстура, захоплений колір, споруди, класифікація частин. [Вигляд рівня](level-appearance.md) |
| **Зберегти в бібліотеку**, **Прибрати** | [Бібліотека рівнів](level-library.md); Прибрати вивантажує рівень. |
| **Бібліотека** | Рівні, збережені в цьому браузері. [Бібліотека рівнів](level-library.md) |
