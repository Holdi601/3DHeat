# Рівні й фонова геометрія

Рівень - це тривимірне місце, де відбувалася гра: мапа, містечко, траса. Поставте його за своїми даними, і ви побачите, *де* тепло. Панель **Тло / рівень** (див. [Словник](glossary.md), щоб дізнатися про «рівень») дає три види контексту:

- **зображення карти**, прив’язане до географії двома якорями - див. [Зображення карти](map-images.md);
- **тривимірний рівень** - `.glb`, `.gltf`, `.obj`, `.stl` або `.ply` - розбитий на землю, споруди та воду й спрощений під час імпорту - див. [Тривимірні рівні](model-levels.md) і [Вигляд рівня](level-appearance.md);
- **світове тло** - для запису, який каже, де на Землі він відбувся (файл Tacview ACMI): справжній рельєф, дороги, воду, аеродроми й будівлі, завантажені з відкритих даних - див. [Світове тло](world-backdrop.md).

Коли нічого не завантажено, сцена темна з сіткою та кольоровими осями (**Сітка** і **Осі** в [Камера і сцена](camera.md)), а панель каже *Нічого не завантажено - сцена показує сітку й осі. Додайте зображення карти або сітку рівня, щоб тепло мало контекст.*

Рівень спільний для всіх трьох вкладок: траса, завантажена на вкладці Аналіз заїздів, - це той самий рівень, який показує теплова карта.

## Поставте рівень за своїми даними {#put-a-level-behind-your-data}

1. Спершу завантажте свої дані ([Завантаження даних](getting-data-in.md)), щоб рівень підігнався під них.
2. Відкрийте **Тло / рівень** на боковій панелі.
3. Натисніть **Зображення карти…** для картинки або **3D-модель…** для тривимірного рівня і виберіть файл. Для запису з реального світу використовуйте натомість **Світове тло** або **Театр**.
4. Дочекайтеся, поки рядок прогресу завершиться. Велику модель спершу спрощують (див. **Ціль спрощення** нижче).
5. Натисніть **F** у виді, щоб охопити все в кадрі. Користуйтеся **Непрозорістю** і **Яскравістю**, доки тепло не виділиться на фоні рівня.
6. Натисніть **Зберегти в бібліотеку**, якщо будете використовувати рівень знову ([Бібліотека рівнів](level-library.md)).

## Що рівень робить для тепла {#what-a-level-does-for-the-heat}

- Він **перекриває**: точки даних за ним затемнюються за кожною поверхнею, а точки за рельєфом ховаються ([Глибина й відсікання](depth-and-culling.md)). Без рівня перекриття немає.
- Його **ріже** [Переріз](slice.md) і, разом із *Різати й рівень*, [відсікання за відстанню](depth-and-culling.md#distance-culling), разом із теплом.
- Це єдине, що розмиває [глибина різкості](camera.md#depth-of-field), крім сітки та коробок.
- Тривимірний рівень **розширює дальню площину камери**, коли він більший за дані: ближня і дальня площини калібруються з набору даних, а експортована мапа завширшки кілька кілометрів інакше лежала б цілком за дальньою площиною і залишила б порожній вигляд. Дальня площина стає 3 × горизонтального розміру рівня, якщо той більший, ближня рухається разом із нею (щонайменше дальня / 100 000), щоб зберегти точність глибини, від якої залежить перекриття, а швидкість польоту піднімається щонайменше до розміру / 12. Її лише розширюють, ніколи не звужують.

## Панель згори донизу {#the-panel-top-to-bottom}

| Частина | Деталі |
|---|---|
| **Зображення карти…**, **3D-модель…** | Завантажити один; він замінює поточний рівень. |
| **Світове тло**, **Забути тайли мапи** | Лише для набору даних із географічною прив’язкою: побудувати під ним справжнє місце як рівень або видалити завантажені тайли. [Світове тло](world-backdrop.md) |
| **Ціль спрощення** | Бюджет трикутників для наступного імпорту моделі: *Повна - без спрощення* (за замовчуванням), *Висока - 8 млн*, *Середня - 3 млн*, *Низька - 800 тис.*, *Силует - 100 тис.* [Тривимірні рівні](model-levels.md#simplification) |
| Прогрес і **Скасувати** | Під час декодування або імпорту. |
| Примітка імпорту | Трикутники до й після, розбиття на землю / споруди / воду, використаний рівень деталізації. |
| Назва й розмір | `ширина×висота px · x × z м/px` для зображення, `N трикутників (з M)` для моделі. |
| **Непрозорість**, **Яскравість** | Для обох видів. |
| Елементи керування зображенням | **Знебарвити**, **Віддзеркалити північ/південь**, **Розміщення** (два якорі), **Припасувати до меж даних**, **Висота**. [Зображення карти](map-images.md) |
| Елементи керування моделлю | Рельєф землі, вода, трикутники землі, каркас, текстура, знятий колір, споруди, класифікація частин. [Вигляд рівня](level-appearance.md) |
| **Зберегти в бібліотеку**, **Прибрати** | [Бібліотека рівнів](level-library.md); Прибрати вивантажує рівень. |
| **Бібліотека** | Рівні, збережені в цьому браузері. [Бібліотека рівнів](level-library.md) |
