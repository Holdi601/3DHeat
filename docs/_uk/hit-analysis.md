# Аналіз влучань

Вкладка **Техніка** показує, куди влучили в один танк, корабель чи солдата і хто саме. Використовуйте її, щоб побачити, з якого боку танка по ньому стріляють, або який ворог завдає найбільше шкоди.

## Спробуйте {#try-it}

1. Завантажте матч, у якому є влучання (див. таблицю нижче, які ігри їх дають).
2. Відкрийте вкладку **Техніка** вгорі.
3. У **Техніка** виберіть юніт, наприклад тип танка. Число в дужках - скільки влучань він отримав.
4. Прочитайте фігуру: кожна позначка - це влучання, поставлене там, де воно потрапило.
5. Відкрийте **Хто влучив**, щоб побачити стрільців, зброю або техніку стрільців, з влучаннями, шкодою, вбивствами й відстанню.

![Вкладка Техніка: демо-танк із мітками влучань і відкритим розділом Хто влучив](../assets/img/en/hit-analysis-tank.webp)

Якщо нічого не завантажено або в даних немає влучань по техніці, вкладка каже, чого бракує і який конвертер використати.

```
        shooter ----> o  hit mark on the figure
        shooter ----> o
  [ tank figure ]
```

Фігура показує влучання там, де дані дають точку або частину тіла. Розбивка (хто влучив, чим, наскільки сильно, з якої відстані) працює для кожного джерела.

## Обмежити областю {#restrict-to-an-area}

Розділ **Область** обмежує аналіз влучаннями, які сталися в місці на мапі.

1. Натисніть **Намалювати прямокутник** або **Намалювати многокутник** і малюйте на тривимірній землі або тактичній мапі.
2. Оберіть **Жертва всередині** (рахувати влучання, якщо влучений юніт був в області) або **Стрілець всередині** (якщо той, хто стріляв).
3. Натисніть **Використати як фільтр**. Чіпи показують «{n} з {total} влучань в області».
4. **Скинути область** прибирає всі області.

Кожна область - це [об’єм](volumes.md), тож ті самі фігури також фільтрують теплову карту й повтор. Область може включати або виключати (область, що виключає, лишає свої влучання поза розглядом, і показує «{n} з {total} влучань поза областю»). Кожна область показується чіпом із кількістю влучань юніта всередині; × на чіпі видаляє її. Кількості, фігура, розбивка й списки фільтрів - усе йде за цим.

Місця влучань: рядок, з якого походить влучання, містить місце однієї зі сторін (жертви для удару або пошкодження, стрільця для пострілу); місце іншої - це власний зразок цього юніта, найближчий за часом (у межах 5 с). Влучання, чиє місце сторони невідоме, пропускається, поки область фільтрує, і панель каже, скільки таких («Пропущено, місце невідоме»).

## Для розробників {#for-developers}

Будь-який конвертер може додавати влучання: рядок жертви (`hit`, `impact`, `hurt`, `wounded`) з `hitBone` (кістка скелета, вибірка Arma, зона влучання Reforger - відображається на голову, груди, живіт, руки й ноги) або `hitLocalX/Y/Z` (метри, x вперед, y вгору, z праворуч), з `other` для стрільця та `damage`.
