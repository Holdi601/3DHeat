# Демо-дані: спробуйте переглядач за п'ять хвилин

![Тепло десяти танкових матчів у демо-долині: що показує крок 4](../assets/img/en/heat-hero.webp)

Власних даних ще немає? Репозиторій створює їх сам. Усе в ньому вигадане: долина, двір і матчі трьох вигаданих стилів гри, де гравців звуть *Blue 1* або *Red 3*. Усі картинки на цьому сайті зроблені з цих даних.

## Створення {#make-it}

```bash
node tools/demo-data.mjs
```

Це записує в `tools/.shots/demo/`:

| Файл | Що це |
|---|---|
| `demo-valley.glb` | долина 12 км із двома пагорбами та селом, як 3D-рівень |
| `demo-yard.glb` | обнесений стінами двір 160 м із будівлями, як 3D-рівень |
| `tanks.parquet` | 10 танкових матчів, 8 проти 8: рух, постріли, влучання з місцем на корпусі, пожежі, знищення, підбиті машини, наведення веж, переможці |
| `tanks/match-NN.parquet` | ті самі матчі, по одному файлу на матч, для [багатьох матчів одразу](many-matches.md) |
| `air.parquet` | повітряний бій 4 проти 4 з ракетами, пастками, знищеннями та промахами |
| `shooter.parquet` | 12 раундів 5 проти 5 пішки: постріли, знищення, закладка, зароблені й витрачені кредити, шоломи та засоби підтримки |
| `mass/` | тека з малими матчами `.3dheat`, для [масового аналізу](mass-analysis.md) |
| набір кіл гонки | два кола однієї машини на вигаданій трасі, для [Аналізу заїздів](race-analysis.md) |

Кожна таблиця називає свої стовпці внизу, тож вона завантажується без жодного зіставлення.

## Спробуйте {#try-it}

1. Запустіть переглядач (`start.bat` у Windows або один раз `npm install`, а потім `npm run dev` на будь-якій системі) і відкрийте `http://127.0.0.1:5273/`.
2. **Тло / рівень → 3D-модель…** і виберіть `demo-valley.glb`.
3. **Джерело → Файли…** і виберіть `tanks.parquet`.
4. Натисніть `F`, щоб вписати дані в кадр. Ви бачите [тепло](heat.md) десяти матчів.
5. Спробуйте панель режимів: **Різниця** (Blue проти Red), **Тепло команд**, **Лінії**.
6. Відкрийте **Висновки** (на бічній панелі **Теплова карта**): він знаходить місця, де стріляли, влучали й знищували набагато частіше, ніж деінде, - навколо двох пагорбів.
7. Відкрийте вкладку **Матч**; у **Матчі в повторі** виберіть *Match 01*; натисніть **Пуск** на часовій шкалі: це [розбір](match-replay.md).

![Розбір Match 01 з танками як фігурами](../assets/img/en/replay-overview.webp)

Для стрільця завантажте `demo-yard.glb` і `shooter.parquet`; для повітряного бою - `air.parquet` (фігури краще видно за **Розмір фігур** 4, це повзунок на панелі **Перегляд команд** на бічній панелі Теплова карта).

## Знімки екрана {#the-screenshots}

Картинки сайту створює з цих даних скрипт, якою б мовою переглядача вони не були:

```bash
node tools/demo-data.mjs
HEAT3D_FIGURE_PACK=none npx vite --port 5321 --strictPort --host 127.0.0.1   # PowerShell: $env:HEAT3D_FIGURE_PACK="none"; npx vite ...
node tools/docs-shots.mjs --lang en
```

Сервер знімків працює без локального пакета фігур, тож показується лише публічний каталог фігур. Картинки потрапляють у `docs/assets/img/<lang>/`. Див. [Супровід документації](maintaining.md).
