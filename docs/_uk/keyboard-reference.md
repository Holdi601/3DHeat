# Довідка з клавіатури й миші

Кожна клавіша й дія миші в одному місці, щоб ви швидко знайшли потрібну. Спершу клацніть на вигляд, щоб він отримав клавіатуру. Клавіші ігноруються, поки в фокусі текстове поле або випадаючий список. Коротка версія також друкується внизу зліва на виді.

Швидкий пошук:

| Я хочу ... | Натисніть |
|---|---|
| летіти | `W A S D`, перетягніть, щоб дивитися |
| побачити все | `F` |
| відтворити або призупинити | `K` |
| відтворити назад | `J` (натисніть ще раз, щоб призупинити), уперед `L` |
| побачити, що означають кольори | `?` або `F1` |
| скасувати на вкладці Тактика | `Ctrl+Z` |

## Камера {#camera}

З [`camera.ts`](https://github.com/Holdi601/3DHeat/blob/main/src/render/camera.ts).

| Введення | Дія |
|---|---|
| `W` / `↑` | Уперед уздовж напряму погляду |
| `S` / `↓` | Назад |
| `A` / `←` | Боком ліворуч |
| `D` / `→` | Боком праворуч |
| `Space` / `E` | Вгору |
| `Q` / лівий `Ctrl` | Вниз |
| `Shift` (будь-який) | Утримуйте: швидкість ×6 |
| лівий `Alt` | Утримуйте: швидкість 15% |
| Перетягування лівою або правою кнопкою на виді | Дивитися (вказівник заблоковано, поки кнопку утримано) |
| Колесо (перспектива) | Швидкість польоту ×1,5 на кожен клік (не більше 4 кліків на одну подію колеса) |
| Колесо (паралельна проєкція) | Масштаб |
| Правий клік | Над виглядом не відкривається контекстне меню |

## Загальні {#global}

З [`App.tsx`](https://github.com/Holdi601/3DHeat/blob/main/src/App.tsx).

| Клавіша | Дія |
|---|---|
| `K` | Відтворити / призупинити [часову шкалу](timeline.md) |
| `F` | Охопити дані в кадрі |
| `C` | Скопіювати позицію камери, рискання й тангаж ([показник камери](camera.md#camera-readout)) |
| `G` | Перейти до введеної точки: відкривається поле під показником камери |
| `Esc` | Закрити картку вибору; потім перестати дивитися на другий юніт; потім перестати стежити за юнітом |
| `T` | Вигляд тактичного показу увімкнено або вимкнено ([Розбір матчу](match-replay.md#display-style)) |
| `?` / `F1` | Режим довідки: що означають кольори ([Налаштування, юніти й клавіші](settings.md#help-mode)) |
| `1` | [Тепло](heat.md) |
| `2` | [Різниця](difference.md) |
| `3` | [Тепло команд](team-heat.md) |
| `4` | [Лінії](line-heat.md) |
| `]` | Межа далекого відсікання назовні ×1,12 (`Shift`: ×1,35) |
| `[` | Межа далекого відсікання всередину ÷1,12 (`Shift`: ÷1,35) |
| `\` | Межу далекого відсікання вимкнено / знову ввімкнено там, де її лишили ([Глибина й відсікання](depth-and-culling.md#keyboard)) |

Режим **Накладання фігур** не має числової клавіші; виберіть його на панелі режимів або відкрийте вкладку Матч. Числові клавіші працюють так само, як панель режимів: клавіша для режиму, який панель показує як недоступний для завантажених даних, нічого не робить.

## Розбір матчу {#match-replay}

У режимі Накладання фігур, який використовує вкладка Матч ([Розбір матчу](match-replay.md)). Вони працюють, коли юніт стежений або ні, крім випадків, зазначених окремо:

| Клавіша | Дія |
|---|---|
| `B` | Додати закладку: момент і камеру |
| `M` | 2D-мапа: кутова, весь вигляд, вимкнено |
| `V` / `Shift+V` | Наступний / попередній вид камери для юніта, за яким стежите |
| `H` | Індикатор на лобовому склі в кабіні та виглядах padlock |
| `Page Down` / `Page Up` | Наступна / попередня подія тих видів, які показує список подій |
| `J` | Відтворити назад; ще раз, щоб призупинити |
| `L` | Відтворити вперед; ще раз, щоб призупинити |
| `.` / `,` | Секунда вперед / назад, на паузі (`Shift`: десять секунд) |
| `Esc` | Спершу перестати дивитися на ціль, потім перестати стежити |
| `Ctrl`+клік або `Alt`+клік на юніті (у виді або в списку юнітів) | Дивитися на нього з юніта, за яким стежите (вид на два юніти); клацніть ще раз, щоб відпустити |
| `Shift`+клік на двох юнітах | Виміряти між ними: пеленг, відстань, різниця висот |

Для `V` потрібен юніт, за яким стежите. Тут `M` - це 2D-мапа, а на вкладці Тактика - «перемістити».

## Стеження за юнітом {#following-a-unit}

Поки камера стежить за юнітом, колесо й клавіші польоту обертають камеру навколо юніта, а не летять вільно ([Камера](camera.md#while-following-a-unit)):

| Введення | Дія |
|---|---|
| Колесо, `W` / `S` | Ближче / далі (вище / нижче у супутниковому вигляді). Не в кабіні та виглядах padlock. |
| `A` / `D`, `Q` / `E` | Орбіта навколо юніта (види Позаду й Орбіта) |
| Перетягування | Дивитися навколо юніта; у кабіні - дивитися всередині |
| `V` / `Shift+V` | Наступний / попередній вид камери |
| `H` | Індикатор на лобовому склі (вид з кабіни та padlock) |
| `Esc` | Перестати дивитися на другий юніт, потім перестати стежити |

## Дошка тактики {#tactics-board}

На вкладці Тактика ([Дошка тактики](tactics-board.md)). `F`, `C`, `G` і `T` працюють, як описано вище; числові клавіші нічого не роблять.

| Клавіша | Дія |
|---|---|
| `Ctrl+Z` | Скасувати |
| `Ctrl+Y` або `Ctrl+Shift+Z` | Повторити |
| `Enter` | Завершити стрілку, що малюється (те саме робить подвійний клік або правий клік) |
| `Esc` | Скасувати перетягування; інакше прибрати стрілку або переміщення, що триває; інакше зняти вибір |
| `Delete` або `Backspace` | Видалити вибране |
| `W` / `E` / `R` | Гізмо переміщення / обертання / масштабу для вибраного (схема клавіш **W / E / R**) |
| `G` / `R` / `S` | Гізмо переміщення / обертання / масштабу для вибраного (схема клавіш **G / R / S**) |
| `R` | Коли нічого не вибрано: повернути наступну фігуру для розміщення на 15°. `Shift+R` повертає її назад. |
| `M` | Коли фігуру вибрано: перемістити її на наступний клік |
| `K` | Відтворити або призупинити план |
| Shift+клік | Додати до вибору або прибрати з вибору |
| Shift+перетягування | Намалювати рамку навколо того, що вибрати |
| `Ctrl` під час перетягування маркера | Прилипання до сітки або до кроку кута |

Клавіші гізмо працюють, лише коли щось вибрано; коли нічого не вибрано, `W A S D` летять камерою, як звичайно.

## Вибір клацанням {#click-to-pick}

Коли ввімкнено **Клацання показує, що там**, а лінійку вимкнено ([Вибір клацанням](camera.md#click-to-pick)):

| Введення | Дія |
|---|---|
| Лівий клік (без перетягування більш ніж на 4 px) | Показати точку даних, а якщо її немає - місце на рівні під вказівником |

## Вимірювання {#measure}

Коли **Лінійка активна** ([Вимірювання](measure.md)):

| Введення | Дія |
|---|---|
| Лівий клік (без перетягування більш ніж на 4 px) | Поставити точку |
| Правий клік | Прибрати останню точку |

## Інше {#elsewhere}

| Де | Введення | Дія |
|---|---|---|
| Ручка будь-якого повзунка (маркер поруч із числом) | Перетягування вгору / вниз | Змінює значення плавно, тим швидше, чим далі тягнете; утримуйте `Shift` для точного керування. Відпустіть, щоб зупинити. |
| Показник швидкості над виглядом | Перетягування вгору / вниз | Змінює швидкість польоту так само. |
| Поля положення | `Enter` | Застосувати введене положення або орієнтацію. |
| Редактор кривої | Подвійний клік / Alt-клік / правий клік | Додати точку / прибрати точку ([Форма спрайта](sprite-shape.md#the-curve-editor)). |

## Вкладка Аналіз заїздів {#race-analysis-tab}

На вкладці Аналіз заїздів `K` відтворює й призупиняє повтор заїзду, `Home` перемотує його на початок, а числові клавіші нічого не роблять. Див. [Аналіз заїздів](race-analysis.md).

## Клавіші, які переглядач залишає за браузером {#keys-the-viewer-keeps-from-the-browser}

Деякі скорочення браузера закрили б сторінку або перезавантажили її й втратили завантажений сеанс; переглядач залишає їх собі. Список створюється з коду: [Клавіші браузера](ref-browser-keys.md).
