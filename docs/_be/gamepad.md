# Геймпад і HOTAS

Камерай можна кіраваць кантролерам у стылі Xbox замест клавіятуры. Выкарыстоўвайце яго, калі хочаце адкінуцца і агледзець вялікую сцэну. Яго ўвод **дадаецца** да клавіятурнага, таму можна карыстацца абодвума адначасова.

## Падключыце кантролер {#connect-a-controller}

1. Падключыце кантролер (або спарце яго).
2. Націсніце на выгляд і націсніце любую кнопку на кантролеры. Браўзеры паказваюць кантролер толькі пасля яго першага ўводу.
3. Адкрыйце **Камера і сцэна → Геймпад**. У спісе прылад ён паказваецца з `●`.
4. Націскайце левы стык, каб ляцець, і правы, каб глядзець. Калі камера дрэйфуе пры стыках у цэнтры, падніміце **Мёртвая зона**.

Працуе любая прылада, якую браўзер адлюстроўвае ў стандартную раскладку геймпада. Джойсцік палёту або дросель (HOTAS) па змаўчанні ігнаруюцца; гл. ніжэй.

## Прывязка {#mapping}

| Кіраванне | Эфект |
|---|---|
| Левы стык | Рух: наперад і назад, і ўбок |
| Правы стык | Погляд: паварот і нахіл, з хуткасцю *Хуткасць погляду* градусаў у секунду пры поўным адхіленні |
| `RT` / `LT` (аналагавыя) | Уверх і ўніз; у паралельнай праекцыі — прыблізіць і аддаліць |
| `RB` (утрымліваць) | У 6 разоў хутчэй |
| `LB` (утрымліваць) | 15% хуткасці |
| `A` (утрымліваць) | Спрынт у 3 разы (спалучаецца з RB/LB) |
| `Y` (націснуць) | Кадраваць даныя |

Нумары кнопак адпавядаюць стандартнай раскладцы: A 0, Y 3, LB 4, RB 5, LT 6, RT 7; стыкі на восях 0–1 (левы) і 2–3 (правы).

## Налады геймпада {#the-gamepad-settings}

У **Камера і сцэна → Геймпад**. **Налады** / **Схаваць** адкрывае або хавае элементы налады.

| Кіраванне | Па змаўчанні | Дыяпазон (кручэнне) | Значэнне |
|---|---|---|---|
| **Уключаны** | уключана | | |
| Стан прылад | | | Кожная падлучаная прылада: `●`, калі яна адсочваецца, `○`, калі не. Для нестандартных прылад: *— не геймпад XInput, ігнаруецца* або *— не геймпад XInput, усё роўна выкарыстоўваецца*. Калі прылад няма: *Геймпад не знойдзены. Браўзеры паказваюць кантролер толькі пасля яго першага ўводу — націсніце на ім кнопку.* |
| **Прылада** | *Толькі геймпады XInput (рэкамендуецца)* | | Паказваецца, калі падлучана нестандартная прылада. Выберыце прыладу па назве, каб адсочваць яе замест гэтага. |
| **Хуткасць погляду** | 150°/s | 20–540 (5000) | Хуткасць павароту пры поўным адхіленні правага стыка. |
| **Мёртвая зона** | 12% | 0–50% (95%) | Радыяльная: дыяганальны нахіл ніколі не перацякае толькі ў адну вось. Падніміце, калі камера дрэйфуе пры стыках у цэнтры. |
| **Крывая стыка** | x² | лінейная (1) да x⁴ (16) | Паказальнік адказу пасля мёртвай зоны: дакладней ля цэнтра, але на поўнай хуткасці на краі. |
| **Інвертаваць Y стыка** | выключана | | |
| **Памяняць стыкі** | выключана | | Рух на правым стыку, погляд на левым. |

Фармаванне стыка: пры адхіленні *m* (даўжыня вектара стыка) і мёртвай зоне *d* выхад = ((m − d) / (1 − d)) ^ крывая ўздоўж напрамку стыка, і 0 унутры мёртвай зоны.

## Чаму па змаўчанні толькі стандартныя пульты {#why-only-standard-pads-by-default}

API геймпада паведамляе **кожную** HID-прыладу з восямі: джойсцікі палёту, дросялі, педалі, рулі. Яны не стаяць у цэнтры: вось павароту або рычаг дросяля стаіць на поўным адхіленні, калі яго ніхто не чапае. Калі счытаць гэта як стык, атрымліваецца пастаянны поўнаскорасны ўвод, які не можа заглушыць ніводная мёртвая зона, і камера круціцца сама з таго моманту, як старонка загружана (і ўсе рэжымы цеплыні таксама выглядаюць зламанымі, бо рухомая камера перазапускае накапленне кожны кадр).

Таму прылада адсочваецца, толькі калі браўзер паведамляе `mapping: "standard"`. Гэта яго спосаб сказаць: «пульт у стылі XInput з восямі там, дзе вы іх чакаеце». Іншыя прылады пералічаны і пазначаны як ігнараваныя, а **Прылада** дазваляе выбраць адну відавочна — напрыклад, каб кіраваць камерай з HOTAS. Калі пульт адсочваецца, камера застаецца з ім, таму два кантролеры не змагаюцца за камеру ў залежнасці ад парадку пералічэння.

**HOTAS:** чытаюцца толькі восі 0–3 (два стыкі) і стандартныя кнопкі. Дросель або педалі на іншых восях нічога не робяць, а стык або дросель, чые восі не стаяць у цэнтры, можа патрабаваць большай **Мёртвай зоны**.

Браўзеры хаваюць кантролер, пакуль ён не паслаў першы ўвод, таму падлучаны, але не закрануты пульт для старонкі пакуль не існуе.
