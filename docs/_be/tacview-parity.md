# Паралельнасць з Tacview

Tacview — вядомая праграма для прагляду запісаў палётаў. Калі вы яе ведаеце, гэтая старонка паказвае, дзе кожная яе функцыя знаходзіцца ў 3DHeat.

Тут пералічаны ўсе магчымасці Tacview 1.9 (яго кіраўніцтва, табліца тэкстаў інтэрфейсу і фармат файлаў ACMI 2.2) і тое, дзе ў гэтым пытанні стаіць [паўтор матчу](match-replay.md) у 3DHeat. Мэта: тое, што Tacview умее рабіць з паўторам і яго данымі, 3DHeat таксама мае ўмець.

**Статус:**
- **done**: ужо ёсць у 3DHeat.
- **new**: зроблена, каб адпавядаць функцыі Tacview.
- **not yet**: дачынна, але не зроблена.
- **n/a**: тут не дачынна, з прычынай.

Дзе шукаць гэтыя функцыі: укладка **Матч**, **Паўтор фігурамі** (або **Накладанне фігур** на ўкладцы «Цеплавая карта»), у бакавых раздзелах **Паўтор**, **Адзінкі**, **Падзеі**, **Закладкі**, **Тактычны дысплей**, **Статыстыка**, **Зрух у часе і абразанне**, **Карта і каардынаты**, **Аўдыя і відэа** і **Подпісы**. Гл. [Паўтор матчу](match-replay.md).

## Для распрацоўшчыкаў: уласцівасці ACMI 2.2 {#for-developers-acmi-22-properties}

Чытаюцца `data/acmi.ts`; лікавыя ўласцівасці становяцца лікавымі слупкамі, тэкставыя — слупкамі катэгорый. Усе яны паказваюцца ў **Зыходных** у картцы адзінкі. Яны чытаюцца з пэўнай мэтай:

| Уласцівасці | Выкарыстанне |
|---|---|
| T (усе чатыры формы), Name, Type, Pilot, Group, Country, Coalition, Color, CallSign | Пазіцыя, паставa, фігура, назва адзінкі, каманда |
| IAS, CAS, TAS, Mach, AOA, AOS, AGL, HDG, HDM, OnGround | Палі, дыяграмы, HUD, вызначэнне ўзлёту і пасадкі |
| VerticalGForce, LongitudinalGForce, LateralGForce | Палі G |
| Throttle(2), Afterburner, EngineRPM(2), NR, AirBrakes, Flaps, LandingGear, Tailhook | Палі |
| FuelWeight..9, FuelVolume..9, FuelFlowWeight..8 | Палі паліва, сумуюцца па бакавых баках |
| RadarMode, RadarAzimuth, RadarElevation, RadarRoll, RadarRange, RadarHorizontalBeamwidth, RadarVerticalBeamwidth, RadarRangeGateAzimuth/Elevation/Min/Max/HorizontalBeamwidth/VerticalBeamwidth | Радарныя конусы і фільтр дальнасці |
| LockedTarget..9, LockedTargetMode, LockedTargetAzimuth/Elevation/Range, FocusedTarget | Лініі захопу |
| EngagementMode(2), EngagementRange(2), VerticalEngagementRange(2) | Купалы паражэння |
| QNH, AltimeterSetting, WindSpeed, WindDirection, HeartRate | Палі |
| Health | Поле |
| Падзеі: Destroyed, TakenOff, Landed, Bookmark, Message, Comment, LeftArea, Timeout | Спіс падзей, статыстыка (смерці, узлёты, пасадкі), закладкі; Message і Comment як субцітры |
| PilotHeadYaw, PilotHeadPitch | Лінія позірку пілота |
| Тэгавы тып Bullseye (Navaid+Static+Bullseye) | Поле bullseye і кольцы на карце |
| Усё астатняе (PilotHeadRoll, упраўленне, паверхні, адхіленні ILS, SpO2, ENL, Label, Debug, Importance, Slot, Visible, Disabled, Radius, памеры...) | Паказваецца як напісана ў **Зыходных** |

Вуглы радара і захопу вымяраюцца адносна ўласных восяў адзінкі: азімут — направа, узнасць — уверх, крэн — правае крыло ўніз. Спецыфікацыя ACMI кажа, што вуглы адносныя да лятальнага апарата, але не кажа, у які бок станоўчы; гэта прачытанне ідзе за яе пераўтварэннем (рысканне па гадзінніку, тангаж уверх, крэн направа).
