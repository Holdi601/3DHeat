# Даведнік

Спісы дакладных назваў, налад і інструментаў, каб шукаць у іх. Каб карыстацца глядзельнікам, іх чытаць не трэба.

Гэтыя спісы створаны з кода глядзельніка праз `node tools/docs-refs.mjs` (запускаць яго не трэба), таму яны заўсёды супадаюць з версіяй, для якой былі зроблены:

- [Тыпы падзей і класы](ref-event-types.md) - выгляды падзей і класы тэхнікі, па якіх сартуецца кожны набор даных, і якія словы ў даных да іх адносяцца
- [Назвы слупкоў](ref-columns.md) - назвы слупкоў, якія загрузчык распазнае для пазіцыі, часу, асобы, каманды, сесіі і кірунку погляду
- [Спіс моў](ref-languages.md) - мовы глядзельніка
- [Клавішы браўзера](ref-browser-keys.md) - сачэтанні браўзера, якія глядзельнік трымае для сябе
- [Захаваныя налады](ref-settings-storage.md) - тое, што браўзер памятае паміж візітамі
- [Табліцы значэнняў](ref-value-tables.md) - табліцы коштаў для ўзважвання значэнняў
- [Інструменты каманднага радка](ref-tools.md) - інструменты ў `tools/`: для вашых даных, для распрацоўшчыкаў і дакументацыі

Таксама даведнік і [Слоўнік](glossary.md) для словаў, якія выкарыстоўваюцца на гэтым сайце. Пішуцца ўручную: [Фарматы даных](data-formats.md), [Даведнік клавіятуры і мышы](keyboard-reference.md), [Адзін файл на матч (.3dheat)](container.md).
