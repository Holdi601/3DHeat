# Аб'екты

**Аб'екты** дазваляе выбраць аднаго гульца (або некалькіх), каб бачыць толькі, куды ён хадзіў. Выкарыстоўвайце, каб сачыць за ўласным рухам або за адным супернікам.

Панэль паказваецца, калі ў наборы даных ёсць слупок асоб. Яе загаловак паказвае колькасць асоб або `selected of total`, калі выбар актыўны (*асоба* — гэта адзін гулец або ШІ, гл. [слоўнік](glossary.md)).

## Выберыце гульца {#pick-a-player}

1. Адкрыйце **Аб'екты** на бакавой панэлі.
2. Упішыце частку імя ў полі пошуку.
3. Адзначце гульца. Загаловак чытаецца, напрыклад, `2 of 10`, і ўсё астатняе знікае.
4. **Ачысціць** паказвае ўсіх зноў.

![Аб'екты з двума выбранымі з дзесяці гульцоў](../assets/img/en/entities-selected.webp)

Выбар паказвае толькі выбраных асоб у рэжымах цеплыні (кропкі, лініі, розніца, Каманды), а таксама ў трэках, фігурах і слядах [накладання фігур](box-replay.md). Пакіньце пустым, каб паказваць усіх; выбраць усіх — тое самае, што не выбраць нікога.

## Панэль {#the-panel}

| Частка | Значэнне |
|---|---|
| Поле пошуку | *Пошук N аб'ектаў...* — фільтруе спіс па падрадку імя без уліку рэгістра. Паказвае `N matches` або `N matches, showing the first 200`; *Нічога не адпавядае «...»*, калі пошук нічога не знаходзіць. |
| Спіс | Да 200 асоб (першыя 200 супадаючых), кожная з галачкай, квадрацікам колеру асобы і імем (*(без імя)* для пустога імя). |
| Падказка пра ўдзел у гульні | Калі час ідзе, у спісе ёсць тыя, *якія ўдзельнічаюць на галоўцы прайгравання*; пошук знаходзіць усіх. |
| **AI (n)** | Згорнутая група з кіраванымі ШІ адзінкамі, акрамя гульцоў. |
| **Дадаць паказаныя** | Дадае ўсіх, хто цяпер у спісе, да выбару. |
| **Толькі паказаныя** | Робіць выбар роўна тымі, хто ў спісе. |
| **Ачысціць** | Ачышчае выбар. |

## Абмежаванні {#limits}

У цеплыні выбар — гэта фільтр, і ён займае адзін з чатырох [месцаў для фільтраў](filters.md#rules). Калі іншыя фільтры ўжо займаюць усе чатыры, панэль кажа *Не прымяняецца да цеплыні: усе месцы для фільтраў заняты. Накладанне фігур усё роўна паказвае толькі гэтыя аб'екты. Ачысціце фільтр у Фільтры, каб вызваліць месца.* Ачысціце фільтр, каб вызваліць месца.

Выбар ачышчаецца пры кожным новым наборы даных. Укладка **Match** ставіць той жа выбар, калі фокусуецца на адным гульцы.

## Для распрацоўшчыкаў {#for-developers}

Выбар захоўваецца як фільтр *persons* ([Фільтры](filters.md#for-developers)). Маска шэйдара ўтрымлівае 65 536 id асоб; асоба за гэтым лімітам не малюецца ў цеплыні, пакуль выбар актыўны.
