# Дэма-даныя: паспрабуйце праглядальнік за пяць хвілін

![Цяпло дзесяці матчаў танкаў у дэма-далінай: што паказвае крок 4](../assets/img/en/heat-hero.webp)

Сваіх даных пакуль няма? Рэпазіторый зробіць іх. Усё ў ім выдумана: даліна, двор і матчы трох выдуманых стыляў гульні з гульцамі па імі *Blue 1* або *Red 3*. Усе карцінкі на гэтым сайце зроблены з імі.

## Стварыце іх {#make-it}

```bash
node tools/demo-data.mjs
```

Гэта запісвае ў `tools/.shots/demo/`:

| Файл | Што гэта |
|---|---|
| `demo-valley.glb` | даліна 12 км з двума пагоркамі і вёскай, як 3D-узровень |
| `demo-yard.glb` | двор 160 м з сцяной і будынкамі, як 3D-узровень |
| `tanks.parquet` | 10 матчаў танкаў, 8 на 8: рух, стрэлы, пападанні з месцам на корпусе, пажары, забойствы, падбітая тэхніка, навядзенне вежы, пераможцы |
| `tanks/match-NN.parquet` | тыя ж матчы, па адным файле на матч, для [многа матчаў адначасова](many-matches.md) |
| `air.parquet` | паветраны бой 4 на 4 з ракетамі, flare, забойствамі і промахамі |
| `shooter.parquet` | 12 раўндаў 5 на 5 пешшу: стрэлы, забойствы, закладка, зароблены і выдаткаваныя крэдыты, шлемы і сродкі падтрымкі |
| `mass/` | папка невялікіх матчаў `.3dheat`, для [масавага аналізу](mass-analysis.md) |
| набор кругоў гонкі | два кругі аднаго аўто на выдуманым маршруце, для [Аналізу заездаў](race-analysis.md) |

Кожная табліца называе свае слупкі ў сваім падвале, таму загружаецца без якога-небудзь супастаўлення.

## Паспрабуйце {#try-it}

1. Запусціце праглядальнік (`start.bat` у Windows або `npm install` адзін раз, а потым `npm run dev` у любой сістэме) і адкрыйце `http://127.0.0.1:5273/`.
2. **Background / level → 3D model…** і выберыце `demo-valley.glb`.
3. **Source → Files…** і выберыце `tanks.parquet`.
4. Націсніце `F`, каб вызначыць даныя ў кадры. Вы бачыце [цяпло](heat.md) дзесяці матчаў.
5. Паспрабуйце панэль рэжымаў: **Розніца** (Blue супраць Red), **Каманды**, **Лініі**.
