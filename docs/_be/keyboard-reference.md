# Даведнік па клавіятуры і мышы

Кожнае дзеянне клавіятуры і мышы ў адным месцы, каб вы маглі знайсці патрэбнае. Спачатку пстрыкніце па выгляду, каб ён атрымаў клавіятуру. Клавішы ігнаруюцца, пакуль фокус у тэкставым полі або ў выпадальным спісе. Кароткая версія таксама надрукавана ўнізе выгляду злева.

Хуткі пошук:

| Я хачу ... | Націсніце |
|---|---|
| лятаць | `W A S D`, перацягнуць для агляду |
| убачыць усё | `F` |
| прайграць або паставіць на паўзу | `K` |
| прайграць назад | `J` (націсніце яшчэ раз для паўзы), наперад `L` |
| убачыць, што азначаюць колеры | `?` або `F1` |
| адрабіць у укладцы Tactics | `Ctrl+Z` |

## Камера {#camera}

З [`camera.ts`](https://github.com/Holdi601/3DHeat/blob/main/src/render/camera.ts).

| Увод | Дзеянне |
|---|---|
| `W` / `↑` | Наперад уздоўж напрамку погляду |
| `S` / `↓` | Назад |
| `A` / `←` | Бакавы рух улева |
| `D` / `→` | Бакавы рух управа |
| `Space` / `E` | Уверх |
| `Q` / левы `Ctrl` | Уніз |
| `Shift` (любы) | Утрымліваць: у 6 разоў хутчэй |
| левы `Alt` | Утрымліваць: 15% хуткасці |
| Левы або правы перацяг па выгляду | Агляд (указальнік заблакаваны, пакуль трымаецца кнопка) |
| Кола мышы (перспектыва) | Хуткасць палёту ×1,5 за адзін пстрычок (не больш за 4 пстрычкі на адну падзею кола) |
| Кола мышы (паралельная праекцыя) | Маштаб |
| Правы клік | Над выглядам кантэкстнае меню не адкрываецца |

## Агульнае {#global}

З [`App.tsx`](https://github.com/Holdi601/3DHeat/blob/main/src/App.tsx).

| Клавіша | Дзеянне |
|---|---|
| `K` | Прайграць / паставіць на паўзу [стужку часу](timeline.md) |
| `F` | Вырраўняць кадр па даных |
| `C` | Скапіяваць становішча камеры, паварот і нахіл ([паказанне камеры](camera.md#camera-readout)) |
| `G` | Перайсці да ўведзенай кропкі: адкрываецца поле пад паказаннем камеры |
| `Esc` | Закрыць картку выбару; потым перастаць глядзець на другую адзінку; потым перастаць сачыць за адзінкай |
| `T` | Уключыць або выключыць тактычны выгляд дысплея ([Прайграванне матчу](match-replay.md#display-style)) |
| `?` / `F1` | Рэжым даведкі: што азначаюць колеры ([Налады, адзінкі і клавішы](settings.md#help-mode)) |
| `1` | [Цеплыня](heat.md) |
| `2` | [Розніца](difference.md) |
| `3` | [Каманды](team-heat.md) |
| `4` | [Лініі](line-heat.md) |
| `]` | Далёкая мяжа адсячэння ў бок выхаду ×1,12 (`Shift`: ×1,35) |
| `[` | Далёкая мяжа адсячэння ў бок уваходу ÷1,12 (`Shift`: ÷1,35) |
| `\` | Далёкая мяжа адсячэння выключана / вернута туды, дзе была ([Глыбіня і адсячэнне](depth-and-culling.md#keyboard)) |

У рэжыму **Накладанне фігур** няма лічбавай клавішы; абярыце яго на панэлі рэжымаў або адкрыйце ўкладку Match. Лічбавыя клавішы праходзяць тую ж праверку, што і панэль рэжымаў: клавіша для рэжыму, які панэль паказвае як недаступны для загружаных даных, нічога не робіць.

## Прайграванне матчу {#match-replay}

У рэжыме Накладанне фігур, які выкарыстоўвае ўкладка Match ([Прайграванне матчу](match-replay.md)). Яны працуюць, калі адзінка выбрана або не выбрана, за выключэннем адзначаных:

| Клавіша | Дзеянне |
|---|---|
| `B` | Дадаць закладку: момант і камеру |
| `M` | 2D-карта: у куце, на ўвесь выгляд, выключана |
| `V` / `Shift+V` | Наступны / папярэдні выгляд камеры для адзінкі, за якой сочыце |
| `H` | Цэласны дысплей у выглядах кабіны і захопу |
| `Page Down` / `Page Up` | Наступная / папярэдняя падзея відаў, якія паказвае спіс падзей |
| `J` | Прайграць назад; яшчэ раз - для паўзы |
| `L` | Прайграць наперад; яшчэ раз - для паўзы |
| `.` / `,` | Секунда наперад / назад, на паўзе (`Shift`: дзесяць секунд) |
| `Esc` | Спачатку перастаць глядзець на мэту, потым перастаць сачыць |
| `Ctrl`+пстрычка або `Alt`+пстрычка па адзінцы (у выглядзе або ў спісе адзінак) | Глядзець на яе з адзінкі, за якой сочыце (выгляд з дзвюх адзінак); націсніце яшчэ раз, каб скінуць |
| `Shift`+пстрычка па дзвюх адзінках | Вымераць паміж імі: пеленг, дальнасць, розніца вышыні |

Для `V` патрэбна адзінка, за якой сочыце. `M` тут - гэта 2D-карта, а ў укладцы Tactics - "перамясціць".

## Сачэнне за адзінкай {#following-a-unit}

Пакуль камера сочыць за адзінкай, кола і клавішы палёту кіруюць вакол адзінкі, а не лятаюць свабодна ([Камера](camera.md#while-following-a-unit)):

| Увод | Дзеянне |
|---|---|
| Кола, `W` / `S` | Бліжэй / далей (вышэй / ніжэй у выглядзе спадарожніка). Не ў выглядах кабіны і захопу. |
| `A` / `D`, `Q` / `E` | Арбіта вакол адзінкі (выгляды пагоні і арбіты) |
| Перацяг | Аглядаць вакол адзінкі; у кабіне - аглядаць унутры |
| `V` / `Shift+V` | Наступны / папярэдні выгляд камеры |
| `H` | Цэласны дысплей (выгляды кабіны і захопу) |
| `Esc` | Перастаць глядзець на другую адзінку, потым перастаць сачыць |

## Дошка тактык {#tactics-board}

У укладцы Tactics ([Дошка тактык](tactics-board.md)). `F`, `C`, `G` і `T` працуюць, як вышэй; лічбавыя клавішы нічога не робяць.

| Клавіша | Дзеянне |
|---|---|
| `Ctrl+Z` | Адрабіць |
| `Ctrl+Y` або `Ctrl+Shift+Z` | Паўтарыць |
| `Enter` | Скончыць стрэлку, якая малюецца (падвойны клік або правы клік робяць тое ж) |
| `Esc` | Скасаваць перацягванне; інакш - адпусціць стрэлку або перамяшчэнне, якое ідзе; інакш - зняць выбар |
| `Delete` або `Backspace` | Выдаліць выбранае |
| `W` / `E` / `R` | Гізма перамяшчэння / кручэння / масштабу для выбранага (схема клавіш **W / E / R**) |
| `G` / `R` / `S` | Гізма перамяшчэння / кручэння / масштабу для выбранага (схема клавіш **G / R / S**) |
| `R` | Калі нічога не выбрана: павярнуць наступную фігуру для размяшчэння на 15°. `Shift+R` вяртае назад. |
| `M` | Калі выбрана фігура: перамясціць яе да наступнай пстрычкі |
| `K` | Прайграць або паставіць план на паўзу |
| Shift+пстрычка | Дадаць або выдаліць з выбару |
| Shift+перацяг | Намаляваць рамку вакол таго, што выбіраць |
| `Ctrl` пры перацягванні маркера | Прыцягнуць да сеткі або да крока кута |

Клавішы гізма працуюць, толькі калі нешта выбрана; калі нічога не выбрана, `W A S D` лятаюць камерай, як звычайна.

## Выбар пстрычкай {#click-to-pick}

Калі **Click shows what is there** уключана, а лінейка выключана ([Выбар пстрычкай](camera.md#click-to-pick)):

| Увод | Дзеянне |
|---|---|
| Левы клік (без перацягвання больш за 4 px) | Паказаць кропку даных або, калі яе няма, месца на ўзроўні пад указальнікам |

## Вымярэнне {#measure}

Калі **Ruler active** уключана ([Вымярэнне](measure.md)):

| Увод | Дзеянне |
|---|---|
| Левы клік (без перацягвання больш за 4 px) | Паставіць кропку |
| Правы клік | Выдаліць апошнюю кропку |

## Іншыя месцы {#elsewhere}

| Дзе | Увод | Дзеянне |
|---|---|---|
| Ручка любога паўзунка (маркер побач з лікам) | Перацягнуць уверх / уніз | Мяняць значэнне плаўна, тым хутчэй, чым далей цягнеце; трымайце `Shift` для тонкай налады. Адпусціце, каб спыніць. |
| Паказанне хуткасці над выглядам | Перацягнуць уверх / уніз | Мяняць хуткасць палёту так жа. |
| Блокі становішчаў | `Enter` | Ужыць уведзенае становішча або арыентацыю. |
| Рэдактар крывой | Двайны клік / Alt-пстрычка / правы клік | Дадаць кропку / выдаліць кропку ([Форма спрайта](sprite-shape.md#the-curve-editor)). |

## Укладка Аналіз заездаў {#race-analysis-tab}

У укладцы Аналіз заездаў `K` прайгрывае і ставіць на паўзу паўтор заезду, `Home` перамотвае яго на пачатак, а лічбавыя клавішы нічога не робяць. Гл. [Аналіз заездаў](race-analysis.md).

## Клавішы, якія праглядальнік пакідае за сабой {#keys-the-viewer-keeps-from-the-browser}

Некаторыя спалучэнні браўзера закрылі б або перазагрузілі старонку і страцілі б загружаны сеанс; праглядальнік пакідае іх за сабой. Спіс згенераваны з кода: [Клавішы браўзера](ref-browser-keys.md).
