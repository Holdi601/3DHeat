# Запісы Tacview (ACMI)

Tacview — гэта праграма, якая запісвае палёты ў авіясімулятарах; яе файлы маюць суфікс `.acmi`. 3DHeat адкрывае іх, каб вы маглі бачыць, дзе лётаў кожны самалёт.

Запісы палётаў Tacview загружаюцца, як любая табліца: выберыце або перацягніце `.acmi` (тэкставы, `.txt.acmi`, або спакаваны, `.zip.acmi`) і націсніце **Загрузіць**. Пасля гэтага вы атрымліваеце цеплыню ўсіх палётаў, а на ўкладцы **Match** — прайграванне з фігурамі, трэкамі і спісам падзей ([Прайграванне матчу](match-replay.md)). ACMI — публічны фармат файлаў Tacview ([дакументацыя](https://www.tacview.net/documentation/acmi/)); DCS (праз экспарцёр Tacview), IL-2 Great Battles, Falcon BMS, X-Plane, MSFS і іншыя пішуць яго, таму гэта чытае любы з іх.

## Што становіцца з запісу {#what-a-recording-becomes}

Адзін радок кожны раз, калі запісваецца пазіцыя аб'екта, адзін радок на кожную падзею ў месцы аб'екта і адзін радок, калі аб'ект знікае (`Removed`, там, дзе ён быў апошні раз). Падзея пра аб'ект, які яшчэ не бачылі, — закладка, паведамленне для ўсіх — становіцца радком аб'екта `(recording)` у апорнай кропцы. Запіс мае ўласныя інструкцыі чытання, таму крок супастаўлення запаўняецца сам. Чытач піша такія слупкі: `Time`, `X`, `Y`, `Altitude`, `Object`, `Coalition`, `Heading`, `Pitch`, `Roll`, `Type`, `Name`, `Pilot`, `Group`, `Country`, `Color`, `Event`, `Latitude`, `Longitude`, `Recording`, `EventObjects`, `RecordingInfo`, а потым любыя іншыя ўласцівасці, якія ёсць у запісе. Іх ролі:

| Слупок | Роля | Значэнне |
|---|---|---|
| Time | час | Секунды пасля ReferenceTime запісу; Unix-секунды, калі ён ёсць, таму гадзіннік паказвае сапраўдны час. |
| X, Y | пазіцыя | Усход і поўнач, метры, на плоскасці, што дакранаецца зямлі ў апорнай кропцы запісу: адлегласці і азімуты дакладныя побач з ёй, а на 100 км дрэйфуюць менш чым на адну тысячную. Поўнач становіцца -Z свету. |
| Altitude | пазіцыя (уверх) | Метры. |
| Object | асоба | Пілот і назва аб'екта з id, напрыклад, `Viper 1 (F-16C_50) #a01`; аб'ект без пілота `(T-90A) #401`. |
| Coalition | каманда | Бок (або колер, калі кааліцыі няма). |
| Heading, Pitch | погляд | Градусы; курс 0 — поўнач. |
| Recording | сесія | Title запісу або назва файла: некалькі запісаў загружаюцца побач, не злучаючы свае трэкі. |
| Type, Name, Pilot, Group, Country, Color, Event, Roll, Latitude, Longitude | фільтры | Захоўваюцца для фільтравання; Type і Name выбіраюць [фігуру](figures.md) кожнага аб'екта, Event падае спіс падзей разбору, Roll нахіляе самалёт. |
| U, V | | Уласныя плоскія метры свету гульні, калі ў кожнага ўзору яны ёсць (DCS іх піша). |
| EventObjects | фільтры | Кожны аб'ект, які называе падзея (`Message|a01|b02|...`), па id. |
| RecordingInfo | | Уласныя ўласцівасці запісу такімі, якімі яны былі ў той момант — DataSource, DataRecorder, Author, Category, Briefing, Comments, ... — як JSON. |
| IAS, Mach, AOA, FuelWeight, ... | фільтры | Любая іншая лікавая ўласцівасць, якую нясе запіс. |
| Parent, CallSign, LockedTarget, Label, Shape, ... | фільтры | Любая іншая тэкставая ўласцівасць запісу; уласцівасць з любым значэннем, якое не лік, з'яўляецца тэкстам. |

Усе чатыры формы пазіцыі Tacview (`lon|lat|alt`, з `u|v`, з `roll|pitch|yaw` і з усімі імі і курсам) чытаюцца; пустыя палі захоўваюць апошняе значэнне; `-id` выдаляе аб'ект, а id, які выкарыстоўваецца зноў пасля гэтага, — гэта новы аб'ект. Экранаваныя коскі і працягнутыя радкі апрацоўваюцца.

Пазіцыі заўсёды праецыруюцца з шыраты і даўгаты, ніколі не браюцца з U/V, таму запісы з усіх гульняў дзеляць адну праекцыю з фонам сапраўднага свету.
