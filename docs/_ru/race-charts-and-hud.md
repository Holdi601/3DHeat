# Графики и HUD

Графики выстраивают ваши круги метр за метром, чтобы было видно, где один гонщик позже затормозил или раньше снял газ. Карточки в левом верхнем углу вида показывают, что сейчас делает каждая машина и каждый гонщик.

![Графики под видом: строки отставания, скорости, газа, тормоза и руля для двух кругов, полосы времени и причин сверху, курсор с карточками](../assets/img/en/race-charts-rows.webp)

## Графики {#the-charts}

Каждый круг на одной оси расстояния — метры вдоль эталона (см. [одна ось расстояния](race-corner-analysis.md#one-distance-axis)), поэтому один и тот же x — одно и то же место на трассе для каждого круга. Один круг строится сам по себе (и проигрывается); второй круг той же трассы строится рядом с ним. Если кругов не загружено (или анализ не удался), область пишет: «Графики появятся, когда будет загружен круг; загрузите другой круг той же трассы, чтобы сравнить два».

### Что на них есть {#what-is-on-them}

- **Легенда**: цвет и подпись каждого построенного круга, эталон помечен «(эталон)»; «+N ещё нарисовано, не построено», когда видимых кругов больше, чем построено; **Графики (N) ▾**; **Весь круг** при приближении; строка подсказки.
- **Две полосы** сверху, для выбранного круга:
  - *время*: [карта времени](race-replay-and-scene.md#time-map-where) в виде полосы, красным — где теряется время, зелёным — где выигрывается;
  - *причина*: каждая потеря круга — столбик над местом, где её причина, цветом причины; наведите на столбик, чтобы увидеть его название и цену.
- **Полосы поворотов**: затенённая полоса от входа в каждый поворот до выхода (как найдено на эталоне) и его название (`T1` …) под осью у вершины.
- **Выбранный вывод**: полоса цветом его причины над его диапазоном.
- **Строки** (графики), по одной на каждый выбранный канал: слева — название, верхнее и нижнее значение диапазона; там, где диапазон пересекает ноль, — нулевая линия. Каждый круг — линия своего цвета: выбранный круг 2 пикселя шириной и непрозрачный, эталон непрозрачный, остальные 1,5 пикселя при 75%. Строка отставания не показывает эталон (он равен нулю сам себе).
- **Курсор**: вертикальная линия там, где эталонная машина (или где указатель), и точка для каждой машины на каждой строке, кроме отставания. У курсора все машины на одном метре; иначе — собственное расстояние каждой машины по часам повтора.

Строится не больше **8** кругов: выбранный круг, лучший в своём классе и эталон — первыми, затем остальные в порядке загрузки.

### Строки и их высота {#rows-and-their-heights}

Строки делят высоту графика по весу, ни одна не ниже 16 пикселей:

| Строка | Вес |
|---|---|
| Отставание (от эталона, в секундах, со знаком) | 1,7 |
| Скорость (км/ч) | 1,7 |
| педаль (газ, тормоз, сцепление) | 1 |
| руль | 1,1 |
| передача | 0,8 |
| лампа (ручной тормоз, ABS …) | 0,55 |
| всё остальное | 1 |

Канал с фиксированным диапазоном отображения в таблице (педали 0–100%) использует его; остальные подгоняются под видимый отрезок кругов. Слишком длинное название строки (длинное слово в другом языке) опускает верхнее значение на строку там, где строка достаточно высокая, и обрезается многоточием там, где нет; полное название показано во всплывающей подсказке.

### Графики по умолчанию {#the-default-graphs}

Пока графики не выбраны: **отставание**, затем каждый канал, который таблица помечает `graph` и который есть у кругов, — газ, тормоз, сцепление, ручной тормоз, руль, передача, скорость. Педаль или лампа, однако, не выводятся, если ни один круг не сдвигает их дальше 0,02 (сцепление, которое никогда не нажимают, графиком не становится). Порядок — как в таблице.

### Выбор графиков {#the-graph-picker}

**Графики (N) ▾** открывает панель над кнопкой:

- поле фильтра (совпадает с названием или id канала);
- **По умолчанию** (возврат к набору по умолчанию; подсказка говорит, сколько их) и **Закрыть**;
- *Отставание от эталона*, затем каждый канал, который несут построенные круги, сгруппированные (движение, управление, двигатель, помощники, шины, тормоза, подвеска, колёса, прочее, время, позиция), с флажком у каждого. Канал на каждое колесо — одна строка с плашкой на каждое колесо (FL, FR, RL, RR).

Отмеченные графики сохраняют порядок таблицы, в каком бы порядке их ни отмечали. Выбор держится до **По умолчанию** или перезагрузки. Каналы, которых нет в таблице, предлагаются в группе *прочее* и называются по своему id («brakeLinePress» → «Brake line press»).

### Наведение, колесо, масштаб, щелчок {#hover-wheel-zoom-click}

| Действие | Что делает |
|---|---|
| наведение | каждая машина, её карточка и её управление переходят на этот метр; метка отмечает её на трассе; таблица показывает значение каждого построенного круга на каждой строке в этой точке (отставание для эталона — «ref»); над карточками — «на N м — курсор графиков». Уход с графика возвращает к повтору |
| колесо | двигает повтор по кругу на 1/200 видимого отрезка за щелчок (Shift: в 5 раз), приостанавливая повтор; при приближении вид следует за курсором |
| Ctrl+колесо (Cmd+колесо) | масштабирует ось расстояния относительно указателя: 1,25× наружу, 0,8× внутрь за щелчок, но не уже 40 м; отдаление до всего круга снимает приближение |
| колесо в сторону | сдвигает вид при приближении (10% отрезка на 100 единиц прокрутки) |
| двойной щелчок, **Весь круг** | отдалить |
| щелчок | переводит повтор туда, где эталон доходит до этого метра |
| Shift+щелчок | выравнивает машины в этом месте (см. [выравнивание](race-replay-and-scene.md#lining-up)) |

Графики перерисовываются на текущем языке при его смене.

Строка подсказки в легенде говорит то же коротко: «Наведение: каждая машина там · колесо: шаг по кругу · Ctrl+колесо: масштаб · щелчок: переход · Shift+щелчок: выравнивание».

## Карточки машин (HUD) {#the-car-cards-hud}

В левом верхнем углу вида — карточка на каждый видимый круг, не больше **6**: первые шесть видимых кругов в порядке загрузки — на момент, где сейчас повтор (или курсор графиков).

**Заголовок:** цвет и подпись круга; живое отставание — время этого круга, чтобы дойти до его текущего расстояния, минус время эталона, чтобы дойти до того же расстояния, например «+0,48 с», — или «эталон»; **⋯** показывает или скрывает все остальные значения (то же, что *Все значения на карточках*). Карточка преследуемой машины подсвечена.

**Машина сверху:** контур кузова цветом круга со стрелкой спереди, четыре шины (передние поворачиваются до 28° вместе с рулём), каждая окрашена по своей температуре, с теми же значками, что у 3D-машины, нарисованной плоско: кольцо проскальзывания, полоса подвески, свечение тормоза, полоса износа, полоса нагрузки.

**Показания:** скорость в км/ч, собственное время круга, его расстояние вдоль эталона.

**Управление:**

- руль, повёрнутый входом руля (полный поворот показан как 180°), с процентом под ним;
- полоска на каждую педаль, слева направо, как в блоке педалей: сцепление, тормоз, газ — каждая со своим процентом и коротким названием, цветом своей педали (только педали, которые есть у круга);
- передача (R — задний ход, N — нейтраль);
- маленькая лампа на каждый канал вкл/выкл, который есть у круга: ручной тормоз, ABS, TC, DRS, ограничитель питов, в воздухе — горит своим цветом, пока включена (выше половины диапазона);
- показание на каждый канал уровня: баланс тормозов, настройки ABS и TC, наддув, топливо.

**След управления:** последние **6 секунд** каждой педали (одна дорожка, каждая своим цветом) и руля (своя дорожка, по центру), заканчивающиеся в этот момент — что водитель делал, подходя к нему. До 160 точек.

**Все значения** (⋯ или *Все значения на карточках*): каждая другая скалярная величина, которую круг несёт в этот момент, затем каждый канал на колесо как четыре значения (FL FR RL RR), названные по таблице каналов или по собственному имени канала, упорядоченные по группам.

### Таблица каналов {#the-channel-table}

`CHANNELS` в [`src/race/schema.ts`](https://github.com/Holdi601/3DHeat/blob/main/src/race/schema.ts) — единственное место, где описан канал: его единица, одно значение на отсчёт или одно на колесо (хранится как `name.FL` …), его группа, диапазон отображения, то, как он рисуется на машине (`glyph`), как он появляется на карточке (`input`: `pedal`, `steering`, `gear`, `lamp`, `level`), является ли он графиком по умолчанию, переключается ли он ступенями, а не плавно (передача, флаги), и как он показан (масштаб, единица, знаки). Подписи и короткие названия — сообщения на каждом языке (`race.channel.<name>.label` / `.short`).

Каналы с рисунком или графиком по умолчанию:

| Канал | Единица | Рисуется как | График по умолчанию |
|---|---|---|---|
| `throttle`, `brake`, `clutch` | 0..1 | педаль (зелёный, красный, …), показана в % | да |
| `handbrake` | 0..1 | лампа | да |
| `steer` | -1..1, вправо положительно | руль | да |
| `gear` | - | передача | да |
| `speed` | м/с, показана в км/ч | - | да |
| `absActive`, `tcActive`, `drs`, `pitLimiter`, `airborne` | 0..1 | лампа | - |
| `brakeBias`, `absLevel`, `tcLevel`, `boost`, `fuel` | - | показание уровня | - |
| `tireTemp` (на колесо) | °C, отображение 40–130 | цвет шины | - |
| `tireTempInner/Middle/Outer` | °C | - | - |
| `slipRatio`, `slipAngle` (на колесо) | как масштабирует игра, отображение ±1,5 | кольцо проскальзывания | - |
| `combinedSlip`, `slipIndex` (на колесо) | отображение 0–1,5, 0–1 | кольцо проскальзывания | - |
| `suspension` (на колесо) | 0..1 | полоса подвески | - |
| `brakeTemp` (на колесо) | °C, отображение 100–900 | свечение тормоза | - |
| `tireWear` (на колесо) | 0..1 | полоса износа | - |
| `wheelLoad` (на колесо) | Н, отображение 0–12 000 | полоса нагрузки | - |

Остальные каналы таблицы (строятся и перечисляются, но не рисуются): `latAcc`, `longAcc`, `vertAcc`, `yaw`, `pitch`, `roll`, `yawRate`, `latVel`, `longVel`, `vertVel`, `bodySlip` (угол сноса), `loose`, `lateral` (смещение от эталона), `rpm`, `power`, `torque`, `waterTemp`, `oilTemp`, `tirePressure`, `camber`, `padLife`, `discLife`, `suspensionM`, `wheelSpeed`, `wheelSurfaceSpeed`, а также `time`, `distance`, `x`, `y`, `z`.

**Канал, которого нет в таблице,** всё равно читается, строится (в группе *прочее*) и перечисляется на карточках, с подписью по своему имени. **Чтобы дать ему правильное название, единицу и рисунок**, добавьте одну запись в таблицу (и её сообщение с подписью в каждый `src/i18n/locales/<language>/race-channels.json`). Новый *вид* рисунка колеса — одна запись в `WHEEL_GLYPHS` (glyph.ts) и её плоский двойник `CARD_GLYPHS` (RaceHud.tsx); оба типизированы по виду, поэтому сборка падает, пока не существуют оба. `src/race/extensible.test.ts` проверяет, что неизвестные каналы доходят до графиков, что каждый значок из таблицы можно нарисовать и что лампы зажигаются.
