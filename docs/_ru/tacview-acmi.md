# Записи Tacview (ACMI)

Tacview — это программа, которая записывает полёты в авиасимуляторах; её файлы оканчиваются на `.acmi`. 3DHeat открывает их, чтобы вы могли видеть, где летала каждая машина.

Записи полётов Tacview загружаются как любая таблица: выберите или перетащите `.acmi` (текстовый, `.txt.acmi` или в архиве, `.zip.acmi`) и нажмите **Загрузить**. Вы получите тепло всех полётов, а на вкладке **Матч** — повтор с фигурами, треками и списком событий ([Повтор матча](match-replay.md)). ACMI — открытый формат файлов Tacview ([документация](https://www.tacview.net/documentation/acmi/)); DCS (через экспортёр Tacview), IL-2 Great Battles, Falcon BMS, X-Plane, MSFS и другие пишут в этом формате, поэтому просмотрщик читает любой из них.

## Во что превращается запись {#what-a-recording-becomes}

Одна строка каждый раз, когда записывается положение объекта, одна строка на событие в месте объекта и одна строка, когда объект уходит (`Removed`, там, где он был последним). Событие, не относящееся ни к одному ещё не виденному объекту, — закладка, сообщение всем, — это строка объекта `(recording)` в опорной точке. Запись содержит собственные инструкции чтения, поэтому шаг сопоставления заполняется сам. Читатель записывает такие столбцы: `Time`, `X`, `Y`, `Altitude`, `Object`, `Coalition`, `Heading`, `Pitch`, `Roll`, `Type`, `Name`, `Pilot`, `Group`, `Country`, `Color`, `Event`, `Latitude`, `Longitude`, `Recording`, `EventObjects`, `RecordingInfo`, а затем любые другие свойства, которые есть в записи. Их роли:

| Столбец | Роль | Значение |
|---|---|---|
| Time | время | Секунды после ReferenceTime записи; у записи с ним — Unix-секунды, так что часы показывают реальное время. |
| X, Y | положение | Восток и север, метры, на плоскости, касающейся Земли в опорной точке записи: расстояния и курсы верны рядом с ней, а на 100 км уходят меньше чем на одну тысячную. Север становится -Z мира. |
| Altitude | положение (вверх) | Метры. |
| Object | персона | Пилот и имя объекта с его идентификатором, например `Viper 1 (F-16C_50) #a01`; необитаемый объект `(T-90A) #401`. |
| Coalition | команда | Сторона (или цвет, если коалиции нет). |
| Heading, Pitch | взгляд | Градусы; курс 0 — это север. |
| Recording | сессия | Title записи или имя файла: несколько записей загружаются рядом, не сливая свои треки. |
| Type, Name, Pilot, Group, Country, Color, Event, Roll, Latitude, Longitude | фильтры | Сохраняются для фильтрации; Type и Name выбирают [фигуру](figures.md) каждого объекта, Event подаёт список событий разбора, Roll наклоняет самолёт. |
| U, V | | Собственные плоские метры игры, когда они есть у каждого отсчёта (DCS их пишет). |
| EventObjects | фильтры | Каждый объект, который называет событие (`Message|a01|b02|...`), по идентификатору. |
| RecordingInfo | | Собственные свойства записи такими, какими они были в этот момент — DataSource, DataRecorder, Author, Category, Briefing, Comments, ... — в виде JSON. |
| IAS, Mach, AOA, FuelWeight, ... | фильтры | Любое другое числовое свойство записи. |
| Parent, CallSign, LockedTarget, Label, Shape, ... | фильтры | Любое другое текстовое свойство записи; свойство, значение которого не число, считается текстом. |

Читаются все четыре формы положения Tacview (`lon|lat|alt`, с `u|v`, с `roll|pitch|yaw` и со всеми ними и курсом); пустые поля сохраняют последнее значение; `-id` удаляет объект, а идентификатор, использованный снова после этого, — это новый объект. Экранированные запятые и продолженные строки обрабатываются.

Положения всегда проецируются из широты и долготы, никогда не берутся из U/V, поэтому записи из всех игр используют одну проекцию с подложкой настоящего мира.
