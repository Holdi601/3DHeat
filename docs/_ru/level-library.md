# Библиотека уровней

Библиотека хранит ваши уровни в этом браузере, чтобы их не нужно было снова загружать и упрощать. **Очистка данных сайта в браузере удаляет библиотеку, и экспорта нет.** Храните исходные файлы.

Обработка уровня — разбор, классификация, сварка, прореживание, упаковка текстур — медленная, и результат каждый раз одинаковый. **Библиотека** внизу панели «Фон / уровень» хранит обработанные уровни в этом браузере, так что упрощённый меш никогда не строится дважды ([`levelLibrary.ts`](https://github.com/Holdi601/3DHeat/blob/main/src/data/levelLibrary.ts)).

## Сохранить уровень и загрузить его снова {#save-and-reload-a-level}

1. Загрузите изображение карты или 3D-модель и проверьте, что выглядит правильно.
2. Нажмите **Сохранить в библиотеку**. Панель скажет *Сохранено. В следующий раз загрузится мгновенно.*
3. В следующий раз откройте список **Библиотека** и нажмите ▸ у уровня.
4. Нажмите ✕, чтобы удалить запись, которая вам больше не нужна.

## Использование {#using-it}

| Элемент | Действие |
|---|---|
| **Сохранить в библиотеку** | Сохраняет текущий уровень. Изображение карты хранится как PNG с двумя якорями; модель — как её обработанные буферы. Панель говорит *Сохранено. В следующий раз загрузится мгновенно.* |
| Список библиотеки | Одна строка на сохранённый уровень: имя (с его сохранённым размером при наведении), треугольники для модели или ширина в пикселях для изображения. |
| ▸ (*Загрузить*) | Загружает запись как текущий уровень. |
| ✕ (*Удалить*) | Удаляет запись. |
| Строка использования | `Используется X из Y.` — оценка хранилища браузера для этого сайта. |

Если ничего не сохранено, список говорит *Пусто. Загрузите карту или модель, затем нажмите «Сохранить в библиотеку».*

## Что хранится {#what-is-stored}

| Вид | Хранится | Не хранится |
|---|---|---|
| Изображение карты | Изображение (PNG), его размер, его якоря | Высота, отражение, непрозрачность, яркость, обесцвечивание — возвращаются к значениям по умолчанию (высота = самая низкая Y текущего набора данных, отражение включено) |
| 3D-уровень | Вершины, цвета вершин, текстурные координаты, их плитки и атлас текстур, треугольники земли / конструкций / воды, рёбра конструкций, количество треугольников | Имена частей и причины классификации, а также все настройки внешнего вида — возвращаются к значениям по умолчанию свежего импорта |

Модель, загруженная из библиотеки, не имеет списка частей; её границы и диапазон высоты земли пересчитываются по её вершинам.

## Где она хранится {#where-it-lives}

В IndexedDB браузера, база `3dheat`, хранилище объектов `levels`, для источника страницы (адреса в адресной строке браузера). Она привязана к профилю этого браузера: другой браузер, другой профиль или другой адрес (например, `localhost` вместо `127.0.0.1`) видят другую, пустую библиотеку. Очистка данных сайта в браузере удаляет её. Записи, сохранённые старыми версиями без конструкций, цветов и воды, по-прежнему загружаются.
