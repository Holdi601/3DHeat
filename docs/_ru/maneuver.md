# Манёвры: как движутся группы

**Выводы → Манёвры** показывает, как юниты каждой стороны движутся *группами*, и называет манёвры, которые они совершают: фланговый удар, клещи, прорыв, засаду, отход, оборону от ракет, «пересечение Т». У каждого указаны уверенность, цифры, на которых он основан, окупился ли он и его параллели в доктрине и истории. **Массовый анализ → Манёвры** считает их по тысячам матчей: как часто каждый манёвр совершается на каждой карте и в каждом режиме, за какую сторону и как часто он окупается.

Всё считается в браузере, в собственном рабочем потоке (`src/insights/maneuver`). Матч из нескольких сотен юнитов занимает 10–500 мс, двухчасовая воздушная война с тысячами объектов — около секунды.

## Использование {#using-it}

- Откройте **Выводы**, вкладка **Манёвры**. Подсчёт идёт при первом открытии; после смены фильтров нажмите **Найти снова**.
- **Точно / Вероятно / Возможно** задаёт уверенность, которая показана в списке (по умолчанию — «Вероятно»).
- **Шкала времени** имеет полосу для каждой стороны и полоску на каждый манёвр; **список** под ней показывает то же самое по времени. Щелчок переключает на повтор с начала манёвра, переводит камеру туда и рисует его в 3D: путь каждой группы — стрелкой (две руки клещей — двумя дугами), контуры групп в ключевой момент (противник — цветом его стороны), фронт противника — белой линией. **Показать все в 3D** добавляет остальные манёвры матча, бледными. Линии передаются видеокарте один раз, когда меняется выбор, а не на каждом кадре: при 480 манёврах, нарисованных во время воспроизведения, времена кадров на настоящей видеокарте (WebGL2 и WebGPU: p99 18,0–18,5 мс, максимум 19,5–20,8 мс) такие же, как без них.
- У открытого манёвра видны его исход (уничтожения и потери юнитов, которые его совершали, пока он шёл и сразу после, в сравнении с обменом их стороны за весь матч), его доказательства и записи базы знаний о нём — доктрина и исторические параллели (Канны для клещей, Седан, 1940, для прорыва, Цусима для пересечения Т, операция «Боло» для ложного удара…).
- Небольшая таблица в конце: по каждому виду и стороне — совершено и окупилось.

## Как находят группы {#how-groups-are-found}

Каждый юнит ставится на общую шкалу времени (шаг 1 с пешком, 2 с в остальных случаях, дольше для очень больших файлов). При гибели юнит удерживается на месте, чтобы возрождение не рисовало линию через карту. На каждом шаге юниты одной стороны и одного вида (авиация, техника, корабли, пехота) связываются, если они близко — 18 м пешком, 170 м для техники, 3 км для кораблей, 5 км для авиации — и движутся одинаково (скорости отличаются не больше чем вдвое в пользу более быстрого, или оба стоят). Скопление сохраняет id той группы, в которой раньше было большинство его членов. Юнит без класса относится к пехоте, технике или авиации по своей скорости.

**Форма** группы читается относительно её курса: колонна или линия — по разбросу вдоль и поперёк курса, клин — когда середина впереди, эшелон — когда участники отходят к одной стороне, коробка — когда они занимают углы.

Всё оценивается в масштабе самого матча: **дальность боя** `R` — это 75-й перцентиль расстояния между убийцей и жертвой (в пределах, разумных для предметной области), а времена манёвра масштабируются по виду юнита (у пехоты — треть наземных).

## Что находит {#what-it-finds}

| Манёвр | Находится, когда |
|---|---|
| Строй | группа держит одну форму на 60% своих шагов движения в течение 30 с |
| Фронтальная атака | группа сближается с противником от дальности до контакта, ¾ R и больше, с направления в пределах 35° от того, куда смотрит противник |
| Фланговая атака | то же, с 50–130° (тыл — дальше); точно только при дружественной *связывающей силе*, которая в это время вступила в бой с противником там (уничтожения в любом случае) |
| Клещи | две фланговые атаки одной стороны на одно и то же тело противника, с противоположных сторон (100° и больше друг от друга), в пределах 90 с; точно, когда руки ведут бой |
| Окружение | компактная группа противника, которую окружает не меньше её самой других сторон, в пределах 1,5 R, от двух и более групп, без разрыва больше 100°, в течение минуты, отрезанная от своей стороны; точно, когда кольцо сомкнулось на ½ R и вело бой за карман |
| Прорыв | группа проходит удерживаемую линию (противники стоят 30 с и слева, и справа от неё, центр их стороны — за ними); точно, когда она уходит на ½ R дальше, остаётся 20 с и ведёт там бой; прорыв — ещё на R дальше |
| Перекрёстное прикрытие (bounding overwatch) | в малой группе часть движется, пока остальные стоят, роли меняются четыре раза и больше, с огнём прикрытия от стоящей части |
| Концентрация / рассредоточение | доля стороны возле её самого плотного места растёт с 35% до 60% (юниты подходят на 1,5 R и больше, затем контакт) — или падает, когда сторона растягивается |
| Ложный удар | малый элемент в контакте привлекает двух и более противников с других участков; большая группа затем бьёт на четырёх дальностях, там, где у противника меньше сил |
| Отход / преследование | группа в контакте поворачивает и отрывается на R от места боя; точно, когда там противник только что убил одного из неё, а группа ушла на 2 R от этого убийцы (пешком — никогда: см. ниже); противники, идущие в ту же сторону и не отстающие, преследуют |
| Глубокая оборона | стоящие юниты в двух и более полосах поперёк оси противника, на глубине R, противник наступает, огонь ведётся из полос |
| Обратный скат | три и больше убийств на малой дистанции стоящими юнитами, жертвы которых перевалили через гребень |
| Засада | движущаяся группа встречает противников, которые стояли 45 с; они стреляют первыми, и движущиеся теряют двоих или половину группы |
| Экран | один-два юнита впереди тела из трёх и более, первыми встречающие противника |
| Внутренние линии | группы одной стороны сближаются между группами другой, её юниты перемещаются между ними |
| Темп | сторона отвечает на контакт (поворот, смена скорости, первый выстрел) в 1,5 раза быстрее; p по критерию Манна–Уитни меньше 0,05 |
| Crank, notch, drag, pump | цель пуска ракеты поворачивает стрелка на 35–70°, 75–105°, больше 140°, или тянет за собой и возвращается |
| Воздушные клещи, стена, ведущий–ведомый, мясорубка | пара расходится на одного противника; трое в линию на противника; элемент в 5–20 км позади другого; двое кружат вокруг одной точки, разнесённые друг от друга |
| Боевой воздушный патруль | кружит вокруг станции три минуты |
| Бой на энергии / на углах | в ближнем бою — курсы в 30° друг от друга, каждый по очереди держит другого у себя на носу, или между ними уничтожение; высота используется и набирается, либо горизонтальный манёвр с крутым поворотом и потерей скорости; точно, когда один убил другого |
| Ударный пакет, SEAD | авиагруппа смешанных ролей, часть которых бьёт по земле; уничтожения ПВО — раньше большинства других наземных уничтожений |
| Линия боя, пересечение Т | три корабля в колонне; колонна поперёк головы колонны противника, под прямым углом |

Каждый манёвр указывает, какие **паттерны** базы знаний он показывает (`patterns-maneuver.ts`: строй, фронтальная атака, двойной охват, окружение, прорыв, огонь и манёвр, ложный удар, отход, преследование, глубокая оборона, экранирование, рассредоточение, оборона от ракет, бой на углах, боевой воздушный патруль, ударный пакет, линия боя, пересечение Т) и записи, которые стоит прочитать первыми; у старых записей новые паттерны переносятся через `knowledge/maneuver-tags.ts`. См. [Линза знаний](knowledge.md).

**Окупился** сравнивает обмен юнитов, пока манёвр шёл (и минуту после), с обменом их стороны за весь матч. Отход окупается, когда после поворота потеряно меньше юнитов, чем до него; оборона от ракет — когда самолёт выживает минуту; окружение — когда карман теряет половину.

## По многим матчам {#over-many-matches}

Сводка каждого матча (`src/mass/summarize.ts`, см. [Массовый анализ](mass-analysis.md)) содержит небольшой раздел `maneuvers`: по каждому виду и стороне — совершено (на уровне «Вероятно» или выше), окупилось, не окупилось, уничтожения и потери. **Массовый анализ → Манёвры** складывает их по матчам, которые оставляет фильтр, — по карте и режиму или по всем вместе — с интервалом Уилсона для доли окупившихся; строка загружает матчи, в которых она была совершена. Сводки, записанные до появления этого раздела, его не содержат: запустите `node tools/3dheat-summarize.mjs <folder> --force`, чтобы его добавить.

## Насколько это надёжно {#how-sure-it-is}

Синтетические матчи с заложенными манёврами (`synth.ts`, запускаются `maneuver.test.ts`): все 28 заложенных видов находятся на уровне «Вероятно» или выше; из 50 сообщённых манёвров 31 — заложенного вида, а остальные 19 тоже есть на самом деле (строй движущейся группы, фронтальный подход прорывающей колонны); ни один не ошибочен. На 30 пустых матчах — случайные блуждания порознь и вперемешку, юниты стоят в случайных местах, авиация летит по прямым, толпа бродит — ничего не сообщается на уровне «Вероятно» или выше.

На реальных данных (десятки наземных боёв, несколько длинных миссий воздушной войны, около десятка матчей шутера): фронтальные атаки, фланги, прорывы и окружения в танковых боях; строи и ближние бои в воздухе; обороны от ракет, орбиты патрулирования и пары ведущий–ведомый в миссиях воздушной войны; фронтальные добивания, колонны и отдельные засады и пары прикрытия в шутере. Пороги — это формы доктрины в масштабе игры: читайте отдельную находку вместе с её доказательствами, а доли в таблице массового анализа — вместе с их интервалами.

### Против нулевых моделей тех же матчей {#against-null-models-of-the-same-matches}

Детектор может обмануться землёй и толпой: в свалке у каждой группы противники со всех сторон. Поэтому каждый вид также запускается на **нулевых моделях**, построенных из тех же матчей (`nulls.ts`), где стороны уже не встречаются так, как было: шкала времени одной стороны поворачивается на треть–две трети матча (*shift*), или её траектории поворачиваются вокруг центра карты (*rotate*); метки команд перемешиваются (*teams*, что по построению сохраняет около половины настоящих боёв). Бои считаются только как уничтожения, спаренные с гибелями: убийца в пределах 2 R и жертва на месте — нулевые модели это ломают. Находки на уровне «Вероятно» или выше, реальные против нулевых моделей (30 танковых боёв; 12 матчей шутера):

| Вид | Танковые бои: реальные / shift / rotate | Шутер: реальные / shift / rotate |
|---|---|---|
| Окружение | 0 / 0 / 0 (было 1,3 / 1,2 / 0,8) | 0 / 0 / 0 |
| Прорыв | 0,03 / 0,02 / 0,05 (было 1,6 / 1,8 / 1,4) | 0 / 0 / 0 |
| Фланг | 0,33 / 0,07 / 0,10 | 1,0 / 0,08 / 0,21 |
| Фронтальная атака | 0,87 / 0,47 / 0,12 | 14,4 / 6,5 / 4,3 |
| Отход | 0,03 / 0 / 0,02 | 0,08 / 0,08 / 0,5 (поэтому пешком никогда не точно) |
| Засада | - | 0,17 / 0,04 / 0,04 |
| Бой на энергии | 1,2 / 0,1 / 0,85 | - |
| Бой на углах | 0,6 / 0,07 / 0,3 | - |

Близкие воздушные бои над центром поля боя переживают поворот вокруг этого центра, поэтому колонка rotate им меньше вредит, чем наземным видам. Виды внутри одной стороны — строй, боевой воздушный патруль, мясорубка, ударный пакет, SEAD, перекрытие, экран — от другой стороны не зависят и так не проверяются. `maneuver.test.ts` проверяет, что нулевые модели убирают заложенные в синтетические матчи фланг, клещи, окружение, прорыв, засаду и отход.

## Ограничения {#limits}

- Группам нужны позиции во времени; файл одних событий их не даёт.
- Направление взгляда из данных не читается: фронт противника — там, где его связывающая сила вступает в бой, иначе — там, куда он движется, иначе — откуда пришёл атакующий.
- Рельеф читается по высотам самих юнитов (обратный скат); проверки прямой видимости нет.
- Очень большие файлы читаются с более длинными шагами; короткие воздушные манёвры в них всё равно читаются по шагам в 2–4 с.
