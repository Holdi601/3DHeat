# Паритет с Tacview

Tacview — популярная программа для просмотра записей полётов. Если вы её знаете, эта страница покажет, где каждый её инструмент находится в 3DHeat.

Здесь перечислена каждая функция Tacview 1.9 (по её руководству, таблице строк интерфейса и формату файлов ACMI 2.2) и то, на каком уровне [повтор матча](match-replay.md) 3DHeat с ней. Цель: всё, что Tacview умеет делать с повтором и его данными, 3DHeat тоже умеет делать.

**Статус:**
- **done**: уже есть в 3DHeat.
- **new**: сделано, чтобы соответствовать функции Tacview.
- **not yet**: применимо, но ещё не сделано.
- **n/a**: здесь не применимо, причина указана.

Где искать функции: вкладка **Матч**, **Повтор фигурами** (или **Наложение фигур** на вкладке «Тепловая карта»), в боковых разделах **Разбор**, **Единицы**, **События**, **Закладки**, **Тактическое отображение**, **Статистика**, **Сдвиг по времени и обрезка**, **Карта и координаты**, **Аудио и видео** и **Подписи**. См. [Повтор матча](match-replay.md).

## Для разработчиков: свойства ACMI 2.2 {#for-developers-acmi-22-properties}

Читаются `data/acmi.ts`; числовые свойства становятся числовыми столбцами, текстовые — столбцами категорий. Все они показываются в **Сырые** в карточке юнита. Эти читаются для дела:

| Свойства | Использование |
|---|---|
| T (все четыре формы), Name, Type, Pilot, Group, Country, Coalition, Color, CallSign | Положение, ориентация, фигура, имя юнита, команда |
| IAS, CAS, TAS, Mach, AOA, AOS, AGL, HDG, HDM, OnGround | Поля, графики, HUD, определение взлёта и посадки |
| VerticalGForce, LongitudinalGForce, LateralGForce | Поля G |
| Throttle(2), Afterburner, EngineRPM(2), NR, AirBrakes, Flaps, LandingGear, Tailhook | Поля |
| FuelWeight..9, FuelVolume..9, FuelFlowWeight..8 | Поля топлива, суммируются по бакам |
| RadarMode, RadarAzimuth, RadarElevation, RadarRoll, RadarRange, RadarHorizontalBeamwidth, RadarVerticalBeamwidth, RadarRangeGateAzimuth/Elevation/Min/Max/HorizontalBeamwidth/VerticalBeamwidth | Конусы радаров и строб дальности |
| LockedTarget..9, LockedTargetMode, LockedTargetAzimuth/Elevation/Range, FocusedTarget | Линии захвата |
| EngagementMode(2), EngagementRange(2), VerticalEngagementRange(2) | Купола поражения |
| QNH, AltimeterSetting, WindSpeed, WindDirection, HeartRate | Поля |
| Health | Поле |
| События: Destroyed, TakenOff, Landed, Bookmark, Message, Comment, LeftArea, Timeout | Список событий, статистика (смерти, взлёты, посадки), закладки; Message и Comment как субтитры |
| PilotHeadYaw, PilotHeadPitch | Линия взгляда пилота |
| Тег типа Bullseye (Navaid+Static+Bullseye) | Поле bullseye и кольца на карте |
| Всё остальное (PilotHeadRoll, управление, поверхности, отклонения ILS, SpO2, ENL, Label, Debug, Importance, Slot, Visible, Disabled, Radius, размеры...) | Показывается как записано в **Сырые** |

Углы радара и захвата берутся относительно собственных осей юнита: азимут вправо, угол места вверх, крен — правое крыло вниз. В спецификации ACMI сказано, что они отсчитываются относительно самолёта, но не сказано, какое направление положительное; это толкование следует её преобразованию (рыскание по часовой, тангаж вверх, крен вправо).
