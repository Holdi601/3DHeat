# Справочник

Списки точных названий, настроек и инструментов, по которым можно что-то найти. Чтобы пользоваться просмотрщиком, их читать не нужно.

Эти списки создаются из кода просмотрщика командой `node tools/docs-refs.mjs` (запускать её не нужно), поэтому они всегда совпадают с версией, для которой были созданы:

- [Типы и классы событий](ref-event-types.md) — виды событий и классы техники, по которым сортируется каждый набор данных, и какие слова в данных к ним относятся
- [Названия столбцов](ref-columns.md) — названия столбцов, которые загрузчик распознаёт для позиции, времени, человека, команды, сессии и направления взгляда
- [Список языков](ref-languages.md) — языки просмотрщика
- [Клавиши браузера](ref-browser-keys.md) — сочетания браузера, которые просмотрщик оставляет за собой
- [Сохранённые настройки](ref-settings-storage.md) — что браузер помнит между визитами
- [Таблицы значений](ref-value-tables.md) — таблицы цен взвешивания по ценности
- [Инструменты командной строки](ref-tools.md) — инструменты из `tools/`: для ваших данных, а также для разработчиков и документации

Также справочные материалы: [Глоссарий](glossary.md) со словами, которые используются на этом сайте. Написаны вручную: [Справочник форматов данных](data-formats.md), [Справочник клавиатуры и мыши](keyboard-reference.md), [Один файл на матч (.3dheat)](container.md).
