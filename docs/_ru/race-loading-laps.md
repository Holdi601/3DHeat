# Загрузка кругов

Файл круга - это запись одной поездки: где была машина и что делал водитель, много
раз в секунду. Загрузите два или больше кругов одной трассы, и вкладка **Анализ заездов**
сможет их сравнить.

![Раздел Круги вкладки Анализ заездов с тремя демо-кругами: список кругов, эталон-звезда, фокус](../assets/img/en/race-loading-laps-list.webp)

## Первые круги {#your-first-laps}

1. Откройте вкладку **Анализ заездов**.
2. Просто смотрите? Нажмите **Демо-круги** (см. [Демо-круги](#demo-laps)).
3. Свои круги: запишите их в игре с помощью записывающего устройства (см. [Форматы файлов](#file-formats)). Записывающее устройство пишет один файл на круг.
4. Нажмите **Загрузить файлы кругов…** и выберите два или больше файлов одной трассы или нажмите **Папка…** и выберите папку, в которой они лежат. Можно также перетащить файлы или папки на 3D-вид.
5. Щёлкните по кругу в списке, чтобы увидеть, где он теряет время.

**Внимание: круги сравниваются по одной трассе за раз.** Загрузка круга другой названной трассы очищает уже загруженные круги.

## Кнопки {#the-buttons}

| Элемент | Что делает |
|---|---|
| **Загрузить файлы кругов…** | выбор файлов `.json`, `.csv`, `.txt`, `.ibt`, `.gz` и `.h3dcars`, сразу несколько (`.h3dcars` - это файл машин, см. [Машины](race-replay-and-scene.md#the-cars)) |
| **Папка…** | выбор папки: каждый файл круга в ней и ниже |
| **Демо-круги** | три придуманных круга придуманной трассы (см. [Демо-круги](#demo-laps)) |
| **Очистить** | удаляет все круги (показывается, когда круги загружены) |
| перетаскивание на вид | файлы и целые папки, перетащенные на 3D-вид, загружаются так же |

Круги **добавляются** к уже загруженным - **кроме случая, когда они с другой названной
трассы: тогда сначала очищаются загруженные круги** (круги сравниваются по одной трассе
за раз). Файлы, которые нельзя прочитать, перечисляются под кнопками, по одной строке на
каждый; остальные всё равно загружаются.

## Форматы файлов {#file-formats}

Формат определяется по содержимому, а не по имени файла. Простыми словами:

- **heat3d-lap** - это файл, который записывает записывающее устройство 3DHeat для большинства игр.
- **FH Companion** - бесплатная программа, которая записывает круги Forza Horizon. Она пишет файл круга и рядом файл `.json.tele.gz` (тот же круг со всеми данными каждой шины, сжатый gzip). Выбирайте оба вместе.
- **iRacing `.ibt`** - собственный файл телеметрии iRacing; включите запись в машине клавишами Alt+L и загрузите файл как есть.
- **CSV круга** - простая таблица, по одной строке на момент.

| Формат | Обычный источник | Читается |
|---|---|---|
| `heat3d-lap` JSON | `heat3d_capture telemetry --game ...` (Forza Horizon и Motorsport через Data Out, AC / ACC / AC EVO / AC Rally, EA SPORTS WRC, DiRT Rally 2.0 / 1, DiRT 4, Richard Burns Rally, BeamNG.drive) | `fromHeat3dLap` |
| JSON круга FH Companion | библиотека кругов FH Companion | `fromFhCompanion` |
| Телеметрия FH Companion `.json.tele.gz` | рядом с каждым файлом круга FH Companion | `readForzaTelemetry` |
| iRacing `.ibt` | собственные файлы телеметрии iRacing (запись включается клавишами Alt+L в машине) | `readIbt` |
| CSV круга | `heat3d_capture laps`, плагин Trackmania или любой CSV с `x`, `z`, столбцом времени и, по желанию, столбцом `lap` | `fromCsv` |

Как записывается каждая игра и что она отправляет, описано в записывающих устройствах:
[GameCapture: игры](https://github.com/Holdi601/3DHeat-GameCapture/blob/main/docs/games.md)
и [GameCapture: формат круга](https://github.com/Holdi601/3DHeat-GameCapture/blob/main/docs/lap-format.md).
См. также [Другие гоночные игры](other-games.md).

## Папки и трассы {#folders-and-courses}

**Папка…** или перетащенная папка берёт все файлы в ней и ниже. Внутри папки
рассматриваются только файлы, которые заканчиваются на `.json`, `.csv`, `.txt`, `.ibt`
или `.tele.gz`, а `.json`, который не является кругом (собственный файл трассы, её карта),
пропускается без ошибки.

**Несколько трасс в одном выборе.** Библиотека кругов FH Companion хранит каждую трассу в
папке с именем `<название трассы> (course_<x>_<z>_to_<x>_<z>)` (или просто `course_...`
для безымянной трассы). Когда выбранные файлы лежат больше чем в одной такой папке трассы,
ничего не загружается; вместо этого в разделе **Круги** написано «Это круги N трасс, а
круги сравниваются по одной трассе за раз. Выберите одну:» и перечисляется каждая трасса с
числом кругов (файлы, которые заканчиваются на `.json`, `.csv` или `.ibt`, файл `course.json`
не учитывается), сначала с самым большим числом кругов. Щелчок по одной загружает файлы этой
трассы.

Трасса определяется по её названию и **старту**, а не финишу: заезды, которые так и не
были доведены до конца, FH Companion хранит под тем же названием и стартом (в `unfinished/`),
с местом остановки как концом, и они идут вместе со своей трассой - помечаются в списке как
**неполный**.

**Несколько трасс среди выбранных файлов.** Когда файлы, выбранные напрямую (не из папок
трасс), - круги больше чем одной названной трассы, тот же выбор предлагается для каждой
трассы; круги без названия трассы идут вместе с той трассой, которая выбрана.

## Названия машин {#car-names}

Круг называется полным названием машины, как его даёт игра. Там, где файл круга не
называет машину:

1. **Папка.** Библиотека FH Companion хранит круги в
   `<трасса>/<класс>/<название машины> '<гг> (car<номер>)/<настройка>/<метка>/<круг>.json`.
   Самая внутренняя папка, совпадающая с `<название> (car<номер>)`, даёт название и номер;
   совпадающая с `car<номер>` - только номер. Такой путь есть только у выбранных папок и
   перетащенных папок.
2. **Другой круг той же машины.** Как только какой-либо круг называет машину, каждый круг с
   той же игрой и номером машины получает это название - круги, загруженные вместе, и круги,
   загруженные позже в этом браузере: названия хранятся в `localStorage` под ключом
   `heat3d.carNames` (по `<игра>:<номер машины>`). В приватном окне они живут, пока живут круги.
3. Иначе «car 1234» по номеру или просто «car».

**Подписи.** В списке кругов круг показывает название своей машины; несколько кругов одной
машины пронумерованы «Название #1», «Название #2». Фразы анализа используют те же подписи,
когда они уникальны; иначе название машины с временем круга, «Название (1:29.616)» (примерные
времена), и дальше нумеруются, если всё ещё не уникальны.

**Группировка.** Круги относятся к одной машине (для огибающих, профилей и сравнений), когда
их номер машины - или название, если номера нет, - и их индекс производительности совпадают
(`carKey`): одна и та же модель с другой настройкой - это другая машина.

**Классы.** Класс производительности круга - это класс игры (Forza D..X, короткое название
класса машины iRacing); статистика ставит их в порядок D, C, B, A, S1, S2, R, X, затем
остальные по алфавиту.

## Демо-круги {#demo-laps}

**Демо-круги** загружает три круга придуманной трассы (четыре прямые и четыре правых поворота),
созданной простой моделью машины
([`synthetic.ts`](https://github.com/Holdi601/3DHeat/blob/main/src/race/synthetic.ts)):
скорость каждого поворота, ограниченная сцеплением, проход разгона вперёд и проход торможения
назад, как делает симулятор круга.

| Круг | Машина | Ошибки |
|---|---|---|
| чистый | Цепкая машина | нет |
| с ошибками | Цепкая машина | тормозит на 35 м раньше на T2, открывает газ на 30 м позже после T3, проходит T4 на 0,88 своей скорости, едет на 1,2 м в одну сторону |
| другая машина | Мощная машина | нет; едет на 1,2 м в другую сторону |

| Машина (номер) | Сцепление | Торможение | Тяга | Мощность/масса | Сопротивление |
|---|---|---|---|---|---|
| Цепкая машина (9001) | 16 м/с² | 13 м/с² | 9 м/с² | 230 Вт/кг | 0,0009 /м |
| Мощная машина (9002) | 12 м/с² | 11 м/с² | 7 м/с² | 380 Вт/кг | 0,0006 /м |

Круг с ошибками выбран в фокус. Трасса выложена так, как Forza хранит свой мир (левосторонний),
поэтому - точно как у настоящего круга Forza - она выходит зеркальной, и вкладка предлагает
**Инвертировать X**. У всех трёх кругов есть данные по каждому колесу, так что у каждой части
вкладки есть что показать.

## Список кругов {#the-lap-list}

Каждая строка, слева направо:

| Элемент | Что делает |
|---|---|
| ● / ○ | показывает / скрывает круг (линии, машину, карточку, графики); скрытые круги всё равно анализируются |
| цветная полоса | цвет круга |
| название и метки | щелчок - **фокус** на круге; при наведении - его исходный файл и машина (название · класс PI · привод) |
| ⌖ | камера следует за этой машиной (щелчок ещё раз - остановить) |
| ★ | сравнивать всё с этим кругом (сделать его эталоном); не действует на эталон |
| × | удалить круг |

**Метки:** *эталон*; *лучший из X* (или *лучший в своём классе*) на самом быстром круге
класса, когда классов несколько; *неполный* на заезде, который не дошёл до финиша.

**Вторая строка:** класс (только при нескольких классах), время круга (`1:29.616`), разрыв
до круга, с которым он сравнивается (лучший в своём классе или эталон), как `+0.512`
(пример), и *стартовал поздно*, когда круг начинается больше чем на 10 м после старта эталона.

Когда кругов больше 8, строка «нарисовано N из M» предлагает **Показать все** (нарисовать
каждый круг: медленнее и путаница) и **Только просматриваемые** (эталон, фокусный круг и лучший
из его класса; статистика в любом случае учитывает каждый круг).

Под списком: подсказка о зеркалье, когда круги говорят, что рисунок зеркальный (см.
[зеркальные миры](race-replay-and-scene.md#mirrored-worlds)), а при двух кругах и больше
подсказка «Щёлкните по кругу, чтобы увидеть, где он теряет время …», и, при нескольких классах,
что каждый круг сравнивается с самым быстрым в своём классе.

### Эталон и фокус {#reference-and-focus}

- **Эталон:** круг, к которому выравнивается каждый другой и с которым по умолчанию идёт
  сравнение. Самый быстрый **полный** круг, если ★ не выбрал другой (первый загруженный круг,
  если ни один не полный). Удаление эталонного круга возвращает к автоматическому выбору.
- **Фокус:** круг, чьи выводы, управление машиной и карты показываются. Он остаётся там, куда
  его поставил пользователь; иначе это **самый медленный** круг, который не эталон («больше
  всего чему научиться»). Выбор круга в фокус также делает его видимым, и лучший круг его
  класса тоже. Фокус на эталоне сравнивает его с тем другим кругом, который был быстрее всех
  на каждом повороте.
- **Классы:** при кругах нескольких классов производительности каждый круг сравнивается с
  самым быстрым полным кругом своего класса (эталоном, в классе эталона). См.
  [Статистика трассы](race-course-statistics.md).

### Цвета {#colours}

Каждый круг получает свой цвет по порядку загрузки, так что круг сохраняет цвет, когда другие
скрыты. Оттенки распределены по цветовому кругу так же, как режим команд тепловой карты
распределяет группы; для каждого места светлота (от 0,52 до 0,66 в OKLCH) и насыщенность
(от 0,12 до 0,18) подбираются так, чтобы стоять как можно дальше от соседних мест (а последний -
от первого)
при обычном, протанопическом и дейтеранопическом зрении, каждый не меньше 3:1 к тёмной поверхности графика.

### Как читается каждый формат {#how-each-format-is-read}

Каждый формат становится одним `LapTrace`: каналы под каноническими именами
(`time`, `distance`, `x`, `y`, `z`, `speed`, `throttle`, `slipRatio.FL` ...,
см. [таблица каналов](race-charts-and-hud.md#the-channel-table)), машина,
время круга, полный ли это круг, и блок `meta`. Для каждого формата `time` и
`distance` сдвигаются, чтобы начинаться с 0, а если в источнике нет `speed`, он
вычисляется как расстояние, делённое на время, по соседним точкам.

#### JSON heat3d-lap {#heat3d-lap-json}

JSON-объект с `"format": "heat3d-lap"`. Читаемые поля:

| Поле | Назначение |
|---|---|
| `channels` | объект из массивов, по одному на канал, под каноническими именами; каналы по каждому колесу как `name.FL`, `name.FR`, `name.RL`, `name.RR`. `time`, `x` и `z` обязательны |
| `car.carOrdinal`, `car.name`, `car.carClass`, `car.carPI`, `car.drivetrain` | машина: id, название, индекс класса Forza (0 D, 1 C, 2 B, 3 A, 4 S1, 5 S2, 6 X), индекс производительности, код привода (0 FWD, 1 RWD, 2 AWD) |
| `lap.seconds` | время круга; если его нет, последнее значение `time` |
| `lap.complete` | `false` отмечает неполный заезд; всё остальное - полный круг |
| `game`, `track` | названия; `game` определяет дисциплину (см. ниже) |
| `units.slipRatio` / `units.slipAngle` | как масштабируется проскальзывание: единица с `raw` означает `scaled`, `normalised` - `peak`, всё остальное - `physical` |
| `meta` | `slip`, `surface`, `discipline`, если заданы, переопределяют всё выше |

Без канала `distance` расстояние суммируется по трёхмерным позициям.

#### Файлы кругов FH Companion {#fh-companion-lap-files}

JSON-объект с объектом `Lap`, в котором массив `samples` (одна точка примерно
каждые 5 м). Поля сопоставляются так:

| FH Companion | Канал |
|---|---|
| `Metres`, `Seconds` | `distance`, `time` (сдвинуто так, чтобы круг начинался с 0) |
| `X`, `Y`, `Z` | `x`, `y`, `z` |
| `Speed`, `Throttle`, `Brake`, `Steer`, `Clutch`, `HandBrake`, `Gear` | то же, в нижнем регистре |
| `LatG`, `LongG` | `latAcc`, `longAcc` (м/с², несмотря на название) |
| `Puddle` | `puddle` |

Машина берётся из `Lap.carOrdinal`, `Lap.carName` (только в новых файлах),
`Class` (или `Lap.carClass` как индекс класса Forza), `Lap.performanceIndex`,
`Lap.drivetrain` и `Lap.peakKilowatts`; время - из `Lap.lapSeconds`; заезд с
`EndedAtFinish: false` - неполный. Игра - `forza-horizon`.

В этих файлах нет данных шин и курса, поэтому блокировки, пробуксовку и заносы
по ним одним не оценить; толчки (по рулю относительно пути) и удары и аварии
- всё ещё можно. Для остального выбирайте и `.tele.gz`, который лежит рядом с
каждым из них.

#### Телеметрия FH Companion (`.json.tele.gz`) {#fh-companion-telemetry-jsontelegz}

JSON, сжатый gzip, `{ version, columns, data }`: весь Data Out Forza для одного
круга, по одной строке на пакет, собственные имена полей игры. Столбцы ищутся по
имени, никогда по позиции. Формат 2 сохраняет каждый пакет (около 110 в секунду
против 64 тактов игры); строка, идентичная предыдущей во всём, кроме собственных
часов записывающего устройства (`t`, `metres`), отбрасывается, так что круг
читается с 64 строками в секунду игры. (Подсказка кнопки загрузки об этом говорит:
«для проскальзывания каждой шины на 64 Гц».)

| Поле Data Out | Канал |
|---|---|
| `t`, `metres` | `time`, `distance` |
| `PositionX/Y/Z` | `x`, `y`, `z` |
| `Yaw`, `Pitch`, `Roll` | `yaw`, `pitch`, `roll` |
| `VelocityX/Y/Z` | `latVel`, `vertVel`, `longVel` (система машины: x вправо, y вверх, z вперёд) |
| `AccelerationX/Y/Z` | `latAcc`, `vertAcc`, `longAcc` |
| `AngularVelocityY` | `yawRate` |
| `Speed`, `CurrentEngineRpm`, `Gear`, `Power`, `Torque`, `Boost`, `Fuel` | `speed`, `rpm`, `gear`, `power`, `torque`, `boost`, `fuel` |
| `Accel`, `Brake`, `Clutch`, `HandBrake` | `throttle`, `brake`, `clutch`, `handbrake`, пересчитаны из 0..255 в 0..1 |
| `Steer` | `steer`, пересчитан из -127..127 в -1..1 |
| `NormalizedSuspensionTravel<Wheel>` | `suspension.<W>` |
| `TireSlipRatio<Wheel>`, `TireSlipAngle<Wheel>`, `TireCombinedSlip<Wheel>` | `slipRatio.<W>`, `slipAngle.<W>`, `combinedSlip.<W>` |
| `TireTemp<Wheel>` | `tireTemp.<W>`, переведено из Фаренгейта в °C |
| `WheelRotationSpeed<Wheel>`, `WheelInPuddle<Wheel>`, `WheelOnRumbleStrip<Wheel>`, `SurfaceRumble<Wheel>` | `wheelSpeed`, `puddle`, `rumble`, `surfaceRumble` по каждому колесу |

`<Wheel>` - это `FrontLeft`, `FrontRight`, `RearLeft`, `RearRight` →
`FL`, `FR`, `RL`, `RR`. Проскальзывание отмечено как `peak` (нормированное
проскальзывание Forza: за пределом 1 шина потеряла сцепление).

**Пара.** Файл круга `<lap>.json` и `<lap>.json.tele.gz`, выбранные или
перетащенные вместе (тот же путь, только `.tele.gz`), становятся **одним** кругом:
каналы телеметрии с машиной, классом, временем, трассой и флагом неполного круга
из файла круга. Название машины из файла телеметрии важнее, когда оно есть.
`.tele.gz` без файла круга тоже загружается: файлы формата 2 содержат `car`
(`ordinal`, `name`, `class`, `pi`), `track` и `lapSeconds`; без них время круга -
собственная длительность телеметрии, а машина неизвестна.

#### iRacing `.ibt` {#iracing-ibt}

Файл телеметрии iRacing читается напрямую (в браузере, без конвертации): заголовок
из 112 байт, подзаголовок диска из 32 байт, таблица переменных (144 байта на канал)
и YAML сессии.

- **Обязательные каналы:** `SessionTime`, `Lap`, `Lat`, `Lon`. Без них:
  «… не содержит каналов SessionTime, Lap, Lat и Lon - это файл телеметрии iRacing?»
- **Позиции:** широта и долгота раскладываются в метрах на плоскости, касательной к
  первой ненулевой фиксации (радиус Земли 6 371 008,8 м): x на восток, z на юг, y -
  высота (`Alt`), поэтому при стандартной камере север смотрит вверх экрана. Это не
  собственная система координат трассы: извлечённая модель трассы не совпала бы.
- **Круги:** сессия делится там, где меняется `Lap`; круг сохраняется, если в нём
  больше 60 точек, он начинается ниже 5% `LapDistPct` и заканчивается выше 95%.
  Неполные круги отбрасываются. Если не осталось ни одного: «… не содержит полного
  круга трассы N км» (длина трассы из YAML) или «… не содержит полного круга».
- **Расстояние:** `LapDist` от старта круга, иначе суммируется по позициям.
- **Машина:** из `DriverInfo`: `CarScreenName` игрока, `CarID` (как номер машины) и
  `CarClassShortName` (как класс). Трасса: `TrackDisplayName`, иначе `TrackName`.

Сопоставленные каналы:

| iRacing | Канал | Пересчёт |
|---|---|---|
| `Speed`, `Throttle`, `Brake`, `Gear`, `RPM` | те же имена | - |
| `Clutch` | `clutch` | `1 - v` (iRacing считает включение сцепления; у нас - педаль) |
| `SteeringWheelAngle` | `steer` | `-v / SteeringWheelAngleMax` (радианы против часовой в -1..1, вправо положительно; максимум не меньше 0,1, π если нет) |
| `LatAccel`, `LongAccel`, `VertAccel` | `latAcc`, `longAcc`, `vertAcc` | - |
| `Yaw`, `Pitch`, `Roll`, `YawRate` | те же, в нижнем регистре | - |
| `BrakeABSactive` | `absActive` | - |
| `dcABS`, `dcTractionControl` | `absLevel`, `tcLevel` | - |
| `dcBrakeBias` | `brakeBias` | делится на 100, если больше 1,5 |
| `dcPitSpeedLimiterToggle` | `pitLimiter` | - |
| `FuelLevel`, `WaterTemp`, `OilTemp` | `fuel`, `waterTemp`, `oilTemp` | - |
| `LFtempCM` ... | `tireTemp.FL` ... | температура середины каркаса |
| `LFshockDefl` ... | `suspensionM.FL` ... | прогиб амортизатора, м |
| `LFpressure` ... | `tirePressure.FL` ... | × 0,145038 (кПа в psi) |
| `LFwearM` ... | `tireWear.FL` ... | `1 - v` |

Префиксы колёс: `LF` → FL, `RF` → FR, `LR` → RL, `RR` → RR. **Каждый другой**
канал с одним значением на точку (не битового типа) передаётся под своим именем -
по каждому колесу, если начинается с префикса колеса (`RRspeed` становится
`speed.RR`), - поэтому графики и списки значений на карточках предлагают их все.
iRacing не записывает проскальзывание шин: управление машиной оценивается по углу
заноса - `Yaw`, подогнанному под направление движения, относительно того, куда
едет машина, - и по рулю относительно пути. Рыскание относительно боковому
ускорению используется, только когда курс нельзя подогнать, поэтому угла заноса
тогда нет (см. [События контроля машины](race-control-events.md)).

Ошибки: «… слишком короткий для файла .ibt», «… не имеет заголовка телеметрии
iRacing», «… не имеет фиксаций позиции».

#### CSV круга {#lap-csv}

Одна строка на точку; много кругов в одном файле различаются по столбцу `lap`.
Разделитель определяется по первым пяти строкам. Необязательная первая строка
`# { ...json... }` описывает заезд: `game`, `track`, `seconds`, `complete`, `meta`,
`car`.

| Столбец (без учёта регистра) | Канал |
|---|---|
| `x`, `y`, `z` | позиция (`x` и `z` обязательны) |
| `elapsed` или `time` | `time` (обязателен для каждого круга) |
| `metres` или `distance` | `distance` (иначе суммируется по позициям) |
| `speed_ms` или `speed` | `speed` (м/с) |
| `throttle`, `brake`, `steer`, `gear`, `clutch`, `handbrake`, `puddle` | то же |
| `lat_g`, `long_g` | `latAcc`, `longAcc` |
| любое каноническое имя канала, например `latVel`, `slipIndex.FL` | оно само |
| `lap` | к какому кругу относится строка |
| `lap_seconds`, `car`, `car_class`, `pi`, `course` | время круга, номер машины, класс, PI, трасса (из первой строки каждого круга) |

Без описания игра принимается как `forza-horizon`, а каждый круг - как полный.
Источник круга показывается как `<файл> · <круг>`, когда в файле несколько кругов.
Ошибки: «… не содержит строк», «… не содержит столбцов x и z», «… не содержит кругов
со столбцом времени».

#### Дисциплина и покрытие {#discipline-and-surface}

Что анализ предполагает о круге, когда круг этого не говорит (`lap.ts`):

- **Дисциплина:** `meta.discipline`, иначе название игры, совпадающее с
  `rally|wrc|dirt|rbr`, - это **ралли**, `trackmania` - **аркада**, всё остальное -
  **трасса**.
- **Покрытие:** `meta.surface`, иначе по названию трассы и источнику: ралли с
  названием `monte` - **смешанное**; `snow|ice|winter|arctic|sweden` - **снег**;
  асфальтовые ралли (Spain/España/Catalunya/Costa Daurada, Croatia/Hrvatska,
  Central Europe, Germany/Deutschland, Japan, Corsica/Corse, Ypres, или слова
  tarmac/asphalt) - **асфальт**; любое название с
  `scramble|trail|cross country|dirt|gravel` - **рыхлое**; другой этап ралли
  оценивается по тому, как вели машину: по точкам быстрее 12 м/с и на покрытии
  (не меньше 200 таких точек), 95-й процентиль бокового ускорения 10 м/с² и больше
  вместе с медианным углом заноса меньше 6° (взятым там, где машина проходила
  поворот на 70% этой скорости или больше, не меньше 30 точек), - это асфальт;
  всё остальное или то, по чему нельзя решить, - рыхлое. Название не ралли
  со словом `rally` - рыхлое; всё остальное - асфальт.
- Для каждой точки канал `loose` (тряска покрытия Forza, материалы Trackmania, см.
  [События контроля машины](race-control-events.md#the-ground)) переопределяет
  покрытие круга.
