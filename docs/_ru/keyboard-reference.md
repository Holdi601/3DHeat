# Справочник клавиатуры и мыши

Все действия клавиатуры и мыши в одном месте, чтобы вы быстро нашли нужное. Сначала щёлкните по виду, чтобы он получил клавиатуру. Клавиши не работают, пока фокус находится в текстовом поле или в выпадающем списке. Короткая версия также печатается в левом нижнем углу вида.

Быстрый поиск:

| Я хочу ... | Нажмите |
|---|---|
| лететь | `W A S D`, перетаскивайте, чтобы смотреть |
| увидеть всё | `F` |
| играть или ставить на паузу | `K` |
| играть назад | `J` (нажмите снова, чтобы остановить), вперёд `L` |
| узнать, что значат цвета | `?` или `F1` |
| отменить во вкладке «Тактика» | `Ctrl+Z` |

## Камера {#camera}

Из [`camera.ts`](https://github.com/Holdi601/3DHeat/blob/main/src/render/camera.ts).

| Ввод | Действие |
|---|---|
| `W` / `↑` | Вперёд по направлению взгляда |
| `S` / `↓` | Назад |
| `A` / `←` | Шаг влево |
| `D` / `→` | Шаг вправо |
| `Space` / `E` | Вверх |
| `Q` / левый `Ctrl` | Вниз |
| `Shift` (любой) | Удерживать: скорость ×6 |
| левый `Alt` | Удерживать: скорость 15% |
| Перетаскивание левой или правой кнопкой по виду | Смотреть (указатель захватывается, пока кнопка нажата) |
| Колёсико (перспектива) | Скорость полёта ×1,5 за щелчок колёсика (не больше 4 щелчков за одно событие колёсика) |
| Колёсико (параллельная проекция) | Масштаб |
| Правый щелчок | Над видом контекстное меню не открывается |

## Общие {#global}

Из [`App.tsx`](https://github.com/Holdi601/3DHeat/blob/main/src/App.tsx).

| Клавиша | Действие |
|---|---|
| `K` | Играть / остановить [временную шкалу](timeline.md) |
| `F` | Показать все данные в кадре |
| `C` | Скопировать положение камеры, рыскание и тангаж ([показания камеры](camera.md#camera-readout)) |
| `G` | Перейти к введённой точке: открывает поле под показаниями камеры |
| `Esc` | Закрыть карточку выбора; затем перестать смотреть на второй объект; затем перестать следовать за объектом |
| `T` | Тактический вид включить или выключить ([Повтор матча](match-replay.md#display-style)) |
| `?` / `F1` | Режим справки: что значат цвета ([Настройки, единицы и клавиши](settings.md#help-mode)) |
| `1` | [Тепло](heat.md) |
| `2` | [Разность](difference.md) |
| `3` | [Тепло команд](team-heat.md) |
| `4` | [Линии](line-heat.md) |
| `]` | Дальняя граница отсечения наружу ×1,12 (`Shift`: ×1,35) |
| `[` | Дальняя граница отсечения внутрь ÷1,12 (`Shift`: ÷1,35) |
| `\` | Дальняя граница отсечения выключить / включить обратно там, где была ([Глубина и отсечение](depth-and-culling.md#keyboard)) |

У режима **Наложение фигур** нет клавиши с цифрой. Выберите его в панели режимов или откройте вкладку «Матч». Клавиши с цифрами проходят ту же проверку, что и панель режимов: клавиша для режима, который панель показывает как недоступный для загруженных данных, ничего не делает.

## Повтор матча {#match-replay}

В режиме Наложение фигур, которым пользуется вкладка «Матч» ([Повтор матча](match-replay.md)). Они работают, когда объект выбран для слежения или нет, если не указано иное:

| Клавиша | Действие |
|---|---|
| `B` | Добавить закладку: момент и камера |
| `M` | Карта 2D: в углу, на весь вид, выключена |
| `V` / `Shift+V` | Следующий / предыдущий вид камеры для объекта, за которым следите |
| `H` | Индикатор на лобовом стекле в кабине и в видах с захватом |
| `Page Down` / `Page Up` | Следующее / предыдущее событие тех видов, которые показывает список событий |
| `J` | Играть назад; ещё раз — пауза |
| `L` | Играть вперёд; ещё раз — пауза |
| `.` / `,` | Секунда вперёд / назад, на паузе (`Shift`: десять секунд) |
| `Esc` | Сначала перестать смотреть на цель, затем перестать следовать |
| `Ctrl` + щелчок или `Alt` + щелчок по объекту (в виде или в списке объектов) | Смотреть на него от объекта, за которым следите (вид из двух объектов); щёлкните ещё раз, чтобы снять |
| `Shift` + щелчок по двум объектам | Измерить между ними: пеленг, дальность, разница высот |

`V` нужен объект, за которым следите. `M` здесь — карта 2D, а во вкладке «Тактика» — «перемещение».

## Слежение за объектом {#following-a-unit}

Пока камера следит за объектом, колёсико и клавиши полёта двигают её вокруг объекта, а не свободно ([Камера](camera.md#while-following-a-unit)):

| Ввод | Действие |
|---|---|
| Колёсико, `W` / `S` | Ближе / дальше (выше / ниже в спутниковом виде). Не работает в кабине и в видах с захватом. |
| `A` / `D`, `Q` / `E` | Орбита вокруг объекта (виды «преследование» и «орбита») |
| Перетаскивание | Смотреть вокруг объекта; в кабине — смотреть внутри неё |
| `V` / `Shift+V` | Следующий / предыдущий вид камеры |
| `H` | Индикатор на лобовом стекле (виды кабины и захвата) |
| `Esc` | Перестать смотреть на второй объект, затем перестать следовать |

## Доска тактики {#tactics-board}

Во вкладке «Тактика» ([Доска тактики](tactics-board.md)). `F`, `C`, `G` и `T` работают, как описано выше; клавиши с цифрами ничего не делают.

| Клавиша | Действие |
|---|---|
| `Ctrl+Z` | Отменить |
| `Ctrl+Y` или `Ctrl+Shift+Z` | Повторить |
| `Enter` | Закончить стрелку, которую рисуете (двойной щелчок или правый щелчок делают то же самое) |
| `Esc` | Отменить перетаскивание; иначе убрать стрелку или перемещение, которое идёт; иначе снять выделение |
| `Delete` или `Backspace` | Удалить выделенное |
| `W` / `E` / `R` | Инструмент «Перемещение» / «Поворот» / «Масштаб» для выделения (схема клавиш **W / E / R**) |
| `G` / `R` / `S` | Инструмент «Перемещение» / «Поворот» / «Масштаб» для выделения (схема клавиш **G / R / S**) |
| `R` | Когда ничего не выделено: повернуть следующую фигуру для установки на 15°. `Shift+R` поворачивает её обратно. |
| `M` | Когда выбрана фигура: переместить её по следующему щелчку |
| `K` | Играть или остановить план |
| Shift + щелчок | Добавить в выделение или убрать из него |
| Shift + перетаскивание | Нарисовать рамку вокруг того, что нужно выбрать |
| `Ctrl` при перетаскивании ручки | Привязка к сетке или к шагу угла |

Клавиши инструмента работают, только когда что-то выделено. Если ничего не выделено, `W A S D` двигают камеру, как обычно.

## Выбор щелчком {#click-to-pick}

Когда включено **Щелчок показывает, что там**, а линейка выключена ([Выбор щелчком](camera.md#click-to-pick)):

| Ввод | Действие |
|---|---|
| Щелчок левой кнопкой (без перетаскивания больше чем на 4 пикселя) | Показать точку данных или, если её нет, место на уровне под указателем |

## Измерение {#measure}

Когда **Линейка активна** ([Измерение](measure.md)):

| Ввод | Действие |
|---|---|
| Щелчок левой кнопкой (без перетаскивания больше чем на 4 пикселя) | Поставить точку |
| Правый щелчок | Убрать последнюю точку |

## В других местах {#elsewhere}

| Где | Ввод | Действие |
|---|---|---|
| Ручка любого ползунка (рядом с числом) | Перетащить вверх / вниз | Значение меняется плавно, быстрее, чем дальше вы тянете; удерживайте `Shift` для точной настройки. Отпустите, чтобы остановить. |
| Индикатор скорости над видом | Перетащить вверх / вниз | Скорость полёта меняется так же. |
| Поля положения | `Enter` | Применить введённое положение или ориентацию. |
| Редактор кривой | Двойной щелчок / Alt + щелчок / правый щелчок | Добавить точку / убрать точку ([Форма спрайта](sprite-shape.md#the-curve-editor)). |

## Вкладка «Анализ заездов» {#race-analysis-tab}

Во вкладке «Анализ заездов» `K` запускает и останавливает повтор заезда, `Home` перематывает его в начало, а клавиши с цифрами ничего не делают. См. [Анализ заездов](race-analysis.md).

## Клавиши, которые просмотрщик оставляет себе из браузера {#keys-the-viewer-keeps-from-the-browser}

Некоторые сочетания браузера закрыли бы или перезагрузили страницу и потеряли бы загруженный сеанс; просмотрщик оставляет их себе. Список создан из кода: [Клавиши браузера](ref-browser-keys.md).
