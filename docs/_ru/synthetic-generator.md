# Генератор синтетических данных

Своих данных нет? Нажмите одну кнопку, и 3DHeat придумает для вас воображаемый бой — такой маленький или большой, какой хотите.

1. Откройте панель **Набор данных** на боковой панели тепловой карты (ниже **Источник**).
2. Прокрутите до **Синтетический генератор**.
3. Задайте **Строки (млн)**. Для первого раза попробуйте 1: значение по умолчанию, 8 миллионов, для первой попытки слишком тяжёлое.
4. Нажмите **Сгенерировать**.

![1 миллион строк, 8 команд, нарисованных в режиме «Тепло команд»](../assets/img/en/synthetic-generator-team-heat.webp)

Панель **Набор данных** может создать набор данных вместо загрузки. Это нужно для двух вещей: попробовать просмотрщик без своих данных и проверить, удерживает ли машина нужное число строк, радиус спрайта и бюджет приемлемую частоту кадров, *прежде* чем загружать на неё большой настоящий набор. Движение в нём устроено как матч «королевской битвы»: команды стартуют врозь, а потом их сжимает вместе, потому что равномерный шум выглядит нормально при любом бюджете и скрывает как раз те артефакты, которые стоит ловить.

## Элементы управления {#controls}

| Элемент | По умолчанию | Значение |
|---|---|---|
| **Строки (млн)** | 8 | Сколько строк создать. Округляется вниз до целого числа тиков для каждого игрока. |
| **Команды** | 8 | Число групп (не меньше 1). |
| **В команде** | 12 | Игроков в группе (не меньше 1). |
| **Половина размера карты (m)** | 4000 | Половина ширины игровой зоны по X и Z. |
| Строка оценки | | «≈ X ГБ ОЗУ, Y ГБ на GPU после квантования.» (около 26 байт ОЗУ и 8 байт на GPU на строку). |
| **Сгенерировать** | | Генерирует в рабочем потоке загрузки, с индикатором хода, и заменяет любой загруженный набор данных. |

Генерация идёт в фоновом рабочем потоке, поэтому десятки миллионов строк не замораживают страницу.

## Что генерируется {#what-it-generates}

Из [`src/data/synth.ts`](https://github.com/Holdi601/3DHeat/blob/main/src/data/synth.ts):

- **Столбцы:** позиция, время, персона (`P000`, `P001`, ...), группа (`Team 1`, `Team 2`, ...), рысканье и тангаж, а также времена жизни. Столбца сессии и столбцов фильтров нет.
- **Время:** один отсчёт на каждого игрока каждые 0,25 с, начиная с 0 (относительное время, без часов).
- **Движение:** каждая команда стартует в своём секторе кольца на расстоянии 55–95% от половины размера карты. Безопасный круг, центр которого близок к середине (смещённый случайно до четверти половины размера), сжимается до 8% половины размера за шесть фаз с плато; каждый игрок рулит к блуждающей точке внутри него, с затуханием и шумом. Высота колеблется между 0 и 220 м.
- **Направление взгляда:** рысканье по направлению движения, тангаж по вертикальной скорости.
- **Повторяемо:** зерно случайных чисел фиксировано (1337), поэтому одинаковые настройки всегда дают одинаковые данные.

На нём работают все режимы тепла, наложение фигур и линейное тепло (целые треки, так как столбца событий нет). Работает и история времени жизни.
