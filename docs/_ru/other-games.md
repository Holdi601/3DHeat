# Другие гоночные игры в просмотрщике

Просмотрщик читает круги из многих гоночных игр, а не только из одной. На этой странице они перечислены и объясняется, как получить круг из каждой.

## Игры {#the-games}

| Игра | Запись | Занос в файле? | Мир отражён? | Примечания |
|---|---|---|---|---|
| Forza Horizon 4/5/6, Forza Motorsport | `heat3d_capture telemetry` (Data Out по UDP) или файлы кругов FH Companion и их `.tele.gz` | да, для каждого колеса (нормированный) | да (левосторонний мир) | `.tele.gz` рядом с каждым файлом круга FH Companion даёт занос каждого колеса; один файл круга этого не даёт |
| Assetto Corsa, ACC, AC EVO, AC Rally | `heat3d_capture telemetry --game ac / acc / acevo / acrally` (общая память) | да, для каждого колеса | измеряется по кругам | также работа ABS и системы контроля тяги, нагрузки на колёса, температуры |
| EA SPORTS WRC, DiRT Rally 2.0 / 1, DiRT 4 | `heat3d_capture telemetry --game wrc / dirtrally2 / dirtrally / dirt4` (UDP) | нет, вычисляется по скоростям колёс | измеряется по кругам | ралли: рыхлое покрытие и прыжки оцениваются по-другому |
| Richard Burns Rally | `heat3d_capture telemetry --game rbr` (NGP UDP) | нет | измеряется по кругам | скоростей колёс нет |
| BeamNG.drive | `heat3d_capture telemetry --game beamng` (мод) | нет, вычисляется по скоростям колёс | измеряется по кругам | |
| Trackmania | плагин Openplanet, `telemetry --game trackmania --install` | коэффициент скольжения для каждого колеса | измеряется по кругам | аркадная физика: заносы оцениваются по-другому |
| iRacing | нет: её собственный файл `.ibt` | нет (не записывается); вычисляется по рысканию | нет (по GPS) | включите запись в машине клавишами Alt+L |

## Как записать круг {#how-to-record-a-lap}

1. Выберите свою игру в таблице и настройте её так, как написано на странице записи для этой игры (настройка в игре, мод или ничего, как для iRacing). Шаги отличаются для каждой игры, поэтому они описаны в документах записи: [GameCapture: игры](https://github.com/Holdi601/3DHeat-GameCapture/blob/main/docs/games.md).
2. Запустите запись и поезжайте. Она пишет один файл на каждый круг.
3. На вкладке **Анализ заездов** нажмите **Загрузить файлы кругов…** и выберите два или больше кругов одной трассы (см. [Загрузка кругов](race-loading-laps.md)).

Для ралли запись даёт один файл на каждый прогон этапа. Для Forza проще всего начать с библиотеки FH Companion и её файлов `.tele.gz` рядом с файлами кругов.

## Что описывают записи {#what-the-recorders-document}

Как записывается каждая игра, что она передаёт, источники её форматов и какие трассы можно экспортировать из её файлов, описывают записи: [GameCapture: игры](https://github.com/Holdi601/3DHeat-GameCapture/blob/main/docs/games.md) (открыто, в [3DHeat-GameCapture](https://github.com/Holdi601/3DHeat-GameCapture)). Файл круга, который пишет любая запись, описан в [GameCapture: формат круга](https://github.com/Holdi601/3DHeat-GameCapture/blob/main/docs/lap-format.md).

## Что просмотрщик делает с этими данными {#what-the-viewer-does-with-them}

Каждая игра в итоге превращается в файлы `heat3d-lap` (или CSV-таблицу круга, или файл читается напрямую, как `.ibt` у iRacing) с каноническими именами каналов из `src/race/schema.ts` и блоком `meta`, в котором сказано, что означают её числа: как масштабируется её занос, круговая трасса, ралли или аркада, покрытие, если оно известно. Поэтому вкладка **Анализ заездов** обрабатывает их всех одинаково. Если модель трассы не загружена, вкладка **Анализ заездов** рисует дорогу по разбросу самих кругов, так что каждой игрой можно пользоваться и без модели.

Чего не передаёт ни одна ралли-игра, то есть занос шин, просмотрщик вычисляет сам: по скорости контактного пятна или поверхности каждого колеса относительно скорости машины там, где игра её передаёт (`(колесо - машина) / машина`), а там, где игра передаёт только вращение, по вращению и радиусу качения, измеренному на самом круге. Угол сноса берётся из собственной скорости машины (Forza, игры AC, Trackmania, RBR), из мировой скорости, спроецированной на оси машины (EA WRC, DiRT, BeamNG), или из курса относительно пути. То, что машина в воздухе, определяется по контакту колёс, нагрузкам или подвеске. См. `src/race/derive.ts`.

Если мир игры левосторонний, как у Forza, трасса в просмотрщике выходит зеркальной. Это видно по рулевому управлению и подвеске на кругах, и вкладка **Анализ заездов** предлагает инвертировать ось. Игры, у которых не задокументировано, левосторонний ли у них мир (RBR, BeamNG, Trackmania), обрабатываются так же: это измеряется, а не предполагается.

Помимо каналов вождения записи сохраняют то, что добавляет каждая игра: срабатывание ABS и контроля тяги в играх AC, распределение тормозов, DRS, ограничитель скорости в боксах, наддув и ресурс тормозных колодок и дисков; у iRacing настройки помощи, распределение тормозов, топливо, температуры масла и воды и любой другой канал, который она пишет под своим именем. Просмотрщик рисует их по своей таблице каналов (индикаторы, уровни, значки, графики), поэтому запись большего количества данных не требует изменения просмотрщика.
