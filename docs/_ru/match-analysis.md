# Разбор матча (Counter-Strike 2)

Вкладка **Матч** проигрывает запись в виде фигур, а для матча Counter-Strike 2 также показывает таблицу результатов: кто выиграл каждый раунд, как, и кто получил убийства. Используйте её, чтобы разобрать матч раунд за раундом, а потом перейти к тому же моменту на тепловой карте.

Вкладка «Матч» проигрывает любую запись в виде фигур: запись War Thunder или Tacview либо демо CS2, которые перечислены в **Матчи в повторе** ([Повтор матча](match-replay.md)). Файл CS2 `.match.json` добавляет таблицу результатов, описанную на этой странице.

## Разбор матча CS2 {#review-a-cs2-match}

1. Конвертируйте демо ([ниже](#where-the-data-comes-from)) в файлы `.parquet` и `.match.json`.
2. На вкладке **Тепловая карта** загрузите файл `.parquet` в разделе **Источник**.
3. Откройте вкладку **Матч** и нажмите **Загрузить файлы матчей…** или перетащите файл `.match.json` на окно просмотра.
4. Щёлкните матч в **Сводки матчей**, затем ячейку полосы раундов, чтобы открыть этот раунд.
5. Нажмите **Показать раунд**, чтобы увидеть этот раунд на тепловой карте, или **Повтор раунда**, чтобы смотреть его в виде фигур.

![Вкладка «Матч»: полоса раундов с открытым раундом, лента убийств и таблица результатов](../assets/img/en/match-analysis-round.webp)

Слова вроде KAST, ADR, eco, force buy и trade объясняются в [глоссарии](glossary.md#counter-strike-words).

## Откуда берутся данные {#where-the-data-comes-from}

Конвертер демо из [3DHeat CS2](https://github.com/Holdi601/3DHeat-CS2) превращает демо в два файла на матч, в папке на каждую карту:

```bash
python -m heat3d_cs2 demos <demo files or folders> -o out
```

| Файл | Где загружается | Что содержит |
|---|---|---|
| `<match>.parquet` | вкладка **Тепловая карта** (панель «Источник», как любой Parquet: один файл, несколько или вся папка) | положение каждого игрока восемь раз в секунду и каждое событие, где оно произошло: убийство, смерть, ранение, выстрел, бросок, дым, вспышка, HE, молотов, ложная граната, ослепление, закладка, разминирование, взрыв; с `match`, `round`, `roundId`, `event`, `player`, `side`, `team`, направлением взгляда, `weapon`, `place`, `opening`, `traded` … |
| `<match>.match.json` | вкладка **Матч** | команды, счёт, каждый раунд (победитель, как, экономика, закладка, каждое убийство по порядку, клатчи, выжившие), строка таблицы результатов каждого игрока |

Футер файла Parquet содержит инструкции чтения (ключ `heat3d`), поэтому он открывается без каких-либо настроек: игрок становится персоной, сторона — группой, каждый раунд (`roundId`, «<match> #NN») — сессией, включается направление взгляда, а мир стоит правильно (мир CS2 правосторонний с Z вверх; при обычном отображении Z вверх он вышел бы зеркальным). См. [Сопоставление столбцов](column-mapping.md) и [Загрузка файлов](loading-files.md). `python -m heat3d_cs2 map <map>` экспортирует геометрию карты в той же системе, она загружается в **Уровень**.

Правила, стоящие за числами, — правила конвертера (они указаны в его README и записаны в каждой сводке). Убийство считается **отомщённым (traded)**, если убийцу убил один из товарищей погибшего в течение **5 с**; **KAST** — это доля раундов с убийством, передачей (учитывается и передача при вспышке), выживанием или отомщённой смертью; **урон** — это реально потерянное здоровье, только у врагов; **клатч** — это последний живой игрок стороны при живых врагах, выигранный, если его сторона выиграла раунд; **закупка** по каждой стороне определяется по среднему стоимости снаряжения в конце фриз-тайма: первый раунд каждой половины основного времени — пистолетный (в овертайме их нет), затем до $1 500 — эко, до $4 000 — форс-закупка, больше — полная закупка.

## Вкладка {#the-tab}

Боковая панель вкладки «Матч» содержит вверху переключатель режима тепловой карты и выбор сессии, ниже разделы матча, а затем панели **Фильтры**, **Уровень** и **Камера** тепловой карты. Вид — это тепловая карта того Parquet, который загружен на вкладке «Тепловая карта».

### Сводки матчей {#match-summaries}

| Элемент | Что делает |
|---|---|
| **Загрузить файлы матчей…** | выбирает файлы `.json` (сразу несколько): сводки `.match.json` |
| перетащить на окно | файлы JSON, перетащенные на окно, пока открыта вкладка «Матч», загружаются так же (остальные файлы игнорируются) |
| **Очистить** | удаляет все матчи |
| **Все матчи** (при двух и больше) | «N матчей, M раундов»: статистика по всем вместе |
| строка матча | «TeamA 13 : TeamB 9», карта · N раундов: открывает этот матч |

Файл принимается, если это JSON с `"format": "heat3d-cs2-match"` и массивами `rounds`, `players` и `teams`. Ошибки выводятся под кнопками: «<файл>: не JSON», «<файл>: не сводка матча CS2 (heat3d-cs2-match)», «<файл>: нет rounds, players или teams». Матч, загруженный повторно (с тем же именем `match`), заменяет прежний. Матчи сортируются сначала по карте, затем по имени. Если загружен ровно один матч, он открывается; иначе выбор остаётся (по умолчанию все матчи).

Если ничего не загружено, раздел объясняет: конвертируйте через `python -m heat3d_cs2 demos`, загрузите файлы `.match.json` здесь, а файлы `.parquet` — на вкладке «Тепловая карта».

### Матч (открыт один матч) {#match-one-match-open}

**Заголовок:** обе команды с их счётом, карта, половины — «halves 7-5, 6-6»: раунды 1–12 и 13–24 (премьер и соревновательная игра MR12; собственная длина половины из сводки, если она указана, — так что для MR15 это 1–15 и 16–30) — затем, если матч дошёл до овертайма, его счёт отдельно: «overtime 4-2», раунды после обеих половин. Ничейный раунд не засчитывается ни одной команде. И «N раундов обрезано в демо», когда сводка содержит неполные раунды.

**Полоса раундов:** ячейка на каждый раунд, окрашенная в цвет стороны, которая выиграла, с его номером и отметкой о том, как он закончился. Ничейный раунд (без победителя) — нейтральная серая ячейка с отметкой `=`, никогда не цвет стороны; её подсказка говорит: «Раунд 30: ничья — ни одна сторона его не выиграла».

| Отметка | Чем закончился |
|---|---|
| B | бомба взорвалась |
| D | бомба обезврежена |
| K | уничтожены все |
| T | вышло время |
| S | сдача |
| = | ничья |
| ? | иное |

Разделитель отмечает начало второй половины (раунд 13 или раунд после длины половины из сводки) и каждой трёхраундовой половины овертайма (раунды 25, 28, 31, …). При наведении на ячейку: «Раунд 7: TeamA (T) — бомба взорвалась, заложена A» («…, заложена, место неизвестно», если в сводке нет места) и закупка и стоимость снаряжения обеих сторон. Щелчок открывает раунд; повторный щелчок закрывает его («Щёлкните раунд, чтобы увидеть его убийства, экономику и повтор.»).

**Раунд:**

- «Раунд 7: <команда> выиграла — <как>» («Раунд 30: ничья — ни одна сторона его не выиграла» для ничьей) и длительность раунда (от конца фриз-тайма до решения, м:сс);
- экономика: команда каждой стороны, закупка (пистолетная, эко, форс-закупка, полная закупка) и стоимость снаряжения («$4 350»);
- закладка: место, игрок и время в раунде (из любой версии сводки); «Заложена <игроком> в 1:05, место неизвестно», когда место не известно;
- **лента убийств** по порядку: время в раунде, атакующий (цветом своей стороны; «world», если атакующего нет), оружие и метки — **HS** выстрел в голову, **WB** сквозь стену, **SM** сквозь дым; **open** первое убийство раунда, **trade** (отомщение товарища в течение 5 с), **traded** (убийца убит в течение 5 с), **team** — убийство своего (самоубийство не считается). Убийства после того, как раунд был решён, приглушены;
- клатчи: «<игрок> (T) один против 3: клатч выигран» / «клатч проигран»;
- кто был жив в конце, по каждой стороне («никто»);
- **Показать раунд**: всё из этого раунда на тепловой карте;
- **Повтор раунда**: проигрывает раунд как коробки, с его начала (ниже).

Кнопки **Показать на тепловой карте** (см. [ниже](#show-in-the-heatmap)) относятся к этому матчу или к открытому раунду.

### Таблица результатов {#scoreboard}

Таблица на каждую команду, строка на каждого игрока:

| Колонка | Что это |
|---|---|
| K, D | убийства, смерти |
| A | передачи, включая передачи при вспышке |
| ± | убийства минус смерти (зелёным выше 0, красным ниже) |
| ADR | урон за раунд, реально потерянное здоровье |
| KAST | % раундов с убийством, передачей, выживанием или отомщённой смертью |
| HS | % убийств выстрелом в голову |
| Open | выигранные–проигранные открывающие дуэли |
| Cl | выигранные/сыгранные клатчи |

При наведении на игрока: убийства с отомщением, сколько раз отомщён, передачи при вспышке, ослеплённые враги, урон утилитой и раунды с мультиубийствами («2×3k»). **Щёлкните игрока**, чтобы увидеть его убийства и смерти на тепловой карте (этот матч).

### По всем матчам (Все матчи) {#across-matches-all-matches}

По всем загруженным матчам:

- «N матчей · M раундов · <карты>», а также «N раундов ничьих, ни одна сторона их не выиграла», когда были ничьи;
- **Выиграно раундов** по каждой стороне: всего, в **пистолетных** раундах (пистолетные раунды из сводки) и в закупках **эко**, **форс** и **полные** (каждое как процент с числом сыгранных раундов; при наведении «выиграно из сыгранных»). Ничейный раунд сыгран обеими сторонами и не выигран ни одной;
- **Бомба**: закладки по каждому месту и как часто сторона T потом выигрывала такие раунды («12 закладок на A (T выиграла 67%)»), закладки, место которых сводка сама по себе не знает («2 закладки на неизвестном месте (T выиграла 50%)»), или «никогда не закладывали»; как заканчивались раунды, самые частые — первыми;
- «Сторона, которая взяла первое убийство, выиграла N% этих раундов.» (самоубийство не считается первым убийством; ничейный раунд не превращает открытие ни в что);
- **Открывающие дуэли, где**: десять мест с наибольшим числом первых убийств (по месту жертвы; названия мест из игры сделаны читаемыми, «TopofMid» → «Top of Mid»), дуэли и доля, которую выиграла сторона T;
- **Игроки**: пятнадцать лучших по убийствам минус смертям, суммированные по всем их матчам (сопоставляется по Steam ID): матчи, K-D, ADR и KAST, взвешенные по сыгранным раундам, HS% — по убийствам, открывающие дуэли. **Щёлкните игрока**, чтобы увидеть его убийства и смерти по всем матчам на тепловой карте.

Кнопки «Показать на тепловой карте» для всех загруженных матчей стоят под этим блоком.

## Показать на тепловой карте {#show-in-the-heatmap}

Каждая ссылка задаёт собственные **фильтры** тепловой карты, поэтому показанное остаётся видимым и редактируемым в панели «Фильтры», а **Показать все** их очищает. Они работают с таблицей тепловой карты, загруженной на вкладке «Тепловая карта»; вкладка «Матч» сама её никогда не загружает.

| Кнопка | Какие события показываются |
|---|---|
| **Позиции** | `position` — где были игроки, восемь раз в секунду |
| **Убийства** | `kill` — где стоял убийца |
| **Смерти** | `death` — где упала жертва |
| **Первые убийства** | `kill` и `death` с `opening` = 1 — первое убийство каждого раунда, где стояли обе стороны (предлагается, только если в таблице есть столбец `opening`) |
| **Смоки** | `smoke` — где упали дымы |
| **Флешки** | `flash` — где вспыхнули вспышки |
| **Молотовы** | `molotov` — где горели молотовы и зажигательные гранаты |
| **HE** | `he` — где взорвались осколочные гранаты |
| **Закладки** | `plant` — где заложили бомбу |
| **Выстрелы** | `shot` — откуда стреляли |

Область зависит от того, где стоит кнопка: все загруженные матчи, этот матч или этот раунд («Показать на тепловой карте — раунд 7»).

Что нельзя применить, сказано под кнопками, а не молча отфильтровано до пустоты: «столбец матча не сохранён — матч не применён», «матч: X нет в загруженных данных», то же для раунда и событий, «игрок X нет в загруженных данных», «сторона X нет в загруженных данных», «данные тепловой карты не загружены: загрузите файлы .parquet матчей на вкладке «Тепловая карта»». Без загруженных данных ссылки также говорят «Загрузите файлы .parquet матчей на вкладке «Тепловая карта», чтобы увидеть их на карте.».

**Повтор раунда** дополнительно переключает тепловую карту в **Повтор коробок**, шкалу времени — в режим *воспроизведение* с окном *время жизни*, перематывает к началу сессии раунда и запускает воспроизведение. Если раунд не является сессией загруженных данных: «этот раунд не является сессией загруженных данных: нечего повторять».

### Версии сводок {#summary-versions}

Вкладка читает сводки версии 1 и версии 2 (`"version"` в файле) рядом и обрабатывает их одинаково:

| | Версия 2 | Версия 1 |
|---|---|---|
| время закладки | секунды в раунде, как и убийства | секунды матча; вкладка вычитает начало раунда |
| место закладки | `A` или `B`; пусто, если демо этого не сообщает | `A`, `B` или номер сущности — читается как неизвестное место |
| длина половины | `halfLength`, от момента, когда стороны впервые меняются; 12, если null | 12 (MR12) |
| пистолетные раунды | `pistolRounds` (первый раунд и первый раунд после половины) | раунды, у которых закупка `pistol` |
| ничейный раунд | `winner` и `winnerTeam` пусты | — |
| самоубийство | `suicide` у убийства, никогда не тимкилл | определяется по тому, что атакующий и жертва — один и тот же игрок |

`noscope` и `attackerBlind` убийства (версия 2) не показываются на вкладке «Матч», которая также не показывает место из таблицы тепловой карты, поэтому пустое `place` строки гранаты там ничего не меняет.

Как фокус превращается в фильтры (`focusFilters`):

- **match** → фильтр по категории по столбцу `match`;
- **round** → фильтр диапазона `round` = N по числовому столбцу `round` (фильтр по категории для категориального), а сессия раунда (`<match> #NN`) выбирается в выборе сессии;
- **events** → фильтр по категории по столбцу `event`;
- **player** → фильтр персоны по этому игроку;
- **side** → фильтр группы.
