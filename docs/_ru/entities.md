# Объекты

**Объекты** позволяют выбрать одного игрока (или несколько), чтобы видеть только то, где был этот игрок. Используйте, чтобы следить за своим собственным перемещением или за одним соперником.

Панель показывается, когда в наборе данных есть столбец персон. В её заголовке указано число персон или `выбрано из всех`, пока выбор активен (*персона* — это один игрок или ИИ, см. [глоссарий](glossary.md)).

## Выбрать игрока {#pick-a-player}

1. Откройте **Объекты** на боковой панели.
2. Введите часть имени в поле поиска.
3. Поставьте отметку у игрока. В заголовке будет, например, `2 из 10`, и всё остальное исчезнет.
4. **Очистить** снова показывает всех.

![Объекты: выбраны два игрока из десяти](../assets/img/en/entities-selected.webp)

Выбор показывает только выбранные персоны в режимах тепла (точки, линии, разность, тепло команд), а также в треках, фигурах и следах [наложения фигур](box-replay.md). Оставьте выбор пустым, чтобы показать всех; выбрать всех — то же самое, что не выбрать никого.

## Панель {#the-panel}

| Часть | Значение |
|---|---|
| Поле поиска | *Поиск среди N объектов...* — фильтрует список по подстроке имени без учёта регистра. Показывает `N совпадений` или `N совпадений, показаны первые 200`; *Ничего не найдено по «...»*, когда поиск ничего не находит. |
| Список | До 200 персон (первые 200 подходящих), у каждой флажок, цветной образец цвета персоны и имя (*(без имени)* для пустого имени). |
| Подсказка «в игре» | Когда время идёт, в списке те, что *в игре на курсоре воспроизведения*; поиск находит всех. |
| **ИИ (n)** | Свёртываемая группа с юнитами под управлением ИИ, отдельно от игроков. |
| **Добавить показанные** | Добавляет в выбор всех, кто сейчас в списке. |
| **Только показанные** | Делает выбор ровно из тех, что в списке. |
| **Очистить** | Очищает выбор. |

## Ограничения {#limits}

В тепле выбор работает как фильтр и занимает один из четырёх [слотов фильтров](filters.md#rules). Когда остальные фильтры уже заняли все четыре, панель говорит *Не применено к теплу: все слоты фильтров заняты. Наложение фигур по-прежнему показывает только этих объектов. Снимите фильтр в разделе «Фильтры», чтобы освободить слот.* Снимите фильтр, чтобы освободить слот.

Выбор очищается при каждом новом наборе данных. Вкладка «Матч» задаёт тот же выбор, когда фокусируется на одном игроке.

## Для разработчиков {#for-developers}

Выбор хранится как фильтр *persons* ([Фильтры](filters.md#for-developers)). Маска в шейдере содержит 65 536 идентификаторов персон; персона сверх этого не рисуется в тепле, пока выбор активен.
