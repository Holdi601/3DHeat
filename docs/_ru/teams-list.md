# Список команд

Панель **Команды** позволяет скрыть команду или поставить её на одну сторону сравнения. Используйте её, чтобы смотреть только на Blue, или чтобы спросить: «куда ходит Blue, а Red туда не ходит?».

*Группа* — это команда или сторона, например Blue и Red ([Группы](sessions-persons-groups.md#group)). Панель показывается, когда в наборе данных есть столбец группы; число групп указано в её заголовке. В режиме «Тепло команд» на боковой панели есть ещё раздел **Просмотр команд** со своими настройками; эта страница описывает список **Команды**.

## Скрыть команду {#hide-a-team}

1. Откройте **Команды** на боковой панели.
2. Снимите отметку у флажка (*Видима*) команды, которую хотите скрыть. Картинка сразу обновится.
3. Нажмите **Показать все**, чтобы вернуть каждую команду.

![Список команд: Blue 5p, Red 5p, с кнопкой Показать все](../assets/img/en/teams-list.webp)

## Каждая строка {#each-row}

| Часть | Значение |
|---|---|
| Флажок (*Видима*) | Показать или скрыть группу. |
| Образец цвета | Цвет группы: её цвет [тепла команд](team-heat.md) в режиме «Тепло команд», её основной цвет в остальных режимах. |
| Имя | Подпись группы (полная подпись при наведении). |
| **+** / **-** (режим «Разность») | Ставит группу на положительную или отрицательную сторону [разности](difference.md); нажмите активную кнопку ещё раз, чтобы не ставить группу ни на одну сторону. |
| `Np` (другие режимы) | Число персон, чья первая строка относится к этой группе. |

![Режим «Разность»: Blue на стороне +, Red на стороне -](../assets/img/en/teams-list-difference.webp)

## Кнопки {#buttons}

| Кнопка | Действие |
|---|---|
| **Показать все** | Делает видимой каждую группу. |
| **Разделить поровну** (режим «Разность») | Первая половина групп (округлённо вверх) на +, остальные на -; одинаковое разделение каждый раз при загрузке. |

## Что делает скрытие группы {#what-hiding-a-group-does}

- В **Тепло**, **Тепло команд** и **Линии** строки группы не дают вклада.
- В **Разность** скрытая группа не даёт вклада, на какой бы стороне она ни стояла, в том числе при разбиении по другому столбцу (см. [Разность](difference.md#for-developers)).
- В **наложении фигур** персоны, чья первая строка относится к этой группе, не рисуются.
- В **Тепло команд** остальные группы сохраняют свои цвета: оттенки назначаются по общему числу групп, а не по видимым, поэтому два изображения остаются сравнимыми.

Изменение видимости перезапускает накопление. При каждом новом наборе данных каждая группа снова видима.

Подсказка панели меняется вместе с режимом: в «Разность» она объясняет + и -; в «Тепло команд» — что образцы показывают цвета, которыми рисуется каждая группа.
