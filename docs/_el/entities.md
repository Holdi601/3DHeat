# Οντότητες

Το πάνελ **Οντότητες** σας αφήνει να διαλέξετε έναν παίκτη (ή μερικούς) για να δείτε μόνο πού πήγε αυτός ο παίκτης. Χρησιμοποιήστε το για να ακολουθήσετε τη δική σας κίνηση ή έναν αντίπαλο.

Το πάνελ εμφανίζεται όταν το σύνολο δεδομένων έχει στήλη προσώπου. Η κεφαλίδα του δείχνει το πλήθος των προσώπων, ή `selected of total` όσο είναι ενεργή μια επιλογή (ένα *πρόσωπο* είναι ένας παίκτης ή ένας AI, βλ. [γλωσσάρι](glossary.md)).

## Διαλέξτε έναν παίκτη {#pick-a-player}

1. Ανοίξτε την **Οντότητες** στην πλαϊνή στήλη.
2. Γράψτε μέρος του ονόματος στο πλαίσιο αναζήτησης.
3. Τικάρετε τον παίκτη. Η κεφαλίδα γράφει, για παράδειγμα, `2 of 10`, και όλα τα υπόλοιπα εξαφανίζονται.
4. Το **Εκκαθάριση** δείχνει ξανά όλους.

![Οντότητες με δύο από τους δέκα παίκτες επιλεγμένους](../assets/img/en/entities-selected.webp)

Η επιλογή δείχνει μόνο τα επιλεγμένα πρόσωπα, στις λειτουργίες θερμότητας (σημεία, γραμμές, διαφορά, θερμότητα ομάδων) καθώς και στις τροχιές, τις φιγούρες και τα ίχνη της [επανάληψης φιγούρων](box-replay.md). Αφήστε την κενή για να δείχνονται όλοι· η επιλογή όλων είναι το ίδιο με το να μην επιλέξετε κανέναν.

## Το πάνελ {#the-panel}

| Τμήμα | Τι σημαίνει |
|---|---|
| Πλαίσιο αναζήτησης | *Search N entities...* - φιλτράρει τη λίστα με υποσυμβολοσειρά του ονόματος, χωρίς διάκριση πεζών και κεφαλαίων. Δείχνει `N matches`, ή `N matches, showing the first 200`· *Nothing matches "..."* όταν η αναζήτηση δεν βρίσκει τίποτα. |
| Λίστα | Έως 200 πρόσωπα (τα πρώτα 200 που ταιριάζουν), το καθένα με πλαίσιο, χρωματικό δείγμα του χρώματος του προσώπου και το όνομα (*(unnamed)* για κενό όνομα). |
| Υπόδειξη σε εξέλιξη | Όταν ο χρόνος παίζει, η λίστα περιέχει εκείνα που *είναι σε εξέλιξη στην κεφαλή αναπαραγωγής*· μια αναζήτηση βρίσκει όλα. |
| **AI (n)** | Μια ομάδα που ανοίγει και κλείνει, με τις μονάδες που ελέγχει το AI, χωριστά από τους παίκτες. |
| **Προσθήκη εμφανιζόμενων** | Προσθέτει στην επιλογή όλους όσους εμφανίζονται τώρα στη λίστα. |
| **Μόνο εμφανιζόμενα** | Κάνει την επιλογή ακριβώς εκείνα που εμφανίζονται στη λίστα. |
| **Εκκαθάριση** | Αδειάζει την επιλογή. |

## Όρια {#limits}

Στη θερμότητα η επιλογή είναι φίλτρο και χρησιμοποιεί μία από τις τέσσερις [θέσεις φίλτρων](filters.md#rules). Όταν τα άλλα φίλτρα έχουν ήδη πιάσει και τις τέσσερις, το πάνελ λέει *Not applied to the heat: all filter slots are taken. The figure replay still shows only these entities. Clear a filter under Filters to free one.* Καθαρίστε ένα φίλτρο για να ελευθερώσετε μια θέση.

Η επιλογή καθαρίζεται σε κάθε νέο σύνολο δεδομένων. Η καρτέλα Match ορίζει την ίδια επιλογή όταν εστιάζει σε έναν παίκτη.

## Για προγραμματιστές {#for-developers}

Η επιλογή αποθηκεύεται ως φίλτρο *persons* ([Φίλτρα](filters.md#for-developers)). Η μάσκα του shader κρατά 65.536 αναγνωριστικά προσώπων· ένα πρόσωπο πέρα από αυτό δεν σχεδιάζεται στη θερμότητα όσο είναι ενεργή μια επιλογή.
