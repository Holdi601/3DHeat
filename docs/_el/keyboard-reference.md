# Αναφορά πληκτρολογίου και ποντικιού

Κάθε πλήκτρο και κάθε ενέργεια ποντικιού σε ένα μέρος, ώστε να βρείτε αυτό που χρειάζεστε. Κάντε πρώτα κλικ στην προβολή, για να πάρει το πληκτρολόγιο. Τα πλήκτρα αγνοούνται όταν έχει την εστίαση ένα πλαίσιο κειμένου ή μια αναπτυσσόμενη λίστα. Η σύντομη εκδοχή τυπώνεται επίσης κάτω αριστερά στην προβολή.

Γρήγορος οδηγός:

| Θέλω να ... | Πατήστε |
|---|---|
| πετάξω | `W A S D`, σύρετε για να κοιτάξετε |
| δω τα πάντα | `F` |
| παίξω ή να βάλω παύση | `K` |
| παίξω προς τα πίσω | `J` (πατήστε ξανά για παύση), προς τα εμπρός `L` |
| δω τι σημαίνουν τα χρώματα | `?` ή `F1` |
| αναιρέσω στην καρτέλα Τακτική | `Ctrl+Z` |

## Κάμερα {#camera}

Από το [`camera.ts`](https://github.com/Holdi601/3DHeat/blob/main/src/render/camera.ts).

| Είσοδος | Αποτέλεσμα |
|---|---|
| `W` / `↑` | Μπροστά, κατά τη διεύθυνση της προβολής |
| `S` / `↓` | Πίσω |
| `A` / `←` | Πλευρική κίνηση αριστερά |
| `D` / `→` | Πλευρική κίνηση δεξιά |
| `Space` / `E` | Πάνω |
| `Q` / αριστερό `Ctrl` | Κάτω |
| `Shift` (οποιοδήποτε) | Κρατημένο: 6× ταχύτητα |
| αριστερό `Alt` | Κρατημένο: 15% ταχύτητα |
| Αριστερή ή δεξιά σύρση πάνω στην προβολή | Βλέπετε γύρω (ο δείκτης κλειδώνει όσο κρατάτε το κουμπί) |
| Τροχός (προοπτική) | Ταχύτητα πτήσης ×1,5 ανά κλικ (το πολύ 4 κλικ ανά γεγονός τροχού) |
| Τροχός (παράλληλη) | Ζουμ |
| Δεξί κλικ | Δεν ανοίγει μενού περιεχομένου πάνω από την προβολή |

## Γενικά {#global}

Από το [`App.tsx`](https://github.com/Holdi601/3DHeat/blob/main/src/App.tsx).

| Πλήκτρο | Αποτέλεσμα |
|---|---|
| `K` | Αναπαραγωγή / παύση της [χρονολογικής γραμμής](timeline.md) |
| `F` | Εστίαση στα δεδομένα |
| `C` | Αντιγραφή της θέσης, του yaw και του pitch της κάμερας ([ένδειξη κάμερας](camera.md#camera-readout)) |
| `G` | Μετάβαση σε σημείο που πληκτρολογείτε: ανοίγει το πλαίσιο κάτω από την ένδειξη κάμερας |
| `Esc` | Κλείνει την κάρτα επιλογής· μετά σταματά να κοιτάζει τη δεύτερη μονάδα· μετά σταματά να ακολουθεί μια μονάδα |
| `T` | Ενεργοποίηση ή απενεργοποίηση της τακτικής εμφάνισης ([Αναπαραγωγή αγώνα](match-replay.md#display-style)) |
| `?` / `F1` | Λειτουργία βοήθειας: τι σημαίνουν τα χρώματα ([Ρυθμίσεις, μονάδες και πλήκτρα](settings.md#help-mode)) |
| `1` | [Θερμότητα](heat.md) |
| `2` | [Διαφορά](difference.md) |
| `3` | [Θερμότητα ομάδων](team-heat.md) |
| `4` | [Γραμμές](line-heat.md) |
| `]` | Το όριο αποκοπής μακριά βγαίνει έξω ×1,12 (`Shift`: ×1,35) |
| `[` | Το όριο αποκοπής μακριά μπαίνει μέσα ÷1,12 (`Shift`: ÷1,35) |
| `\` | Το όριο αποκοπής μακριά απενεργοποιείται / ξανανοίγει εκεί που ήταν ([Βάθος και αποκοπή](depth-and-culling.md#keyboard)) |

Η λειτουργία **Επικάλυψη φιγούρων** δεν έχει πλήκτρο αριθμού· επιλέξτε την από τη γραμμή λειτουργιών ή ανοίξτε την καρτέλα Αγώνας. Τα πλήκτρα αριθμών περνούν από τον ίδιο έλεγχο με τη γραμμή λειτουργιών: ένα πλήκτρο για λειτουργία που η γραμμή δείχνει ως μη διαθέσιμη για τα φορτωμένα δεδομένα δεν κάνει τίποτα.

## Αναπαραγωγή αγώνα {#match-replay}

Στη λειτουργία Επικάλυψη φιγούρων, που χρησιμοποιεί η καρτέλα Αγώνας ([Αναπαραγωγή αγώνα](match-replay.md)). Λειτουργούν όταν μια μονάδα ακολουθείται ή όχι, εκτός όπου σημειώνεται αλλιώς:

| Πλήκτρο | Αποτέλεσμα |
|---|---|
| `B` | Προσθήκη σελιδοδείκτη: η στιγμή και η κάμερα |
| `M` | Χάρτης 2D: γωνία, όλη η προβολή, ανενεργό |
| `V` / `Shift+V` | Επόμενη / προηγούμενη προβολή κάμερας της ακολουθούμενης μονάδας |
| `H` | Οθόνη κεφαλής στην προβολή από το πιλοτήριο και στις προβολές padlock |
| `Page Down` / `Page Up` | Επόμενο / προηγούμενο συμβάν από τα είδη που δείχνει η λίστα συμβάντων |
| `J` | Αναπαραγωγή προς τα πίσω· ξανά, για παύση |
| `L` | Αναπαραγωγή προς τα εμπρός· ξανά, για παύση |
| `.` / `,` | Ένα δευτερόλεπτο μπροστά / πίσω, σε παύση (`Shift`: δέκα δευτερόλεπτα) |
| `Esc` | Σταματά να κοιτάζει τον στόχο πρώτα, μετά σταματά να ακολουθεί |
| `Ctrl`+κλικ ή `Alt`+κλικ σε μια μονάδα (στην προβολή ή στη λίστα μονάδων) | Την κοιτάζει από την ακολουθούμενη μονάδα (προβολή δύο μονάδων)· κάντε ξανά κλικ για να την αφήσετε |
| `Shift`+κλικ σε δύο μονάδες | Μέτρηση ανάμεσά τους: διεύθυνση, απόσταση, διαφορά ύψους |

Το `V` χρειάζεται ακολουθούμενη μονάδα. Το `M` είναι ο χάρτης 2D εδώ, και η «μετακίνηση» στην καρτέλα Τακτική.

## Ακολουθώντας μια μονάδα {#following-a-unit}

Όσο η κάμερα ακολουθεί μια μονάδα, ο τροχός και τα πλήκτρα πτήσης την οδηγούν γύρω από τη μονάδα αντί να πετά ελεύθερα ([Κάμερα](camera.md#while-following-a-unit)):

| Είσοδος | Αποτέλεσμα |
|---|---|
| Τροχός, `W` / `S` | Πιο κοντά / πιο μακριά (πιο ψηλά / πιο χαμηλά στην δορυφορική προβολή). Όχι στις προβολές πιλοτηρίου και padlock. |
| `A` / `D`, `Q` / `E` | Τροχιά γύρω από τη μονάδα (προβολές καταδίωξης και τροχιάς) |
| Σύρση | Κοιτάζει γύρω από τη μονάδα· στο πιλοτήριο, κοιτάζει γύρω μέσα στο πιλοτήριο |
| `V` / `Shift+V` | Επόμενη / προηγούμενη προβολή κάμερας |
| `H` | Οθόνη κεφαλής (προβολές πιλοτηρίου και padlock) |
| `Esc` | Σταματά να κοιτάζει τη δεύτερη μονάδα, μετά σταματά να ακολουθεί |

## Πίνακας τακτικής {#tactics-board}

Στην καρτέλα Τακτική ([Πίνακας τακτικής](tactics-board.md)). Τα `F`, `C`, `G` και `T` λειτουργούν όπως παραπάνω· τα πλήκτρα αριθμών δεν κάνουν τίποτα.

| Πλήκτρο | Αποτέλεσμα |
|---|---|
| `Ctrl+Z` | Αναίρεση |
| `Ctrl+Y` ή `Ctrl+Shift+Z` | Επανάληψη |
| `Enter` | Τελειώνει το βέλος που σχεδιάζεται (το ίδιο κάνει το διπλό κλικ ή το δεξί κλικ) |
| `Esc` | Ακυρώνει μια σύρση· αλλιώς αφαιρεί το βέλος ή την κίνηση σε εξέλιξη· αλλιώς αποεπιλέγει |
| `Delete` ή `Backspace` | Διαγράφει την επιλογή |
| `W` / `E` / `R` | Εργαλείο Μετακίνηση / Περιστροφή / Κλίμακα για την επιλογή (σύστημα πλήκτρων **W / E / R**) |
| `G` / `R` / `S` | Εργαλείο Μετακίνηση / Περιστροφή / Κλίμακα για την επιλογή (σύστημα πλήκτρων **G / R / S**) |
| `R` | Χωρίς επιλογή: γυρίζει την επόμενη φιγούρα για τοποθέτηση κατά 15°. Το `Shift+R` την γυρίζει πίσω. |
| `M` | Με επιλεγμένη φιγούρα: τη μεταφέρει στο επόμενο κλικ |
| `K` | Αναπαραγωγή ή παύση του σχεδίου |
| Shift+κλικ | Προσθήκη στην επιλογή ή αφαίρεση από αυτήν |
| Shift+σύρση | Σχεδιάζει ένα πλαίσιο γύρω από ό,τι θα επιλεγεί |
| `Ctrl` ενώ σύρετε μια λαβή | Κουμπώνει στο πλέγμα ή στο βήμα γωνίας |

Τα πλήκτρα του εργαλείου λειτουργούν μόνο όταν κάτι είναι επιλεγμένο· χωρίς επιλογή, τα `W A S D` πετούν την κάμερα όπως συνήθως.

## Επιλογή με κλικ {#click-to-pick}

Με ενεργή την **Το κλικ δείχνει τι υπάρχει εκεί** και με τον χάρακα ανενεργό ([Επιλογή με κλικ](camera.md#click-to-pick)):

| Είσοδος | Αποτέλεσμα |
|---|---|
| Αριστερό κλικ (χωρίς σύρση πάνω από 4 px) | Δείχνει το σημείο δεδομένων, ή αλλιώς το σημείο του επιπέδου, κάτω από τον δείκτη |

## Μέτρηση {#measure}

Με **Χάρακας ενεργός** ([Μέτρηση](measure.md)):

| Είσοδος | Αποτέλεσμα |
|---|---|
| Αριστερό κλικ (χωρίς σύρση πάνω από 4 px) | Τοποθετεί ένα σημείο |
| Δεξί κλικ | Αφαιρεί το τελευταίο σημείο |

## Αλλού {#elsewhere}

| Πού | Είσοδος | Αποτέλεσμα |
|---|---|---|
| Η λαβή κάθε ρυθμιστή (η λαβή δίπλα στον αριθμό) | Σύρση πάνω / κάτω | Αλλάζει την τιμή συνεχώς, πιο γρήγορα όσο σύρετε πιο μακριά· κρατήστε το `Shift` για λεπτό έλεγχο. Αφήστε για να σταματήσετε. |
| Η ένδειξη ταχύτητας πάνω από την προβολή | Σύρση πάνω / κάτω | Αλλάζει την ταχύτητα πτήσης με τον ίδιο τρόπο. |
| Κουτιά θέσης | `Enter` | Εφαρμόζει τη θέση ή τον προσανατολισμό που πληκτρολογήσατε. |
| Επεξεργαστής καμπύλης | Διπλό κλικ / Alt-κλικ / δεξί κλικ | Προσθέτει σημείο / αφαιρεί σημείο ([Σχήμα sprite](sprite-shape.md#the-curve-editor)). |

## Καρτέλα Ανάλυση αγώνα {#race-analysis-tab}

Στην καρτέλα Ανάλυση αγώνα το `K` παίζει και βάζει σε παύση την αναπαραγωγή του αγώνα, το `Home` την επαναφέρει στην αρχή, και τα πλήκτρα αριθμών δεν κάνουν τίποτα. Δείτε [Ανάλυση αγώνα](race-analysis.md).

## Πλήκτρα που κρατά ο προβολέας από το πρόγραμμα περιήγησης {#keys-the-viewer-keeps-from-the-browser}

Μερικές συντομεύσεις του προγράμματος περιήγησης θα έκλειναν ή θα ξανάφορτωναν τη σελίδα και θα χάνονταν μια φορτωμένη συνεδρία· ο προβολέας τις κρατά για τον εαυτό του. Η λίστα δημιουργείται από τον κώδικα: [Πλήκτρα περιηγητή](ref-browser-keys.md).
