# Gamepad και HOTAS

Μπορείτε να πετάξετε την κάμερα με χειριστήριο τύπου Xbox αντί για το πληκτρολόγιο. Χρησιμοποιήστε το όταν θέλετε να γείρετε πίσω και να κοιτάξετε γύρω σε μια μεγάλη σκηνή. Η είσοδός του **προστίθεται** σε αυτή του πληκτρολογίου, οπότε μπορείτε να χρησιμοποιείτε και τα δύο ταυτόχρονα.

## Σύνδεση χειριστηρίου {#connect-a-controller}

1. Συνδέστε το χειριστήριο (ή κάντε ζεύξη).
2. Κάντε κλικ στην προβολή και πατήστε οποιοδήποτε κουμπί του χειριστηρίου. Τα προγράμματα περιήγησης εμφανίζουν ένα χειριστήριο μόνο αφού δώσει την πρώτη του είσοδο.
3. Ανοίξτε **Κάμερα & σκηνή → Gamepad**. Η λίστα συσκευών το δείχνει με `●`.
4. Σπρώξτε τον αριστερό μοχλό για πτήση, τον δεξιό για βλέμμα. Αν η κάμερα παρασύρεται με τους μοχλούς στο κέντρο, αυξήστε τη **Νεκρή ζώνη**.

Κάθε συσκευή που το πρόγραμμα περιήγησης αντιστοιχίζει στη διάταξη standard gamepad λειτουργεί. Ένας μοχλός πτήσης ή ένα throttle (HOTAS) αγνοείται από προεπιλογή· δείτε παρακάτω.

## Αντιστοίχιση {#mapping}

| Στοιχείο ελέγχου | Αποτέλεσμα |
|---|---|
| Αριστερός μοχλός | Κίνηση: εμπρός/πίσω και πλάγια |
| Δεξιός μοχλός | Βλέμμα: yaw και pitch, με *Ταχύτητα βλέμματος* μοίρες το δευτερόλεπτο σε πλήρη απόκλιση |
| `RT` / `LT` (αναλογικά) | Πάνω / κάτω· στην παράλληλη προβολή, ζουμ μέσα / έξω |
| `RB` (κρατημένο) | 6× ταχύτερα |
| `LB` (κρατημένο) | 15% ταχύτητα |
| `A` (κρατημένο) | 3× sprint (συνδυάζεται με RB/LB) |
| `Y` (πάτημα) | Εστίαση στα δεδομένα |

Οι αριθμοί των κουμπιών ακολουθούν τη standard διάταξη: A 0, Y 3, LB 4, RB 5, LT 6, RT 7· μοχλοί στους άξονες 0-1 (αριστερά) και 2-3 (δεξιά).

## Οι ρυθμίσεις Gamepad {#the-gamepad-settings}

Στο **Κάμερα & σκηνή → Gamepad**. Το **Ρυθμίσεις** / **Απόκρυψη** ανοίγει και κλείνει τα στοιχεία ρύθμισης.

| Στοιχείο ελέγχου | Προεπιλογή | Εύρος (jog) | Τι σημαίνει |
|---|---|---|---|
| **Ενεργό** | ενεργό | | |
| Κατάσταση συσκευής | | | Κάθε συνδεδεμένη συσκευή, `●` όταν ακολουθείται, `○` όταν όχι, με *— δεν είναι χειριστήριο XInput, αγνοείται* ή *— δεν είναι χειριστήριο XInput, χρησιμοποιείται παρ' όλα αυτά* για μη τυπικές συσκευές. Χωρίς καμία: *Δεν εντοπίστηκε χειριστήριο. Τα προγράμματα περιήγησης εμφανίζουν ένα χειριστήριο μόνο αφού στείλει την πρώτη του είσοδο - πατήστε ένα κουμπί του.* |
| **Χρήση συσκευής** | *Μόνο χειριστήρια XInput (συνιστάται)* | | Εμφανίζεται όταν είναι συνδεδεμένη μη τυπική συσκευή. Διαλέξτε συσκευή με το όνομά της για να την ακολουθήσετε. |
| **Ταχύτητα βλέμματος** | 150°/s | 20-540 (5000) | Ρυθμός στροφής σε πλήρη απόκλιση του δεξιού μοχλού. |
| **Νεκρή ζώνη** | 12% | 0-50% (95%) | Ακτινική: μια διαγώνια ώθηση δεν διαρρέει ποτέ σε έναν μόνο άξονα. Αυξήστε την αν η κάμερα παρασύρεται με τους μοχλούς στο κέντρο. |
| **Καμπύλη μοχλού** | x² | γραμμική (1) έως x⁴ (16) | Εκθέτης απόκρισης μετά τη νεκρή ζώνη: πιο λεπτός έλεγχος κοντά στο κέντρο, και πάντα πλήρης ταχύτητα στην άκρη. |
| **Αντιστροφή Y μοχλού** | κλειστό | | |
| **Εναλλαγή μοχλών** | κλειστό | | Κίνηση με τον δεξιό μοχλό, βλέμμα με τον αριστερό. |

Η διαμόρφωση του μοχλού: με απόκλιση *m* (το μήκος του διανύσματος του μοχλού) και νεκρή ζώνη *d*, η έξοδος = ((m - d) / (1 - d)) ^ καμπύλη κατά την κατεύθυνση του μοχλού, και 0 μέσα στη νεκρή ζώνη.

## Γιατί μόνο τυπικά χειριστήρια από προεπιλογή {#why-only-standard-pads-by-default}

Το Gamepad API αναφέρει **κάθε** συσκευή HID με άξονες: μοχλούς πτήσης, throttles, πεντάλ, τιμόνια. Αυτές δεν στέκονται στο κέντρο. Ένας άξονας στρέψης ή ένας μοχλός throttle βρίσκεται σε πλήρη απόκλιση όταν κανείς δεν τον αγγίζει. Αν διαβαστεί ως μοχλός, είναι μόνιμη είσοδος πλήρους ταχύτητας που καμία νεκρή ζώνη δεν μπορεί να καταστείλει. Η κάμερα θα γυρνούσε μόνη της από τη στιγμή που φορτώνει η σελίδα, και όλες οι λειτουργίες θερμότητας θα φαίνονταν χαλασμένες, επειδή μια κινούμενη κάμερα ξαναρχίζει τη συσσώρευση σε κάθε καρέ.

Γι' αυτό μια συσκευή ακολουθείται μόνο όταν το πρόγραμμα περιήγησης αναφέρει `mapping: "standard"`, δηλαδή ότι είναι χειριστήριο τύπου XInput με τους άξονες εκεί που περιμένετε. Οι άλλες συσκευές εμφανίζονται στη λίστα και σημειώνονται ως αγνοημένες. Το **Χρήση συσκευής** επιλέγει μία ρητά, για παράδειγμα για να πετάτε την κάμερα με HOTAS. Μόλις ακολουθηθεί ένα χειριστήριο, η κάμερα μένει μαζί του, ώστε δύο χειριστήρια να μην μαλώνουν για την κάμερα ανάλογα με τη σειρά καταμέτρησης.

**HOTAS:** διαβάζονται μόνο οι άξονες 0-3 (δύο μοχλοί) και τα τυπικά κουμπιά. Ένα throttle ή πεντάλ σε άλλους άξονες δεν κάνει τίποτα, και ένας μοχλός ή throttle των οποίων οι άξονες δεν στέκονται στο κέντρο μπορεί να χρειάζεται μεγαλύτερη **Νεκρή ζώνη**.

Τα προγράμματα περιήγησης κρύβουν ένα χειριστήριο μέχρι να στείλει την πρώτη του είσοδο, οπότε ένα συνδεδεμένο χειριστήριο που δεν έχει αγγιχτεί δεν υπάρχει ακόμα για τη σελίδα.
