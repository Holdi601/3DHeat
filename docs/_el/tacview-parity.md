# Ισοδυναμία με Tacview

Το Tacview είναι ένα δημοφιλές πρόγραμμα για την παρακολούθηση καταγραφών πτήσεων. Αν το ξέρετε, αυτή η σελίδα δείχνει πού βρίσκεται κάθε εργαλείο του στο 3DHeat.

Καταγράφει κάθε λειτουργία του Tacview 1.9 (το εγχειρίδιό του, τον πίνακα κειμένων της διεπαφής του και τη μορφή αρχείου ACMI 2.2) και πού στέκεται η [αναπαραγωγή αγώνα](match-replay.md) του 3DHeat απέναντί της. Στόχος: ό,τι μπορεί να κάνει το Tacview για μια αναπαραγωγή και τα δεδομένα της, θα μπορεί να το κάνει και το 3DHeat.

**Κατάσταση:**
- **έτοιμο**: ήδη στο 3DHeat.
- **νέο**: φτιαγμένο για να ταιριάζει σε μια λειτουργία του Tacview.
- **όχι ακόμα**: ισχύει, αλλά δεν έχει φτιαχτεί.
- **δεν ισχύει**: δεν ισχύει εδώ, με τον λόγο.

Πού βρίσκονται οι λειτουργίες: η καρτέλα **Αγώνας**, η **Αναπαραγωγή φιγούρων** (ή η **Επικάλυψη φιγούρων** στην καρτέλα Χάρτης θερμότητας), στις ενότητες της πλαϊνής στήλης **Αναπαραγωγή**, **Μονάδες**, **Συμβάντα**, **Σελιδοδείκτες**, **Τακτική οθόνη**, **Στατιστικά**, **Μετατόπιση χρόνου και περικοπή**, **Χάρτης και θέση**, **Ήχος και βίντεο** και **Ετικέτες**. Βλ. [Αναπαραγωγή αγώνα](match-replay.md).

## Για προγραμματιστές: ιδιότητες ACMI 2.2 {#for-developers-acmi-22-properties}

Διαβάζονται από το `data/acmi.ts`· οι αριθμητικές ιδιότητες γίνονται στήλες αριθμών, οι κείμενο στήλες κατηγοριών. Όλες φαίνονται στα **Ακατέργαστα** της κάρτας μονάδας. Αυτές διαβάζονται για συγκεκριμένο σκοπό:

| Ιδιότητες | Χρήση |
|---|---|
| T (και οι τέσσερις μορφές), Name, Type, Pilot, Group, Country, Coalition, Color, CallSign | Θέση, στάση, σχήμα, όνομα μονάδας, ομάδα |
| IAS, CAS, TAS, Mach, AOA, AOS, AGL, HDG, HDM, OnGround | Πεδία, γραφήματα, HUD, ανίχνευση απογείωσης και προσγείωσης |
| VerticalGForce, LongitudinalGForce, LateralGForce | Πεδία G |
| Throttle(2), Afterburner, EngineRPM(2), NR, AirBrakes, Flaps, LandingGear, Tailhook | Πεδία |
| FuelWeight..9, FuelVolume..9, FuelFlowWeight..8 | Πεδία καυσίμου, αθροισμένα στις δεξαμενές |
| RadarMode, RadarAzimuth, RadarElevation, RadarRoll, RadarRange, RadarHorizontalBeamwidth, RadarVerticalBeamwidth, RadarRangeGateAzimuth/Elevation/Min/Max/HorizontalBeamwidth/VerticalBeamwidth | Κώνοι ραντάρ και πύλη εμβέλειας |
| LockedTarget..9, LockedTargetMode, LockedTargetAzimuth/Elevation/Range, FocusedTarget | Γραμμές κλειδώματος |
| EngagementMode(2), EngagementRange(2), VerticalEngagementRange(2) | Θόλοι εμπλοκής |
| QNH, AltimeterSetting, WindSpeed, WindDirection, HeartRate | Πεδία |
| Health | Πεδίο |
| Συμβάντα: Destroyed, TakenOff, Landed, Bookmark, Message, Comment, LeftArea, Timeout | Λίστα συμβάντων, στατιστικά (θάνατοι, απογειώσεις, προσγειώσεις), σελιδοδείκτες· τα Message και Comment ως υπότιτλοι |
| PilotHeadYaw, PilotHeadPitch | Γραμμή οράσεως πιλότου |
| Ετικέτα τύπου Bullseye (Navaid+Static+Bullseye) | Πεδίο bullseye και κύκλοι χάρτη |
| Όλα τα υπόλοιπα (PilotHeadRoll, χειρισμοί, επιφάνειες, αποκλίσεις ILS, SpO2, ENL, Label, Debug, Importance, Slot, Visible, Disabled, Radius, μεγέθη...) | Εμφανίζονται όπως έχουν γραφτεί στα **Ακατέργαστα** |

Οι γωνίες ραντάρ και κλειδώματος μετρώνται ως προς τους άξονες της ίδιας της μονάδας: αζιμούθιο προς τα δεξιά, υψόμετρο προς τα πάνω, κύλιση με τη δεξιά πτέρυγα προς τα κάτω. Η προδιαγραφή ACMI λέει ότι είναι ως προς το αεροσκάφος, αλλά όχι ποια φορά είναι θετική· αυτή η ερμηνεία ακολουθεί τον μετασχηματισμό της (yaw δεξιόστροφα, pitch προς τα πάνω, roll με τη δεξιά πτέρυγα).
