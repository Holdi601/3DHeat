# Αναφορά μορφών δεδομένων

Αυτή η σελίδα απαριθμεί κάθε είδος αρχείου που μπορεί να ανοίξει το 3DHeat, και πώς πρέπει να
μοιάζει ένας πίνακας μέσα σε αυτό. Ένας πίνακας είναι γραμμές και στήλες, όπως ένα
λογιστικό φύλλο: κάθε γραμμή λέει πού βρισκόταν κάτι και, αν το έχετε, πότε και ποιος.

Τι διαβάζει η καρτέλα Χάρτης θερμότητας, στήλη προς στήλη, και οι υποδείξεις που μπορεί να
κρατά ένα αρχείο Parquet. (Η καρτέλα Ανάλυση αγώνα διαβάζει αρχεία γύρων, και η καρτέλα
Αγώνας τις περιλήψεις αγώνων· βλ. [Ανάλυση αγώνα](race-analysis.md) και [Ανάλυση αγώνα (CS2)](match-analysis.md).)

## Αρχεία {#files}

Αυτή είναι η μία πλήρης λίστα των αρχείων που μπορούν να φορτωθούν. Το πάνελ **Πηγή**
(**Αρχεία…**, **Φάκελος…**, ή σύρσιμο και απόθεση) δέχεται ακριβώς αυτά:

| Επέκταση | Τι είναι | Διαβάζεται από |
|---|---|---|
| `.parquet`, `.pq` | πίνακας Parquet | ο αναγνώστης Parquet (παρακάτω) |
| `.csv`, `.tsv`, `.txt` | κείμενο με διαχωριστικά | ο αναγνώστης κειμένου (παρακάτω) |
| `.3dheat` | ένας αγώνας σε ένα αρχείο (ένα ZIP που κρατά τον πίνακα και τα συνοδευτικά του) | φορτώνεται ως ο πίνακας που περιέχει - [Ένα αρχείο ανά αγώνα](container.md) |
| `.acmi` (και `.txt.acmi`, `.zip.acmi`) | καταγραφή πτήσης Tacview | ο δικός του αναγνώστης - [Εγγραφές Tacview](tacview-acmi.md) |
| `.json`, `.json.gz` | καταγραφή OCAP (τύπου Arma) | ο δικός του αναγνώστης |
| `.gpx`, `.kml`, `.kmz`, `.nmea`, `.nma`, `.igc`, `.fit` | διαδρομές GPS: GPX, KML/KMZ, αρχεία καταγραφής NMEA, αρχεία πτήσεων ανεμοπορίας IGC, αρχεία αθλητισμού FIT | ο δικός του αναγνώστης· οι θέσεις έρχονται από γεωγραφικό πλάτος και μήκος |

Δεν φορτώνονται ως θέσεις: τα μικρά αρχεία JSON που βρίσκονται δίπλα σε έναν πίνακα για να τον
περιγράφουν (ονόματα που τελειώνουν σε `.match.json`, `.course.json`, `.level.json`,
`.meta.json`, `.summary.json`, `.session.json`, `.hints.json`), και οι επιπλέον πίνακες ενός
μετατροπέα (`<match>.events.parquet` και τα παρόμοια, βλ. [Μετατροπείς](converters.md)), εκτός
αν τα επιλέξετε μόνα τους. Οτιδήποτε άλλο παραλείπεται με αιτιολογία. Πώς φιλτράρεται μια
επιλογή εξηγείται στο [Φόρτωση αρχείων](loading-files.md#which-files-are-kept).

Τα κενά αρχεία παραλείπονται. Σε μια επιλογή που περιέχει αρχεία `movement*.<ext>`, φορτώνονται
μόνο αυτά ([Φόρτωση αρχείων](loading-files.md#which-files-are-kept)).

Τα δεδομένα είναι **μία γραμμή ανά δείγμα**: μία θέση τη στιγμή, προαιρετικά με το ποιος, σε
ποια ομάδα, σε ποια συνεδρία, πού κοιτούσε, και όσες επιπλέον στήλες θέλετε. Οι γραμμές
γεγονότων (ένας θάνατος, μια τοποθέτηση, μια βολή) μπορούν να βρίσκονται στον ίδιο πίνακα με
τις γραμμές θέσεων, και ξεχωρίζουν με μια στήλη γεγονότος.

## Κείμενο με διαχωριστικά (CSV, TSV, TXT) {#delimited-text-csv-tsv-txt}

Το μικρότερο χρήσιμο αρχείο, τρεις γραμμές:

```
x,y,z,t,player,team
10.5,2.0,-30.2,0.00,Blue 1,Blue
11.0,2.0,-29.8,0.25,Blue 1,Blue
-4.2,1.5,18.9,0.00,Red 3,Red
```

Οι στήλες αντιστοιχίζονται μόνες τους ([Αντιστοίχιση στηλών](column-mapping.md)).

Διαβάζεται από σαρωτή σε επίπεδο bytes που αποκωδικοποιεί μόνο τις αντιστοιχισμένες στήλες
([`csv.ts`](https://github.com/Holdi601/3DHeat/blob/main/src/data/csv.ts)).

| Πτυχή | Κανόνας |
|---|---|
| Κεφαλίδα | Η πρώτη μη κενή γραμμή κρατά τα ονόματα των στηλών. Ένα κενό όνομα γίνεται `column_N`. |
| Διαχωριστικό | Εντοπίζεται από τις πρώτες 20 μη κενές γραμμές των πρώτων 1 MiB, ανάμεσα σε κόμμα, ερωτηματικό, στηλοθέτη και κάθετο, με **συνέπεια**: νικά το διαχωριστικό που δίνει τον ίδιο αριθμό πεδίων σε κάθε δειγματοληπτούμενη γραμμή, και μετά εκείνο που δίνει περισσότερα πεδία. Το κενό διάστημα δεν εντοπίζεται ποτέ αλλά μπορεί να επιλεγεί· μπορεί να πληκτρολογηθεί κάθε μεμονωμένος χαρακτήρας ([Αντιστοίχιση στηλών](column-mapping.md#the-fields)). |
| Εισαγωγικά | RFC 4180: τα πεδία μπορούν να είναι τυλιγμένα σε διπλά εισαγωγικά, και το `""` μέσα σε εισαγωγικά είναι κυριολεκτικό εισαγωγικό. |
| Κενά διαστήματα | Τα κενά, οι στηλοθέτες και τα εισαγωγικά στην αρχή και το τέλος κάθε πεδίου αφαιρούνται. |
| Πεδία ανά γραμμή | Το πολύ 4 096· περισσότερα είναι σφάλμα (*είναι σωστό το διαχωριστικό;*). |
| Αριθμοί | Προαιρετικό πρόσημο, ψηφία, προαιρετικό `.` και δεκαδικά, προαιρετικός εκθέτης (`1.5e-3`). Το δεκαδικό κόμμα (`1,5`), οι διαχωριστές χιλιάδων ή οι μονάδες στο τέλος (`12 m`) δεν αναλύονται και μετρούν ως λείπουσες τιμές. Αν το αρχείο σας έχει δεκαδικά κόμματα, αλλάξτε τα σε τελείες πριν τη φόρτωση (η εύρεση και αντικατάσταση σε έναν επεξεργαστή κειμένου δουλεύει). |
| Αριθμητική στήλη | Μια στήλη προσφέρεται ως αριθμητική όταν περισσότερο από το 90% των μη κενών τιμών στις πρώτες 50 γραμμές αναλύονται ως αριθμοί. |
| Πλήθος γραμμών | Υπολογίζεται πριν τη φόρτωση από το μέσο μήκος γραμμής των πρώτων 1 MiB. |
| Κωδικοποίηση κειμένου | UTF-8. |

## Parquet {#parquet}

Διαβάζεται με το [hyparquet](https://github.com/hyparam/hyparquet), κομμάτι στηλών προς κομμάτι
σε πίνακες τύπου (typed arrays), ζητώντας μόνο τις αντιστοιχισμένες στήλες ([`parquet.ts`](https://github.com/Holdi601/3DHeat/blob/main/src/data/parquet.ts), [`ingestParquet.ts`](https://github.com/Holdi601/3DHeat/blob/main/src/data/ingestParquet.ts)).

| Πτυχή | Κανόνας |
|---|---|
| Πλήθος γραμμών | Ακριβές, από το υποσέλιδο, πριν τη φόρτωση. |
| Προεπισκόπηση | Οι πρώτες 50 γραμμές, αποκωδικοποιημένες ως αντικείμενα· οι τιμές τους αποφασίζουν ποιες στήλες φαίνονται αριθμητικές. |
| Ακέραιοι | Τα `INT32` και τα `INT64` (αποκωδικοποιημένα ως BigInt) γίνονται αριθμοί. |
| Δεκαδικοί | `FLOAT`, `DOUBLE`. |
| Λογικές τιμές | 1 και 0. |
| Συμβολοσειρές | Χρησιμοποιούνται για στήλες προσώπου, ομάδας, συνεδρίας και κατηγορίας· μια συμβολοσειρά που μοιάζει με αριθμό γίνεται δεκτή για αριθμητικούς ρόλους. |
| Λογικοί τύποι `TIMESTAMP`, `DATE` | Αποκωδικοποιούνται σε χρονικές στιγμές (χιλιοστά του δευτερολέπτου από το 1970)· όταν χρησιμοποιούνται ως άξονας χρόνου, η ρύθμιση μονάδας αγνοείται. |
| Εμφωλευμένες στήλες | Οι στήλες δομής και λίστας δεν προορίζονται για κανέναν ρόλο (προεπισκοπούνται ως κείμενο JSON)· δεν έχουν δοκιμαστεί. |
| Μεταδεδομένα υποσέλιδου | Το κλειδί `heat3d` διαβάζεται ως υποδείξεις αντιστοίχισης (παρακάτω). |

Μια στήλη θέσης, χρόνου ή βλέμματος που περιέχει κάτι διαφορετικό από αριθμό αποκωδικοποιείται
ως λείπουσα τιμή.

## Ρόλοι και τύποι στηλών {#column-roles-and-types}

| Ρόλος | Τύπος στο αρχείο | Απαιτείται | Αποθηκεύεται ως | Όρια |
|---|---|---|---|---|
| X, Y, Z | αριθμός | δύο από τα τρία | κινητή υποδιαστολή 32 bit, μετά την [αντιστοίχιση αξόνων](axes-units-and-time.md) | Μια γραμμή χωρίς χρήσιμη θέση πετιέται. |
| Χρόνος | αριθμός σε μία από τις [μονάδες χρόνου](axes-units-and-time.md#time-units), χρονική στιγμή Parquet, ή κείμενο ISO-8601 | όχι | δευτερόλεπτα κινητής υποδιαστολής 32 bit από την πιο πρώιμη γραμμή | Η ταξινόμηση αρνείται πάνω από 400 000 000 γραμμές ([γιατί](memory-and-budgets.md#the-sort-ceiling)). |
| Πρόσωπο | οτιδήποτε· κωδικοποιημένο με λεξικό | όχι | αναγνωριστικό 32 bit | |
| Συνεδρία | οτιδήποτε· κωδικοποιημένο με λεξικό | όχι | αναγνωριστικό 32 bit | Οι ετικέτες καταγράφονται έως 100 000 συνεδρίες. |
| Ομάδα | οτιδήποτε· κωδικοποιημένο με λεξικό | όχι | αναγνωριστικό 16 bit | Έως 4 096 ομάδες, αλλιώς η ομαδοποίηση πετιέται. |
| Στροφή, κλίση | αριθμός, μοίρες ή ακτίνια | όχι | κινητή υποδιαστολή 32 bit σε ακτίνια | |
| Κατεύθυνση X, Y, Z | αριθμός | όχι (και τα τρία μαζί) | μετατρέπεται σε στροφή και κλίση | |
| Στήλη φίλτρου, *εύρος* | αριθμός | όχι | κινητή υποδιαστολή 32 bit | Έως 4 φίλτρα ενεργά ταυτόχρονα. |
| Στήλη φίλτρου, *κατηγορία* | οτιδήποτε· κωδικοποιημένο με λεξικό | όχι | αναγνωριστικό 32 bit | Έως 4 096 τιμές, αλλιώς η στήλη δεν κρατιέται. |

Μια στήλη `TIMESTAMP` του Parquet που κρατιέται ως στήλη φίλτρου είναι ένα *εύρος* χιλιοστών
του δευτερολέπτου από την εποχή - ένας ρυθμιστής, όχι μια λίστα.

## Οι υποδείξεις `heat3d` {#the-heat3d-hints}

Ένα αρχείο Parquet μπορεί να κρατά τις δικές του οδηγίες ανάγνωσης στα μεταδεδομένα κλειδιού/τιμής
του υποσέλιδου του, κάτω από το κλειδί **`heat3d`**, ως αντικείμενο JSON ([`MappingHints`](https://github.com/Holdi601/3DHeat/blob/main/src/data/automap.ts)).
Ο προβολέας τις εφαρμόζει πάνω από τις δικές του εικασίες όταν το αρχείο είναι το πρώτο μιας
επιλογής· κάθε καταχώριση είναι προαιρετική, και κάθε αποτέλεσμα εμφανίζεται ακόμη και είναι
επεξεργάσιμο στο πάνελ [Αντιστοίχιση στηλών](column-mapping.md#the-heat3d-hints-in-a-parquet-footer). Ό,τι δεν
αναλύεται ως αντικείμενο JSON αγνοείται.

### Σχήμα {#schema}

```
{
  "columns": {
    "x": string, "y": string, "z": string,          ονόματα στηλών για τη θέση
    "time": string,                                  η στήλη χρόνου
    "timeUnit": "seconds" | "milliseconds" | "microseconds" | "nanoseconds"
              | "unix_seconds" | "unix_milliseconds" | "iso8601",
    "personId": string, "teamId": string, "sessionId": string,
    "lookMode": "none" | "yawPitch" | "vector",
    "yaw": string, "pitch": string,
    "dirX": string, "dirY": string, "dirZ": string,
    "angleUnit": "degrees" | "radians",
    "extra": [string, ...]                           στήλες φίλτρου προς διατήρηση, οι πιο χρήσιμες πρώτα
  },
  "axes": {
    "up": "y" | "z",
    "flipX": boolean, "flipY": boolean, "flipZ": boolean,
    "scale": number                                  πρέπει να είναι > 0
  },
  "entity": {
    "size": number                                   μέγεθος ενός παρακολουθούμενου πράγματος σε μονάδες αρχείου, > 0
  }
}
```

| Καταχώριση | Εφαρμόζεται όταν | Αποτέλεσμα |
|---|---|---|
| `columns.x` … `columns.dirZ`, `time`, `personId`, `teamId`, `sessionId` | η αναφερόμενη στήλη υπάρχει στο αρχείο | Ορίζει τον ρόλο. |
| `columns.timeUnit` | είναι μία από τις επτά μονάδες | Ορίζει τη μονάδα χρόνου. |
| `columns.angleUnit` | `"degrees"` ή `"radians"` | Ορίζει τη μονάδα γωνίας. |
| `columns.lookMode` | `"vector"` με τα dirX, dirY και dirZ όλα ορισμένα· `"yawPitch"` με το yaw ορισμένο· `"none"` | Ορίζει τη λειτουργία βλέμματος. |
| `columns.extra` | είναι πίνακας | Αντικαθιστά την αυτόματη λίστα φίλτρων, κρατώντας μόνο υπάρχουσες στήλες που δεν χρησιμοποιούνται από ρόλο· καθεμία είναι *εύρος* όταν έμοιαζε αριθμητική στην προεπισκόπηση, αλλιώς *κατηγορία*. Χωρίς αυτήν, κρατιέται η αυτόματη λίστα χωρίς τις στήλες που μια υπόδειξη έχει δώσει σε ρόλο. |
| `axes.up` | `"y"` ή `"z"` | Άξονας προς τα πάνω. |
| `axes.flipX/Y/Z` | μία λογική τιμή | Αναστροφές. |
| `axes.scale` | αριθμός > 0 | Κλίμακα μονάδας. |
| `entity.size` | αριθμός > 0 | [Μέγεθος οντότητας](sessions-persons-groups.md#entity-size) (πολλαπλασιάζεται με την κλίμακα μονάδας κατά τη φόρτωση). Ο μόνος τρόπος να οριστεί. |

### Παράδειγμα {#example}

Ένα φανταστικό εξαγόμενο ενός shooter: Z προς τα πάνω, εκατοστά, ένας κόσμος αριστερόστροφος,
παίκτες περίπου 72 cm πλάτος.

```json
{
  "columns": {
    "x": "pos_x", "y": "pos_y", "z": "pos_z",
    "time": "t", "timeUnit": "seconds",
    "personId": "player", "teamId": "side", "sessionId": "round_id",
    "lookMode": "yawPitch", "yaw": "view_yaw", "pitch": "view_pitch", "angleUnit": "degrees",
    "extra": ["event", "weapon", "map"]
  },
  "axes": { "up": "z", "flipY": true, "scale": 0.01 },
  "entity": { "size": 72 }
}
```

### Γράφοντάς το {#writing-it}

Με το pyarrow, τα προσαρμοσμένα μεταδεδομένα σχήματος γράφονται στα μεταδεδομένα κλειδιού/τιμής
του αρχείου:

```python
import json
import pyarrow as pa
import pyarrow.parquet as pq

table = pa.table({...})
hints = {"columns": {"x": "pos_x", "y": "pos_y", "z": "pos_z", "time": "t"}, "axes": {"up": "z"}}
meta = dict(table.schema.metadata or {})
meta[b"heat3d"] = json.dumps(hints).encode("utf-8")
pq.write_table(table.replace_schema_metadata(meta), "movement.parquet")
```

Το `npm run inspect -- file.parquet` τυπώνει το σχήμα ενός αρχείου, που είναι ένας γρήγορος
τρόπος να ελέγξετε τα ονόματα στηλών στα οποία αναφέρονται οι υποδείξεις.

## Τι γράφει η καρτέλα Χάρτης θερμότητας {#what-the-heatmap-tab-writes}

Τίποτα δεν γράφεται πίσω στα δεδομένα. Οι έξοδοι είναι:

- βίντεο, σε WebM (VP9 ή VP8) - [Διαδρομή κάμερας και βίντεο](camera-path-and-video.md)·
- μια θέση κάμερας, αντιγραμμένη στο πρόχειρο ως κείμενο - [Κάμερα](camera.md#pose)·
- επίπεδα αποθηκευμένα στη [βιβλιοθήκη επιπέδων](level-library.md) του περιηγητή.
