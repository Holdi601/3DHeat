# Συντήρηση της τεκμηρίωσης

Αυτή η σελίδα απευθύνεται σε όποιον φροντίζει τον περιηγητή και αυτόν τον ιστότοπο. Περιέχει τα βήματα για να μένουν σωστές οι σελίδες, οι εικόνες και οι μεταφράσεις μετά από μια αλλαγή.

Ο ιστότοπος ελέγχεται ξανά σε **κάθε έκδοση** και όποτε αλλάζει πολλά κάτι: συντομεύσεις πληκτρολογίου, η διαδρομή μέσα στη διεπαφή, οι ρυθμίσεις, οι μορφές αρχείων. Η λίστα ελέγχου:

1. **Ξαναδημιουργήστε τις σελίδες αναφοράς**: `node tools/docs-refs.mjs` (και `--lang <lang>` για κάθε γλώσσα). Το `node tools/docs-refs.mjs --check` αποτυγχάνει όταν μια σελίδα είναι ξεπερασμένη.
2. **Ξαναδημιουργήστε τα στιγμιότυπα** από τα [δεδομένα επίδειξης](demo-data.md). Χρησιμοποιήστε υπολογιστή ή κοντέινερ με περιοχή en-US, ώστε οι αριθμοί να διαβάζονται `0.35` και όχι `0,35` (τα πλαίσια αριθμών ακολουθούν την περιοχή του προγράμματος περιήγησης μέχρι να αλλάξει). Φτιάξτε τα δεδομένα επίδειξης με `node tools/demo-data.mjs`, ξεκινήστε διακομιστή ανάπτυξης στη θύρα 5321 **χωρίς** τοπικό πακέτο φιγούρων, `HEAT3D_FIGURE_PACK=none npx vite --port 5321 --strictPort --host 127.0.0.1`, και μετά τρέξτε `node tools/docs-shots.mjs --lang <lang>`. Δείτε κάθε εικόνα: μόνο ονόματα επίδειξης (*Demo Valley*, *Blue 1*, *Red 3* ...), χωρίς πραγματικούς χάρτες, παίκτες ή εγγραφές.
3. **Καταγράψτε τι άλλαξε** από την τελευταία ετικέτα έκδοσης: `git log --oneline <last tag>..HEAD`, και την ενότητα **Docs** του `CHANGELOG.md`, που αντιστοιχίζει κάθε λειτουργία με τη σελίδα της. Κάθε νέα λειτουργία χρειάζεται σελίδα ή ενότητα, με εικόνα όπου φαίνεται στην οθόνη.
4. **Ανεξάρτητη επισκόπηση** των αγγλικών σελίδων από κάποιον που δεν τις έγραψε, για τρεις αναγνώστες: έναν αρχάριο, έναν οκτάχρονο, έναν έμπειρο. Είναι τα βήματα πλήρη και με τη σωστή σειρά, είναι οι λέξεις αυτές της διεπαφής, είναι οι εικόνες επίκαιρες, είναι σωστές οι ετικέτες των διαγραμμάτων;
5. **Διορθώστε ό,τι βρήκε η επισκόπηση.**
6. **Μεταφράστε ξανά τις αλλαγμένες σελίδες** με βάση το hash της πηγής τους, και μετά κάντε την επισκόπηση ανά γλώσσα. Βλ. `tools/docs-translate.md`.
7. **Σαρώστε για εμπιστευτικούς όρους** στα αλλαγμένα αρχεία, και ελέγξτε ότι καμία εικόνα δεν δείχνει τίποτα άλλο εκτός από δεδομένα επίδειξης.
8. **Δημοσιεύστε** μόνο όταν εγκριθεί η έκδοση.

Ο ίδιος έλεγχος καλύπτει και τους ιστότοπους τεκμηρίωσης των σχετικών αποθετηρίων (βλ. τη σελίδα [Αρχική](index.md#related-repositories)).

## Τα εργαλεία κάτω από το exporters/ {#the-tools-under-exporters}

Τα εργαλεία γύρω από τον περιηγητή είναι ξεχωριστά δημόσια έργα, καθένα με τη δική του άδεια MIT, τις δικές του εκδόσεις, το δικό του wiki και τον δικό του έλεγχο ενημερώσεων, καρφιτσωμένα σε αυτό το αποθετήριο ως git submodules:

| Φάκελος | Αποθετήριο |
|---|---|
| `exporters/gamefiles/` | [3DHeat-GameFiles](https://github.com/Holdi601/3DHeat-GameFiles) - πίστες και επίπεδα από τα δικά τα αρχεία των παιχνιδιών |
| `exporters/gamecapture/` | [3DHeat-GameCapture](https://github.com/Holdi601/3DHeat-GameCapture) - καταγραφείς τηλεμετρίας γύρων· επίπεδα από βίντεο παιχνιδιού |
| `exporters/unreal/` | [3DHeat-UnrealExporter](https://github.com/Holdi601/3DHeat-UnrealExporter) - plugin για το Unreal Editor |
| `exporters/cs2/` | [3DHeat-CS2](https://github.com/Holdi601/3DHeat-CS2) - demos και χάρτες του CS2 |
| `exporters/watcher/` | [3DHeat-Watcher](https://github.com/Holdi601/3DHeat-Watcher) - καταγράφει το παιχνίδι στο παρασκήνιο |

**Καρφιτσωμένο** σημαίνει ότι αυτό το αποθετήριο καταγράφει ένα ακριβές commit από κάθε εργαλείο. Ένα checkout του περιηγητή παίρνει αυτά τα commits:

```bash
git clone --recursive https://github.com/Holdi601/3DHeat
# or, after a plain clone:
git submodule update --init
```

Και οι δύο διαδρομές ενημέρωσης που αναφέρονται παραπάνω εκτελούν `git submodule update --init` μετά τη λήψη, οπότε τα εργαλεία ακολουθούν τον περιηγητή στα commits που καρφιτσώνει η νεότερη έκδοσή του — όχι στα νεότερα commits των ίδιων των εργαλείων. Μια νεότερη έκδοση ενός εργαλείου φτάνει στον περιηγητή όταν μετακινηθεί η καρφίτσα εδώ: οι αλλαγές σε ένα εργαλείο γίνονται commit και push πρώτα στον δικό του φάκελο (στο δικό του αποθετήριο), και μετά γίνεται commit εδώ η νέα καρφίτσα. Κάθε εργαλείο ελέγχει επίσης για τις δικές του νεότερες εκδόσεις· αυτό τεκμηριώνεται στο δικό του αποθετήριο.
