# Tacview 동등성

Tacview는 비행 기록을 보는 데 많이 쓰는 프로그램입니다. 이것을 알고 있다면, 이 페이지에서 Tacview의 각 도구가 3DHeat의 어디에 있는지 볼 수 있습니다.

이 페이지는 Tacview 1.9의 모든 기능(매뉴얼, 사용자 인터페이스 문자열 표, ACMI 2.2 파일 형식)을 나열하고, 3DHeat의 [매치 리플레이](match-replay.md)가 각 기능과 어떤 위치에 있는지 보여줍니다. 목표는 Tacview가 리플레이와 그 데이터에 대해 할 수 있는 것을 3DHeat도 할 수 있게 하는 것입니다.

**상태:**
- **완료**: 이미 3DHeat에 있습니다.
- **신규**: Tacview의 기능에 맞추어 만들었습니다.
- **아직 없음**: 해당하지만, 아직 만들지 않았습니다.
- **해당 없음**: 여기에는 해당하지 않습니다. 이유를 함께 적었습니다.

기능은 **매치** 탭, **피규어 리플레이**(또는 히트맵 탭의 **피규어 오버레이**)에서 찾을 수 있습니다. 사이드바의 **리플레이**, **유닛**, **이벤트**, **북마크**, **전술 표시**, **통계**, **시간 이동과 트림**, **지도와 위치**, **오디오와 비디오**, **라벨** 섹션에도 있습니다. [매치 리플레이](match-replay.md)를 보세요.

| 미터법 / 야드파운드법 단위 | 미터법 / 야드파운드법 | 완료 (두 가지 설정, 여덟 가지가 아님) |

## 개발자용: ACMI 2.2 속성 {#for-developers-acmi-22-properties}

`data/acmi.ts`가 읽습니다. 숫자 속성은 숫자 열이 되고, 문자 속성은 범주 열이 됩니다. 모두 유닛 카드의 **원시**에 표시됩니다. 다음 목적으로 읽습니다.

| 속성 | 용도 |
|---|---|
| T (네 가지 형식 모두), Name, Type, Pilot, Group, Country, Coalition, Color, CallSign | 위치, 자세, 그림, 유닛 이름, 팀 |
| IAS, CAS, TAS, Mach, AOA, AOS, AGL, HDG, HDM, OnGround | 필드, 차트, HUD, 이륙과 착륙 감지 |
| VerticalGForce, LongitudinalGForce, LateralGForce | G 필드 |
| Throttle(2), Afterburner, EngineRPM(2), NR, AirBrakes, Flaps, LandingGear, Tailhook | 필드 |
| FuelWeight..9, FuelVolume..9, FuelFlowWeight..8 | 연료 필드, 탱크별로 합산 |
| RadarMode, RadarAzimuth, RadarElevation, RadarRoll, RadarRange, RadarHorizontalBeamwidth, RadarVerticalBeamwidth, RadarRangeGateAzimuth/Elevation/Min/Max/HorizontalBeamwidth/VerticalBeamwidth | 레이더 원뿔과 거리 게이트 |
| LockedTarget..9, LockedTargetMode, LockedTargetAzimuth/Elevation/Range, FocusedTarget | 락온선 |
| EngagementMode(2), EngagementRange(2), VerticalEngagementRange(2) | 교전 돔 |
| QNH, AltimeterSetting, WindSpeed, WindDirection, HeartRate | 필드 |
| Health | 필드 |
| 이벤트: Destroyed, TakenOff, Landed, Bookmark, Message, Comment, LeftArea, Timeout | 이벤트 목록, 통계(사망, 이륙, 착륙), 북마크. Message와 Comment는 자막으로 |
| PilotHeadYaw, PilotHeadPitch | 조종사 시선 |
| 타입 태그 Bullseye(Navaid+Static+Bullseye) | 불스아이 필드와 지도 고리 |
| 그 밖의 모든 것(PilotHeadRoll, 조작, 표면, ILS 편차, SpO2, ENL, Label, Debug, Importance, Slot, Visible, Disabled, Radius, 크기 등) | 적힌 그대로 **원시**에 표시 |

레이더와 락온 각도는 유닛 자신의 축에 대해 잽니다. 방위는 오른쪽, 고도는 위, 롤은 오른쪽 날개가 아래입니다. ACMI 명세는 이것들이 항공기에 대한 상대값이라고는 말하지만, 어느 쪽이 양수인지는 말하지 않습니다. 이 해석은 그 변환을 따릅니다(요는 시계 방향, 피치는 위, 롤은 오른쪽 날개가 아래).
