# 기동: 그룹이 움직이는 방식

**인사이트 → 기동**은 각 진영의 유닛들이 *그룹으로* 어떻게 움직이는지 따라가고, 그들이 하는 기동에 이름을 붙입니다. 측면 공격, 협공, 돌파, 매복, 철수, 미사일 방어, 'T자 가로지르기' 같은 기동입니다. 각 기동마다 얼마나 확실한지, 그 근거가 된 수치, 성과가 있었는지, 교리와 역사 속의 유사 사례를 보여 줍니다. **대량 분석 → 기동**은 수천 경기에 걸쳐 이를 셉니다. 맵, 모드, 진영별로 각 기동을 얼마나 자주 하는지, 그리고 얼마나 자주 성과가 있는지 보여 줍니다.

모든 계산은 여러분의 브라우저 안, 자기만의 워커(`src/insights/maneuver`)에서 이루어집니다. 유닛이 몇백 개인 경기는 10~500 ms가 걸리고, 유닛이 수천 개인 두 시간짜리 공중전은 약 1초가 걸립니다.

## 사용 방법 {#using-it}

- **인사이트**를 열고 **기동** 탭을 고르세요. 처음 열면 바로 센 결과를 보여 줍니다. 필터를 바꾼 뒤에는 **다시 찾기**를 누르세요.
- **확실 / 가능성 높음 / 가능**으로 보여 줄 확신의 수준을 정합니다(기본값은 가능성 높음).
- **타임라인**에는 진영마다 한 줄씩, 기동마다 막대 하나가 있습니다. 그 아래 **목록**은 같은 내용을 시간 순으로 보여 줍니다. 항목을 클릭하면 리플레이가 그 시작 지점으로 옮겨 가고, 카메라가 그곳으로 날아가며, 기동을 3D로 그립니다. 그룹마다 움직인 경로는 화살표로, 양익 포위의 두 팔은 호로 그립니다. 핵심 순간의 그룹 윤곽은 그리고(적은 그 진영의 색으로), 적의 전선은 흰 선으로 그립니다. **모두 3D로 그리기**를 누르면 같은 경기의 다른 기동도 흐리게 함께 그립니다. 선은 선택이 바뀔 때 그래픽 카드로 한 번만 보냅니다. 매 프레임마다 보내지 않습니다. 재생 중에 기동 480개를 그려도, 실제 GPU에서 프레임 시간(WebGL2와 WebGPU 모두, p99 18.0~18.5 ms, 최대 19.5~20.8 ms)은 그리지 않을 때와 같습니다.
- 열어 본 기동에는 결과가 나옵니다. 그 기동을 한 유닛들이 기동 중과 직후에 격파한 수와 잃은 수를 보여 주고, 같은 진영이 경기 전체에서 교환한 것과 비교합니다. 또 근거와, 지식 기반에 있는 관련 항목(교리와 역사적 유사 사례)을 보여 줍니다. 예를 들어 협공에는 칸나에, 돌파에는 1940년 세당, 'T자 가로지르기'에는 쓰시마, 양동에는 볼로 작전 같은 사례입니다.
- 맨 아래 작은 표는 종류별, 진영별로 수행한 기동과 성과가 있었던 기동을 보여 줍니다.

## 그룹을 찾는 방법 {#how-groups-are-found}

모든 유닛은 공통된 시간축 위에 놓입니다. 걸어서 이동할 때는 1초 간격, 그 밖에는 2초 간격으로 보고, 아주 큰 파일은 더 긴 간격을 씁니다. 유닛이 죽은 자리에서는 위치를 그대로 두어서, 부활이 지도를 가로지르는 선으로 그려지지 않게 합니다. 모든 간격마다 같은 진영에 속하고 같은 종류(항공기, 차량, 함선, 보병)인 유닛들을 서로 가까우면 묶습니다. 가까움의 기준은 걸어서 18 m, 차량 170 m, 함선 3 km, 항공기 5 km입니다. 움직임도 비슷해야 합니다. 속도가 더 빠른 쪽 속도의 절반 이내이거나, 둘 다 멈춰 있어야 합니다. 묶인 무리는 구성원 대다수가 속했던 그룹의 번호를 그대로 유지합니다. 등급이 없는 유닛은 속도를 보고 걸어서, 차량에, 또는 공중에 있는 것으로 봅니다.

그룹의 **모양**은 진행 방향을 기준으로 읽습니다. 앞뒤와 좌우로 퍼진 정도로 종대나 횡대를 가립니다. 가운데가 앞서 나가면 쐐기형, 구성원들이 한쪽으로 계단처럼 물러서면 사선 대형, 모서리를 지키면 상자형입니다.

모든 판단은 경기 자체의 규모에 맞춰 합니다. **교전 거리** `R`은 킬러와 그 희생자 사이 거리의 75 백분위수입니다(해당 영역의 합리적인 범위로 제한합니다). 기동의 시간은 유닛 종류에 따라 조정합니다. 보병은 지상 기준의 3분의 1입니다.

## 찾아내는 기동 {#what-it-finds}

| 기동 | 찾는 조건 |
|---|---|
| 대형 | 그룹이 움직이는 단계의 60%에서 30초 동안 같은 모양을 유지함 |
| 정면 공격 | 그룹이 교전 거리 밖에서 접촉까지 좁혀 옴, ¾ R 이상, 적이 향한 방향에서 35° 이내에서 |
| 측면 공격 | 같은 조건이지만 50~130°에서(뒤쪽은 그 이상). 적을 거기서 맞서 싸우는 *고정 전력*이 있을 때만 확실함(어느 쪽이든 격파가 있어야 함) |
| 협공 | 한 진영의 측면 공격 두 건이 같은 적 몸체에 서로 반대편에서 90초 안에 이루어짐(100° 이상 떨어져 있음). 두 팔이 함께 싸우면 확실함 |
| 포위 | 적의 조밀한 그룹을, 상대 진영의 구성원이 1.5 R 안에서 그와 같거나 더 많이 둘러쌈. 둘 이상의 그룹이 참여하고, 틈은 100°를 넘지 않으며, 1분 동안 유지되고, 자기 진영에서 끊어져 있어야 함. 고리가 ½ R 안으로 좁혀지고 그 포켓 안에서 싸우면 확실함 |
| 돌파 | 그룹이 버티고 있는 전선을 통과함(좌우 양쪽에 적이 30초 동안 서 있고, 그 진영의 중심이 그 너머에 있어야 함). ½ R을 넘어가 20초 동안 머물면서 거기서 싸우면 확실함. R만큼 더 나아가면 완전한 돌파 |
| 엄호하의 약진 | 작은 그룹에서 일부는 움직이고 나머지는 서 있음. 역할이 네 번 이상 바뀌며, 서 있는 쪽이 엄호 사격을 함 |
| 전력 집중 / 분산 | 한 진영의 가장 조밀한 지점 근처에 있는 비율이 35%에서 60%로 올라감(유닛이 1.5 R 이상에서 모이고, 그다음 접촉). 또는 진영이 흩어지면서 떨어짐 |
| 양동 | 접촉 중인 작은 부대가 다른 곳의 적 둘 이상을 끌어냄. 그 뒤 더 큰 그룹이 4 R 떨어진 곳, 적이 적은 곳을 침 |
| 철수 / 추격 | 접촉 중인 그룹이 몸을 돌려 싸우던 곳에서 R만큼 벌어짐. 그곳의 적이 방금 그 그룹의 한 유닛을 죽였고, 그 그룹이 그 킬러에서 2 R 떨어지면 확실함(걸어서 하는 경우는 절대 아님. 아래를 보세요). 같은 방향으로 움직이며 따라붙는 적은 추격하는 것으로 봄 |
| 종심 방어 | 적의 진로를 가로질러 둘 이상의 띠에 서 있는 유닛들이 R 깊이로 자리 잡음. 적이 다가오고, 띠에서 사격함 |
| 역사면 방어 | 능선을 넘어온 피해자 쪽 유닛들을, 서 있던 유닛들이 짧은 거리에서 셋 이상 격파함 |
| 매복 | 움직이는 그룹이 45초 동안 서 있던 적을 만남. 적이 먼저 쏘고, 움직이던 쪽은 두 유닛을 잃거나 그룹의 절반을 잃음 |
| 전방 경계 | 셋 이상으로 이루어진 본대보다 앞서 움직이는 한두 유닛이, 적을 먼저 만남 |
| 내선 | 한 진영의 그룹들이 상대 그룹들 사이에서 서로 가깝게 모이고, 그 유닛들이 그 사이를 옮겨 다님 |
| 템포 | 한 진영이 접촉에 대응하는 속도(방향 전환, 속도 변화, 첫 사격)가 1.5배 빠름. Mann-Whitney p가 0.05 미만 |
| 크랭크, 노치, 드래그, 펌프 | 미사일 발사의 표적이 발사자를 35~70°, 75~105°, 또는 140°를 넘어 돌려 세우거나, 끌었다가 되돌림 |
| 공중 협공, 벽, 리드-트레일, 그라인더 | 한 쌍이 한 적에게 갈라져 덤빔. 세 대가 나란히 적을 향함. 한 요소가 다른 요소보다 5~20 km 뒤에 있음. 두 대가 한 점 둘레를 선회하며 서로 떨어져 있음 |
| 전투 공중 초계 | 한 지점 둘레를 3분 동안 선회함 |
| 에너지 / 각도 전투 | 근접 전투에서. 진행 방향이 30° 떨어져 있고, 서로 번갈아 상대를 코앞에 둠. 또는 그사이에서 격파가 있음. 고도를 쓰고 올라가거나, 수평으로 날며 급선회하고 속도를 줄임. 한쪽이 상대를 격파하면 확실함 |
| 타격 편대, SEAD | 역할이 섞인 공중 그룹으로, 그중 일부가 지상을 공격함. 방공 격파가 대부분의 다른 지상 격파보다 앞섬 |
| 전투 대열, T자 가로지르기 | 종대로 늘어선 함선 셋. 또는 적 종대의 머리 앞을 가로질러 정사각형으로 늘어선 종대 |

각 기동은 지식 기반의 어떤 **패턴**을 보여 주는지(`patterns-maneuver.ts`: 대형, 정면 공격, 이중 포위, 포위, 돌파, 사격과 기동, 양동, 철수, 추격, 종심 방어, 전방 경계, 분산, 미사일 방어, 각도 전투, 전투 공중 초계, 타격 편대, 전투 대열, T자 가로지르기)과, 먼저 읽을 항목을 알려 줍니다. 예전 항목은 `knowledge/maneuver-tags.ts`를 거쳐 새 패턴을 받습니다. [지식 렌즈](knowledge.md)를 보세요.

**성과 있음**은 그 기동이 진행된 동안(그리고 1분 뒤까지) 유닛들의 교환을, 같은 진영이 경기 전체에서 한 교환과 비교합니다. 철수는 몸을 돌린 뒤에 잃은 유닛이 돌리기 전보다 적을 때 성과가 있다고 봅니다. 미사일 방어는 항공기가 1분을 버틸 때, 포위는 포켓이 절반을 잃을 때 성과가 있다고 봅니다.

## 여러 경기에 걸쳐 {#over-many-matches}

경기마다의 요약(`src/mass/summarize.ts`, [대량 분석](mass-analysis.md)을 보세요)에는 작은 `maneuvers` 항목이 들어 있습니다. 종류와 진영별로, 수행한 수(가능성 높음 이상), 성과가 있었던 수, 성과가 없었던 수, 격파와 손실을 담습니다. **대량 분석 → 기동**은 필터가 남긴 경기들을 합산합니다. 맵과 모드별로, 또는 전체를 한꺼번에 보여 줍니다. 성과율에는 윌슨 신뢰구간을 붙이고, 한 행을 클릭하면 그 행의 기동이 나온 경기를 불러옵니다. 이 항목이 생기기 전에 만들어진 요약에는 이 항목이 없습니다. `node tools/3dheat-summarize.mjs <폴더> --force`를 실행해 추가하세요.

## 얼마나 확실한지 {#how-sure-it-is}

기동을 미리 심어 둔 합성 경기(`synth.ts`, `maneuver.test.ts`가 실행함)에서는 심은 28종이 모두 가능성 높음 이상으로 찾아졌습니다. 보고된 기동 50건 중 31건은 심은 종류였고, 나머지 19건은 실제로도 있었습니다(움직이는 그룹의 대형, 돌파하는 종대의 정면 접근). 틀린 것은 없었습니다. 기동이 없는 경기 30개(서로 떨어진 무작위 걸음과 섞인 걸음, 무작위로 서 있는 유닛, 직선으로 나는 항공기, 우왕좌왕하는 군중)에서는 가능성 높음 이상으로 아무것도 보고되지 않았습니다.

실제 데이터(수십 건의 지상전, 긴 공중전 임무 몇 건, 슈팅 경기 열두 건 정도)에서는 다음과 같이 나왔습니다. 전차전에서는 정면 공격, 측면 공격, 돌파, 포위. 공중전에서는 대형과 근접 전투. 공중전 임무에서는 미사일 방어, 전투 공중 초계 선회, 리드-트레일 쌍. 슈팅 경기에서는 정면 처형, 종대, 그리고 몇몇 매복과 엄호하의 약진 쌍. 임계값은 교리의 모양을 게임 규모에 맞춘 것입니다. 하나의 발견은 근거와 함께 읽고, 대량 분석 표의 비율은 신뢰구간과 함께 읽으세요.

### 같은 경기에 대한 귀무 모델과 비교 {#against-null-models-of-the-same-matches}

탐지기는 지형과 군중에게 속을 수 있습니다. 난전에서는 모든 그룹에 사방으로 적이 있기 때문입니다. 그래서 각 종류를 같은 경기로 만든 **귀무 모델**(`nulls.ts`)에서도 돌립니다. 이 모델에서는 두 진영이 실제처럼 마주치지 않습니다. 한 진영의 시간축을 경기의 3분의 1에서 3분의 2 사이만큼 돌려 놓거나(*shift*), 그 궤적을 맵 중심을 기준으로 돌려 놓습니다(*rotate*). 팀 이름은 무작위로 섞습니다(*teams*. 구성상 실제 전투의 절반 정도는 그대로 남습니다). 전투는 격파를 그 죽음과 짝지어서만 셉니다. 킬러는 2 R 안에 있고, 희생자는 그 자리에 있어야 합니다. 귀무 모델은 이 조건을 깨뜨립니다. 탱크전 30개와 슈팅 경기 12개에서, 실제와 귀무 모델에 대해 가능성 높음 이상으로 찾은 수는 다음과 같습니다.

| 종류 | 탱크전: 실제 / shift / rotate | 슈팅: 실제 / shift / rotate |
|---|---|---|
| 포위 | 0 / 0 / 0 (전에는 1.3 / 1.2 / 0.8) | 0 / 0 / 0 |
| 돌파 | 0.03 / 0.02 / 0.05 (전에는 1.6 / 1.8 / 1.4) | 0 / 0 / 0 |
| 측면 | 0.33 / 0.07 / 0.10 | 1.0 / 0.08 / 0.21 |
| 정면 공격 | 0.87 / 0.47 / 0.12 | 14.4 / 6.5 / 4.3 |
| 철수 | 0.03 / 0 / 0.02 | 0.08 / 0.08 / 0.5 (그래서 걸어서는 절대 확실하지 않음) |
| 매복 | - | 0.17 / 0.04 / 0.04 |
| 에너지 전투 | 1.2 / 0.1 / 0.85 | - |
| 각도 전투 | 0.6 / 0.07 / 0.3 | - |

전장의 중심 근처에서 벌어진 근접 공중전은 그 중심을 기준으로 돌려도 살아남기 때문에, rotate 열은 지상 종류보다 이들에게 덜 불리합니다. 한 진영 안에서 일어나는 종류(대형, 전투 공중 초계, 그라인더, 타격 편대, SEAD, 엄호하의 약진, 전방 경계)는 상대 진영에 기대지 않으므로 이 방식으로는 시험하지 않습니다. `maneuver.test.ts`는 귀무 모델이 합성 경기에서 심어 둔 측면, 협공, 포위, 돌파, 매복, 철수를 실제로 없애는지 확인합니다.

## 한계 {#limits}

- 그룹을 알려면 시간에 따른 위치가 필요합니다. 이벤트만 있는 파일에는 위치가 없습니다.
- 방향은 데이터에서 읽지 않습니다. 적의 전선은 고정 전력이 교전하는 곳이고, 없으면 적이 움직이는 방향이며, 그것도 없으면 공격자가 온 방향입니다.
- 지형은 유닛 자신의 높이로 읽습니다(역사면 방어). 시선이 통하는지 검사하지는 않습니다.
- 아주 큰 파일은 더 긴 간격으로 샘플링합니다. 그래도 그 안의 짧은 공중 기동은 2~4초 간격으로 읽습니다.
