# 키보드와 마우스 참조

모든 키와 마우스 동작을 한곳에 모았습니다. 필요한 것을 찾으십시오. 키를 쓰기 전에 먼저 뷰를 클릭하십시오. 그래야 뷰가 키보드를 받습니다. 글 상자나 드롭다운에 초점이 있으면 키는 무시됩니다. 짧은 요약은 뷰 왼쪽 아래에도 인쇄되어 있습니다.

빠른 찾기:

| 하고 싶은 것 | 누를 키 |
|---|---|
| 날아다니기 | `W A S D`, 드래그하여 둘러보기 |
| 모두 보기 | `F` |
| 재생 또는 일시정지 | `K` |
| 거꾸로 재생 | `J`(다시 누르면 일시정지), 앞으로 `L` |
| 색의 뜻 보기 | `?` 또는 `F1` |
| 전술 탭에서 되돌리기 | `Ctrl+Z` |

## 카메라 {#camera}

[`camera.ts`](https://github.com/Holdi601/3DHeat/blob/main/src/render/camera.ts)에서 가져왔습니다.

| 입력 | 효과 |
|---|---|
| `W` / `↑` | 보는 방향으로 앞으로 |
| `S` / `↓` | 뒤로 |
| `A` / `←` | 왼쪽으로 옆걸음 |
| `D` / `→` | 오른쪽으로 옆걸음 |
| `Space` / `E` | 위로 |
| `Q` / 왼쪽 `Ctrl` | 아래로 |
| `Shift`(어느 쪽이든) | 누르고 있으면: 6배 빠르게 |
| 왼쪽 `Alt` | 누르고 있으면: 15% 속도 |
| 뷰에서 왼쪽 또는 오른쪽 드래그 | 둘러보기(버튼을 누르는 동안 포인터 잠금) |
| 휠(원근) | 비행 속도 ×1.5 한 칸마다(휠 이벤트 하나당 최대 4칸) |
| 휠(평행) | 확대/축소 |
| 오른쪽 클릭 | 뷰 위에서는 맥락 메뉴를 열지 않음 |

## 전역 {#global}

[`App.tsx`](https://github.com/Holdi601/3DHeat/blob/main/src/App.tsx)에서 가져왔습니다.

| 키 | 효과 |
|---|---|
| `K` | [타임라인](timeline.md) 재생 / 일시정지 |
| `F` | 데이터에 맞춰 보기 |
| `C` | 카메라의 위치, 방향(yaw)과 기울기(pitch)를 복사([카메라 표시](camera.md#camera-readout)) |
| `G` | 입력한 지점으로 가기: 카메라 표시 아래의 상자를 엽니다 |
| `Esc` | 선택 카드를 닫고, 그다음 두 번째 유닛 보기를 멈추고, 그다음 유닛 따라가기를 멈춥니다 |
| `T` | 전술 표시 보기 켜기/끄기([경기 리플레이](match-replay.md#display-style)) |
| `?` / `F1` | 도움말 모드: 색의 뜻([설정, 단위, 키](settings.md#help-mode)) |
| `1` | [히트](heat.md) |
| `2` | [차이](difference.md) |
| `3` | [팀 히트](team-heat.md) |
| `4` | [선](line-heat.md) |
| `]` | 먼 컬링 경계를 ×1.12만큼 밖으로(`Shift`: ×1.35) |
| `[` | 먼 컬링 경계를 ÷1.12만큼 안으로(`Shift`: ÷1.35) |
| `\` | 먼 컬링 경계를 끄기 / 끈 자리에서 다시 켜기([깊이와 컬링](depth-and-culling.md#keyboard)) |

**피규어 오버레이** 모드에는 숫자 키가 없습니다. 모드 막대에서 고르거나 경기 탭을 여십시오. 숫자 키도 모드 막대와 같은 검사를 거칩니다. 불러온 데이터에서 막대가 쓸 수 없다고 표시한 모드의 키는 아무 일도 하지 않습니다.

## 경기 리플레이 {#match-replay}

[경기 리플레이](match-replay.md)에서 쓰는 피규어 오버레이 모드에서 작동합니다(경기 탭이 씁니다). 유닛을 따라가든 따라가지 않든 작동하며, 표시한 경우는 예외입니다:

| 키 | 효과 |
|---|---|
| `B` | 책갈피 추가: 그 순간과 카메라 |
| `M` | 2D 지도: 모서리, 전체 뷰, 끄기 |
| `V` / `Shift+V` | 따라가는 유닛의 다음 / 이전 카메라 보기 |
| `H` | 조종석과 패들록 보기에서 헤드업 디스플레이 |
| `Page Down` / `Page Up` | 이벤트 목록이 보여 주는 종류의 다음 / 이전 이벤트 |
| `J` | 거꾸로 재생; 다시 누르면 일시정지 |
| `L` | 앞으로 재생; 다시 누르면 일시정지 |
| `.` / `,` | 1초 앞으로 / 뒤로, 일시정지 상태에서(`Shift`: 10초) |
| `Esc` | 먼저 대상을 보기 멈추고, 그다음 따라가기를 멈춤 |
| 유닛을 `Ctrl`+클릭 또는 `Alt`+클릭(뷰에서 또는 유닛 목록에서) | 따라가는 유닛의 위치에서 그것을 봄(두 유닛 보기); 다시 클릭하면 해제 |
| 유닛 두 개를 `Shift`+클릭 | 둘 사이를 잼: 방위, 거리, 높이 차이 |

`V`는 따라가는 유닛이 있어야 합니다. 여기서 `M`은 2D 지도이고, 전술 탭에서는 "이동"입니다.

## 유닛 따라가기 {#following-a-unit}

카메라가 유닛을 따라가는 동안에는 휠과 날아다니는 키가 자유 비행 대신 유닛 주위를 돕니다([카메라](camera.md#while-following-a-unit)):

| 입력 | 효과 |
|---|---|
| 휠, `W` / `S` | 더 가까이 / 더 멀리(위성 보기에서는 더 높이 / 더 낮게). 조종석과 패들록 보기에서는 작동하지 않음. |
| `A` / `D`, `Q` / `E` | 유닛 주위 공전(추적 보기와 공전 보기) |
| 드래그 | 유닛 주위를 둘러보기; 조종석에서는 안을 둘러보기 |
| `V` / `Shift+V` | 다음 / 이전 카메라 보기 |
| `H` | 헤드업 디스플레이(조종석과 패들록 보기) |
| `Esc` | 두 번째 유닛 보기를 멈추고, 그다음 따라가기를 멈춤 |

## 전술 보드 {#tactics-board}

전술 탭([전술 보드](tactics-board.md))에서 씁니다. `F`, `C`, `G`, `T`는 위와 같이 작동합니다. 숫자 키는 아무 일도 하지 않습니다.

| 키 | 효과 |
|---|---|
| `Ctrl+Z` | 되돌리기 |
| `Ctrl+Y` 또는 `Ctrl+Shift+Z` | 다시 하기 |
| `Enter` | 그리고 있는 화살표를 끝냄(더블클릭이나 오른쪽 클릭도 같습니다) |
| `Esc` | 끌기를 취소; 아니면 진행 중인 화살표나 이동을 놓음; 아니면 선택 해제 |
| `Delete` 또는 `Backspace` | 선택 항목 삭제 |
| `W` / `E` / `R` | 선택 항목의 이동 / 회전 / 크기 기즈모(키 방식 **W / E / R**) |
| `G` / `R` / `S` | 선택 항목의 이동 / 회전 / 크기 기즈모(키 방식 **G / R / S**) |
| `R` | 아무것도 선택하지 않았을 때: 다음에 놓을 피규어를 15° 돌립니다. `Shift+R`은 되돌립니다. |
| `M` | 피규어를 선택했을 때: 다음 클릭 위치로 옮깁니다 |
| `K` | 계획 재생 / 일시정지 |
| Shift+클릭 | 선택에 더하거나 선택에서 뺌 |
| Shift+드래그 | 선택할 것을 둘러싸는 상자를 그림 |
| 손잡이를 드래그하는 동안 `Ctrl` | 격자나 각도 단위에 맞춤 |

기즈모 키는 무언가 선택했을 때만 작동합니다. 아무것도 선택하지 않았으면 `W A S D`는 평소처럼 카메라를 날아다니게 합니다.

## 클릭으로 고르기 {#click-to-pick}

**클릭하면 그곳에 무엇이 있는지 표시**가 켜져 있고 **자 켜짐**이 꺼져 있을 때([클릭으로 고르기](camera.md#click-to-pick)):

| 입력 | 효과 |
|---|---|
| 왼쪽 클릭(4 px보다 많이 드래그하지 않을 때) | 데이터 점을 보여 줍니다. 없으면 포인터 아래의 레벨 위 지점을 보여 줍니다 |

## 측정 {#measure}

**자 켜짐**이 켜져 있을 때([측정](measure.md)):

| 입력 | 효과 |
|---|---|
| 왼쪽 클릭(4 px보다 많이 드래그하지 않을 때) | 점을 하나 놓음 |
| 오른쪽 클릭 | 마지막 점을 지움 |

## 그 밖의 곳 {#elsewhere}

| 어디서 | 입력 | 효과 |
|---|---|---|
| 슬라이더의 손잡이(숫자 옆의 손잡이) | 위 / 아래로 드래그 | 값을 계속 바꿈. 더 멀리 끌수록 더 빠르게 바뀝니다. 세밀하게 조절하려면 `Shift`를 누르십시오. 놓으면 멈춥니다. |
| 뷰 위의 속도 표시 | 위 / 아래로 드래그 | 같은 방식으로 비행 속도를 바꿉니다. |
| 자세 상자 | `Enter` | 입력한 위치나 방향을 적용합니다. |
| 곡선 편집기 | 더블클릭 / Alt-클릭 / 오른쪽 클릭 | 점 추가 / 점 제거([스프라이트 모양](sprite-shape.md#the-curve-editor)) |

## 레이스 분석 탭 {#race-analysis-tab}

레이스 분석 탭에서는 `K`가 레이스 리플레이를 재생하고 일시정지하며, `Home`은 되감고, 숫자 키는 아무 일도 하지 않습니다. [레이스 분석](race-analysis.md)을 보십시오.

## 브라우저에서 뷰어가 가져가는 키 {#keys-the-viewer-keeps-from-the-browser}

어떤 브라우저 단축키는 페이지를 닫거나 새로 고쳐서 불러온 세션을 잃게 만듭니다. 뷰어는 그런 키를 자기가 씁니다. 목록은 코드에서 생성됩니다: [브라우저 키](ref-browser-keys.md).
