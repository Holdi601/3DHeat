# 히트 모드

점 하나마다 작은 빛이 더해지고, 빛들이 쌓이며, 쌓인 것을 색으로 칠합니다. 모드는 그것을 칠하는 다섯 가지 방법이며, 각각 질문 하나에 답합니다.

히트맵 탭 사이드바 맨 위의 모드 막대는 [데이터셋](glossary.md)을 어떻게 그릴지 고릅니다. 1-4 키는 **히트**, **차이**, **팀 히트**, **라인**을 고릅니다. 피규어 오버레이에는 키가 없습니다.

![히트, 차이, 팀 히트, 피규어 오버레이, 라인이 있는 모드 막대](../assets/img/en/heat-modes-bar.webp)

| 모드 | 답하는 질문 |
|---|---|
| **히트** | 어디서, 얼마나 일어났나? |
| **차이** | 어느 쪽이 더 많이 했나? |
| **팀 히트** | 누구의 것이었나? |
| **라인** | 사람들은 어느 방향으로 갔나? |
| **피규어 오버레이** | 누가 언제 어디에 있었나? |

![같은 데이터를 히트, 차이, 팀 히트, 라인 네 가지 모드로 본 모습](../assets/img/en/heat-modes-grid.webp)

| 모드(막대 표시) | 키 | 그리는 것 | 필요한 것 |
|---|---|---|---|
| **히트** | 1 | 누적 밀도: 보이는 행마다 카메라를 향한 원형 스프라이트를 하나씩 더합니다. [히트](heat.md) | 데이터셋 |
| **차이** | 2 | 부호 있는 밀도: 한 집단은 더하고, 다른 집단은 뺍니다. [차이](difference.md) | 두 쪽: 그룹이 최소 두 개이거나, 보관한 열로 나눈 것 |
| **팀 히트** | 3 | 그룹별로 색을 입힌 밀도: 그룹마다 색 하나이고, 그룹이 겹치는 곳에서는 색을 섞습니다. [팀 히트](team-heat.md) | 그룹 열 |
| **피규어 오버레이** | - | 사람마다 피규어(또는 상자) 하나가 타임라인을 따라 움직입니다. 리플레이입니다. [피규어 오버레이](box-replay.md), [매치 리플레이](match-replay.md) | 사람 열 |
| **라인** | 4 | 선 히트: 사람의 각 샘플에서 그 사람의 다음 샘플까지 선을 긋고, 옆으로 갈수록 세기가 줄어듭니다. [선 히트](line-heat.md) | 사람 열과 시간 열 |

데이터가 지원하지 않는 모드는 흐리게 표시되고, 툴팁에 이유가 나옵니다. 예를 들면 *사용할 수 없음 - 차이 모드에는 그룹 두 개나 나눌 수 있는 보관된 열이 필요합니다. 이 데이터에는 그룹이 하나뿐입니다.* 새 데이터셋이 현재 모드를 지원하지 못하면, 보기는 **히트**로 돌아갑니다.

1-4 키도 같은 방식으로 데이터를 확인합니다. 흐리게 표시된 모드의 키는 아무 일도 하지 않습니다.

## 모든 히트 모드가 공유하는 것 {#what-every-heat-mode-shares}

피규어 오버레이를 뺀 히트 모드 네 가지는 입력만 다른 같은 기계입니다([`engine.ts`](https://github.com/Holdi601/3DHeat/blob/main/src/render/engine.ts)):

1. **어떤 행인가.** [타임라인](timeline.md)의 구간이 시간순으로 정렬된 행들의 연속된 범위를 고릅니다. [필터](filters.md), 그룹 표시 여부, 차이 분할, [거리 컬링](depth-and-culling.md#distance-culling), [단면](slice.md)은 버텍스 셰이더에서 행마다 기여할지, 그리고 얼마나 강하게 기여할지를 정합니다.
2. **스플래팅.** 기여하는 행은 각각 스프라이트(라인 모드에서는 선분)로, 부동소수점 **히트 대상**에 그려지며 자기 램프 값을 더합니다. 한 프레임이 감당할 수 있는 양보다 행이 많으면, 가중치를 보정한 층화 표본만 그립니다. [샘플링과 예산](sampling-and-budgets.md)을 보세요.
3. **누적.** 아무것도 바뀌지 않는 동안 프레임을 합칩니다. 모든 행이 정확히 한 번씩 기여할 때까지 합칩니다. [누적](accumulation.md)을 보세요.
4. **합성.** 각 픽셀의 누적 값은 **포화점**으로 나누고, **밀도 응답**으로 모양을 잡고, **최소 히트**만큼 올린 뒤, **히트 램프**에서 찾습니다. 램프의 알파 값이 장면 위에 섞입니다. [색과 노출](colour-and-exposure.md)을 보세요.

4단계의 모든 것은 합성 시점에 적용됩니다. 그래서 그 조절 장치를 끌어도 누적이 다시 시작되지 않습니다. 1-2단계에 속한 것을 바꾸면 누적이 다시 시작됩니다.
