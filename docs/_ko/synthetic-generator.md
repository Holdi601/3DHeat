# 합성 생성기

자신의 데이터가 없나요? 버튼 하나를 누르면 3DHeat가 원하는 크기의 가상 전투를 만들어 줍니다.

1. 히트 사이드바의 **데이터셋** 패널(**소스** 아래)을 여세요.
2. **합성 데이터 생성기**까지 스크롤하세요.
3. **행(백만)**을 정하세요. 먼저 1로 해 보세요. 기본값 8백만은 처음 시도하기에는 무겁습니다.
4. **생성**을 누르세요.

![행 100만 개, 팀 8개, 팀 히트로 그린 그림](../assets/img/en/synthetic-generator-team-heat.webp)

**데이터셋** 패널은 데이터를 불러오는 대신 데이터셋을 만들 수 있습니다. 두 가지 목적이 있습니다. 자신의 데이터 없이 뷰어를 시험해 보는 것, 그리고 큰 실제 데이터를 *불러오기 전에*, 주어진 행 수, 스프라이트 반경, 예산이 그 컴퓨터에서 쓸 만한 프레임 속도를 유지하는지 확인하는 것입니다. 움직임은 배틀 로열 경기처럼 만들어집니다. 팀은 떨어진 곳에서 시작하고, 그다음 모여듭니다. 균일한 잡음은 어떤 예산에서도 괜찮아 보이고, 잡아낼 가치가 있는 바로 그 결함을 가리기 때문입니다.

## 컨트롤 {#controls}

| 컨트롤 | 기본값 | 뜻 |
|---|---|---|
| **행(백만)** | 8 | 생성할 행 수. 모든 플레이어에 대해 틱의 정수 개수로 내림합니다. |
| **팀** | 8 | 그룹 수 (최소 1). |
| **팀당** | 12 | 그룹당 플레이어 수 (최소 1). |
| **맵 절반 크기(m)** | 4000 | X와 Z에서 플레이 가능한 영역 너비의 절반. |
| 추정 줄 | | "≈ X GB의 RAM, 양자화 후 GPU에 Y GB." (행당 약 26바이트의 RAM과 8바이트의 GPU). |
| **생성** | | 인제스트 워커에서 진행률과 함께 생성하고, 불러온 데이터셋을 바꿉니다. |

생성은 백그라운드 워커에서 실행되므로, 수천만 행이어도 페이지가 멈추지 않습니다.

## 무엇을 만드나요 {#what-it-generates}

[`src/data/synth.ts`](https://github.com/Holdi601/3DHeat/blob/main/src/data/synth.ts)에서:

- **열:** 위치, 시간, 사람 (`P000`, `P001`, ...), 그룹 (`Team 1`, `Team 2`, ...), 요(yaw)와 피치, 수명. 세션 열과 필터 열은 없습니다.
- **시간:** 0부터 시작하여 0.25초마다 플레이어당 샘플 하나 (상대 시간, 벽시계 시간 없음).
- **움직임:** 각 팀은 반지름의 55-95% 위치에 있는 고리의 자기 구역에서 시작합니다. 가운데 근처에 중심을 둔 안전한 원(무작위로 절반 크기의 최대 1/4만큼 옮겨짐)이 여섯 단계에 걸쳐 절반 크기의 8%까지 줄어들며, 중간중간 멈춥니다. 모든 플레이어는 그 안의 떠도는 점을 향해 조향하며, 감쇠와 잡음이 있습니다. 높이는 0에서 220m 사이에서 출렁입니다.
- **시선 방향:** 요는 이동 방향을 따르고, 피치는 수직 속도에서 옵니다.
- **반복 가능:** 난수 시드가 1337로 고정되어 있으므로, 같은 설정은 항상 같은 데이터를 만듭니다.

모든 히트 모드, 상자 재생, 라인 히트(이벤트 열이 없으므로 전체 궤적)가 이 데이터에서 작동합니다. 수명 기록도 작동합니다.
