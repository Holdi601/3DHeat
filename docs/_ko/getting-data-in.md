# 데이터 가져오기

3DHeat이 무엇이든 그리려면 먼저 표가 필요합니다. 표의 각 행은 어디에 있었는지를 알려 주고, 가지고 있다면 언제, 누구였는지도 알려 줍니다. 이 섹션은 파일이 그림이 되는 과정을 보여 줍니다. 아직 데이터가 없다면 [데모 데이터](demo-data.md)를 해 보세요.

**지금 할 일:**

1. 히트맵 사이드바에서 **소스**를 열고 **파일…**을 누릅니다(또는 파일이나 폴더를 드롭 영역에 끌어다 놓습니다).
2. **열 매핑**을 봅니다. 상자들은 보통 이미 채워져 있습니다.
3. **메모리 추정**이 *맞음*이라고 나오는지 확인합니다.
4. **불러오기**를 누릅니다.

```mermaid
flowchart LR
  A["소스<br/>파일이나 폴더 고르기"] --> B["미리보기<br/>첫 행들"]
  B --> C["열 매핑<br/>X, Y, Z, 시간, 사람, 팀"]
  C --> D["메모리 추정<br/>맞음, 빠듯함, 안 맞음"]
  D --> E["불러오기"]
  E --> F["그림"]
```

히트맵 탭에 보이는 모든 것은 **데이터셋** 하나에서 나옵니다. 데이터셋은 행들의 표입니다. 각 행에는 위치가 있고, 선택적으로 시간, 사람, 그룹, 세션, 바라보는 방향, 그리고 필터링을 위해 보관한 여러 추가 열이 있습니다. 이 섹션은 데이터셋이 어떻게 만들어지는지 설명합니다.

## 파일에서 그림까지의 과정 {#the-path-from-files-to-picture}

1. **소스** 패널에서 **파일 고르기**. 파일 하나, 여러 개, 폴더 트리, 또는 끌어다 놓기로 고를 수 있습니다. Parquet, CSV, Tacview, GPS 트랙 등을 받습니다. 전체 목록은 [데이터 형식](data-formats.md#files)에 있습니다. [파일 불러오기](loading-files.md)를 보세요.
2. **미리보기.** 선택한 파일 중 첫 번째 파일을 엽니다. 열 이름, 처음 50행, 숫자로 보이는 열, 그리고 (Parquet의 경우) 각 열의 논리 형식과 파일 자체의 읽기 지침인 `heat3d` 푸터 항목을 보여 줍니다.
3. **자동 매핑.** 열들을 X, Y, Z, 시간, 사람, 세션, 그룹, 바라보는 방향 같은 역할에 배정하고, 몇 개는 필터링용으로 보관합니다. 모든 추정은 **열 매핑** 패널에 보이며 바꿀 수 있습니다. [열 매핑](column-mapping.md)과 [축, 단위, 시간](axes-units-and-time.md)을 보세요.
4. **집계.** 각 파일의 행 수를 읽습니다(Parquet 푸터에서는 정확히, CSV에서는 추정으로). 그래서 패널은 아무것도 불러오기 전에 불러오기에 메모리가 얼마나 드는지, 그리고 들어가는지를 알려 줄 수 있습니다. 들어가지 않으면 *N*행마다 하나씩 불러오자고 제안합니다. [메모리와 예산](memory-and-budgets.md)을 보세요.
5. **불러오기.** 백그라운드 작업자가 모든 파일에서 매핑된 열만 읽습니다. 여러 파일을 동시에, [파서 스레드](memory-and-budgets.md#parser-threads) 예산까지 읽고, 선택한 순서대로 하나의 데이터셋으로 합칩니다. 모든 파일이 사람, 그룹, 세션의 사전을 하나씩 공유하고, 시간 기준점도 하나이며, 모든 행은 시간순으로 정렬됩니다. [세션, 사람, 그룹](sessions-persons-groups.md)을 보세요.
6. **업로드.** 메인 스레드가 한 프레임 동안 "GPU로 N행 업로드 중"이라고 알리고, GPU 예산 안에서 행을 GPU 메모리에 채웁니다. [GPU 메모리 상주](gpu-memory.md)를 보세요.
7. **첫 그림.** 카메라가 데이터에 맞춰지고, 스프라이트 반경과 채도는 데이터의 범위와 행 수로 정해집니다. 8프레임을 그린 뒤에는 채도를 그림 자체에서 측정합니다([색과 노출](colour-and-exposure.md)).

## 불러오기 전에 확인하는 요구 사항 {#requirements-checked-before-a-load}

| 필요한 것 | 없으면 어떻게 되나 |
|---|---|
| **X / Y / Z 중 최소 두 개** | 불러오기가 거부됩니다. 정확히 두 개만 있으면 세 번째 축은 0이 되고, 데이터는 3D 장면에서 평평한 면으로 그려집니다. 위에서 내려다본 지도 히트맵이 원하는 모양이 바로 이것입니다. |
| 시간 열 | 선택 사항입니다. 없으면 타임라인이 꺼지고, 보기는 **전체** 모드에 머무르며, 사이드바가 이를 알려 줍니다. |
| 사람 열 | 선택 사항입니다. [피규어 오버레이](box-replay.md)(사람마다 피규어 하나), [선 히트](line-heat.md)(사람이 걸은 경로), 보간, 자취, **수명** 기록에 필요합니다. |
| 그룹 열 | 선택 사항입니다. [팀 히트](team-heat.md)와 [차이](difference.md) 모드(그룹이 최소 두 개)에 필요합니다. |

불러온 데이터가 지원하지 못하는 모드는 모드 막대에서 흐리게 표시됩니다. 마우스를 올리면 이유가 나옵니다.

## 자기 데이터가 없을 때 {#without-your-own-data}

**데이터셋** 패널(**소스** 아래)에는 [합성 생성기](synthetic-generator.md)가 있습니다. 배틀 로얄 모양의 데이터셋을 원하는 크기로 만들어 줍니다. 뷰어를 시험해 보거나, 컴퓨터가 얼마나 감당하는지 확인할 때 쓸모가 있습니다.
