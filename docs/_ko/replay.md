# 리플레이

리플레이는 경기를 3D로 다시 재생합니다. 모든 유닛은 실제 그 차량이나 사람의 모습으로 그려집니다. 무슨 일이 있었는지 보거나, 많은 경기를 비교하거나, 누가 누구를 맞혔는지 볼 때 쓰세요.

- [경기 리플레이](match-replay.md): 경기 하나를 재생합니다. 피겨, 트레이서, 피격, Tacview 방식의 카메라를 씁니다.
- [여러 경기 동시에](many-matches.md): 수백 경기를 서로 겹쳐 놓습니다.
- [피겨](figures.md): 유닛에 쓰는 모양과 그 모양의 출처입니다.
- [피격 분석](hit-analysis.md): 차량이나 병사가 어디를 맞았는지, 누가 쐈는지 보여 줍니다.
