# 레벨 라이브러리

라이브러리는 이 브라우저에 레벨을 보관하므로, 레벨을 다시 불러오고 단순화할 필요가 없습니다. **브라우저에서 사이트 데이터를 지우면 라이브러리도 삭제되며, 내보내기는 없습니다.** 원본 파일은 보관하세요.

레벨을 처리하는 것(파싱, 분류, 용접, 데시메이션, 텍스처 패킹)은 느리고, 결과는 매번 같습니다. 배경 / 레벨 패널 아래의 **라이브러리**는 처리된 레벨을 이 브라우저에 보관하므로, 데시메이션된 메시를 두 번 다시 만들지 않습니다 ([`levelLibrary.ts`](https://github.com/Holdi601/3DHeat/blob/main/src/data/levelLibrary.ts)).

## 레벨 저장하고 다시 불러오기 {#save-and-reload-a-level}

1. 지도 이미지나 3D 모델을 불러오고, 제대로 보이는지 확인하세요.
2. **라이브러리에 저장**을 누르세요. 패널에 *Saved. It will load instantly next time.*(저장됨. 다음에는 즉시 불러옵니다.)라고 나타납니다.
3. 다음에는 **라이브러리** 목록을 열고, 레벨의 ▸를 누르세요.
4. 더 이상 필요 없는 항목은 ✕를 눌러 지우세요.

## 사용법 {#using-it}

| 컨트롤 | 효과 |
|---|---|
| **라이브러리에 저장** | 현재 레벨을 저장합니다. 지도 이미지는 두 앵커와 함께 PNG로, 모델은 처리된 버퍼로 저장합니다. 패널에 *Saved. It will load instantly next time.*이라고 나타납니다. |
| 라이브러리 목록 | 저장된 레벨마다 한 행: 이름(마우스를 올리면 저장된 크기), 모델이면 삼각형 수, 이미지면 픽셀 너비. |
| ▸ (*Load*) | 항목을 현재 레벨로 불러옵니다. |
| ✕ (*Delete*) | 항목을 지웁니다. |
| 사용량 줄 | `Using X of Y.` - 이 사이트의 브라우저 저장 공간 추정치. |

저장된 것이 없으면 목록에 *Empty. Load a map or model, then "Save to library".*(비어 있음. 지도나 모델을 불러온 뒤 "라이브러리에 저장"을 누르세요.)라고 나옵니다.

## 저장되는 것 {#what-is-stored}

| 종류 | 저장되는 것 | 저장되지 않는 것 |
|---|---|---|
| 지도 이미지 | 이미지 (PNG), 크기, 앵커 | 고도, 뒤집기, 불투명도, 밝기, 채도 제거 - 기본값으로 되돌아감 (고도 = 현재 데이터셋의 가장 낮은 Y, 뒤집기 켜짐) |
| 3D 레벨 | 정점, 정점 색, 텍스처 좌표, 그 타일과 텍스처 아틀라스, 지면 / 구조물 / 물 삼각형, 구조물 가장자리, 삼각형 수 | 부품 이름과 분류 이유, 그리고 모든 외관 설정 - 새로 가져온 것의 기본값으로 되돌아감 |

라이브러리에서 불러온 모델에는 부품 목록이 없으며, 경계와 지면 높이 범위는 정점에서 다시 계산합니다.

## 저장 위치 {#where-it-lives}

브라우저의 IndexedDB에, 데이터베이스 `3dheat`, 객체 저장소 `levels`, 그리고 페이지의 출처(브라우저 주소창의 주소)에 저장됩니다. 이것은 그 브라우저 프로필에만 있습니다. 다른 브라우저, 다른 프로필, 또는 다른 주소(예: `127.0.0.1` 대신 `localhost`)는 다른, 빈 라이브러리를 봅니다. 브라우저에서 사이트 데이터를 지우면 이것도 삭제됩니다. 구조물, 색, 물이 없는 이전 버전에서 저장한 항목도 여전히 불러와집니다.
