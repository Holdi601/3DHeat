# 참조

찾아볼 때 쓰는 정확한 이름, 설정, 도구 목록입니다. 뷰어를 쓰는 데 이 목록을 읽을 필요는 없습니다.

이 목록들은 `node tools/docs-refs.mjs`로 뷰어 코드에서 만들어집니다(직접 실행할 필요는 없습니다). 그래서 만들어진 버전과 항상 맞습니다.

- [이벤트 종류와 등급](ref-event-types.md) - 모든 데이터가 분류되는 이벤트 종류와 차량 등급, 그리고 데이터의 어떤 단어가 어디에 해당하는지
- [열 이름](ref-columns.md) - 위치, 시간, 사람, 팀, 세션, 바라보는 방향을 읽을 때 로더가 인식하는 열 이름
- [언어 목록](ref-languages.md) - 뷰어가 지원하는 언어
- [브라우저 키](ref-browser-keys.md) - 뷰어가 자기 용도로 쓰는 브라우저 단축키
- [저장된 설정](ref-settings-storage.md) - 브라우저가 방문 사이에 기억하는 것들
- [가치 표](ref-value-tables.md) - 가치 가중치의 가격표
- [명령줄 도구](ref-tools.md) - `tools/` 안의 도구. 여러분의 데이터용, 그리고 개발자와 문서용

이 밖의 참조 자료로는 이 사이트에서 쓰는 단어를 정리한 [용어집](glossary.md)이 있습니다. 직접 쓴 페이지는 [데이터 형식](data-formats.md), [키보드와 마우스 참조](keyboard-reference.md), [경기 하나를 담은 파일 (.3dheat)](container.md)입니다.
