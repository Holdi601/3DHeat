# Преглед тастатуре и миша

Сваки тастер и свака радња мишем на једном месту, па можете лако да нађете онај који вам треба. Прво кликните на приказ да би имао тастатуру. Тастери се занемарују док је у фокусу поље за текст или падајући списак. Кратка верзија је исписана и у доњем левом углу приказа.

Брзо тражење:

| Желим да ... | Притисните |
|---|---|
| летим | `W A S D`, превлачите за гледање |
| видим све | `F` |
| пустим или паузирам | `K` |
| пустим уназад | `J` (поново притисните за паузу), унапред `L` |
| видим шта значе боје | `?` или `F1` |
| поништим у картици Тактика | `Ctrl+Z` |

## Камера {#camera}

Из [`camera.ts`](https://github.com/Holdi601/3DHeat/blob/main/src/render/camera.ts).

| Улаз | Дејство |
|---|---|
| `W` / `↑` | Напред у смеру погледа |
| `S` / `↓` | Назад |
| `A` / `←` | Бочно лево |
| `D` / `→` | Бочно десно |
| `Space` / `E` | Горе |
| `Q` / леви `Ctrl` | Доле |
| `Shift` (било који) | Држите: 6× брже |
| леви `Alt` | Држите: 15% брзине |
| Леви или десни превлак по приказу | Гледање (показивач је закључан док држите дугме) |
| Точкић (перспектива) | Брзина летења ×1,5 по зарезу (највише 4 зареза по догађају точкића) |
| Точкић (паралелно) | Зум |
| Десни клик | Над приказом не отвара контекстни мени |

## Опште {#global}

Из [`App.tsx`](https://github.com/Holdi601/3DHeat/blob/main/src/App.tsx).

| Тастер | Дејство |
|---|---|
| `K` | Пушта / паузира [временску линију](timeline.md) |
| `F` | Уклапа податке у кадар |
| `C` | Копира положај камере, скретање и нагиб ([очитавање камере](camera.md#camera-readout)) |
| `G` | Иде на тачку коју укуцате: отвара поље испод очитавања камере |
| `Esc` | Затвара картицу избора; затим престаје да гледа другу јединицу; затим престаје да прати јединицу |
| `T` | Укључује или искључује тактички приказ ([Реприза меча](match-replay.md#display-style)) |
| `?` / `F1` | Режим помоћи: шта значе боје ([Подешавања, јединице и тастери](settings.md#help-mode)) |
| `1` | [Топлота](heat.md) |
| `2` | [Разлика](difference.md) |
| `3` | [Топлота тимова](team-heat.md) |
| `4` | [Линије](line-heat.md) |
| `]` | Граница одсецања далеко се помера ван ×1,12 (`Shift`: ×1,35) |
| `[` | Граница одсецања далеко се помера унутра ÷1,12 (`Shift`: ÷1,35) |
| `\` | Граница одсецања далеко искључена / враћена тамо где је била ([Дубина и одсецање](depth-and-culling.md#keyboard)) |

Режим **Преклапање фигура** нема тастер са бројем; изаберите га у траци режима или отворите картицу Меч. Тастери са бројевима иду истом провером као трака режима: тастер за режим који трака приказује као недоступан за учитане податке не ради ништа.

## Реприза меча {#match-replay}

У режиму Преклапање фигура, који користи картица Меч ([Реприза меча](match-replay.md)). Раде кад је јединица праћена или није, осим где је наведено:

| Тастер | Дејство |
|---|---|
| `B` | Додаје обележивач: тренутак и камеру |
| `M` | 2D мапа: угао, цели приказ, искључено |
| `V` / `Shift+V` | Следећи / претходни поглед камере праћене јединице |
| `H` | Приказ на стакленом екрану у кабини и у погледима падлок |
| `Page Down` / `Page Up` | Следећи / претходни догађај врста које показује листа догађаја |
| `J` | Пуштање уназад; још једном за паузу |
| `L` | Пуштање унапред; још једном за паузу |
| `.` / `,` | Секунда напред / назад, паузирано (`Shift`: десет секунди) |
| `Esc` | Прво престаје да гледа циљ, затим престаје да прати |
| `Ctrl`+клик или `Alt`+клик на јединицу (у приказу или у листи јединица) | Гледа је из праћене јединице (приказ две јединице); још једном кликните да је избаците |
| `Shift`+клик на две јединице | Мери између њих: азимут, домет, разлику у висини |

`V` захтева праћену јединицу. `M` је овде 2D мапа, а у картици Тактика значи „помери”.

## Праћење јединице {#following-a-unit}

Док камера прати јединицу, точкић и тастери за летење окрећу око јединице, уместо да лете слободно ([Камера](camera.md#while-following-a-unit)):

| Улаз | Дејство |
|---|---|
| Точкић, `W` / `S` | Ближе / даље (више / ниже у сателитском приказу). Не у кабини и падлок погледима. |
| `A` / `D`, `Q` / `E` | Кружи око јединице (погледи јурње и орбите) |
| Превлачење | Гледа око јединице; у кабини, гледа унутар ње |
| `V` / `Shift+V` | Следећи / претходни поглед камере |
| `H` | Приказ на стакленом екрану (погледи кабине и падлок) |
| `Esc` | Престаје да гледа другу јединицу, па престаје да прати |

## Табла тактике {#tactics-board}

У картици Тактика ([Табла тактике](tactics-board.md)). `F`, `C`, `G` и `T` раде као горе; тастери са бројевима не раде ништа.

| Тастер | Дејство |
|---|---|
| `Ctrl+Z` | Поништи |
| `Ctrl+Y` или `Ctrl+Shift+Z` | Врати |
| `Enter` | Завршава стрелицу која се црта (дупли клик или десни клик раде исто) |
| `Esc` | Отказује превлачење; иначе скида стрелицу или померање у току; иначе поништава избор |
| `Delete` или `Backspace` | Брише избор |
| `W` / `E` / `R` | Алатка Помери / Ротирај / Скалирај за избор (шема тастера **W / E / R**) |
| `G` / `R` / `S` | Алатка Помери / Ротирај / Скалирај за избор (шема тастера **G / R / S**) |
| `R` | Ништа није изабрано: окреће следећу фигуру за постављање за 15°. `Shift+R` је враћа. |
| `M` | Изабрана фигура: премешта је на следећи клик |
| `K` | Пушта или паузира план |
| Shift+клик | Додаје или скида из избора |
| Shift+превлачење | Црта оквир око онога што се бира |
| `Ctrl` док превлачите ручицу | Привлачи на мрежу или на корак угла |

Тастери алатке раде само кад је нешто изабрано; кад ништа није изабрано, `W A S D` лете камером као обично.

## Избор кликом {#click-to-pick}

Кад је **Клик показује шта је ту** укључено и лењир искључен ([Избор кликом](camera.md#click-to-pick)):

| Улаз | Дејство |
|---|---|
| Леви клик (без превлачења више од 4 пиксела) | Приказује тачку података, или место на нивоу, испод показивача |

## Мерење {#measure}

Кад је **Лењир активан** ([Мерење](measure.md)):

| Улаз | Дејство |
|---|---|
| Леви клик (без превлачења више од 4 пиксела) | Поставља тачку |
| Десни клик | Уклања последњу тачку |

## Остало {#elsewhere}

| Где | Улаз | Дејство |
|---|---|---|
| Ручица било ког клизача (ручица поред броја) | Превлачење горе / доле | Мења вредност непрекидно, брже што даље превлачите; држите `Shift` за фино подешавање. Отпустите да станете. |
| Приказ брзине изнад приказа | Превлачење горе / доле | Мења брзину летења на исти начин. |
| Поља положаја | `Enter` | Примењује уписани положај или оријентацију. |
| Уређивач кривуље | Дупли клик / Alt-клик / десни клик | Додаје тачку / уклања тачку ([Облик спрајта](sprite-shape.md#the-curve-editor)). |

## Картица Анализа трке {#race-analysis-tab}

У картици Анализа трке `K` пушта и паузира репризу трке, `Home` је враћа на почетак, а тастери са бројевима не раде ништа. Видите [Анализа трке](race-analysis.md).

## Тастери које приказивач задржава од прегледача {#keys-the-viewer-keeps-from-the-browser}

Неки прегледачки прецице би затворили или поново учитали страницу и изгубили учитану сесију; приказивач их задржава за себе. Списак се прави из кода: [Тастери прегледача](ref-browser-keys.md).
