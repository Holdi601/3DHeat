# Одржавање документације

Ова страна је за онога ко брине о приказивачу и овом сајту. Наводи кораке да странице, слике и преводи остану тачни после измене.

Овај сајт се поново проверава са **сваким издањем** и кад се нешто јако промени: пречице, пут кроз корисничко сучеље, подешавања, формати датотека. Списак провере:

1. **Поново направите референтне странице**: `node tools/docs-refs.mjs` (и `--lang <lang>` за сваки језик). `node tools/docs-refs.mjs --check` пада кад је нека страница застарела.
2. **Поново направите снимке екрана** из [демо података](demo-data.md). Користите рачунар или контејнер чији је регион en-US, па бројеви изгледају `0.35`, а не `0,35` (поља за бројеве прате регион прегледача док се не промени). Направите демо податке са `node tools/demo-data.mjs`, покрените развојни сервер на порту 5321 **без** локалног пакета фигура, `HEAT3D_FIGURE_PACK=none npx vite --port 5321 --strictPort --host 127.0.0.1`, па покрените `node tools/docs-shots.mjs --lang <lang>`. Погледајте сваку слику: само демо имена (*Demo Valley*, *Blue 1*, *Red 3* ...), без правих мапа, играча или снимака.
3. **Наведите шта се променило** од последње ознаке издања: `git log --oneline <last tag>..HEAD`, и одељак **Docs** у `CHANGELOG.md`, који везује сваку функцију за њену страницу. Свака нова функција треба страницу или одељак, са сликом кад се види на екрану.
4. **Независан преглед** енглеских страница од некога ко их није писао, за три читаоца: почетника, осмогодишњака и стручњака. Да ли су кораци потпуни и у правом редоследу, да ли су речи оне из корисничког сучеља, да ли су слике актуелне и ознаке на дијаграмима тачне?
5. **Поправите оно што је преглед нашао.**
6. **Поново превеците измењене странице** по њиховом хешу изворног текста, па покрените преглед по језику. Видите `tools/docs-translate.md`.
7. **Претражите поверљиве термине** у измењеним датотекама и проверите да ниједна слика не показује ништа осим демо података.
8. **Објавите** само кад је издање одобрено.

Иста провера покрива и сајтове документације сродних репозиторијума (видите страницу [Почетна](index.md#related-repositories)).

## Алати под exporters/ {#the-tools-under-exporters}

Алати око приказивача су засебни јавни пројекти, сваки са својом MIT лиценцом, издањима, викијем и провером ажурирања. Закачени су у овом репозиторијуму као git подмодули:

| Фасцикла | Репозиторијум |
|---|---|
| `exporters/gamefiles/` | [3DHeat-GameFiles](https://github.com/Holdi601/3DHeat-GameFiles) - стазе и нивои из архива самих игара |
| `exporters/gamecapture/` | [3DHeat-GameCapture](https://github.com/Holdi601/3DHeat-GameCapture) - снимачи телеметрије кругова; нивои из снимака игре |
| `exporters/unreal/` | [3DHeat-UnrealExporter](https://github.com/Holdi601/3DHeat-UnrealExporter) - додатак за Unreal Editor |
| `exporters/cs2/` | [3DHeat-CS2](https://github.com/Holdi601/3DHeat-CS2) - CS2 демои и мапе |
| `exporters/watcher/` | [3DHeat-Watcher](https://github.com/Holdi601/3DHeat-Watcher) - снима игру у позадини |

**Закачено** значи да овај репозиторијум бележи тачно један commit сваког алата. Провера приказивача добија те commit-ове:

```bash
git clone --recursive https://github.com/Holdi601/3DHeat
# or, after a plain clone:
git submodule update --init
```

Оба горња начина ажурирања покрећу `git submodule update --init` после повлачења, па алати прате приказивач до commit-ова које његово најновије издање закачи, а не до најновијих commit-ова самих алата. Новије издање алата стиже до приказивача кад се помери закачење овде. Измене алата се прво commit-uju и push-uju у његовој фасцикли (у његовом репозиторијуму), па се тек онда commit-uje ново закачење овде. Сваки алат такође проверава своја новија издања; то је документовано у његовом репозиторијуму.
