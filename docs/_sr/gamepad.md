# Геймпад и HOTAS

Камеру можете летети контролером у стилу Xbox-а уместо тастатуром. Користан је кад желите да се опустите и погледате около по великој сцени. Његов унос се **додаје** тастатурном, па можете користити оба истовремено.

## Повежите контролер {#connect-a-controller}

1. Прикључите контролер (или га упарите).
2. Кликните на приказ и притисните било које дугме на контролеру. Прегледачи приказују контролер тек после његовог првог уноса.
3. Отворите **Камера и сцена → Геймпад**. Списак уређаја га приказује са `●`.
4. Померите леву палицу за летење, а десну за гледање. Ако се камера помера кад су палице у центру, подигните **Мртву зону**.

Сваки уређај који прегледач пресликава на стандардни распоред геймпада ради. Палица за летење или гас (HOTAS) се подразумевано занемарује; видите испод.

## Мапирање {#mapping}

| Контрола | Ефекат |
|---|---|
| Лева палица | Кретање: напред/назад и бочно |
| Десна палица | Гледање: скретање и нагињање, брзином *Look speed* степени у секунди при пуном отклону |
| `RT` / `LT` (аналогно) | Горе / доле; у паралелној пројекцији, приближавање / удаљавање |
| `RB` (држано) | 6× брже |
| `LB` (држано) | 15% брзине |
| `A` (држано) | 3× трчање (комбинује се са RB/LB) |
| `Y` (притисак) | Уоквирите податке |

Бројеви дугмади прате стандардни распоред: A 0, Y 3, LB 4, RB 5, LT 6, RT 7; палице су на осама 0-1 (лева) и 2-3 (десна).

## Подешавања геймпада {#the-gamepad-settings}

У **Камера и сцена → Геймпад**. **Подешавања** / **Сакриј** отвара контроле за подешавање.

| Контрола | Подразумевано | Опсег (клизач) | Значење |
|---|---|---|---|
| **Укључено** | укључено | | |
| Статус уређаја | | | Сваки повезани уређај: `●` кад се прати, `○` кад не, са *- није XInput контролер, занемарен* или *- није XInput контролер, ипак се користи* за нестандардне уређаје. Без иједног: *Није нађен ниједан контролер. Прегледачи откривају контролер тек кад пошаље први унос, па притисните дугме на њему.* |
| **Користи уређај** | *Само XInput контролери (препоручено)* | | Приказује се кад је прикључен нестандардни уређај. Изаберите уређај по имену да га пратите уместо тога. |
| **Брзина гледања** | 150°/s | 20-540 (5000) | Брзина окретања при пуном отклону десне палице. |
| **Мртва зона** | 12% | 0-50% (95%) | Радијална: дијагонални притисак никад не прелази у једну осу сам. Подигните је ако се камера помера кад су палице у центру. |
| **Крива палице** | x² | линеарна (1) до x⁴ (16) | Експонент одзива после мртве зоне: финија контрола близу центра, а и даље пуна брзина на ивици. |
| **Обрни Y палице** | искључено | | |
| **Замени палице** | искључено | | Кретање на десној палици, гледање на левој. |

Облик отклона палице: са отклоном *m* (дужина вектора палице) и мртвом зоном *d*, излаз је ((m - d) / (1 - d)) ^ curve дуж правца палице, а 0 унутар мртве зоне.

## Зашто подразумевано само стандардни контролери {#why-only-standard-pads-by-default}

API геймпада пријављује **сваки** HID уређај са осама: палице за летење, гасове, педале, волане. Они се не враћају у центар: осовина за увијање или полуга гаса стоји на пуном отклону кад је нико не додирује. Кад се то прочита као палица, добија се стални унос пуном брзином који ниједна мртва зона не може да потисне, а камера се окреће сама од тренутка кад се страница учита. Сви топлотни режими тада изгледају покварено, јер покретна камера поново покреће акумулацију сваки кадар.

Зато се уређај прати само кад прегледач пријави `mapping: "standard"`, што значи „XInput-стил контролер са осама тамо где их очекујете”. Остали уређаји се наводе и означавају као занемарени, а **Користи уређај** га изричито укључује, на пример за летење камером са HOTAS-ом. Кад се контролер прати, камера остаје уз њега, па два контролера не оспоравају камеру у зависности од редоследа набрајања.

**HOTAS:** читају се само осе 0-3 (две палице) и стандардна дугмад. Гас или педале на другим осама не раде ништа, а палица или гас чије осе не стоје у центру може захтевати већу **Мртву зону**.

Прегледачи сакривају контролер док не пошаље први унос, па прикључен контролер који нико није додирнуо за страницу још не постоји.
