# 遊戲手把與 HOTAS

你可以用 Xbox 式手把來操作攝影機，不必使用鍵盤。當你想往後靠、環顧一個大場景時很適合。手把的輸入會**加上**鍵盤的輸入，所以兩者可以同時使用。

## 連接手把 {#connect-a-controller}

1. 插上手把（或與它配對）。
2. 在檢視畫面上點一下，然後按下手把上的任一按鈕。瀏覽器只有在手把送出第一次輸入後才會顯示它。
3. 打開 **攝影機與場景 → 遊戲手把**。裝置清單會以 `●` 顯示它。
4. 推左搖桿飛行，推右搖桿環顧。如果搖桿在置中時攝影機仍會漂移，請提高 **死區**。

瀏覽器能對應到標準遊戲手把配置的任何裝置都可以使用。飛行搖桿或油門（HOTAS）預設會被忽略；見下文。

## 對應 {#mapping}

| 控制項 | 效果 |
|---|---|
| 左搖桿 | 移動：前進／後退與橫移 |
| 右搖桿 | 環顧：偏航與俯仰，搖桿推到底時以每秒 *環視速度* 度數轉動 |
| `RT` / `LT`（類比） | 上／下；在平行投影中，為放大／縮小 |
| `RB`（按住） | 快 6 倍 |
| `LB`（按住） | 15% 速度 |
| `A`（按住） | 3 倍衝刺（可與 RB／LB 併用） |
| `Y`（按下） | 對準資料 |

按鈕編號依照標準配置：A 0、Y 3、LB 4、RB 5、LT 6、RT 7；搖桿在軸 0–1（左）與軸 2–3（右）。

## 遊戲手把設定 {#the-gamepad-settings}

位於 **攝影機與場景 → 遊戲手把**。**設定** / **隱藏** 會打開或收起調整控制項。

| 控制項 | 預設 | 範圍（撥動） | 意義 |
|---|---|---|---|
| **啟用** | 開 | | |
| 裝置狀態 | | | 所有已連接的裝置：有被跟隨時顯示 `●`，沒有時顯示 `○`；非標準裝置會顯示 *- 不是 XInput 手把，已忽略* 或 *- 不是 XInput 手把，仍然使用*。若沒有任何裝置：*未偵測到手把。瀏覽器要等手把送出第一次輸入後才會顯示它——請按下它上面的任一按鈕。* |
| **使用裝置** | *僅限 XInput 手把（建議）* | | 連接了非標準裝置時顯示。改為依名稱選擇一個裝置來跟隨它。 |
| **環視速度** | 150°/秒 | 20–540（5000） | 右搖桿推到底時的轉動速率。 |
| **死區** | 12% | 0–50%（95%） | 以半徑計算：斜向推動不會只漏到單一軸上。若搖桿置中時攝影機仍會漂移，請提高它。 |
| **搖桿曲線** | x² | 線性（1）到 x⁴（16） | 死區之後的反應指數：中央附近控制更細，邊緣仍是全速。 |
| **反轉搖桿 Y** | 關 | | |
| **交換搖桿** | 關 | | 右搖桿移動，左搖桿環顧。 |

搖桿形狀的計算：若推動量為 *m*（搖桿向量的長度），死區為 *d*，則沿搖桿方向的輸出 = ((m - d) / (1 - d)) ^ 曲線，在死區之內則為 0。

## 為什麼預設只跟隨標準手把 {#why-only-standard-pads-by-default}

遊戲手把 API 會回報**每一個**帶有軸的 HID 裝置——飛行搖桿、油門、踏板、方向盤——而這些裝置在沒有人碰它們時，並不會停在中央：扭轉軸或油門桿會停在全推位置。若把它們當成搖桿讀取，就會變成一個死區無法抑制的永久全速輸入，攝影機從頁面載入的那一刻起就會自己旋轉（而且每種熱度模式看起來也都會壞掉，因為攝影機一直在動，累積會每個影格重新開始）。

所以，只有當瀏覽器回報 `mapping: "standard"` 時，裝置才會被跟隨——這是瀏覽器在說「這是一個 XInput 式手把，軸就在你預期的位置」。其他裝置會列出並標示為已忽略，而 **使用裝置** 可以明確選擇其中一個——例如用 HOTAS 操作攝影機。一旦跟隨某個手把，攝影機就會一直跟著它，所以兩個控制器不會因為列舉順序而互相爭奪攝影機。

**HOTAS：** 只讀取軸 0–3（兩根搖桿）與標準按鈕。其他軸上的油門或踏板不會有任何作用；而軸不會停在中央的搖桿或油門，可能需要較大的 **死區**。

瀏覽器會把尚未送出第一次輸入的手把隱藏起來，所以就頁面而言，插著但沒有被碰過的手把目前還不存在。
