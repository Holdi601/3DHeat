# 關卡外觀

這些控制項會改變 3D 關卡的外觀，讓熱度能從關卡中突顯出來，同時你仍然能看清楚地點。這裡的任何設定都不會改變資料。

## 快速開始 {#quick-start}

1. 載入 3D 關卡（[3D 關卡](model-levels.md)）。
2. 在**背景／關卡**中，把**亮度**調低，直到熱度成為畫面上最亮的東西。
3. 打開**地面起伏**，調高**坡度陰影**或**等高線強度**，直到你能分辨山丘與平地。
4. 打開**結構**。調低**面的不透明度**即可看見建築物內部，或開啟**結構材質**，讓它們呈現實體。
5. 如果地面上繪有圖案，請試著開啟與關閉**地面材質**。

![已展開地面起伏與結構區段，關卡以起伏提示顯示](../assets/img/en/level-appearance-sections.webp)

載入 [3D 關卡](model-levels.md)後，背景／關卡面板會顯示這些控制項。預設值即為新匯入關卡所取得的值（[`modelLevelFrom`](https://github.com/Holdi601/3DHeat/blob/main/src/ui/panels/LevelPanel.tsx)、[`level.ts`](https://github.com/Holdi601/3DHeat/blob/main/src/render/level.ts)）。變更它們只會重新繪製場景；熱度累積會保留。

## 整個關卡 {#the-whole-level}

| 控制項 | 預設值 | 範圍 | 意義 |
|---|---|---|---|
| **不透明度** | 100% | 0-100% | 低於 100% 時，關卡會被混合且不寫入深度，因此不再[遮擋](depth-and-culling.md)熱度。 |
| **亮度** | 0.9 | 0-2（撥動 64） | |

關卡以去飽和的方式繪製：灰色的地面、帶色調的外殼，因此熱度是畫面上唯一有飽和色彩的東西。與[地圖影像](map-images.md)不同，3D 關卡沒有去飽和滑桿。

## 地面起伏 {#ground-relief}

從遠處看，山丘與平地會呈現同樣的灰色，因此檢視器加入了三種提示。每一種都針對不同的問題：

| 控制項 | 預設值 | 意義 |
|---|---|---|
| **等高線間距** | 依地面的高度範圍而定 | 等高線之間的高度，對數刻度，從關卡高度範圍的 1/4000 到 1/2；滑軌最底部為*關閉*。預設值為地面高度範圍的 1/40，並捨入到 1/2/5 的步進——10 m 的線適合山坡，但對採石場的地面毫無用處。每第 5 條線會畫得較粗。等高線以螢幕空間繪製，因此在任何縮放下都只有一個像素寬，而且它們是唯一能在坡度太緩、完全無法產生陰影的地面上仍然有效的提示。 |
| **等高線強度** | 35% | 0-100% |
| **坡度陰影** | 55% | 依陡峭程度加深顏色，讓河岸與懸崖在任何鏡頭角度下都能辨認——不像光源，面對光源時會變得平坦。 |
| **高度漸層** | 50% | 在地面高度範圍內，低地較暗、高地較亮：這是大尺度的形狀。 |

區段標題會顯示等高線狀態：*每 N m*（即等高線間距），若間距已關閉則顯示*無等高線*。

## 地面表面 {#ground-surface}

| 控制項 | 預設值 | 顯示條件 | 意義 |
|---|---|---|---|
| **水體** | 開啟 | 關卡有水體時 | 湖泊、河流與海洋，以淡藍灰色平面繪製：所有地形提示都不適用於依定義就是平坦的表面。 |
| **水體不透明度** | 60% | 水體開啟時 | 海岸線與淺水下的地面會透過半透明的水體顯示出來。 |
| **地面三角形** | 30%（有材質的關卡為 0） | 一律顯示 | 地形本身的邊緣會疊在陰影表面上方，在距攝影機關卡寬度的 6% 到 25% 之間逐漸淡出。顯示地面的取樣有多粗糙，並為坡度提供判斷距離的依據。首次使用時才會建立，在大型關卡上需要一點時間。 |
| **地面僅顯示線框** | 關閉 | 一律顯示 | 以地面的邊緣取代地形表面。完全是示意性的——它也會放棄陰影、等高線與遮擋，因此通常*地面三角形*是較好的選擇。 |
| **地面材質** | 開啟 | 關卡有材質時 | 以檔案所帶的材質（瀝青、路肩、草地）繪製地面。網格光照會輕柔地疊加在上面，因為材質本身已包含精細的起伏。要在熱度下減弱它，請使用**亮度**；去飽和則屬於地圖影像。 |
| **擷取的顏色** | 關閉 | 關卡有頂點顏色時 | 以掃描所擷取的顏色為地面上色，而不是灰色——否則重建的道路與路肩將無法區分。引擎匯出的關卡沒有這些顏色；沒有時面板會顯示*此關卡不含顏色。* |

## 結構 {#structures}

**結構**標題會顯示結構的三角形數量；下方的提示說明它們如何繪製（*以其自身材質實心繪製*或*以半透明外殼繪製，讓你能看見其內部的熱度*），以及有多少部分是結構。

| 控制項 | 預設值 | 意義 |
|---|---|---|
| **結構材質** | 結構帶有材質時開啟 | 以其自身材質實心繪製結構。開啟時會把面的不透明度設為 100%，並關閉邊緣；關閉時則回到 25% 的帶色調半透明外殼。有材質的結構會從攝影機所看見的那一側受光，因為一個標誌是背靠背的兩個面，哪一面能通過深度測試則取決於捨入誤差。 |
| **線框邊緣** | 開啟；結構三角形超過 300,000 個或有材質時關閉 | 結構去除重複後的邊，每條邊一條線。 |
| **邊的不透明度** | 50% | |
| **外殼面** | 開啟 | 一層淡淡的表面，帶有明亮的菲涅耳邊緣，使建築物讀起來像一個體積，而不是籠子或霧團。 |
| **面的不透明度** | 25%（結構三角形超過 300,000 個時為 35%，有材質時為 100%） | 滑軌上為 0-60%，拖曳把手可到 100%。請保持在低值：實心結構會遮住其內部的資料。 |
| **銳利邊緣** | 開啟（有材質時關閉） | 依每個三角形自己的法線為其上色，法線由片段著色器根據螢幕空間導數計算。匯出的關卡經過焊接並帶有平均法線，這會把每個盒子的角落圓化成「融化的鋁箔」；為了修正而拆分每個頂點，則會使頂點緩衝區倍增。若關卡的曲面比其角落更重要，請關閉它。 |
| **結構色調** | 青色 | 顏色選擇器，以及預設值**青色**、**琥珀色**、**紫羅蘭色**、**白色**。 |
| **顯示部件分類（N）** | | 每個部件、其類別與原因；見[3D 關卡](model-levels.md#ground-structures-and-water)。 |
