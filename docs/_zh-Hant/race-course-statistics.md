# 賽道統計

載入同一條賽道的許多圈，檢視器會統計失誤：哪個彎道最耗時、有多少圈在那裡出錯，以及原因為何。用它來找出最值得練習的彎道。

試試看：**示範圈** 會提供三圈，足以讓本節出現。

![賽道統計與失誤地圖：依有多少圈在各彎道損失時間，為賽道上色，以及彎道列表](../assets/img/en/race-course-mistake-map.webp)

把一條賽道的整個資料夾（數十圈、多輛車、多個性能等級）載入後，每一圈都會被逐一判定，然後加以統計。本頁說明依等級的比較、什麼算是失誤、**賽道統計** 區段、失誤地圖、熱度圖匯出、來自多條賽道的賽道，以及圈數很多時的效能限制。

## 與同等級中最快的圈比較 {#against-the-best-of-its-own-class}

每一圈會逐彎與**其所屬性能等級中最快的完整圈**（參考圈，且位於參考圈的等級中）比較；參考圈本身則與其等級中在每個彎道最快的那位比較，若它獨自一個等級，則與所有圈比較。車輛依遊戲的性能等級分組（在 Forza 中為 D 至 X；C 與 S2 是其中兩個）。C 級車的煞車點與 S2 級車的煞車點相比，並不能說明駕駛的好壞。時間地圖、圈的列表中的差距，以及*逐彎分析*表格，都依循同樣的比較方式（參閱[每一圈與誰比較](race-corner-analysis.md#who-each-lap-is-compared-with)）。

統計是建立在對每一圈的分析之上的，而不是與之並列。

## 什麼算是失誤 {#what-counts-as-a-mistake}

一次**發生** 是一圈在一個彎道（分段）中的一次失誤。一圈在某個彎道中的失誤包括：

1. **分析找出的駕駛原因**：對其損失的發現，且該發現歸因於駕駛（而非車輛或情況），在其比較圈上損失 **0.05 秒** 或以上。其代價為該彎道的損失。
2. **每一次車輛控制上的失誤**：該圈在此彎道犯下、而另一圈沒有犯下的（不共有的），代價為 **0.03 秒** 或以上，例如車輪鎖死、輪胎空轉、車尾甩出、推向外側、打轉。其代價為該事件本身的時間。
3. **每一次碰撞與撞車**，無論是否共有，也無論代價多少。

一個彎道中可以有好幾個失誤；每種類型在**每一圈、每個彎道只計一次**。獲得的時間、車輛的份額，以及因前一彎道而較晚到達，都不算失誤。

### 從發現到失誤 {#from-findings-to-mistakes}

| 發現 | 失誤 |
|---|---|
| 入彎過快、出彎慢，且煞車比另一圈晚了幾公尺以上 | 煞車太晚 |
| 煞車太早 | 煞車太早 |
| 煞車太輕 | 煞車太輕 |
| 以車輪鎖死為原因 | 車輪鎖死 |
| 滑行 | 滑行 |
| 還有抓地力可用、到頂點較慢，且煞車時另一圈只是收油門 | 彎中段太慢 |
| 走線太緊 | 走線太緊 |
| 推向外側 | 推向外側 |
| 轉向量太少／太多 | 轉向錯誤 |
| 踩油門較晚、全油門較晚、猶豫不決 | 油門踩得太晚 |
| 出彎較慢 | 出彎太慢 |
| 輪胎空轉 | 打滑（空轉） |
| 車尾甩出，在彎中段側滑 | 車尾甩出 |
| 衝出彎道外側 | 衝出彎道外側 |
| 白白損失速度 | 白白減速 |
| 收油門（入彎時，或在直道上） | 收油門 |
| 幾乎停下、打轉、撞到或撞車為原因 | 該彎道的事件說明是哪一種時，為打轉／撞到東西／撞車（依序為撞車、打轉、撞到）；否則為幾乎停下 |
| 飛行距離較長 | 飛得太遠 |

兩種模式（pattern）會以其中找出的原因，依同一張表計算。*入彎時給出的，比出彎時收回的還多* 是其條目原因的失誤：煞車太早即為*煞車太早*，車輪鎖死即為*車輪鎖死*，滑行即為*滑行*，未用的抓地力即為*彎中段太慢*。*入彎過快、出彎慢* 在該圈煞車比另一圈晚時為*煞車太晚*；否則為其出彎原因的失誤，即*油門踩得太晚*、*打滑（空轉）*、*車尾甩出*、*衝出彎道外側* 或*出彎太慢*。當原因屬於車輛，或是因較晚到達而形成的模式，則不計入。

不計入的項目：較晚到達、起跑，以及每一項*車輛*發現（拉力、抓地、煞車、驅動），以及每一個獲得時間或持平的彎道。

### 失誤種類與其順序 {#the-kinds-in-their-order}

煞車：*煞車太晚*、*煞車太早*、*煞車太輕*、*車輪鎖死*。入彎：*滑行*、*彎中段太慢*、*走線太緊*、*推向外側*、*轉向錯誤*。出彎：*油門踩得太晚*、*出彎太慢*、*打滑（空轉）*、*車尾甩出*、*衝出彎道外側*、*白白減速*。直道：*收油門*。事故：*打轉*、*撞到東西*、*撞車*、*幾乎停下*、*飛得太遠*。

## 賽道統計區段 {#the-course-statistics-section}

從 **3** 圈起顯示，位於 **單圈** 與 **可改進之處** 之間。

- **摘要**：「40 圈，9 輛車，3 個等級：逐彎與其所屬等級中最快的圈比較。」（車輛以車號計算，或以名稱計算。）
- **等級標籤**（有多個等級時）：**全部**，以及每個等級一個標籤，附上其圈數，依遊戲順序排列（D、C、B、A、S1、S2、R、X，然後其他）。點選一個等級即只看其圈數；**Shift+點擊** 可加入或移除一個等級。下方的所有內容（列表、地圖、熱度圖匯出）都會依所選的等級而變。
- **最常出錯之處**：每種失誤，依出現的圈數由多到少排列（其次依次數、再依代價）。最多顯示 8 項（**全部 N 種** 顯示其餘項目，**收起** 則再隱藏）。每一列包含：名稱、「N 圈中的 M 圈」、其占比的長條，以及「K 次 · 約 X 秒 · 最多出現在 T3 (5)、T7 (4)、T1 (2)」，即其出現次數（依圈與彎道計）、總共付出的代價，以及最多圈在其中犯下此失誤的三個彎道。**點選一列** 會在失誤地圖上顯示它（並開啟地圖）；再點一次則顯示所有失誤。
- **逐彎分析**（或選取某一失誤時為*逐彎分析 - <失誤>*）：每個分段顯示「N 圈中的 M 圈損失時間 · X 秒」，即駛完整個彎道的圈數、在那裡相對於其等級最佳圈損失 **0.05 秒** 或以上的圈數，以及它們在那裡損失的所有時間。展開後會列出其最常見的三種失誤及其圈數。**點選一個彎道** 會開啟它、以攝影機框住它，並切換到失誤地圖：對每個失誤（或只顯示所選的那一個），會有一行說明，例如「40 圈中有 12 圈在此煞車太早。在 9 輛不同的車上發生，每次約 0.21 秒。」，以及犯下此失誤的圈，**最差的排在最前**，每圈附上其代價。最多顯示 8 圈，其餘以「+N 更多」表示。**點選一圈** 會聚焦該圈，並重播該失誤（從其前 40 公尺開始對齊）。
- **在熱圖中顯示**：見下文。執行時顯示「正在建立熱圖…」；沒有失誤時此按鈕停用。

## 失誤地圖 {#the-mistake-map}

**視圖 → 失誤地圖** 會沿著參考路徑，在每一公尺上繪出（所選等級中）有多少圈在該處犯下失誤，無論哪種類型，或統計中所選的那一種。每一圈在每一公尺只計一次；每個發生的範圍（其原因或事件所在之處）會向兩側各擴寬 6 公尺，使短的失誤也看得見。在越多圈犯錯之處，線條越寬、越亮：寬度為 `3 + 10 · （此處的圈數 / 全賽道最多的圈數）` 公尺，顏色由暗褐色漸變為明亮的橘色；沒有人犯錯之處則是一條 2 公尺的灰色帶。圖例：*few laps ↔ most laps*（少圈 ↔ 多圈）。

開啟 **標籤** 後，每個彎道的頂點都會標示其最常見的失誤：「T3 · 12/40 煞車太早」（犯此失誤的圈數／駛過該彎道的圈數）；選取某一種類型時為「T3 · 12/40」；沒有失誤時為「T3 · 乾淨」。將游標移到標籤上，會列出該彎道的損失與其最常見的五種失誤；點選標籤則會在統計中開啟或收起該彎道。

## 在熱圖中顯示 {#show-in-the-heatmap}

**在熱圖中顯示** 會把同一份資料交給熱度圖分頁，成為一個名為「<賽道> 上的失誤」（或「賽道上的失誤」）的資料集，讓熱度圖的整組工具（熱度模式、篩選、時間軸、切片）都能用於分析圈在哪裡出錯。

它是一份在記憶體中建立的 CSV（`mistakeTable`），每個發生的每個格點（每 2 公尺）各一列，位置為**該圈自己在該處的位置**：

| 欄位 | 內容 |
|---|---|
| `x`、`y`、`z` | 該圈在該公尺處的位置（遊戲座標） |
| `elapsed` | 該圈在該處的時間，秒 |
| `lap` | 該圈的標籤 |
| `car` | 車輛名稱（或「car 1234」） |
| `mistake` | 失誤名稱，依目前語言 |
| `car_class` | 等級，無則為 `-` |
| `corner` | 彎道標籤，例如 `T3` |
| `cost` | 該發生的代價，秒 |

它會透過熱度圖自己的載入器載入，並附上對應提示：Y 軸向上、不翻轉座標軸、比例為 1；時間 `elapsed` 以秒計；**人物** = `car`，**群組** = `mistake`，**場次** = `lap`；沒有視線方向；`car_class`、`corner` 與 `cost` 保留為篩選欄位。分頁接著切換到**熱圖**並框住資料。只會匯出統計中所選的等級。

## 多條賽道 {#courses-from-several-tracks}

圈是**一次分析一條賽道**。若一個資料夾包含多條賽道的圈（整個圈數庫），會逐一提供每條賽道供載入（附上其圈數，多者在前）；未完成的跑步（FH Companion 的 `unfinished/`）會與其賽道一起，並標示為*部分*。以檔案方式選取的多條有名稱賽道的圈，也會以同樣方式提供，未註明賽道的圈則歸入所選的賽道。載入與目前已載入賽道不同的賽道時，會取代已載入的圈。詳見：[載入圈](race-loading-laps.md#folders-and-courses)。

## 圈數很多時的效能 {#performance-with-many-laps}

數十圈可在一兩秒內分析完成（一律全部分析）。繪製的內容則有限制，以確保畫面維持在影格率：

| 限制 | 數值 | 效果 |
|---|---|---|
| 預設繪製的圈數 | 8（`SHOW_ALL_UP_TO`） | 載入超過 8 圈後，新加入的圈會被隱藏，除非它是參考圈、聚焦的圈或其等級中最佳的圈。**全部顯示** 會繪製每一圈；**只顯示正在查看的** 則恢復原狀。聚焦一圈會取消其隱藏，並連同其等級中的最佳圈一起顯示 |
| 普通車輛與細線 | 可見超過 10 個（`PLAIN_PAST`） | 除聚焦的圈、被追趕的車與參考圈以外的圈：每 6 公尺一個線段點（而非每 1.5 公尺），車輛以普通方式繪製 |
| 有圖表的圈 | 8（`CHART_LAPS`） | 先顯示聚焦的圈、其等級最佳圈與參考圈；「+N 更多已繪製，未建圖表」 |
| HUD 卡片 | 6 | 前六個可見的圈 |
| 統計 | 從 3 圈起 | 低於此數時隱藏本區段 |
| 列出的發現 | 駕駛 12 項、車輛／情境 8 項、獲得時間 10 項 | 每個聚焦的圈 |
| 顯示的車輛配對 | 3 | 超過 3 組時，以一組加上選擇器顯示 |

失誤的發生只會在每次分析時計算一次，並加以快取；失誤地圖的密度則依等級選擇與失誤種類快取。
