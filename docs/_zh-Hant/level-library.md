# 關卡庫

關卡庫會把你的關卡保存在這個瀏覽器中，讓你不必重新載入與簡化。**清除瀏覽器中該網站的資料會刪除關卡庫，而且沒有匯出功能。** 請保留你的原始檔案。

處理一個關卡——解析、分類、焊接、減面、打包紋理——很慢，而且每次結果都一樣。關卡面板底部的 **關卡庫** 會把處理過的關卡保存在這個瀏覽器中，所以減面後的網格絕不會被重建兩次（[`levelLibrary.ts`](https://github.com/Holdi601/3DHeat/blob/main/src/data/levelLibrary.ts)）。

## 儲存與重新載入關卡 {#save-and-reload-a-level}

1. 載入地圖圖像或 3D 模型，並確認它看起來正確。
2. 按下 **儲存至關卡庫**。面板會顯示 *已儲存。下次將立即載入。*
3. 下次打開 **關卡庫** 清單，然後在該關卡上按 ▸。
4. 若不再需要某個項目，按 ✕ 刪除它。

## 使用方式 {#using-it}

| 控制項 | 效果 |
|---|---|
| **儲存至關卡庫** | 儲存目前的關卡。地圖圖像會以 PNG 加上其兩個錨點儲存；模型則以其處理過的緩衝區儲存。面板會顯示 *已儲存。下次將立即載入。* |
| 關卡庫清單 | 每個已儲存的關卡一列：名稱（滑鼠移上去可看到其儲存大小）、模型的三角形數，或圖像的寬度（像素）。 |
| ▸（*載入*） | 將該項目載入為目前的關卡。 |
| ✕（*刪除*） | 移除該項目。 |
| 用量行 | `已使用 X，共 Y。`——瀏覽器對此網站的儲存空間估計。 |

若沒有任何已儲存的項目，清單會顯示 *空白。請載入地圖或模型，然後按「儲存至關卡庫」。*

## 保存了什麼 {#what-is-stored}

| 種類 | 有保存 | 沒有保存 |
|---|---|---|
| 地圖圖像 | 圖像（PNG）、其大小、其錨點 | 高度、翻轉、不透明度、亮度、去飽和——會恢復為預設值（高度 = 目前資料集的最低 Y，翻轉為開） |
| 3D 關卡 | 頂點、頂點顏色、紋理座標、它們的圖塊與紋理圖集、地面／結構／水面三角形、結構邊緣、三角形數量 | 零件名稱與分類理由，以及所有外觀設定——會恢復為全新匯入的預設值 |

從關卡庫載入的模型沒有零件清單，其邊界與地面高度範圍會從它的頂點重新計算。

## 保存位置 {#where-it-lives}

保存在瀏覽器的 IndexedDB 中，資料庫為 `3dheat`，物件儲存區為 `levels`，對應頁面的來源（瀏覽器網址列中的位址）。它只存在於該瀏覽器設定檔中：另一個瀏覽器、另一個設定檔，或另一個位址（例如用 `localhost` 而不是 `127.0.0.1`），看到的會是另一個空的關卡庫。清除瀏覽器中該網站的資料會刪除它。沒有結構、顏色或水面的舊版本所儲存的項目，仍然可以載入。
