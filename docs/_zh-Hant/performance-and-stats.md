# 效能面板與統計浮層

檢視畫面右上角的方塊顯示檢視器有多吃力：每秒幾個影格、畫了多少個點，以及它是否仍在精煉畫面。**效能** 面板讓你用畫質換取速度。

## 統計浮層 {#the-stats-overlay}

這是熱度與對戰分頁中，檢視畫面右上角的方塊（[`StatsOverlay.tsx`](https://github.com/Holdi601/3DHeat/blob/main/src/ui/StatsOverlay.tsx)）。它每個動畫影格都會讀取引擎的即時讀數。

![對戰場景上的統計浮層，帶有編號標註：1 後端、2 FPS、3 影格、4 時間窗內資料列、5 Sprite／影格、6 預算、7 熱度解析度、8 覆蓋率](../assets/img/en/performance-stats-overlay.webp)

| 行 | 意義 |
|---|---|
| **後端** | *WebGPU* 或 *WebGL2*。滑鼠移上去可看到沒有使用 WebGPU 的原因（若有使用則不顯示）。見[兩種後端](backends.md)。 |
| **FPS** | 每秒影格數，至少以 0.4 秒為平均。 |
| **影格** | 影格時間（毫秒），已平滑處理（90% 舊值、10% 新值）。這是影格之間的時間，不是 GPU 時間——不會量測每個通道的 GPU 時間。 |
| **時間窗內資料列** | 候選資料列：目前時間視窗中的資料列，在著色器進行逐資料列過濾之前的數量。 |
| **Sprite／影格** | 上一個影格的計畫送出的 sprite 數（在不繪製任何東西的閒置影格上，會保持計畫中的數字）。 |
| **預算** | 這個影格規劃時使用的 sprite 預算——即自適應控制器的值，在繪製所有資料列時會提高到所有候選。 |
| **熱度解析度** | 熱度緩衝區佔畫布的解析度比例：*熱度解析度*設定乘以自適應第二段的比例。 |
| **覆蓋率** | 漸進式累積已使用了多少比例的所有資料列：收斂中以百分比顯示（琥珀色），完成時顯示 *精確*。有雜訊的影格不會被誤認為完成的畫面。 |
| **方塊** | [箱形重播](box-replay.md)中繪製的箱子。 |
| **未常駐** | 只有在資料列放不進 GPU 預算時才顯示：有多少筆。見 [GPU 記憶體駐留](gpu-memory.md)。 |

## 速度顯示 {#the-speed-display}

位於檢視畫面右下角，只在透視模式中出現：飛行速度，以及以該速度穿越資料所需的時間。拖曳它可以改變速度。見[攝影機](camera.md#fly-speed)。

## 如果檢視器很慢 {#if-the-viewer-is-slow}

先看統計浮層，然後：

1. **時間窗內資料列遠大於 Sprite／影格，覆蓋率低於 100%**——影格無法畫出全部內容；畫面靜止時，它會在數個影格內收斂。縮小時間窗、加上過濾，或剔除以減少候選數；或接受取樣的結果。
2. **Sprite／影格等於時間窗內資料列，但影格仍然很慢**——成本是依螢幕上的每個 sprite 計算：降低*最大像素半徑*（[Sprite 形狀](sprite-shape.md#pixel-clamps)）或*熱度解析度*。
3. **資料列很少但仍然很慢**——多半是關卡的問題：結構數量多且開啟邊緣、地面三角形、景深。見[關卡外觀](level-appearance.md)。
4. **全部都很慢，而且出現紅色橫幅**——軟體渲染（[軟體渲染偵測](software-rendering.md)）。

## 效能面板 {#the-performance-panel}

| 控制項 | 預設 | 效果 |
|---|---|---|
| 提示 | | 每個影格都會潑灑一組分層隨機的可見資料列子集，權重會按比例放大以作補償，所以在任何預算下，期望熱度都是精確的；保持視角不動時，會持續合併影格，直到每個資料列都有貢獻為止。 |
| **每個影格繪製所有資料列** | 開 | 每個開始新估計的影格都會繪製所有候選資料列（最多約 2.68 億）；下面的預算會變成下限。[取樣與預算](sampling-and-budgets.md#draw-every-row-each-frame) |
| **自適應預算** | 開 | 調整每個影格的 sprite 數，然後調整熱度解析度，以維持目標影格率——並在切割已無助益時停止切割。[取樣與預算](sampling-and-budgets.md#the-adaptive-budget) |
| **目標 FPS** | 60 | 20–240（使用把手可到 1000）。低於 15 的值會當作 15。 |
| **起始 sprite／影格** / **Sprite／影格** | 4.00M | 65,536–268,435,456，對數刻度。自適應開啟時顯示為*起始*，因為控制器會移動它。 |
| **熱度解析度** | 100% | 25–100%。片段成本與面積的平方成比例：50% 會讓混合工作量變成四分之一，而熱度場夠平滑，幾乎看不出差異。 |
| **漸進式精緻化** | 開 | 畫面靜止時跨影格累積。關閉時，每個影格都顯示單一影格的估計。[累積](accumulation.md) |
| **資源預算** | 自動偵測 | RAM、GPU 與解析器執行緒的預算。[記憶體與預算](memory-and-budgets.md#resource-budgets) |

以上設定都不會被儲存；重新載入後會恢復預設值。
