# 累積

當檢視器無法在一個影格內繪製所有的點時，它會先繪製其中一部分，再繪製另一部分，並在你保持不動時把這些畫面加總起來。畫面會逐漸變得清楚，就像照片顯影一樣。移動攝影機會重新開始。統計覆蓋層的**覆蓋率**一行會顯示進度有多深。

![統計覆蓋層：畫面顯影時覆蓋率顯示百分比，完成時顯示*精確*](../assets/img/en/performance-stats-overlay.webp)

## 給開發者 {#for-developers}

當一個影格無法繪製所有資料列時，它會繪製一個樣本並加權放大；此時畫面是一個無偏但有雜訊的估計。**累積**會把連續的影格合併起來，使估計在畫面不變時收斂到精確的答案。每個影格會從五種模式中選擇一種（[`engine.ts`](https://github.com/Holdi601/3DHeat/blob/main/src/render/engine.ts)）；最後使用的模式保存在 `engine.live.accumMode` 中。

| 模式 | 何時使用 | 對累加器的作用 |
|---|---|---|
| **reset** | 攝影機移動、有改變場景的事情發生、漸進式精緻化關閉、成長中的時間窗開始（播放的第一個影格，或跳轉之後），或播放中的線熱度移動 | 以此影格的估計取代。 |
| **extend** | **累積**時間窗自上一個影格以來只有增長 | 此影格只繪製剛變為可見的資料列，以完整權重加入。沒有任何東西會衰減。 |
| **ema** | 滑動時間窗（**時間窗**、**存續時間**）移動 | `acc = acc × (1 - 0.34) + frame × 0.34`：約三個影格的指數移動平均。 |
| **mean** | 沒有任何東西改變，且估計尚未完成 | 在第 *n* 個影格時 `acc = acc × (1 - 1/n) + frame × 1/n`：滾動平均。 |
| **skip**（閒置） | 已收斂且沒有任何東西改變 | 不繪製任何東西；此影格只重新合成。 |

### 各模式的理由 {#why-each}

- **滾動平均，而非總和。**將緩衝區乘以 1 - 1/n 並加上新影格的 1/n，在代數上等同於最後把總和除以 *n*，但緩衝區永遠只保存一個場的量。總和會達到場的 *n* 倍，而在 16 位元的目標上會在 65,504 處飽和；若除數持續增長，靜止的視角就會隨著停留時間越久而逐漸變暗——而每個影格都會重置的移動攝影機，看起來則完全正確。煙霧測試會斷言，合併 16 個影格的結果是單一影格的 1.00 倍。
- **播放累積時使用 extend。**已累積的資料列仍然可見，因此一個影格只需要剛到達的那一小段時間的資料——它可以放進一個影格中，因此被精確地加入。若改為重新估計，每個影格都會點亮不同的隨機子集並使其淡出，看起來就像一陣陣突然亮起又消失，而暫停時的影格還會持續填充。測試會斷言播放期間總量單調上升，並在暫停 2.5 秒的期間保持在 0.02% 之內。
- **滑動時間窗使用移動平均。**這些資料確實每個影格都在變化。固定的混合權重能跟上移動的時間窗（自播放開始以來所有影格的平均值會落後於播放頭），而且比重新開始安靜得多。
- **播放的線條使用 reset。**線熱度的頭部每個影格都在移動；移動平均會把每一條都抹成一道條紋，因此每個影格都會完整繪製，尾端的淡出就是畫面本身的效果。
- **部分影格會經過暫存目標。**以完整權重的一部分合併的影格，會從零開始繪製到獨立的目標中，然後再混合進累加器，而不是直接以 1/n 的權重繪製。直接繪製時，每個 Sprite 會以它所加入之總量的 1/n 大小被加入，而半精度浮點目標會把它捨入掉——在最密集的地方情況最糟（[半精度浮點累積](half-float-accumulation.md)）。

### 收斂 {#convergence}

每個影格的計畫都知道有多少候選資料列，以及提交了多少，因此涵蓋每一筆資料列所需的影格數為 ⌈候選數 / 提交數⌉。一旦合併了那麼多影格，畫面就是**已收斂**：統計覆蓋層的*覆蓋率*一行會從百分比變為*精確*，之後的影格則為閒置。在**每個影格繪製所有資料列**開啟時（預設），單一影格通常就能涵蓋全部，因此收斂是即時的；漸進式機制只有在時間窗中的資料列超過單一繪製計畫所能承載的數量（約 6,700 萬）時才需要。

### 什麼會使它重新開始 {#what-restarts-it}

設定分為三組，依據它們變更後，累積的緩衝區仍然具有什麼意義：

| 群組 | 變更項目 | 效果 |
|---|---|---|
| **幾何**：哪些資料列會被計入，以及計入多少 | 視圖模式；線路；Sprite 半徑、中心與邊緣強度、衰減、平滑漸變、曲線、像素限制、壓平；近、遠與平面的距離剔除；遮擋與隱藏地形後方；切片；畫布大小；熱度解析度；群組可見性與正負號；差異分割；全部／播放；歷史；欄位篩選器與實體選取；半精度增益 | 重置。 |
| **時間窗**：時間範圍 | 播放頭移動；存續時間的後備與淡出 | 延伸（累積）或移動平均（滑動）。 |
| **合成**：僅著色 | 飽和度、密度響應、最低熱度、色彩漸層；切開關卡；格線與軸；盒子重播設定與場次；景深 | 重新繪製，不觸及熱度。 |

攝影機移動一律會重置。因此拖曳飽和度或漸層是免費的；拖曳 Sprite 半徑則會在每一步都使收斂重新開始。
