# 鍵盤與滑鼠參考

所有按鍵與滑鼠操作都集中在這裡，方便你找到需要的那一個。先點一下畫面，讓它取得鍵盤焦點。當文字框或下拉選單有焦點時，按鍵會被忽略。畫面左下角也會印出簡短版本。

快速查找：

| 我想要 ... | 按下 |
|---|---|
| 飛行 | `W A S D`，拖曳即可環顧 |
| 看到全部 | `F` |
| 播放或暫停 | `K` |
| 倒轉播放 | `J`（再按一次暫停），正向播放 `L` |
| 查看顏色代表什麼 | `?` 或 `F1` |
| 在戰術頁籤中復原 | `Ctrl+Z` |

## 鏡頭 {#camera}

來自 [`camera.ts`](https://github.com/Holdi601/3DHeat/blob/main/src/render/camera.ts)。

| 輸入 | 效果 |
|---|---|
| `W` / `↑` | 沿檢視方向前進 |
| `S` / `↓` | 後退 |
| `A` / `←` | 向左平移 |
| `D` / `→` | 向右平移 |
| `Space` / `E` | 向上 |
| `Q` / 左 `Ctrl` | 向下 |
| `Shift`（任一側） | 按住：6 倍速 |
| 左 `Alt` | 按住：15% 速度 |
| 在畫面上左鍵或右鍵拖曳 | 環顧（按住按鍵期間鎖定指標） |
| 滾輪（透視） | 每格飛行速度 ×1.5（每次滾輪事件最多 4 格） |
| 滾輪（平行） | 縮放 |
| 按右鍵 | 在畫面上不會開啟內容選單 |

## 全域 {#global}

來自 [`App.tsx`](https://github.com/Holdi601/3DHeat/blob/main/src/App.tsx)。

| 按鍵 | 效果 |
|---|---|
| `K` | 播放／暫停[時間軸](timeline.md) |
| `F` | 框選資料 |
| `C` | 複製鏡頭的位置、偏航與俯仰（[鏡頭讀數](camera.md#camera-readout)） |
| `G` | 前往輸入的點：開啟鏡頭讀數下方的方塊 |
| `Esc` | 關閉點選卡片；接著停止注視第二個單位；再來停止跟隨單位 |
| `T` | 開啟或關閉戰術顯示外觀（[對戰重播](match-replay.md#display-style)） |
| `?` / `F1` | 說明模式：顏色代表什麼（[設定、單位與按鍵](settings.md#help-mode)） |
| `1` | [熱度](heat.md) |
| `2` | [差異](difference.md) |
| `3` | [隊伍熱度](team-heat.md) |
| `4` | [線條](line-heat.md) |
| `]` | 遠端剔除界線向外 ×1.12（`Shift`：×1.35） |
| `[` | 遠端剔除界線向內 ÷1.12（`Shift`：÷1.35） |
| `\` | 遠端剔除界線關閉／恢復到原本的位置（[深度與剔除](depth-and-culling.md#keyboard)） |

**模型疊加**模式沒有數字鍵；請在模式列中選取，或開啟對戰頁籤。數字鍵與模式列使用相同的檢查：若模式列顯示該模式對目前載入的資料不可用，按下對應的數字鍵不會有任何反應。

## 對戰重播 {#match-replay}

在模型疊加模式中使用，對戰頁籤會使用此模式（[對戰重播](match-replay.md)）。除非另有註明，這些按鍵在有或沒有跟隨單位時都可以使用：

| 按鍵 | 效果 |
|---|---|
| `B` | 新增書籤：記下時刻與鏡頭 |
| `M` | 2D 地圖：角落、整個畫面、關閉 |
| `V` / `Shift+V` | 被跟隨單位的下一個／上一個鏡頭視角 |
| `H` | 在駕駛艙與鎖定視角中顯示抬頭顯示器 |
| `Page Down` / `Page Up` | 下一個／上一個事件清單所列類型的事件 |
| `J` | 倒轉播放；再按一次暫停 |
| `L` | 正向播放；再按一次暫停 |
| `.` / `,` | 暫停時前進一秒／後退一秒（`Shift`：十秒） |
| `Esc` | 先停止注視目標，然後停止跟隨 |
| 在畫面中或單位清單中 `Ctrl`+點擊或 `Alt`+點擊單位 | 從被跟隨的單位觀看它（雙單位視角）；再點一次即可取消 |
| `Shift`+點擊兩個單位 | 測量兩者之間：方位、距離、高度差 |

`V` 需要有被跟隨的單位。這裡的 `M` 是 2D 地圖，在戰術頁籤中則是「移動」。

## 跟隨單位 {#following-a-unit}

鏡頭跟隨單位時，滾輪與飛行按鍵會繞著該單位移動，而不是自由飛行（[鏡頭](camera.md#while-following-a-unit)）：

| 輸入 | 效果 |
|---|---|
| 滾輪、`W` / `S` | 靠近／遠離（在衛星視角中為升高／降低）。在駕駛艙與鎖定視角中無效。 |
| `A` / `D`、`Q` / `E` | 繞著單位環繞（追隨與環繞視角） |
| 拖曳 | 繞著單位環顧；在駕駛艙中則是在艙內環顧 |
| `V` / `Shift+V` | 下一個／上一個鏡頭視角 |
| `H` | 抬頭顯示器（駕駛艙與鎖定視角） |
| `Esc` | 停止注視第二個單位，然後停止跟隨 |

## 戰術看板 {#tactics-board}

在戰術頁籤中（[戰術看板](tactics-board.md)）。`F`、`C`、`G` 與 `T` 的作用與上述相同；數字鍵則沒有作用。

| 按鍵 | 效果 |
|---|---|
| `Ctrl+Z` | 復原 |
| `Ctrl+Y` 或 `Ctrl+Shift+Z` | 重做 |
| `Enter` | 結束正在畫的箭頭（雙擊或按右鍵效果相同） |
| `Esc` | 取消拖曳；否則放下正在進行的箭頭或移動；否則取消選取 |
| `Delete` 或 `Backspace` | 刪除所選項目 |
| `W` / `E` / `R` | 所選項目的移動／旋轉／縮放控點（按鍵配置 **W / E / R**） |
| `G` / `R` / `S` | 所選項目的移動／旋轉／縮放控點（按鍵配置 **G / R / S**） |
| `R` | 未選取任何項目時：將下一個要放置的模型旋轉 15°。`Shift+R` 則反向旋轉。 |
| `M` | 選取模型時：下一次點擊時將它移到該處 |
| `K` | 播放或暫停計畫 |
| Shift+點擊 | 加入或移出選取範圍 |
| Shift+拖曳 | 畫出方框來選取範圍 |
| 拖曳控點時按住 `Ctrl` | 貼齊到格線或角度間隔 |

控點按鍵只有在選取了某個項目時才有作用；未選取任何項目時，`W A S D` 會照常控制鏡頭飛行。

## 點選檢視 {#click-to-pick}

在**點按顯示該處內容**開啟、且量尺關閉時（[點選檢視](camera.md#click-to-pick)）：

| 輸入 | 效果 |
|---|---|
| 左鍵點擊（拖曳不超過 4 px） | 顯示指標下方的資料點；若沒有，則顯示關卡上該處的內容 |

## 測量 {#measure}

在**量尺已啟用**時（[測量](measure.md)）：

| 輸入 | 效果 |
|---|---|
| 左鍵點擊（拖曳不超過 4 px） | 放下一個點 |
| 右鍵點擊 | 移除最後一個點 |

## 其他位置 {#elsewhere}

| 位置 | 輸入 | 效果 |
|---|---|---|
| 任何滑桿的把手（數字旁的控點） | 向上／向下拖曳 | 持續改變數值，拖曳越遠變化越快；按住 `Shift` 可微調。放開即停止。 |
| 畫面上方的速度顯示 | 向上／向下拖曳 | 以同樣方式改變飛行速度。 |
| 姿態方塊 | `Enter` | 套用輸入的位置或方向。 |
| 曲線編輯器 | 雙擊／Alt-點擊／右鍵點擊 | 新增一個點／移除一個點（[Sprite 形狀](sprite-shape.md#the-curve-editor)）。 |

## 競賽分析頁籤 {#race-analysis-tab}

在競賽分析頁籤中，`K` 會播放與暫停競賽重播，`Home` 會將它倒回開頭，數字鍵則沒有作用。請見[競賽分析](race-analysis.md)。

## 檢視器保留給自己的瀏覽器按鍵 {#keys-the-viewer-keeps-from-the-browser}

有些瀏覽器快捷鍵會關閉或重新載入頁面，並使已載入的工作階段遺失；檢視器會把這些按鍵保留給自己。清單由程式碼產生：[瀏覽器按鍵](ref-browser-keys.md)。
