# 攝影機與操作

你可以像鳥一樣在場景中飛行：**W A S D** 移動，拖曳滑鼠即可環顧。本頁說明如何飛行、如何跳到俯視或側視，以及如何精確讀取攝影機的位置。

## 四步開始飛行 {#fly-in-4-steps}

1. 在檢視上點按一次，讓它取得鍵盤焦點。
2. 按住 **W** 向前飛，**S** 向後，**A** 與 **D** 向左右，**空格** 向上，**Q** 向下。
3. 按住滑鼠左鍵或右鍵並拖曳即可環顧。
4. 按 **F** 重新框住所有資料。

攝影機是自由飛行攝影機，具有透視與平行兩種投影、預設視角、可輸入的姿態，以及景深。它的設定位於側邊欄底部的**攝影機與場景**面板中（在賽車分析與對戰分頁中也會顯示）。實作位於 [`camera.ts`](https://github.com/Holdi601/3DHeat/blob/main/src/render/camera.ts)。

## 飛行 {#flying}

| 輸入 | 效果 |
|---|---|
| `W` `A` `S` `D` 或方向鍵 | 向前（沿著視線方向，包含其俯仰）、向左、向後、向右 |
| `空格` 或 `E` | 向上（世界的上方） |
| `Q` 或左 `Ctrl` | 向下 |
| `Shift`（按住） | 速度 6 倍 |
| 左 `Alt`（按住） | 速度 15% |
| 按住左鍵或右鍵拖曳 | 環顧。拖曳時指標會被鎖定。 |
| 滑鼠滾輪 | 每格飛行速度 ×1.5（透視）；縮放（平行） |
| `F` | 框住資料 |
| 點按（不拖曳） | 顯示指標下方的內容（[檢查檢視](#inspecting-the-view)） |
| `C` | 複製攝影機的位置、偏航與俯仰 |
| `G` | 跳至輸入的某一點 |
| `Esc` | 關閉拾取卡（並停止跟隨單位） |

### 跟隨單位時 {#while-following-a-unit}

當攝影機在重播中跟隨某個單位時（[對戰重播](match-replay.md)），飛行按鍵的作用會不同：

| 輸入 | 效果 |
|---|---|
| 滾輪、`W` / `S` | 靠近單位／遠離單位（在衛星視角中為升高／降低） |
| `A` / `D`、`Q` / `E` | 繞單位旋轉（追尾與環繞視角） |
| 拖曳 | 繞著單位環顧（駕駛艙：在艙內環顧） |
| `V` / `Shift+V` | 下一個／上一個攝影機視角 |
| `Esc` | 先停止注視第二個單位，再停止跟隨 |

移動按鍵會與[遊戲手把](gamepad.md)的輸入相加；其他操作請見[鍵盤參考](keyboard-reference.md)。當文字方塊或下拉式選單取得焦點時，按鍵會被忽略。俯仰角會限制在剛好不到正上方與正下方。

## 攝影機與場景面板 {#camera--scene-panel}

![攝影機與場景面板：投影、預設視角、視野按鈕、飛行速度與姿態](../assets/img/en/camera-panel.webp)

### 投影 {#projection}

**投影**：*透視*（預設）或*平行*。

*平行*（正交）會消除透視縮短，因此兩個密度相同的熱點，不論位於畫面的哪裡，看起來大小都相同——這正是地圖熱圖存在的意義所在——而等角視角之所以是等角，也是因為它。在平行模式下，滑鼠滾輪會縮放（沒有會改變比例的前後移動），並且[速度顯示](#fly-speed)會隱藏。

**切換時主體保持相同大小。** 平行投影沒有視野角，因此其視錐高度與攝影機的距離無關；直接切換不是會大幅縮放，就是什麼都看不到。切換到平行時，視錐高度會設為透視攝影機在對焦距離上所涵蓋的範圍（2 × 距離 × tan(視野 / 2)，對焦距離即上次框住時的距離）。切換回來時，會還原你離開時的透視姿態，且視覺比例相同，而不是停在平行視角中漂移到的位置。

### 預設視角 {#preset-views}

| 群組 | 按鈕 | 方向 |
|---|---|---|
| **等角** | **NE**、**NW**、**SE**、**SW** | 平行，俯仰 -35.264°（= atan(1/√2)，即三個軸投影長度相同的角度），偏航 -45°、45°、-135°、135°。四個角，因為單一角度總會被較近的物體遮住一半地圖。 |
| **立面** | **Top**、**Bottom**、**Front**、**Back**、**Left**、**Right** | 平行。Top 正對下方（俯仰 -89.9°），Bottom 正對上方，Front 沿 -Z（偏航 0°），Back 沿 +Z（180°），Left 沿 -X（-90°），Right 沿 +X（90°）。 |
| | **回到透視** | 返回你離開時的透視姿態。在透視中停用。 |
| | **四分之三視角** | 透視，偏航 -35°，俯仰 -28°。 |

每個預設視角都會切換投影本身——在透視下，「俯視」仍會朝消失點收斂，相等的面積看起來就不再相等——並從該方向框住資料。

### 視野 {#field-of-view}

**視野**——垂直角度。預設 65°，滑桿範圍 10–140°（使用把手時為 179°），並有按鈕**平坦 20°**、**長 35°**、**標準 50°**、**寬 65°**、**極寬 90°**。較窄的視野會使透視變得扁平，更接近平行投影；較寬的視野會誇大深度，使距離難以判斷。在平行模式下它仍會即時生效，此時它會設定切換回來時所求的比例，以及**框住**所用的距離。

### 飛行速度 {#fly-speed}

**飛行速度**——全速時每秒的世界單位（公尺）。預設 120；每次載入時，會設為資料的水平範圍 / 12。採對數刻度，範圍 0.02–20,000（使用把手時為 200,000；把手是以比例而非數量來調整）。滑鼠滾輪每格會乘以或除以 1.5，範圍在 0.02–200,000 之間。

相同的數值會顯示在檢視的右下角（僅透視）：以 m/s 或 km/s 為單位的速度，以及以該速度穿越資料（若載入了 3D 關卡，則為關卡）所需的時間。上下拖曳即可改變速度。

### 近與遠 {#near-and-far}

**近**（預設 0.5）與**遠**（預設 40,000）為裁切距離。兩者在每次載入時都會依資料重新計算（近 = max(0.05, 範圍 / 20,000)，遠 = 範圍 × 12），並且只會因較大的 3D 關卡而擴大，絕不會縮小（[關卡](levels.md#what-a-level-does-for-the-heat)）。兩者的比例決定了遮蔽所依賴的深度精度，因此過小的近值加上過大的遠值，會削弱[遮蔽](depth-and-culling.md)。從場景外部或其地面上方很高的位置觀看時，實際使用的近裁切面會移出到該距離的 2%，使從高空看的地圖仍保有足夠的深度精度，讓水面與岸邊不會閃爍；方框仍會顯示所設定的數值。

### 姿態 {#pose}

五個數字方塊——**X**、**Y**、**Z**，以及**偏航 °**、**俯仰 °**——在它們都沒有焦點時，會隨攝影機一起更新。輸入數值後按 `Enter`（或離開方塊），即可將攝影機移到該處。**複製**會把 `pos X Y Z · yaw A · pitch B` 放到剪貼簿（若選取該慣例，後面還會加上 `(game yaw)`）。飛行是用來探索的；座標則是用來重現某個視角的。它們與[攝影機讀數](#camera-readout)是相同的數字：即資料本身的座標（包括軸被反轉時），以及所選[慣例](#yaw-conventions)中的偏航角。

### 反轉世界軸 {#invert-world-axis}

**反轉世界軸 X / Y / Z** 會以反轉該軸的方式繪製世界。若某遊戲使用左手座標系的世界，在這個右手座標系的檢視器中就會呈現鏡像——右轉的彎道會畫成左轉的——此時反轉 X 或 Z 即可修正。**只改變繪製**：資料、分析以及工具所顯示的每一個座標（姿態、標尺、切片）都仍保持遊戲自己的數值。檢視會原地翻轉，讓你仍然看著同一個地點。此設定會記在瀏覽器中（`localStorage` 鍵 `heat3d.mirror`）；比較一下載入時的[翻轉](axes-units-and-time.md#flips)，後者會改變資料本身。

## 檢查檢視 {#inspecting-the-view}

攝影機在哪裡、指標下方是什麼內容，以及前往某一點——這些都在攝影機與場景面板的**檢查**區塊中，另外在檢視的左上角還有兩個覆蓋層。程式碼位於 [`pose.ts`](https://github.com/Holdi601/3DHeat/blob/main/src/render/pose.ts)、[`pick.ts`](https://github.com/Holdi601/3DHeat/blob/main/src/render/pick.ts) 與 [`inspector.ts`](https://github.com/Holdi601/3DHeat/blob/main/src/render/inspector.ts)。

| 控制項 | 預設 | 意義 |
|---|---|---|
| **在檢視上顯示攝影機位置** | 開 | 下方的攝影機讀數。也可以用其 **×** 關閉。 |
| **點按顯示該處內容** | 開 | 點按拾取，見下文。 |
| **偏航慣例** | 檢視器 | 讀數、姿態方塊與跳轉方塊顯示並讀取哪一種偏航角。 |

這三項都會記在瀏覽器中（`localStorage` 鍵 `heat3d.inspect`）。

### 攝影機讀數 {#camera-readout}

位於檢視的左上角：攝影機的 **x**、**y**、**z**、**偏航**與**俯仰**，即時更新，並附上標示偏航慣例的標籤。它顯示的數字與[姿態](#pose)方塊相同，飛行時不會增加任何負擔（它會在畫面時鐘上寫入頁面，而不會重新繪製面板）。

- **複製**（或在文字方塊以外的任何地方按 `C`）會把 `x X y Y z Z yaw A pitch B (viewer yaw)` 放到剪貼簿，無論語言為何，小數點一律使用 `.`——這是跳轉方塊以及任何腳本都能讀回的格式。
- **跳至**（或 `G`）會在其下方開啟一個方塊：貼上一個點並按 `Enter` 即可前往檢視它，或貼上一整組複製的姿態，即可站在該視角。按 `Esc` 關閉方塊。

### 座標：資料本身的座標系 {#coordinates-the-datas-own-frame}

所有檢查工具顯示或接受的座標，都位於**已載入資料本身的座標系**中：載入時的[軸對應](axes-units-and-time.md)（上方軸、翻轉、比例）已被還原。從檢視中讀到的位置，就是來源表格中的數字；把表格中的數字輸入跳轉方塊，就會落在該處。當對應不改變任何東西時（一個 Y 軸向上、未縮放的載入——這也是擷取工具與關卡匯出工具所寫入的格式），座標就只是世界座標；否則讀數會附上**資料座標系**標籤。沒有資料集時，座標即為世界座標。偏航與俯仰始終以檢視器的世界為準，Y 軸向上。

### 偏航慣例 {#yaw-conventions}

| 慣例 | 偏航 0° 的朝向 | 增加的方向 | 使用者 |
|---|---|---|---|
| **檢視器** | -Z | -X | 自由飛行攝影機、[預設視角](#preset-views) |
| **遊戲／擷取工具** | +X | -Z | 擷取工具的 `yaw` 欄位與姿態；在以檢視器座標系匯出的關卡中，則為遊戲自己的偏航角 |

俯仰在兩者中相同：自水平面向上。兩者只相差四分之一圈，此外沒有其他差異：

> 檢視器偏航 = 遊戲偏航 - 90°

在遊戲慣例中，方向 `d` 為 `(cos p · cos y, sin p, -cos p · sin y)`，在檢視器的慣例中為 `(-sin y · cos p, sin p, -cos y · cos p)`。若要直接輸入擷取表格中的偏航角，或將讀數與之比較，請選取**遊戲／擷取工具**。

### 跳至某一點 {#going-to-a-point}

**跳至某點**，位於檢查區塊中（以及讀數的**跳至**方塊）：

- 文字方塊接受 `x, y, z` 或 `x y z`（或 `x; y; z`），小數點可以是點或逗號——`-321.6, 137.8, -59.9` 與 `-321,6 137,8 -59,9` 是同一個點。五個數字會加上偏航與俯仰；從讀數或姿態方塊複製的姿態會被整體讀取，包括標籤與慣例；
- **偏航 °**與**俯仰 °**（可選）會依所選慣例轉動攝影機；
- **看向**會保持目前的朝向（若原本是水平看，則會向下傾斜至少 20°），並沿該朝向後退到目前的距離，且保持在場景寬度的 0.3% 到 3% 之間——在兩公里的關卡上為 6 到 60 m。對焦距離、平行視角的高度與飛行速度都會隨之調整，使視角到達時即可使用；
- **站在這裡**會把攝影機放在該點上，並轉到指定的偏航與俯仰，或保持原來的樣子。

貼上的姿態若帶有自己的偏航與俯仰，永遠會以該視角呈現。

### 點按拾取 {#click-to-pick}

在檢視上點按——按下後放開，拖曳不超過 4 像素；拖曳仍然是環顧——會在左上角顯示一張卡片，列出指標下方的內容。當[標尺](measure.md)開啟時，點按會改用於標尺。

**已繪製的資料點優先。** 在點按位置 8 像素內、實際已繪製的樣本中最近的一個：即時間視窗與生命期內的資料列、通過[篩選器](filters.md)的、所顯示的群組與差異分割、在距離裁切之內，且未被切片裁掉熱圖的。在箱形重播中，則為指標下方的方框（方框上任何位置）。卡片會以來源自己的欄位名稱列出該資料列所帶有的每個欄位——時間（牆上時鐘時間，或檔案自己的秒數，格式為 `m:ss.ss`）、人員、群組、工作階段、每個保留的欄位、位置與觀看方向——以及與攝影機的距離。記憶體中只保存載入時留下的欄位：未被選為[篩選欄位](column-mapping.md)的欄位不會顯示。

**否則為關卡的表面**：點按的射線與關卡真實三角面相交的點（不是標尺的參考平面），並附上它所屬的**部件**（匯出器的名稱，例如 `structure:props`、`ground:terrain …`）、其**類型**（地面、結構、水面、地圖影像）、座標與距離。被切片或距離裁切所隱藏的幾何會被略過。若關卡有[導航網格](model-levels.md#navigation-meshes)，會有一行說明它，並標示該點是否位於其上（✓）。部件名稱前綴為 `≈` 的，是根據部件的包圍框推測的，因為該部分的關卡在載入時已被簡化。

卡片會一直保留，直到你將其關閉（**×**、`Esc`）、另一次點按回答了其他問題，或點按空白處。場景中該點會畫上青色十字，螢幕上則在其上方畫一個圓環。其按鈕有：**複製**（每個數值，以及 `x, y, z` 格式的座標）、**看向**，以及**站在這裡**（對資料點而言，若該資料列帶有觀看方向，則以該資料列的方向觀看；對表面而言，則在其上方 1.7 m 處）。

關卡會在第一次需要拾取的點按時建立拾取索引：在其佔地範圍上建立一個柱狀格網，每次只在畫面更新之間花幾毫秒建立（對於數百萬個三角面的關卡，約需一秒的工作），在關卡改變之前都會保留。在此之前，卡片會顯示*正在為拾取準備關卡*與百分比，並在準備完成時回應點按。對超過四百萬個已繪製資料列的資料點搜尋，同樣會分散到多個畫面更新中完成。

## 景深 {#depth-of-field}

攝影機與場景中的一個可收合區段，啟用時標題為*景深——開*。預設為關閉：這是一種呈現效果，預設的視角應該呈現資料本身，而不是對資料的詮釋。

| 控制項 | 預設 | 範圍（旋鈕） | 意義 |
|---|---|---|---|
| **啟用** | 關 | | |
| **對焦於對準的目標** | 開 | | 以上次框住時所用的距離對焦（*對焦於 N m。*）。 |
| **對焦距離** | 1000 | 1–200,000，對數刻度（10,000,000） | 當對焦為手動時顯示。 |
| **光圈** | ±35% | ±2% 到 ±200%，對數刻度（±3200%） | 保持清晰的景深，以對焦距離的比例表示——採相對值而非 f 值，因為場景從一個房間到八公里的地圖都有可能。 |
| **最大模糊** | 12 px | 1–48（256） | 最大模糊半徑；成本隨之增加。 |

景深會模糊**關卡、格線與方框**——*不會模糊熱圖*。某個像素上的熱量，是許多深度上精靈的總和，因此它沒有單一的深度可以失焦；若依其後方的幾何來模糊它，那麼它漂浮在前方的任何地方都會出錯。清晰的資料搭配柔化的背景，對使用者來說也更有用。模糊是在合成階段以 24 點黃金角度收集完成的，並加上權重，使清晰的前景不會被其後方模糊的背景向外抹開。調整它時會重新繪製，而不會重新開始熱量的累積。

## 畫布解析度 {#canvas-resolution}

畫布會以顯示器的像素比例繪製，上限為 2。熱量緩衝區可能會以比這更低的解析度繪製（[熱量解析度](performance-and-stats.md)）。
