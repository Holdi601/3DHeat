# 圖表與 HUD

圖表會把你的圈逐公尺對齊，讓你看出某位車手在哪裡煞車較晚、在哪裡收油門較早。畫面左上角的卡片，會顯示每輛車與每位車手目前正在做什麼。

![畫面下方的圖表：兩圈的時間差、速度、油門、煞車與方向盤各列，上方的時間與原因條，以及附有卡片的游標](../assets/img/en/race-charts-rows.webp)

## 圖表 {#the-charts}

每一圈都排在同一條距離軸上，單位為沿參考路徑的公尺（參閱[單一距離軸](race-corner-analysis.md#one-distance-axis)），因此每一圈的同一個 x 座標，都代表賽道上的同一個地點。一圈會單獨成圖（並可播放）；同一條賽道的第二圈，則會與它一同成圖比較。若沒有載入任何圈（或分析失敗），此區會顯示：「載入一圈後才會出現圖表；再載入同一條賽道的另一圈即可比較兩者。」

### 圖表上有什麼 {#what-is-on-them}

- **圖例**：每個已成圖的圈的顏色與標籤，參考圈會標註「（參考）」；當可見的圈數多於已成圖的圈數時，會顯示「+N 更多已繪製，未建圖表」；另有 **圖表（N）▾**、縮放時的 **整圈**，以及一行提示。
- **上方的兩條狀帶**，針對聚焦的圈：
  - *時間*：[時間地圖](race-replay-and-scene.md#time-map-where)呈現為一條狀帶，落後時為紅色，領先時為綠色；
  - *原因*：它的每一次損失，以原因的顏色顯示為一根條，位於其原因所在的位置上；將游標移到條上，可看到其標題與代價。
- **彎道色帶**：從每個彎道的入口到出口的淺色帶（依參考圈所見），以及軸線下方頂點處的彎道名稱（`T1` 等）。
- **所選發現**：以其原因的顏色，在其範圍上顯示的一條色帶。
- **各列（圖表）**：每個所選的通道一列，左側為其名稱，以及其範圍的上限與下限；範圍跨越零時，會有一條零線。每一圈都是以其顏色繪製的一條線：聚焦的圈為 2 像素寬且不透明，參考圈不透明，其他的圈則為 1.5 像素寬、75% 不透明。時間差那一列不含參考圈（它與自己的差為零）。
- **游標**：參考車所在位置（或指標所在位置）的一條垂直線，並在每一列（時間差除外）上為每輛車畫一個點——在游標處，每輛車都位於同一公尺；否則每輛車的點，會依重播時鐘顯示其各自的距離。

最多會有 **8** 圈成圖：聚焦的圈、其等級中最佳的圈與參考圈優先，其餘則依載入順序排列。

### 各列與其高度 {#rows-and-their-heights}

各列依權重分配圖表的高度，且沒有任何一列低於 16 像素：

| 列 | 權重 |
|---|---|
| 時間差（相對於參考圈，秒，帶正負號） | 1.7 |
| 速度（km/h） | 1.7 |
| 踏板之一（油門、煞車、離合器） | 1 |
| 方向盤 | 1.1 |
| 檔位 | 0.8 |
| 指示燈之一（手煞車、ABS 等） | 0.55 |
| 其他 | 1 |

表格中有固定顯示範圍的通道（踏板為 0 至 100%）會使用該範圍；其他通道則會配合各圈可見的區段調整。若列名對所占空間而言太長（例如另一種語言中的長字），而該列夠高時，上方的數值會下移一行；列太矮時則以省略號截斷，完整名稱顯示於工具提示中。

### 預設圖表 {#the-default-graphs}

在你選擇圖表之前：先是**時間差**，然後是表格中標記為 `graph`、且各圈都具備的每個通道——油門、煞車、離合器、手煞車、方向盤、檔位、速度——但踏板或指示燈通道，除非某一圈的值超過 0.02，否則會被略過（從未踩下的離合器不會成為圖表）。順序依表格排列。

### 圖表選擇器 {#the-graph-picker}

**圖表（N）▾** 會在按鈕上方開啟一個面板：

- 一個篩選框（符合通道的名稱或 ID）；
- **預設**（恢復預設組合；其工具提示會說明有幾項）與 **關閉**；
- *與參考圈的時間差*，接著是成圖的各圈所帶有的每個通道，依群組分類（運動、操作輸入、引擎、輔助、輪胎、煞車、懸吊、車輪、其他、計時、位置），每項附一個核取方塊；逐輪的通道則為一行，並為每個車輪附一個標籤（FL、FR、RL、RR）。

勾選的順序不影響表格的排列順序。你的選擇會保留，直到按下**預設**或重新載入為止。表格不認識的通道會列在*其他*之下，並依其自身的 ID 命名（例如 "brakeLinePress" → "Brake line press"）。

### 指標、滾輪、縮放與點擊 {#hover-wheel-zoom-click}

| 操作 | 作用 |
|---|---|
| 指向 | 每輛車、其卡片與其操作輸入都會移到該公尺；軌道上會以標記點標出；表格會列出該處每個已成圖的圈在每一列上的數值（參考圈的時間差顯示為「ref」）；在卡片上方顯示「在 N 公尺 - 圖表的游標」。移出繪圖區時，會交還給重播 |
| 滾輪 | 每格沿圈前進或後退可見範圍的 1/200（Shift：5 倍），並暫停重播；縮放時，視圖會跟隨游標 |
| Ctrl+滾輪（Cmd+滾輪） | 以指標為中心縮放距離軸，每格縮小 1.25 倍／放大 0.8 倍，最窄不小於 40 公尺；縮放到整圈即結束縮放 |
| 橫向滾輪 | 縮放時左右平移（每 100 單位的捲動量平移可見範圍的 10%） |
| 雙擊、**整圈** | 縮小顯示 |
| 點擊 | 將重播跳到參考車抵達該公尺的位置 |
| Shift+點擊 | 在該處將各車對齊（參閱[對齊](race-replay-and-scene.md#lining-up)） |

語言變更時，圖表會以目前語言重新繪製。

圖例中的提示列以簡短的文字說明同樣的內容：「指向：該處每輛車 · 滾輪：沿圈移動 · Ctrl+滾輪：縮放 · 點擊：跳轉 · Shift+點擊：對齊」。

## 車輛卡片（HUD） {#the-car-cards-hud}

位於畫面左上角，每個可見的圈各一張卡片——最多 **6** 張，即依載入順序排列的前六個可見的圈——顯示重播（或圖表游標）目前所在位置的資料。

**標題：** 該圈的顏色與標籤；即時時間差——該圈抵達目前距離所需的時間，減去參考圈抵達同一距離的時間，例如「+0.48 秒」——或「參考」；**⋯** 可顯示或隱藏其他所有數值（與*卡片上的所有數值*相同）。被追趕的那輛車，其卡片會醒目標示。

**從上方看車：** 以該圈的顏色繪製的車身輪廓，前端有一個箭頭；四個輪胎（前輪會隨方向盤轉動至多 28°），並依其溫度上色，符號與 3D 車輛的平面版本相同：滑移環、懸吊桿、煞車發光、磨損帶與負載條。

**讀數：** 速度（km/h）、該圈自己的時間，以及其沿參考路徑的距離。

**操作輸入：**

- 依方向盤輸入轉動的方向盤（滿舵以 180° 繪製），下方附上百分比；
- 每個踏板一條，由左至右依踏板盒的排列：離合器、煞車、油門——各附其百分比與簡稱，並以其顏色顯示（只顯示該圈帶有的踏板）；
- 檔位（R 為倒車，N 為空檔）；
- 該圈帶有的每個開／關通道一個小指示燈——手煞車、ABS、TC、DRS、維修道限速器、騰空——開啟時以其顏色亮起（高於其範圍的一半時）；
- 每個等級通道一個讀數：煞車分配、ABS 與 TC 設定、增壓、燃油。

**操作軌跡：** 每個踏板（一條通道，各以其顏色顯示）與方向盤（其自己的通道，置中）在最近 **6 秒** 的軌跡，結束於此時此刻——也就是駕駛在進入這一刻之前做了什麼。最多 160 個點。

**所有數值**（⋯ 或*卡片上的所有數值*）：該圈此刻帶有的每個其他純量數值，接著是每個逐輪通道的四個數值（FL FR RL RR），依通道表或通道自身的名稱命名，並依群組排序。

### 通道表 {#the-channel-table}

[`src/race/schema.ts`](https://github.com/Holdi601/3DHeat/blob/main/src/race/schema.ts) 中的 `CHANNELS` 是描述通道的唯一位置：它的單位、它是每個樣本一個值，還是每個車輪一個值（儲存為 `name.FL` 等）、它的群組、顯示範圍、它在車上如何繪製（`glyph`）、它在卡片上如何呈現（`input`：`pedal`、`steering`、`gear`、`lamp`、`level`）、它是否為預設圖表、它是逐步跳變而非平滑混合（檔位、旗標），以及它如何顯示（比例、單位、位數）。標籤與簡稱是各語言中的訊息（`race.channel.<name>.label` / `.short`）。

有繪製方式或預設圖表的通道：

| 通道 | 單位 | 繪製方式 | 預設圖表 |
|---|---|---|---|
| `throttle`、`brake`、`clutch` | 0..1 | 踏板（綠、紅等），以 % 顯示 | 是 |
| `handbrake` | 0..1 | 指示燈 | 是 |
| `steer` | -1..1，向右為正 | 方向盤 | 是 |
| `gear` | - | 檔位 | 是 |
| `speed` | m/s，以 km/h 顯示 | - | 是 |
| `absActive`、`tcActive`、`drs`、`pitLimiter`、`airborne` | 0..1 | 指示燈 | - |
| `brakeBias`、`absLevel`、`tcLevel`、`boost`、`fuel` | - | 等級讀數 | - |
| `tireTemp`（逐輪） | °C，顯示 40-130 | 輪胎顏色 | - |
| `tireTempInner/Middle/Outer` | °C | - | - |
| `slipRatio`、`slipAngle`（逐輪） | 依遊戲的縮放，顯示 ±1.5 | 滑移環 | - |
| `combinedSlip`、`slipIndex`（逐輪） | 顯示 0-1.5、0-1 | 滑移環 | - |
| `suspension`（逐輪） | 0..1 | 懸吊桿 | - |
| `brakeTemp`（逐輪） | °C，顯示 100-900 | 煞車發光 | - |
| `tireWear`（逐輪） | 0..1 | 磨損帶 | - |
| `wheelLoad`（逐輪） | N，顯示 0-12 000 | 負載條 | - |

表中其他的通道（繪成圖表並列出，但不作繪製）：`latAcc`、`longAcc`、`vertAcc`、`yaw`、`pitch`、`roll`、`yawRate`、`latVel`、`longVel`、`vertVel`、`bodySlip`（漂移角）、`loose`、`lateral`（與參考圈的偏移）、`rpm`、`power`、`torque`、`waterTemp`、`oilTemp`、`tirePressure`、`camber`、`padLife`、`discLife`、`suspensionM`、`wheelSpeed`、`wheelSurfaceSpeed`，另加 `time`、`distance`、`x`、`y`、`z`。

**不在表中的通道** 仍會被讀取、繪成圖表（歸在*其他*之下）並列在卡片上，名稱取自其自身的 ID。**若要為它提供正式的名稱、單位與繪製方式**，請在表中新增一項（並在每個 `src/i18n/locales/<language>/race-channels.json` 中加入其標籤訊息）。新的*車輪繪製種類*只需在 `WHEEL_GLYPHS`（glyph.ts）中新增一項，並在其平面版本 `CARD_GLYPHS`（RaceHud.tsx）中新增一項；兩者都依種類加上型別，因此兩者缺一，建置就會失敗。`src/race/extensible.test.ts` 會檢查未知通道是否會進入圖表、表中的每個符號是否都能繪製，以及指示燈是否會亮起。
