# 命中分析

**載具**頁籤顯示一輛戰車、船艦或士兵在何處被命中，以及是誰命中的。用它來查看戰車哪一側會被擊中，或哪個敵人造成最多傷害。

## 試試看 {#try-it}

1. 載入一場有命中紀錄的對戰（哪些遊戲會提供命中紀錄，請見下表）。
2. 打開畫面頂端的**載具**頁籤。
3. 在**載具**下選擇一個單位，例如某種戰車。括號中的數字是它被命中的次數。
4. 閱讀圖形：每個標記代表一次命中，放置在它被擊中的位置。
5. 打開**誰命中的**，即可查看射手、武器或射手載具，以及命中次數、傷害、擊殺與距離。

![載具頁籤：一輛帶有命中標記的示範戰車，並展開了誰命中的](../assets/img/en/hit-analysis-tank.webp)

如果沒有載入任何資料，或資料中沒有載具的命中紀錄，此頁籤會說明缺少什麼，以及該使用哪一個轉換器。

```
        shooter ----> o  hit mark on the figure
        shooter ----> o
  [ tank figure ]
```

當資料提供了點或身體部位時，圖形會顯示命中的位置。明細（誰命中的、以什麼武器、傷害多大、從多遠的距離）則適用於每一種來源。

## 限制在某個區域 {#restrict-to-an-area}

**區域**區段會把分析限制在地圖上某個地點所發生的命中。

1. 按下**畫矩形**或**畫多邊形**，然後在 3D 地面或戰術地圖上繪製。
2. 選擇**受害者在內**（當被命中的單位位於區域內時計為一次命中）或**射手在內**（當開火的一方位於區域內時）。
3. 按下**用作篩選**。標籤會顯示「{n} / {total} 次命中在區域內」。
4. **重設區域**會移除所有區域。

每個區域都是一個[體積](volumes.md)，因此同樣的形狀也會篩選熱度圖與重播。區域可以是包含或排除（排除區域會把其中的命中排除在外，並顯示「{n} / {total} 次命中在區域外」）。每個區域都會以一個標籤顯示，標籤上標示該單位有多少次命中位於其中；標籤上的 × 會將它移除。計數、圖形、明細與篩選清單都會隨之更新。

命中的位置：產生該命中的資料列保存了一方的位置（受傷或被擊中時為受害者，開火時為射手）；另一方的位置則是該單位在時間上最接近的自身取樣（5 秒之內）。在區域篩選中，若某一方的位置未知，則該命中會被排除，面板會說明有多少被排除（「已排除，位置未知」）。

## 給開發者 {#for-developers}

任何轉換器都可以新增命中：受害者的資料列（`hit`、`impact`、`hurt`、`wounded`），並帶有 `hitBone`（骨架骨骼、Arma 的選取部位、Reforger 的命中區域，會對應到頭部、胸部、腹部、手臂與腿部），或 `hitLocalX/Y/Z`（公尺，x 為前、y 為上、z 為右），再加上 `other`（射手）與 `damage`。
