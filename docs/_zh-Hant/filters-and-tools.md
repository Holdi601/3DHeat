# 篩選與工具

這些面板讓你選擇要查看*哪些*資料，並量測你所看到的東西。當畫面太雜亂時就使用它們：只顯示一支隊伍、一位玩家、一個地點，或建築物的某一層。

每個面板都會縮小資料範圍，而且它們可以一起運作：一列只有在通過**所有**面板（AND）時才會被繪製。

```
all rows -> Filters -> Teams -> Entities -> Slice -> picture
              AND       AND       AND        AND
```

例如：在篩選中取消勾選*Tank*，在隊伍中隱藏紅隊，並在實體中選取一位玩家。你就只會看到那位玩家非坦克的移動。

| 面板 | 功能 | 熱度模式 | 模型疊加 |
|---|---|---|---|
| [篩選](filters.md) | 對載入時保留的任何欄位進行範圍與類別篩選。 | 是 | 否（僅欄位篩選） |
| [差異分割](difference.md#the-difference-split-panel) | 在差異模式中，決定哪些列相加、哪些相減。 | 僅差異 | 否 |
| [隊伍](teams-list.md) | 顯示或隱藏各隊伍；把隊伍放到 + 或 − 方。 | 是 | 是 |
| [實體](entities.md) | 選取個別玩家。 | 是 | 是 |
| [切片](slice.md) | 從關卡與熱度中切出一段，以查看建築物內部。 | 是，以及關卡 | 否 |
| [指標](measure.md) | 尺規，以及游標下的熱度值。 | 是 | 是 |
| [體積與比較](volumes.md) | 繪製 3D 形狀並查詢其中發生的事情。也可以篩選。 | 是 | 是 |
| [明細](breakdown.md) | 在某個地點，哪一種載具、玩家或武器表現最好。 | 不適用 | 不適用 |

命中分析在**載具**頁籤中有自己的區域篩選：請參閱[命中分析](hit-analysis.md)。

熱圖、列、人員與群組等詞彙，會在[詞彙表](glossary.md)中說明。

## 面板的位置 {#where-the-panels-are}

熱圖頁籤的側邊欄，由上至下：

1. 模式列與場次選擇器
2. 來源、欄位對應、資料集
3. 路線（線條模式）
4. 熱度面板，或隊伍檢視器
5. 差異分割
6. 隊伍
7. 實體
8. 篩選
9. 背景 / 關卡
10. 切片
11. 指標
12. 攝影機路徑與渲染
13. 效能
14. 攝影機與場景

對戰頁籤會顯示模式列、場次選擇器、其自己的面板、篩選、背景 / 關卡，以及攝影機與場景。
