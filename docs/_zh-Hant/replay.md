# 重播

重播會以 3D 播放一場比賽，每個單位都以其所代表的載具或人物呈現。用它來觀看發生了什麼、比較許多場比賽，或查看誰擊中了誰。

- [比賽重播](match-replay.md)：播放一場比賽，包含模型、曳光、命中，以及 Tacview 風格的攝影機。
- [一次疊加多場比賽](many-matches.md)：把數百場比賽疊放在一起。
- [模型](figures.md)：用於單位的外形，以及它們的來源。
- [命中分析](hit-analysis.md)：某輛載具或某位士兵在哪裡被擊中，以及由誰擊中。
