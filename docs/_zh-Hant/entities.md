# 實體

**實體**讓你挑選一位（或幾位）玩家，只看那位玩家去過哪裡。用它來追蹤你自己的移動，或某位對手。

當資料集有人員欄位時會顯示此面板。它的標題會顯示人員數；當有選取時，會顯示 `已選取 / 總數`（*人員* 是一位玩家或 AI，見[詞彙表](glossary.md)）。

## 挑選玩家 {#pick-a-player}

1. 在側邊欄打開 **實體**。
2. 在搜尋框中輸入名稱的一部分。
3. 勾選該玩家。標題會顯示例如 `2 / 10`，其他的都會消失。
4. **清除** 會再次顯示所有人。

![實體：十位玩家中已選取兩位](../assets/img/en/entities-selected.webp)

在熱度模式（點、線、差異、隊伍熱度）中，以及[圖示重播](box-replay.md)的軌跡、圖示與尾跡中，選取都只會顯示被選取的人員。保持空白即顯示所有人；選取全部與不選取任何人的效果相同。

## 面板 {#the-panel}

| 部分 | 意義 |
|---|---|
| 搜尋框 | *搜尋 N 個實體……*——依名稱中不分大小寫的子字串過濾清單。顯示 `N 個符合`，或 `N 個符合，顯示前 200 個`；搜尋沒有結果時顯示 *沒有符合「……」的項目*。 |
| 清單 | 最多 200 位人員（前 200 個符合者），每一位都有核取方塊、該人員顏色的色塊，以及名稱（名稱為空時顯示 *（未命名）*）。 |
| 進行中提示 | 時間播放時，清單只包含那些*在播放頭處進行中*的人員；搜尋則會找出全部。 |
| **AI（n）** | 可收合的群組，裡面是 AI 控制的單位，與玩家分開。 |
| **加入列出項目** | 把目前列出的所有人加入選取。 |
| **只選列出項目** | 把選取設為正好是列出的這些人。 |
| **清除** | 清空選取。 |

## 限制 {#limits}

在熱度中，選取是一個過濾器，會佔用四個[過濾器欄位](filters.md#rules)之一。當其他過濾器已經用完全部四個欄位時，面板會顯示 *未套用到熱度：所有過濾器欄位都已佔用。圖示重播仍然只會顯示這些實體。請在過濾器下清除一個過濾器以釋出欄位。* 清除一個過濾器即可釋出欄位。

每次有新的資料集時，選取都會被清除。對戰分頁在聚焦某一位玩家時，也會設定同樣的選取。

## 給開發者 {#for-developers}

選取會被保存為 *persons* 過濾器（[過濾器](filters.md#for-developers)）。著色器的遮罩可容納 65,536 個人員 id；當選取有效時，超出此範圍的人員不會在熱度中被繪製。
