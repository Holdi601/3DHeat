# Tacview 對等功能

Tacview 是很受歡迎的飛行紀錄檢視程式。如果你用過它，本頁會告訴你它的每項工具在 3DHeat 中的位置。

本頁列出 Tacview 1.9 的每一項功能（依據其手冊、使用者介面字串表以及 ACMI 2.2 檔案格式），並說明 3DHeat 的[對戰重播](match-replay.md)在這些方面的進度。目標是：Tacview 能為重播及其資料做到的事，3DHeat 也能做到。

**狀態：**
- **已完成**：3DHeat 已經有。
- **新增**：為了對應某項 Tacview 功能而建置。
- **尚未**：適用，但尚未建置。
- **不適用**：此處不適用，並附上原因。

功能位置：**對戰**分頁、**模型重播**（或熱圖分頁中的**模型疊加**），以及側邊欄的各區段：**重播**、**單位**、**事件**、**書籤**、**戰術顯示**、**統計**、**時間平移與修剪**、**地圖與位置**、**音訊和影片**與**標籤**。見[對戰重播](match-replay.md)。

## 給開發者：ACMI 2.2 屬性 {#for-developers-acmi-22-properties}

由 `data/acmi.ts` 讀取；數值屬性成為數值欄位，文字屬性成為類別欄位。它們全部都會顯示在單位卡的**原始**下。以下這些屬性各有用途：

| 屬性 | 用途 |
|---|---|
| T（四種形式皆是）、Name、Type、Pilot、Group、Country、Coalition、Color、CallSign | 位置、姿態、模型、單位名稱、隊伍 |
| IAS、CAS、TAS、Mach、AOA、AOS、AGL、HDG、HDM、OnGround | 欄位、圖表、HUD，以及起飛與降落偵測 |
| VerticalGForce、LongitudinalGForce、LateralGForce | G 欄位 |
| Throttle(2)、Afterburner、EngineRPM(2)、NR、AirBrakes、Flaps、LandingGear、Tailhook | 欄位 |
| FuelWeight..9、FuelVolume..9、FuelFlowWeight..8 | 燃油欄位，依油箱加總 |
| RadarMode、RadarAzimuth、RadarElevation、RadarRoll、RadarRange、RadarHorizontalBeamwidth、RadarVerticalBeamwidth、RadarRangeGateAzimuth/Elevation/Min/Max/HorizontalBeamwidth/VerticalBeamwidth | 雷達錐與距離閘 |
| LockedTarget..9、LockedTargetMode、LockedTargetAzimuth/Elevation/Range、FocusedTarget | 鎖定線 |
| EngagementMode(2)、EngagementRange(2)、VerticalEngagementRange(2) | 交戰圓頂 |
| QNH、AltimeterSetting、WindSpeed、WindDirection、HeartRate | 欄位 |
| Health | 欄位 |
| 事件：Destroyed、TakenOff、Landed、Bookmark、Message、Comment、LeftArea、Timeout | 事件列表、統計（死亡、起飛、降落）、書籤；Message 與 Comment 作為字幕 |
| PilotHeadYaw、PilotHeadPitch | 飛行員視線 |
| 類型標籤 Bullseye（Navaid+Static+Bullseye） | Bullseye 欄位與地圖上的環 |
| 其他所有（PilotHeadRoll、操控、表面、ILS 偏差、SpO2、ENL、Label、Debug、Importance、Slot、Visible、Disabled、Radius、尺寸……） | 依原樣顯示在**原始**下 |

雷達與鎖定的角度是相對於單位自己的軸線量測的：方位角向右、仰角向上、滾轉為右翼向下。ACMI 規格說明它們是相對於飛機的，但沒有說明哪個方向為正；此處的解讀遵循其轉換方式（偏航順時針、俯仰向上、滾轉右翼向下）。
