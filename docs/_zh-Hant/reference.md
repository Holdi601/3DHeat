# 參考

用來查詢的精確名稱、設定與工具清單。使用檢視器時不必閱讀它們。

這些清單是由 `node tools/docs-refs.mjs` 從檢視器的程式碼產生的（你不需要執行它），因此它們總是與製作時的版本相符：

- [事件類型與等級](ref-event-types.md)——每個資料集都會歸入的事件種類與車輛等級，以及資料中哪些詞會對應到它們
- [欄位名稱](ref-columns.md)——載入器能辨識的欄位名稱，用於位置、時間、人物、隊伍、場次與視線方向
- [語言清單](ref-languages.md)——檢視器支援的語言
- [瀏覽器按鍵](ref-browser-keys.md)——檢視器為自己保留的瀏覽器快捷鍵
- [已儲存的設定](ref-settings-storage.md)——瀏覽器在多次造訪之間記住的內容
- [數值表](ref-value-tables.md)——數值加權的價格表
- [命令列工具](ref-tools.md)——`tools/` 中的工具：供你的資料使用，也供開發者與文件使用

此外也屬於參考的，還有[詞彙表](glossary.md)，用於說明本網站所用的詞彙。以下為手寫的內容：[資料格式](data-formats.md)、[鍵盤與滑鼠參考](keyboard-reference.md)、[每場比賽一個檔案 (.3dheat)](container.md)。
