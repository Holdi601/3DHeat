# Referenz

Listen mat genauen Nimm, Astellungen a Werkzeuger, fir Saachen nozeschloen. Dir musst se net liesen, fir den Viewer ze benotzen.

Dës Lëschte ginn aus dem Code vum Viewer mat `node tools/docs-refs.mjs` generéiert (Dir musst et net lafen loossen), sou datt se ëmmer zu der Versioun passen, mat där se gemaach goufen:

- [Evenementtypen a -klassen](ref-event-types.md) - d'Evenementaarten an d'Fuerzeegklassen, an deenen all Datesaz ageuerdnet gëtt, a wéi d'Wierder an den Donnéeë dorobber passen
- [Kolonnennimm](ref-columns.md) - d'Kolonnennimm, déi de Lueder fir Positioun, Zäit, Persoun, Equipe, Sessioun a Blécksrichtung erkennt
- [Sprooch-Lëscht](ref-languages.md) - d'Sprooche vum Viewer
- [Browser-Tasten](ref-browser-keys.md) - d'Browser-Kuerzbefehle, déi de Viewer fir sech behält
- [Gespäichert Astellungen](ref-settings-storage.md) - wat de Browser sech tëscht de Besicher mierkt
- [Wäerttabellen](ref-value-tables.md) - d'Präistabellen vun der Wäertgewiichtung
- [Kommandozeil-Werkzeich](ref-tools.md) - d'Werkzeich an `tools/`: fir Är Donnéeën, a fir d'Entwéckler an d'Dokumentatioun

Och Referenz, an de [Glossar](glossary.md) fir d'Wierder, déi op dëser Säit benotzt ginn. Vun Hand geschriwwen: [Datenformater](data-formats.md), [Tastatur- an Maus-Referenz](keyboard-reference.md), [Eng Datei pro Match (.3dheat)](container.md).
