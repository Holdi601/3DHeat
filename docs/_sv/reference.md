# Referens

Listor med exakta namn, inställningar och verktyg, att slå upp saker i. Du behöver inte läsa dem för att använda betraktaren.

Listorna genereras från betraktarens kod med `node tools/docs-refs.mjs` (du behöver inte köra den), så de alltid stämmer med den version de gjordes för:

- [Händelsetyper och klasser](ref-event-types.md) – händelsesorterna och fordonsklasserna som varje datamängd sorteras in i, och vilka ord i datan som hör till dem
- [Kolumnnamn](ref-columns.md) – kolumnnamnen som laddaren känner igen för position, tid, person, lag, session och blickriktning
- [Språklista](ref-languages.md) – betraktarens språk
- [Webbläsarens tangenter](ref-browser-keys.md) – webbläsargenvägar som betraktaren behåller för sig själv
- [Sparade inställningar](ref-settings-storage.md) – det webbläsaren minns mellan besöken
- [Värdetabeller](ref-value-tables.md) – prislistorna för värdeviktning
- [Kommandoradsverktyg](ref-tools.md) – verktygen i `tools/`: för dina data, och för utvecklare och dokumentationen

Också referens, och [ordlistan](glossary.md) för orden som används på webbplatsen. Skrivet för hand: [Dataformat](data-formats.md), [Tangentbords- och musreferens](keyboard-reference.md), [En fil per match (.3dheat)](container.md).
